# スプレンダー

宝石を集めてカードを買い、15点を目指すボードゲーム「スプレンダー」（基本セット）を、ブラウザで CPU と遊べるようにしたもの。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

絵（宝石・カード・貴族・アイコン）は、すべて SVG で自作している。

## 遊び方

- 人数は2〜4人（あなた＋CPU 1〜3人）
- 手番には、次のどれか1つを行う
  - 違う色の宝石を3個取る
  - 同じ色の宝石を2個取る（その色が4個以上残っているときだけ）
  - カードを予約して黄金を1個取る（場のカードか、山札の一番上を伏せたまま。予約は3枚まで）
  - 場か予約したカードを買う（ボーナスの分だけ安くなる。黄金はどの色の代わりにもなる）
- 手番の終わりに、宝石が10個を超えていたら、超えた分を選んで返す
- 手番の終わりに、ボーナスが条件を満たすと貴族が訪れる（3点。1手番に1人まで。複数なら選ぶ）
- だれかが15点に達したら、その巡の終わりまで続け、点数の多い人が勝ち。同点なら、買ったカードの少ない人が勝ち

人数による違い：

| 人数 | 宝石（各色） | 黄金 | 貴族 |
|---|---|---|---|
| 2人 | 4個 | 5個 | 3枚 |
| 3人 | 5個 | 5個 | 4枚 |
| 4人 | 7個 | 5個 | 5枚 |

### ルールブックに書かれていないので決めたこと

- 場に残っている宝石の色が3色に満たないときは、残っている色を1個ずつ取ってよい
- どの操作もできないときだけ、パスできる（画面では自動でパスする）。全員が続けてパスしたら、その時点で終わる
- 同点で、買ったカードの数も同じなら、その全員を勝ちとする
- 最初の手番の人は、ランダムに決める

### 画面の操作

- 宝石：右の列から選んで「取る」。同じ色をもう一度押すと2個になる
- カード・山札：タップして「買う」「予約」。金色に光っているカードは、今買えるカード
- 支払いは、色の宝石を先に使い、足りない分を黄金で払う
- 相手の行をタップすると、予約しているカードが見られる（伏せて予約したカードは裏のまま）
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

自分から見える情報だけ（山札の並びや、相手が伏せて予約したカードは見ない）で、「ねらうカードを決めて宝石を集め、買えるようになったら買う」方針で打つ。強すぎないように、場のカードの見落とし・評価の揺れ・買えるのに見送る、といった誤りを混ぜている。

CPU 同士の対戦で、勝率と試合の長さを測れる。

```bash
# 試合数・人数・席ごとの強さ（normal は画面の CPU、strong は見落としのない比較用）
node scripts/cpu-match.mjs 400 2 normal,strong
```

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm install
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/cards.js` | カード90枚と貴族10枚のデータ |
| `public/js/game.js` | ルール。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`art.js`・`animator.js` | 画面・絵・動き |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |

### オンライン対戦を入れるとき

ルールとビューは、netplay-kit の「ゲームの定義」の形（`server/src/game-definition.js`）で用意してある。netplay-kit の `sync.mjs` で部屋の処理を写し、この定義を `createHandler` と `startDevServer` に渡す。画面は、ローカル対戦と同じ `getView()` / `send()` の形のオンライン用のコントローラーを足す。
