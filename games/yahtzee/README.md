# ヤッツィー

5個のサイコロで役を作り、得点表の13の欄を埋めて点数を競うダイスゲーム「ヤッツィー（Yahtzee）」を、ブラウザで遊べるようにしたもの。ひとりでハイスコアを目指すほか、CPU（1〜3人）と対戦できる。スマホの縦持ち向け（PC でも遊べる。横にした低い画面では、得点表とサイコロを左右に並べる）。ホーム画面に置くと、オフラインでも遊べる。

絵（サイコロ・アイコン）は、すべて SVG で自作している。

## 遊び方

Hasbro の Yahtzee の公式ルールに合わせた。

- サイコロは5個。全員が13回ずつ手番を行う
- 手番では、サイコロを3回まで振れる。2回目と3回目は、残したいサイコロを選んで、ほかを振り直す
- 振り終えたら（途中でもよい）、得点表の空いている欄を1つ選んで記入する。条件に合わない欄に書くと0点
- 上段（1〜6の目）：その目の合計。上段の合計が63点以上なら、ボーナス35点
- 下段

| 欄 | 条件 | 点数 |
|---|---|---|
| スリーカード | 同じ目が3個以上 | 5個の合計 |
| フォーカード | 同じ目が4個以上 | 5個の合計 |
| フルハウス | 3個と2個の組 | 25点 |
| S・ストレート | 4つ続いた目 | 30点 |
| L・ストレート | 5つ続いた目 | 40点 |
| ヤッツィー | 5個とも同じ目 | 50点 |
| チャンス | なんでも | 5個の合計 |

- ヤッツィーボーナス：ヤッツィーの欄に50点を書いたあと、またヤッツィーを出したら、記入のたびに100点
- ジョーカー：ヤッツィーの欄が埋まっている（50点でも0点でも）ときにヤッツィーを出したら
  - その目の上段が空いていれば、そこに書く
  - 上段が埋まっていれば、下段の空いている欄に書く。フルハウス・ストレートも満点になる
  - 下段も埋まっていれば、空いている上段に0点で書く
- 合計点が一番高い人の勝ち。同点なら、その全員で勝ちを分け合う

### ルールブックに書かれていないので決めたこと

- 手番は席の順（あなたから）。全員が同じ13回なので、順番による差はない
- 5個とも同じ目でも、ジョーカーでなければフルハウスにはならない（公式ルールのとおり、ジョーカーのときだけ満点）

### 画面

- 得点表は、全員の列を並べる。手番の人の列を明るくする
- 振ったあとは、記入できる欄に、書いたら何点になるか（先読み）を薄く出す。ジョーカーのときは、書ける欄にだけ出す
- 欄はタップで選び、もう一度タップするか「記入」のボタンで決める（細い行の押し間違いを防ぐため）
- サイコロはタップで「残す」を切り替える。残すサイコロは琥珀色の縁と「残す」の札で示す。振ると、残さないサイコロだけが転がる
- CPU の手番も、残したサイコロと転がるサイコロが見える。記入した欄は光らせる
- ヤッツィー・ヤッツィーボーナス・上段ボーナスを取ったら、見出しを出す
- 途中でホームに戻っても、「続きから」で再開できる
- ハイスコアは上位10回分を、日付・相手の人数・CPU の強さと一緒に残す（遊んだ回数と平均も出す）。人数に関係なく、あなたの点数を記録する

## CPU

| 強さ | 中身 |
|---|---|
| やさしい | 期待値を計算しない。一番多い目（4つ続いた目が見えたらストレート）を残し、点数が一番高い欄に書く。揺れが大きい |
| ふつう | つよいと同じ計算で選ぶが、欄の値に揺れを混ぜ、上段ボーナスの見込みを軽く見る |
| つよい | 振り直しを期待値で選ぶ（下記）。揺れなし |

ふつうとつよいは、出目の組（順番を問わない5個、252通り）と残し方の組（462通り）の表を使い、残りの振り直しの回数ぶん、各残し方の期待値を正確に計算する。振り終えたときの値は、記入できる欄のうち一番よい欄の値で、欄の値は「点数 − その欄を後に取っておいたときの平均の点数 ＋ 上段ボーナスに近づく分（ボーナスを取れる見込みの差 × 35）」。1手の計算は1ミリ秒ほど。

ひとりで遊んだときの平均点（各 1000 試合）：

| 強さ | 平均 | 中央 | 上段ボーナス | ヤッツィー（50点） |
|---|---|---|---|---|
| やさしい | 195.0 | 183 | 3.2% | 40.3% |
| ふつう | 230.2 | 219 | 23.6% | 34.0% |
| つよい | 244.8 | 239 | 64.3% | 36.1% |

参考：最適な戦い方の平均は約 254.6 点。人がふつうに遊ぶと 200〜230 点くらい。

2人での勝率（各 1000 試合）：ふつう 72.1% 対 やさしい 27.9%、つよい 58.5% 対 ふつう 41.5%。運の要素が大きいので、つよいでも負けることは多い。

```bash
# 試合数・席ごとの強さ（easy・normal・strong・random はでたらめ）。1つだけならひとりで遊んだときの平均点
node scripts/cpu-match.mjs 1000 strong
node scripts/cpu-match.mjs 1000 strong,normal
```

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest。web-games の直下で）
npm test -w games/yahtzee
```

| ファイル | 役割 |
|---|---|
| `public/js/game.js` | ルールと点数の計算。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | 画面に渡すビュー（記入できる欄と先読みの点数を含む） |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカルのゲームの進行と、途中経過の保存 |
| `public/js/records.js` | ハイスコアの記録 |
| `public/js/ui.js` | 画面。届いたイベント（振る・記入）を動きで見せる |
| `public/js/art.js` | サイコロの絵 |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |
| `server/src/handler.js` | オンライン対戦のサーバーの入口（AWS Lambda） |
| `public/js/online-config.js` | オンライン対戦の接続先 |
| `public/js/netplay/` | netplay-kit のクライアントとロビーの画面の写し（同期で置く。手で直さない） |

保存の名前（localStorage）は `yahtzee.save`（途中経過）・`yahtzee.settings`（相手の人数と強さ）・`yahtzee.records`（ハイスコア）。

### オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜4人で、足りない席は CPU で埋められる。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'yahtzee' })`。web-games の1つのスタックから `?game=yahtzee` で呼ばれる）
- ゲームの定義は `server/src/game-definition.js`（記録だけを保存して再現する。各席には、その席から見えるビューだけを送る）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
