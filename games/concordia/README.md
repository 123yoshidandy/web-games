# コンコルディア

古代ローマの地中海で、植民者を送り、家を建て、品を生産して交易し、人物のカードを集めるボードゲーム「コンコルディア（Concordia、Mac Gerdts 2013）」の基本ゲームを、ブラウザで遊べるようにしたもの。CPU を相手に 2〜5 人で遊べる（人間 1 人＋CPU 1〜4 人）。スマホの横画面と PC に対応し（縦持ちのスマホでは横向きに回して描く）、ホーム画面に追加するとオフラインでも遊べる（PWA）。

地図は、基本の地図「Imperium」の都市・州・文字・道に合わせ（公式の盤面のスキャンから読み取った）、都市の位置と海岸線は実際の地中海の地理から自作した。地図・カード・アイコンの絵はすべて自作で、公式の画像は使っていない。

## 遊ぶ

ビルドは要らない。リポジトリのルートで HTTP サーバーを立てて開く。

```bash
python3 -m http.server 8080
# http://localhost:8080/public/ を開く（ルートを開くと public/ へ移る）
```

## ルール

- 準備
  - 都市の品：都市に付いた文字（A〜D）ごとに品のトークンを切って置く。州のボーナスは、その州の都市の品のうち、いちばん値の高い品（品の面を上に）
  - 各人：陸と海の植民者を 1 人ずつローマに、倉庫に陸と海の植民者 2 人ずつと 食料 2・れんが・道具・ワイン・布 1 ずつ。家 15 軒。お金は手番の順に 5・6・7・8・9
  - 手札（7 枚）：護民官・建築家・属州総督 2 枚・商人・元老院議員・外交官
  - 市場：売り物のカードの山 I〜V のうち、人数までの山を使う（2 人は I・II、5 人は全部）。山ごとに切り、I を上にして重ね、7 枚を並べる
  - プラエフェクトゥス・マグヌスは最後の手番の人
- 手番：手札から 1 枚を使って効果を行い、自分の捨て札に置く
  - 護民官：捨て札を全部手札に戻し、戻した枚数（護民官を含む）が 3 枚を超えた分、1 枚につき 1 セステルティウス。食料 1 と道具 1 で植民者を 1 人ローマに置ける
  - 建築家：盤上の自分の植民者の数だけ歩数を割り振って動かす（陸は陸路、海は海路。1 歩目は都市から道へ、次からは都市を通って隣の道へ）。ほかの植民者のいる道は通り抜けられるが、止まれない。動かしたあと、植民者のいる道の両端の都市に家を建てる
    - 品：れんが 1＋その都市の品 1（れんがの都市は食料 1）
    - お金：れんが 1・食料 2・道具 3・ワイン 4・布 5 ×（建てたあとのその都市の家の数）
    - 1 つの都市に自分の家は 1 軒まで。ローマには建てられない
  - 属州総督：品の面の州を選んで生産させる（ボーナスの品を 1 つ受け取り、州の家すべてが持ち主にその都市の品を 1 つずつ出す。ボーナスはお金の面になる）。または、お金の面のコインの数だけ受け取り、全部の州を品の面に戻す（コインは布の州 1、ほかの州 2）。プラエフェクトゥス・マグヌスの持ち主が生産させるとボーナスは 2 つで、マグヌスは右の人（手番の逆回り）へ移る
  - 商人：3 セステルティウス（買った商人は 5）を受け取り、2 種類までの品を売り買いする（値段は れんが 3・食料 4・道具 5・ワイン 6・布 7）
  - 元老院議員：市場から 2 枚まで買う（カードの費用＋置き場所の追加の費用）。執政官：市場から 1 枚、カードの費用だけで買う。買ったあと、市場は左に詰めて山札から補充する
  - 植民者：食料 1・道具 1 ずつで、ローマか自分の家がある都市に植民者を置く（何人でも）。または、5＋盤上の自分の植民者の数 のセステルティウス
  - 外交官：ほかの人の捨て札のいちばん上のカードの効果を行う（外交官はまねられない。護民官を使った人の捨て札は空になるので、護民官もまねられない）
  - 職人（石工・農夫・鍛冶・ぶどう酒造り・織工）：その品の都市の自分の家が、それぞれ 1 つ生産する
- 倉庫は 12 マス。品 1 つと、倉庫の植民者 1 人が 1 マスを使う。入りきらない品は受け取れない
- 終わり：市場の最後のカードを買うか、15 軒目の家を建てた人がコンコルディアのカード（7 点）を受け取り、ほかの人が最後の手番を 1 回ずつ行う
- 得点：持っているカード（手札と捨て札）の神ごとに、1 枚あたりの点 × その神のカードの枚数
  - ウェスタ：お金と品の値（商人の値段）の合計 10 につき 1
  - ユピテル：れんが以外の都市の家 1 軒につき 1（最大 15）
  - サトゥルヌス：家のある州 1 つにつき 1（最大 12）
  - メルクリウス：家で生産する品の種類 1 つにつき 2（最大 10）
  - マルス：盤上の植民者 1 人につき 2（最大 12）
  - ミネルウァ：職人カードごとに、その品の都市の家 1 軒につき、石工・農夫・鍛冶 3、ぶどう酒造り 4、織工 5
- 同点：プラエフェクトゥス・マグヌスの持ち主か、そのあと最初に受け取る人の勝ち

- 都市の文字（A〜D）と道（陸路 44・海路 35）：BGG にある公式の盤面のスキャンを目で読み取ったもの（文章の資料は見つからなかった）。文字の数（A 7・B 8・C 10・D 5）は Pianeer の戦略ガイド（pianeer.org）と一致し、道はルールブックの建築家の例（陸路 コロニア〜ノウァリア、ローマ〜アクィレイア〜ウィンドボナ、海路 ローマ〜マッシリア、隣り合う都市が 5 つ）と矛盾しない
- 文字ごとの品のトークン（A：れんが 2・食料 2・道具・ワイン・布、B：れんが 2・食料 2・道具 2・ワイン・布、C：れんが 3・食料 2・道具 2・ワイン 2・布、D：各 1）：GitHub の yav/concordia（実装）の値。品ごとの合計（れんが 8・食料 7・道具 6・ワイン 5・布 4）は Pianeer と一致
- 市場の置き場所の追加の費用（左から なし・好きな品・好きな品・布・布・好きな品＋布・布 2 つ）：yav/concordia の値。ルールブックの例（1 番目なし・3 番目「好きな品」・4 番目「布」・6 番目「好きな品＋布」）と合う
- 州のボーナスのお金の面のコイン（布の州 1、ほか 2）：yav/concordia と Pianeer で一致

## 資料で分からない点の決め方

公開された資料で確かめられなかった点は、次のように決めた（`public/js/cards.js`・`public/js/map.js` の冒頭にも書いている）。

| 場面 | 確かめたこと | 決めたこと |
|---|---|---|
| 道 | 盤面のスキャンを目で読み取った（文章の資料はない） | 読み取ったとおりに入れた。紛らわしかったのは アッタリア〜アンティオキア〜テュロス の海路で、アンティオキアで止まる別々の線と読んだ |
| 都市の位置 | — | 盤の絵は使わず、実際の都市の経度・緯度に置いた。海岸線も実際の地理をもとに描き、海路は陸にかからないように曲げた |
| 人数 | Imperium は 3〜5 人用（2 人は Italia の地図を使う） | Italia の地図は作らず、2 人でも Imperium で遊べるようにした（州は減らさない） |
| 市場の置き場所の 2・5・7 番目の費用 | 実装（yav/concordia）の値だけで、ほかの資料では確かめられない | 実装の値を使った |
| 外交官でまねたとき | 属州総督をまねてもマグヌスが効くことは明記されている。まねて買ったカードの行き先と、買った商人をまねたときの額は明記がない | 買ったカードは自分の手札に入り、買った商人をまねたら 5 を受け取る |
| 倉庫に入りきらない品 | 受け取る品は選べる（空きを残してはいけない） | 選ばずに、受け取る順（ボーナス → 州の都市の並び）で入るだけ入れる |
| 途中の得点（初めて遊ぶとき向け） | ルールブックにある任意の決まり | 入れていない |

## 操作

- 手札を押すと、カードの説明と使い方が出る（自分の番でないときは説明だけ）
- 建築家：光る植民者を押してから、行き先の道を押す（行ける道が光る）。続けて光る都市を押すと、費用を見て家を建てられる。「終える」で手番を終える
- 属州総督：「州を選んで生産」で、品の面の州のボーナスが光る。押すと生産する
- 商人：品ごとの ＋／− で売り買いを決める（2 種類まで。倉庫の空きとお金を見ながら）
- 元老院議員・執政官：買うカードを選ぶ。好きな品で払う分は安い品から自動で選び、押して変えられる
- 植民者：「植民者を置く」で置ける都市が光る。押して陸か海を選び、「置く」で決める
- 外交官：まねられる相手のカードが並ぶ
- 上の欄はプレイヤー（お金・家の数・捨て札のいちばん上・マグヌスの王冠）。押すと品などの詳しい状態が見られる。右の欄は市場と自分の倉庫
- 途中で閉じても、タイトルの「続きから」で再開できる（操作の記録を保存して再現する）

## CPU

手番では、手札の各カードの使い方（州・売り買い・買うカード・植民者の置き方・外交官でまねる相手）を候補として挙げ、盤面の写しで試し、局面の評価がいちばん上がるものを選ぶ。評価は「今の得点の見込み」と「経済（お金・品・家・植民者・カード・植民者から数歩先の建てたい都市への近さ）」を、ゲームの進み具合で重みを変えて足したもの。建築家は、建てたい都市へ植民者を寄せてから、払える範囲で値打ちの高い都市に建てる。

見えない情報（市場の山札の並び、ほかの人の手札）は使わない。CPU の判断にゲームの乱数は使わない（揺れは局面から作った別の乱数で付ける）。

- やさしい・ふつう の 2 段階（画面で選ぶ）。やさしいは、評価の揺れが大きく、外交官を使わず、商人で買い足さず、建築家で先の都市を目指さない
- 強さの測定：`npm run cpu-match -- <試合数> <人数> <席ごとの強さ>`（強さの並びは試合ごとにずらす）

2026-11-18 に測った勝率：

| 対戦 | 試合数 | 勝率 |
|---|---|---|
| やさしい 対 ふつう（2 人） | 200 | 18.0% 対 82.0% |
| やさしい・ふつう・やさしい・ふつう（4 人） | 100 | やさしい 1 人あたり 7.0%・ふつう 1 人あたり 43.0% |
| ふつう 3 人（席ごとの勝ち） | 60 | 15・17・28 試合 |
| ふつう 5 人（席ごとの勝ち） | 60 | 11・8・12・9・20 試合 |

どの組み合わせでも全試合が最後まで進んだ。1 試合は 30〜39 周ほどで、勝者の点は平均 129〜147 点。2 人では 15 軒目の家で終わる試合が多く（200 試合中 180）、人数が増えるほど市場の最後のカードで終わる試合が増える。3 人・5 人では最後の手番の人がやや多く勝っている（最初のお金がいちばん多く、プラエフェクトゥス・マグヌスも最後の人から始まるため。CPU がこの差を詰められていない可能性もある）。

## 開発

```bash
npm install
npm test                                  # Vitest（地図のデータ・ルール・得点・ビュー・CPU・記録の再現・ゲームの定義・PWA）
npm run cpu-match -- 200 2 easy,normal    # CPU どうしの勝率
```

- ロジック（`game.js`）は DOM に依存しない。操作の入口は `applyCommand` の 1 つで、受け付けた操作を記録し、`Game.replay` で同じゲームを再現できる（乱数は準備でだけ使う）。断る操作は状態を変えない
- 隠す情報（ほかの人の手札・市場の山札の並び）は、ビュー（`game-view.js`）で本人以外から消す
- 画面を確かめるときは、`python3 -m http.server <port>` で配信し、スマホの横の大きさ（667×375 など）で開く。`window.__app` から画面の状態に触れられる
- service worker（`public/sw.js`）が先に読むファイルの一覧は、JS を足したら書き足す（`test/pwa.test.js` が確かめる）

## オンライン対戦（未実装）

ロジックは DOM から切り離し、操作の入口を 1 つにして、記録から再現できるようにしてある。各人のビューには、自分から見えるものだけを入れている。netplay-kit を同期すれば、`server/src/game-definition.js` をそのまま部屋の処理に渡せる。対戦中に部屋を出た人の席は、CPU（ふつう）が代わりに続ける。
