# ロード・オブ・ウォーターディープ

エージェントを街の場所に送って冒険者と金貨を集め、クエストを達成して点を競うワーカープレイスメントのボードゲーム「ロード・オブ・ウォーターディープ（Lords of Waterdeep、Peter Lee・Rodney Thompson、Wizards of the Coast 2012）」の基本セットを、ブラウザで CPU と遊べるようにしたもの。2〜5人（あなた＋CPU 1〜4人）。スマホの縦持ち向けで、スクロールなしで1画面に収まる。ホーム画面に置くと、オフラインでも遊べる。

絵とアイコンは、すべて CSS と SVG で自作している（公式の画像は使っていない）。カードの名前は日本語に訳し、説明の文も自分で書いた。

## 遊び方（基本セット）

- 8ラウンド。各自、ロード（秘密の目標）1枚・クエスト2枚・陰謀カード2枚を持って始める。金貨は先手番から4・5・6…
- エージェントの数：2人は4人、3人は3人、4〜5人は2人。5ラウンド目に1人ずつ増える
- 先手番から順に、エージェントを1人ずつ空いている場所に置き、その場所の効果を受ける。番の終わりに、そろったクエストを1枚達成できる
- 全員が置き終わったら、港に置いたエージェントを、港の順に空いている場所へ置き直す（そこの効果も受ける）。そのあとラウンドが終わる
- 冒険者は4種類：戦士（橙）・盗賊（黒）・魔法使い（紫）・僧侶（白）

| 場所 | すること |
|---|---|
| ウォーターディープ城 | 先手番の印を取り（次のラウンドから先手番）、陰謀カードを1枚引く |
| オーロラの店 | 金貨4 |
| 黒杖の塔 | 魔法使い1 |
| 凱旋の野 | 戦士2 |
| 笑う獅子亭 | 盗賊2 |
| 台座の神殿 | 僧侶1 |
| 崖見の宿（3か所） | 表のクエストを1枚取る。それぞれ金貨2・陰謀カード1枚・先に表の4枚を入れ替える、がつく |
| ウォーターディープ港（3か所） | 陰謀カードを1枚使う（持っていないと置けない）。ラウンドの終わりに置き直す |
| 建築家の会館 | 売り物の3つから1つを金貨で建てる。売れ残りには毎ラウンド1点が積まれ、建てた人が得る |
| 建てた建物 | 新しい場所になる。自分以外の人が使うと、持ち主も得る |

- 終わり：残った冒険者1体1点・金貨2枚で1点・ロードの点（2種類のクエスト1枚につき4点。建物のロードは建物1つにつき6点）を足し、一番点の高い人の勝ち。同点なら金貨の多い人

### カードの揃え方（方針）

原作の基本セットに沿って、種類と効果の型を揃えた。要求と報酬の数は原作を参考にした近似で、すべてが原作と同じではない。名前は日本語に訳し、分かりにくい固有名詞（神の名前・地名など）は意味が分かる言葉に置き換えた（例：Blackstaff Tower → 黒杖の塔、Cliffwatch Inn → 崖見の宿）。

| 種類 | 数 | 内容 |
|---|---|---|
| クエスト | 51枚 | 魔術・信仰・謀略・戦争・交易を10〜11枚ずつ。うちプロット13枚（その種類のクエストで2点・場所で得る冒険者がもう1体・副官（エージェントが1人増える）・ラウンドの初めに好きな冒険者1・建物を建てるたびに4点） |
| 陰謀カード | 36枚 | 相手にも少し渡して自分が得る5種・全員が得る募集・5択の頼みごと・相手から1体ずつ返させる攻撃4種・義務クエスト6種（各2〜3枚） |
| 建物 | 22種 | 冒険者・金貨を得る建物のほか、宮殿（大使）・ゾアスター（相手の置いた場所を使う）・石の家（建物の数だけ金貨）・英雄の庭（取ったクエストをすぐ達成で4点）など |
| ロード | 11人 | 5種類から2種類の組み合わせ10人と、建物のロード1人 |

### 資料で分からない点の決め方

- 大使は、取った次のラウンドの初めに、だれよりも先に置く。大使は宮殿には置けない。大使が出ているラウンドは、宮殿を使えない
- 港で置き直すときは、港には置けない。ゾアスターでは港とゾアスター自身は選べない
- プロットの「もう1体」は、場所の効果で決まった数の冒険者を得たときだけ効く（選んで取るとき・持ち主の分・クエストの報酬には効かない）。金貨のプロットは、場所で金貨を得るたびに金貨2
- 「その種類のクエストで2点」のプロットは、そのプロット自身の達成には効かない
- 相手を選ぶカードは、相手が1人なら選ばずに決まる
- 置ける場所がないときは、そのエージェントは置かずに番を飛ばす（ふつうは起きない）
- 山札が尽きたら、捨て札を混ぜて山にする。建物の山が尽きたら、会館の売り物は減っていく

### 画面の操作

- 置ける場所が光る。タップで選んで（下に説明と「置く」）、もう一度タップか「置く」で置く
- クエストのカード・場所・売り物の建物をタップすると、下に説明が出る
- 決めること（冒険者・クエスト・建物・陰謀カード・相手・達成）はダイアログで選ぶ。外をタップして閉じると盤面を見られ、下の「選ぶ」で開き直す
- 相手の欄をタップすると、受けているクエスト・プロット・建物が見られる。自分の段の「手元」でロードと陰謀カードを見る
- ロードの目標に合うクエストには右上に印、そろっているクエストは緑の枠がつく

## CPU

打てる手（置く場所・選ぶもの）を1つずつゲームの写しで試し、その後の自分の状態に点数を付けて一番よい手を選ぶ。写しでは、見えない山札を CPU 用の乱数で混ぜ直す（山札の順をのぞかない）。ゲームの乱数は使わないので、記録から同じ試合を再現できる。

- やさしい：ロードの目標・プロット・建物の先の値打ちを考えない。クエストは、ほぼそろうまで見込みを低く見る
- ふつう：ロードの目標に合うクエストを重く見て、集めた分だけクエストの見込みが増える。建物とプロットの先の値打ちも数える

```bash
# 試合数・強さの並び（easy・normal）。席の並びは試合ごとに1つずつずらす
node scripts/cpu-match.mjs 200 easy,normal
```

測った結果（2026-11-25）：2人で200試合、ふつうの勝率 89.5%（平均 157 点、やさしい 130 点）。5人（ふつう1・やさしい4）で100試合、ふつうの勝率 45%。どの人数でも、進まなくなった試合はない。

置く番に操作の欄の電球（ヒント）を押すと、ふつうの CPU が選ぶ手を示す（置く場所を選んでおき「置く」を光らせる）。決めるダイアログにも電球があり、選ぶ資源・クエスト・建物などを光らせる。CPU と同じく、見えない山札は混ぜ直して試すので、山札の順はのぞかない。

## 開発

```bash
# 画面
cd public && python3 -m http.server 8000
# テスト（Vitest。リポジトリの直下から）
npm test -w games/lords-of-waterdeep
```

- `public/js/game.js`：ルール（DOM に依存しない）。操作はすべて `applyCommand(seat, command)` を通し、記録から `Game.replay` で再現できる。断る操作は状態を変えない
- `public/js/cards.js`：場所・建物・クエスト・陰謀カード・ロードのデータ
- `public/js/game-view.js`：プレイヤーから見てよい情報だけのビュー（陰謀カードとロードは本人にだけ）
- `public/js/cpu-player.js`：CPU
- `public/js/game-controller.js`：ローカル対戦。操作のたびに `lords-of-waterdeep.save` に記録を保存し、「続きから」で再現する
- `public/js/ui.js`・`help.js`：画面と遊び方
- `server/src/game-definition.js`：オンライン対戦用のゲームの定義（netplay-kit の形。まだ部屋の処理は入れていない）
