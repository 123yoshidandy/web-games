# お邪魔者

金鉱掘りとお邪魔者に分かれて坑道を掘る、正体隠しのカードゲーム「お邪魔者（Saboteur）」の基本ゲームを、ブラウザで CPU と遊べるようにしたもの。3〜10人（あなた＋CPU 2〜9人）。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

絵（道のカード・道具・役割・アイコン）は、すべて SVG で自作している。

## 遊び方（基本ゲーム）

- 役割：人数ごとの数のお邪魔者と金鉱掘りのカードを、人数+1枚混ぜて1枚ずつ配る（1枚は使わない）。自分の役割は自分だけが知る

| 人数 | 3 | 4 | 5 | 6 | 7 | 8 | 9 | 10 |
|---|---|---|---|---|---|---|---|---|
| お邪魔者 | 1 | 1 | 2 | 2 | 3 | 3 | 3 | 4 |
| 金鉱掘り | 3 | 4 | 4 | 5 | 5 | 6 | 7 | 7 |
| 手札 | 6 | 6 | 6 | 5 | 5 | 4 | 4 | 4 |

- 盤面：スタートと、8マス右の列に伏せたゴール3枚（1枚が金）
- 手番には1枚を出すか、1枚を伏せて捨てる。そのあと山札があれば1枚引く
  - 道：隣のカードとすべての辺が合い、スタートからつながる場所に置く。180度回してよい。道具が1つでも壊れていると置けない
  - 壊す：ほかの人の道具（つるはし・ランプ・トロッコ）を壊す。同じ道具を2つは壊せない
  - 直す：自分かほかの人の、壊れた道具を1つ直す（2種類が描かれたカードは、どちらか1つ）
  - 地図：伏せたゴールを1枚、自分だけ見る
  - 落盤：スタートとゴール以外の道のカードを1枚取り除く
- 道がゴールに届いたらめくる。金なら金鉱掘りの勝ち。石なら道に合う向きで置いて続ける
- 山札と全員の手札がなくなったら、お邪魔者の勝ち
- 金塊（1つ×16・2つ×8・3つ×4）
  - 金鉱掘りの勝ち：人数ぶん（9枚まで）引き、金にたどり着いた人から反時計回りに、金鉱掘りが1枚ずつ取る
  - お邪魔者の勝ち：お邪魔者がそれぞれ、1人なら4・2〜3人なら3・4人なら2の金塊をもらう
- 3ラウンドの金塊の合計がいちばん多い人の勝ち（同じなら全員）

### カードの構成

- 道のカード40枚：つながる道31枚（縦の直線4・横の直線3・曲がり角4と5・T字5と5・十字5）、行き止まり9枚（Wikipedia の基本ゲームの表による）
- アクション27枚：壊す9枚（道具ごとに3）、直す9枚（道具ごとに2、2種類のどちらかを直すもの3）、地図6枚、落盤3枚

### 資料で分からない点・食い違う点の決め方

- 金鉱掘りの勝ちのときに引く金塊は、人数ぶん（10人のときは9枚。3ラウンドで28枚に収めるため）
- 金塊は、各自が選ぶ代わりに、高いものから自動で取る
- お邪魔者が金にたどり着いたときも金鉱掘りの勝ち。金塊は、その人から反時計回りで次の金鉱掘りから取る
- 道具を壊すカードは、自分以外にだけ出せる
- 石のゴール2枚の形は、曲がり角（上と右・上と左）とした
- 次のラウンドは、前のラウンドの最後に手番をした人の次の席から始める

### 画面の操作

- 盤面は指（マウス）で動かし、2本指（ホイール）で拡大・縮小する。＋・−・全体のボタンもある。ページはズームしない
- 手札を押すと、出せる先が光る
  - 道：置ける場所に半透明の候補が出る。押すとそこに置く。その場所が回した向きでしか置けなければ、回して置く。両方の向きで置ける場所は、「回す」ボタンで向きを選ぶ
  - 壊す・直す：相手の札が光る。2種類を直せるカードで両方壊れていれば、直す道具を選ぶ
  - 地図：伏せたゴールが光る。見たゴールには「金」「石」の印が残る
  - 落盤：取り除ける道が光る
- 壊れた道具は、各人の札に赤い斜線のアイコンで出る
- 記録は1行で流れ、右上のボタンで一覧を見られる
- 記録・遊び方・ラウンドの結果を開いている間は、CPU が止まる
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

自分の役割と、見えている情報（だれがどこに道を置いたか、だれを壊したか・直したか、落盤で何を取り除いたか）だけで打つ。ほかの人の役割・手札、伏せたゴールの中身は見ない。

- 正体の推測：このラウンドの記録を順にたどり、道の先端をゴールに近づけた人は金鉱掘りらしく、行き止まりで延ばしたり遠ざけたりした人はお邪魔者らしい、などと疑いの点数を付ける
- 金鉱掘り：金に近づく道を置く。金の場所が分からなければ地図を使う。疑わしい人の道具を壊し、信用できる人を直す
- お邪魔者：道がゴールから遠いうちは、金鉱掘りのふりをすることが多く、ふりをしないときも目立たない道を置く。ゴールに近づくと、行き止まり・壊す・落盤で邪魔をする
- 強すぎないように、評価の揺れと、ときどき2番目の手を選ぶ誤りを混ぜている

```bash
# 試合数・人数・強さ（全員同じ。normal は画面の CPU）。金鉱掘りとお邪魔者の勝ち数と、正体の当たり方を出す
node scripts/cpu-match.mjs 100 5 normal
```

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。3〜10人で、足りない席は CPU で埋められる。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'saboteur' })`。web-games の1つのスタックから `?game=saboteur` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm install
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/cards.js` | カードのデータと、人数ごとの役割・手札・金塊 |
| `public/js/board.js` | 盤面と、道のつながりの計算 |
| `public/js/game.js` | ルール。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー |
| `public/js/cpu-player.js` | CPU（正体の推測を含む） |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`art.js`・`animator.js` | 画面・絵・動き |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |
| `server/src/handler.js`・`public/js/online-config.js`・`public/js/netplay/` | オンライン対戦のサーバーの入口・接続先・netplay-kit の写し |
