# ショッテントッテン

9つの境界石を取り合う2人用のカードゲーム「ショッテントッテン（Schotten Totten）」を、ブラウザで CPU と遊べるようにしたもの。スマホの縦持ち向け（横にしても遊べる）。ホーム画面に置くと、オフラインでも遊べる。

絵（氏族カード・戦術カード・境界石・アイコン）は、すべて自作。氏族の6色には、色だけに頼らず見分けられるよう、形の違う印（円・三角・四角・ひし形・星・六角）を付けている。

## 遊び方

- 氏族カード 6色×1〜9 の54枚。各自に6枚配る。境界石は9つ
- 手番の流れ（BGA と同じ）
  1. 手札から1枚を、自分の側の、まだ取られていない境界石に出す（各石3枚まで）
  2. 取れる境界石を主張する（何個でも。しなくてもよい）
  3. 1枚引く（山札がなければ引かない）
- 組の強さ：同色の連番 ＞ 同じ数 ＞ 同色 ＞ 連番 ＞ 合計。同じ種類なら合計の大きい方、それも同じなら先に3枚そろえた方
- 主張：自分の側に3枚そろっていて、相手より強ければ取れる。相手がそろっていなくても、場に出ているカードだけから、相手がどう埋めても上回れないと示せれば取れる（自分の手札は証明に使わない）
- 境界石を5つ取るか、隣り合う3つを取った方の勝ち
- 置ける石がないときは、パスできる

### 戦術カード（タイトル画面で選ぶ。既定はなし）

10枚の別の山札。手札は7枚になり、引くときに氏族か戦術の山札を選ぶ。戦術カードは、相手が出した枚数＋1枚までしか出せない。

| カード | 効果 |
|---|---|
| ジョーカー（2枚） | 色と数を選んで出す。1人1枚まで |
| スパイ | 色を選んで、7として出す |
| 盾持ち | 色と数（1〜3）を選んで出す |
| 目隠し鬼 | その石は合計だけで比べる |
| 泥んこ合戦 | その石は4枚ずつ出す |
| 新兵募集 | どちらかの山札から合わせて3枚引き、2枚をそれぞれの山札の下に戻す |
| 策士 | 自分の氏族カード1枚を、別の石に動かすか捨てる |
| バンシー | 相手の氏族カード1枚を捨てさせる |
| 裏切り者 | 相手の氏族カード1枚を、自分の側の石に動かす |

策士・バンシー・裏切り者が対象にできるのは、まだ取られていない石の氏族カードだけ。

### ルールに書かれていないので決めたこと

- 最初の手番はランダム
- 主張の証明では、まだ場に出ていないジョーカー・スパイ・盾持ちも、相手が使えるものとして数える（相手がジョーカーをもう出していれば、もう1枚は数えない）。相手の手札が0枚で、山札もないときは、相手はもうカードを足せないものとして数える
- 戦術カードでカードが捨てられると、両側ともそろわない石が残り、だれも主張できなくなることがある。山札がどちらもなく、両者が続けてパスしたら終わりにし、取った石の多い方の勝ち（同じなら引き分け）とする
- 開始時に主張する上級の変種は入れていない

### 画面の操作

- 手札を選ぶと、出せる石の自分の側に点線の枠が出る。石を押すと出す
- ジョーカー・スパイ・盾持ちは、石を押すと色と数を選ぶ画面が出る
- バンシー・裏切り者・策士は、狙える場のカードが白く光る。押して選ぶ
- 主張できる石には「主張」の札が光る。押すと取る。主張できる石がなく、引く山札も選ばなくてよいときは、自動で番を終える
- そろった組の下（相手は上）に、組の種類（色連番・同数・同色・連番・合計）を出す
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

自分から見える情報だけ（相手の手札・山札の並びは見ない）で打つ。

- 境界石ごとに、勝てる見込み（0〜1）を見積もる。今すぐ主張できる石は1、相手が主張できる石は0
- それ以外は、自分と相手が作れそうな組の強さの差から出す。自分は「手札だけで作れる組」と「まだ出ていないカードまで使える組」の強い方、相手は「まだ出ていないカード（相手の手札を含む）で作れる組」を、足りない枚数ごとに割り引く
- 見込みの合計と、隣り合う3つを取れる見込みがいちばん増える手を選ぶ。戦術カードも同じ物差しで比べ、使うことの損を少し引く
- 主張できる石は、すべて主張する
- 強さは「やさしい」「ふつう」の2段階（タイトル画面で選ぶ）。評価に揺れを入れ、ときどき2番目以下の手を選ぶ。やさしいの方が揺れと誤りが大きい

CPU 同士の勝率（1000試合、席は交互。strong は揺れのない比較用、random はでたらめに打つ比較用）：

| 対戦 | 戦術カードなし | あり |
|---|---|---|
| ふつう 対 やさしい | 82.5% | 81.4% |
| strong 対 ふつう | 57.8% | 63.4% |
| やさしい 対 random | 97.3% | 98.0% |

戦術カードありの4000試合のうち、行き詰まりの決まりで終わったのは7試合だった。

```bash
# 試合数・強さA・強さB（easy・normal・strong・random）・戦術カード（tactics と書くとあり）
node scripts/cpu-match.mjs 400 normal easy tactics
```

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2人で、足りない席は CPU で埋められる。戦術カードを使うかを部屋の設定に持つ。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'schotten-totten' })`。web-games の1つのスタックから `?game=schotten-totten` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm install
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/game.js` | ルール。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/formation.js` | 組の強さと、残りの枠を埋めたときのいちばん強い組（主張の証明と CPU が使う） |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー（主張できる石を含む） |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`art.js`・`animator.js` | 画面・絵・動き |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義（戦術カードはロビーの設定） |
| `server/src/handler.js`・`public/js/online-config.js`・`public/js/netplay/` | オンライン対戦のサーバーの入口・接続先・netplay-kit の写し |
