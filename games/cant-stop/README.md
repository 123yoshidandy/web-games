# キャント・ストップ

4 つのダイスを振って 2〜12 の列を登り、先に 3 本の列の頂上を取った人が勝つ、押し引きのボードゲーム。ブラウザで、CPU を相手に 2〜4 人で遊べる（人間 1 人＋CPU 1〜3 人）。スマホの縦・横の画面と PC に対応し、ホーム画面に追加するとオフラインでも遊べる（PWA）。

盤面・ダイス・アイコンの絵は、すべて自作の SVG。

## 遊ぶ

ビルドは要らない。リポジトリのルートで HTTP サーバーを立てて開く。

```bash
python3 -m http.server 8080
# http://localhost:8080/public/ を開く（ルートを開くと public/ へ移る）
```

## ルール

- 列の長さ：2・12 が 3 マス、3・11 が 5、4・10 が 7、5・9 が 9、6・8 が 11、7 が 13 マス
- 手番：4 つのダイスを振り、2 つずつの組に分ける（3 通り）。選んだ組の 2 つの和の列で、白いランナーを 1 マスずつ進める。ランナーは 1 回の手番で 3 つまで
  - 両方の和で進めるなら、両方とも進む（同じ和なら 2 マス）
  - 片方しか進めない（取られた列・頂上・ランナーが足りない）なら、その片方だけ
  - ランナーが 1 つしか残っていなくて、2 つの和がどちらも新しい列なら、どちらか 1 つを選ぶ
- 進んだら、続ける（もう一度振る）か止めるかを決める。止めると、ランナーの位置に自分のマーカーを置く
- どの組でも進めなければバースト。その手番の進みをすべて失う（前の手番までのマーカーは残る）
- 止めたとき頂上にいた列は自分のものになり、ほかの人のマーカーはその列から取り除かれる。取られた列には誰も進めない
- 3 列を取ったら（止めた時点で）勝ち
- 最初の手番はシードから決める

## 操作

- 手番の初めのダイスは自動で振る。進め方が 1 つしかないときも、自動で進む
- 3 行の組から 1 つを押す。両方進む組は行全体が 1 つのボタン、どちらか 1 つを選ぶ組は左右が別々のボタン、使えない和は打ち消し線
- 進んだあとは、バーストの確率と、この手番の進み（バーストすれば失うマス）を見て、「続ける」か「止める」
- キーボード：1〜3 で組、Space で続ける、S で止める
- 途中で閉じても、タイトルの「続きから」で再開できる（操作の記録を保存して再現する）

## CPU

組は「列の長さに対する進み」と「新しいランナーを出す損」で選び、続けるかどうかは「バーストの確率 × 失う進み」と「もう 1 回振ったときの見込みの進み（1296 通りの平均）」を比べて決める。人間らしいゆらぎ（慎重さの幅、組の選び方のゆらぎ）を入れて、強すぎないようにしている。

- ふつう（既定）・やさしい の 2 段階
- 強さの測定：`npm run sim -- <試合数> <強さの並び>`（例：`npm run sim -- 400 normal,strong`）。`strong`（ゆらぎなし）・`naive`（ランナーが 3 つ出たら止める）・`random` は測定用

## ファイルの構成

| ファイル | 内容 |
|---|---|
| `public/js/game.js` | ゲーム本体。進め方の一覧（`moveOptions`）、バーストの確率、`applyCommand` と `Game.replay` |
| `public/js/game-view.js` | ビュー |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦のコントローラー（`getView()` / `send()`） |
| `public/js/board-view.js` | 盤面とダイスの絵（SVG） |
| `public/js/main.js` | 画面の進行 |
| `server/src/game-definition.js` | オンライン対戦用のゲームの定義（netplay-kit の形。まだ使っていない） |
