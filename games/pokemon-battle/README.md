# ポケモン6対6タクティクス

8×10 マスのフィールドで、6体ずつのポケモンを動かして戦うタクティクス。手持ち6体・技・戦術ルール（ガンビット）を事前に組み、手動でも自動でも戦える。CPU 対戦とオンライン対戦（2人）。スマホ縦向き。

## 遊び方

- 自軍フェイズと敵軍フェイズを交互に行う。自分のフェイズでは、ポケモンを1体ずつ「動いて、技を使うか待機」させる。全員が行動するか「フェイズ終了」で相手のフェイズへ
- 相手を全員たおせば勝ち。30ターンで決着しなければ、残りHPの割合の合計で判定（同じなら引き分け）
- 移動力は素早さの種族値で決まる（100以上=5、60〜99=4、59以下=3マス）。味方は通り抜けられるが止まれない。相手と岩は通れない
- 技は1体2つ。威力・命中率・射程（縦横の歩数。1は隣だけ）がある
- ダメージ = 威力 ×（攻撃 ÷ 防御）× 0.4 × タイプ相性 × 乱数(0.85〜1.0)。物理技は こうげき÷ぼうぎょ、特殊技は とくこう÷とくぼう。ステータスはレベル50（個体値31・努力値0）の実数値
- 戦術ルール：1体に3つまで。上から順に評価し、最初に合った条件の行動をする
  - 条件：射程内に敵がいる／自分のHPが30%以下／敵が隣接している／常時
  - 行動：最も弱い敵を攻撃（残りHPが少ない敵）／最も近い敵を攻撃／敵から離れて攻撃／待機する
  - どれも合わなければ「最も近い敵を攻撃」
- 操作：ポケモンを押す → 光るマスを押して動く → 技を選んで相手を押す。相手を直接押すと、届くマスへ動いて一番効く技で攻撃する。「おまかせ」はその1体、「全員おまかせ」は残り全員をルールで動かす。上の AUTO を入れると、自分のフェイズを毎回ルールで戦う
- 電球のボタンで、おすすめの手（動かすポケモン・行き先・相手）が光る

## CPU

`public/js/cpu-player.js`。強さはタイトルで選ぶ。

- やさしい：全員が「常時：最も近い敵を攻撃」
- ふつう：おすすめの戦術ルール（HP30%以下なら離れて攻撃・射程内なら最も弱い敵・ほかは最も近い敵）
- つよい：ルールを使わず、まだ動いていない全員の行動の候補（動ける先 × 技 × 相手）を比べる。与えるダメージの割合・たおせる見込み・動いた先で次に受けそうなダメージ（相手の動ける範囲と射程から）を点にし、攻撃できないときは岩をよけた歩数で近づく
- CPU の手持ちはシードと席から6体を選ぶ（技は最初の組）。乱数は使わず、同じ局面なら同じ手
- ヒントは「つよい」と同じ考え方

`npm run cpu-match -w games/pokemon-battle -- 100` の結果（各組100試合、同じ手持ちで先手後手を入れ替える）：

| 組 | 勝率 | 平均ターン |
|---|---|---|
| ふつう 対 やさしい | 64% | 5.7 |
| つよい 対 やさしい | 94% | 5.0 |
| つよい 対 ふつう | 92% | 5.3 |
| つよい 対 つよい | 50% | 6.4 |

## 決めたこと

- 盤は Issue の「10×8」を縦に置き、8列×10行にした（スマホ縦で、マスを大きくするため）。自分の軍を下に描く（オンラインの席1は上下左右を返して描く）
- ポケモンは24種、技は50種。実在の名前・タイプ・種族値・技の威力と命中を使い、射程はこのゲームで決めた（接触技は1、特殊技は2、大技は3で命中が低い）。追加効果（反動・能力の変化・状態異常・優先度・急所）は入れていない
- タイプ一致の威力アップ（1.5倍）は、Issue の簡易式にないので入れていない。計算は `public/js/damage.js` の `calcDamage` だけにまとめ、本家に寄せるときはここを差し替える
- 同じポケモンは手持ちに1体まで。岩（通れないマス）だけを置き、地形効果は入れていない。マップは3つ（点対称）からシードで選ぶ
- 「最も弱い敵」は残りHPがいちばん少ない敵。射程内に届く敵がいなければ、その敵へ近づいて待機する
- 待ったはない（命中と乱数の幅を見たあとに戻すと有利になる。`standards.skip.undo`）
- 結果の音：KO は `capture`、ほかの攻撃と待機は `place`、相手の手は `notify`、自分の番で `turn`

## オンライン対戦

- 共通のロビーから2人で遊ぶ（足りない席は CPU「つよい」）。先手とマップはシードで決める
- 始まると、両方の画面がそれぞれの編成（タイトルの「編成と戦術」で保存したもの）を送り、そろったら対戦に入る。そろうまで相手の手持ちは届かない。相手の戦術ルールは最後まで届かない
- 部屋を出た人の席は CPU が引き継ぐ（`onPlayerGone`）
- `public/js/online-config.js` の `DEPLOYED_SERVER_URL` は空（サーバーにこのゲームを載せてデプロイしたら書く）

## 開発

```bash
npm test -w games/pokemon-battle                       # ルール・再現・ヒント・オンライン・PWA のテスト
npm run cpu-match -w games/pokemon-battle -- 100       # CPU 同士の対戦
node scripts/online-e2e.mjs pokemon-battle --finish    # 2人分の画面でオンライン対戦を終わりまで
node scripts/layout-check.mjs pokemon-battle --sizes all
```

| ファイル | 中身 |
|---|---|
| `public/js/data.js` | タイプ相性・技・ポケモン（種族値と覚える技）・マップ・戦術ルールの条件と行動 |
| `public/js/damage.js` | ダメージ計算（差し替えられる独立の関数） |
| `public/js/rules.js` | 動けるマス・攻撃の候補・戦術ルールの評価（状態を変えない。ゲームとビューの両方に使える） |
| `public/js/game.js` | ルール本体。操作は `applyCommand` だけ。シード付きの乱数で、記録から再現できる |
| `public/js/game-view.js` | 席ごとのビュー（シード・対戦前の相手の編成・相手の戦術ルールを隠す） |
| `public/js/cpu-player.js` | CPU の3段階とヒント（`suggest`） |
| `public/js/game-controller.js` | ローカル対戦（保存と「続きから」） |
| `public/js/ui.js`・`team.js`・`help.js` | 画面・編成の保存・遊び方 |
| `public/js/sound/bgm.js` | BGM「バトルフィールド」 |
| `server/src/game-definition.js` | オンライン対戦の定義 |
