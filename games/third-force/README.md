# 3rd Force

条件と行動を並べて戦術を組み、兵器どうしの自動の戦いで勝ちを目指すゲーム。

[マメッコホームページ](http://mamecco.es.land.to/)の「3rd Force」を独自に実装したもの（もとは単独のリポジトリ `123yoshidandy/3rd-force` で、戦術を JS で書いて PR で足す形だった）。web-games に移すときに、戦術を JS のコードではなく、画面で並べる「条件 → 行動」のルールで組む形にした。兵器の絵は描き直した（自作の SVG）。

## 遊び方

- 兵器は左右の陣地から現れ、敵陣へ進んで撃ち合う。歩兵か爆撃機が敵陣に着くと、敵の体力を 100 減らす。先に体力を 0 にした方の勝ち。5000 tick（約 83 秒）で決着がつかなければ、体力の多い方が勝つ
- 戦いの最中に手は出せない。前もって組んだ**戦術**で勝負が決まる
- **出撃ルール**（最大 12 行）：上から見て、条件（2 つまで、AND）の合った最初の 1 行だけが動く。お金が足りない行に当たったら、そこで止めて貯める。出す場所がふさがっていれば次の行へ。行ごとに休み（0〜5 秒）を付けられる
  - 条件：いつでも・お金・脅威（自陣に近づいた敵。一番近い 1 体を「対象」にする。「この兵種で迎撃していない」も付けられる）・対象の高さの敵・数・体力・時間・確率
  - 行動：出撃（兵種かランダムを、対象の高さ・上端〜下端・ランダム・一番手薄に）・編成（名前を付けた最大 8 体の組）・ためる
- **兵器の動き**：兵種ごとのカードで、進む先（敵陣まで・射程の手前・中央・自陣の前）・間合い（前の同じ高さの敵から 20〜80 離れる）・退却（弾切れ・撃てる敵なし・体力 25/50% 以下）を選ぶ
- 退却した兵器は消え、出した費用が全額戻る。後ろへは半分の速さ。同じ高さ（±10）の前にいる敵だけを撃てる
- 「試す」は選んだ相手と 10 回戦った成績、「ヒント」は足すと強くなりそうな 1 行を出す
- 戦術は `#r=`、対戦は `#b=` の URL で共有できる。同じ戦術とシードなら、いつも同じ対戦になる

## CPU

組み込みの戦術は、どれもエディタで作れるルールで書いてある（`public/js/cpu-tactics.js`。写して直せる）。

| 強さ | 戦術 | 中身 |
|---|---|---|
| やさしい | ランダム | 原作の random.js。お金が 2000 たまったら、ランダムな兵種をランダムな高さに出す |
| ふつう | サンプル | 原作の sample.js。中央を越えた敵を、空ならミサイル、地上なら戦車で迎え撃ち、ときどき歩兵を出す |
| つよい | 攻め | 原作のつよい戦術の main.js。近い敵を迎え撃ち、お金が 10000 を越えたら編成で押す。兵種ごとに間合いと退却を決める |
| 守り | 守り | ロケット砲とミサイルで中央を守り、お金がたまったら戦車で守った歩兵を送る |

`npm run cpu-match -w games/third-force` で総当たりの勝率を出す（シードで決まるので、何度流しても同じ表になる）。並びは やさしい < ふつう < つよい。守りは崩しにくく、ふつう・つよいとは引き分けが多い。

原作の JS の戦術3本は、`test/reference-tactics.js` に関数の戦術として移してあり、ルールで書いた版と勝率が近いことをテストで確かめている。

## オンライン対戦

2段の提出型（netplay-kit の turn 型）。

1. 両方の席が戦術（共有コード）を出す。相手の戦術は、そろうまでビューに入らない
2. そろったら、サーバーがシードを作って対戦を流し、勝者を決める。ビューには記録（エンジンの版・シード・両方の戦術）が入り、端末は同じ対戦を手元で流して見せる

部屋はすべて公開。CPU の席と、抜けた人の席は、ロビーで選んだ組み込みの戦術を出す。再戦は全員の「もう1回」で始まり、勝ち数を引き継ぐ。観戦は 4 人まで。

## 決めたこと

- 原作のルールはそのまま（退却で費用が全額戻る・弾数の上限・後ろへは半分の速さ・5000 tick）
- 直したのは、決定性と遊べなくなる不具合だけ：乱数をシード付きにし（射撃・A のルール・B のルールの3本）、tick を固定した。重なりをよけて盤面の外へ出る（y を 0〜100 に収め、端では向きを変える）。終局後に出撃する。B の座標の反転を 180 度回転（x→200−x、y→100−y）にそろえ、どちらの席も同じ形で戦えるようにした
- 1 回の判断で動く出撃ルールは 1 行だけ（原作の戦術は、脅威の数だけ同時に出せた）
- 兵器の強化（原作のカスタマイズ）と、手で出撃する遊び方は、まだ入れていない。エンジンは戦術を関数でも受け取れるので、あとから足せる

## 開発

```bash
npm test -w games/third-force             # ルール・決定性・記録からの再現・共有コード・ヒント・オンライン・PWA
npm run cpu-match -w games/third-force    # 組み込みの戦術の総当たり
npm run check:browser -w games/third-force # ブラウザ（ヘッドレス Chrome）でも、決めた組の対戦のハッシュが node と同じか
node scripts/golden.mjs > test/golden.json # エンジンの版を上げたとき、決定性のテストの値を作り直す
```

- `public/js/battle.js`：対戦のシミュレーター（DOM・時刻・Math.random を使わない）。`createBattle`・`step`・`runBattle`
- `public/js/rules.js`：戦術の形・検証・評価。`public/js/codec.js`：共有コード
- `public/js/match.js`：記録（`applyCommand`・`replay`）。記録は `{ engine, seed, tactics }` だけ
- `public/js/cpu-suggest.js`：ヒントと「試す」（画面からは `hint-worker.js` の Web Worker で回す）
- 描画は requestAnimationFrame で、経過時間に合わせて 60 tick/秒で進める。描画の速さは対戦の中身に影響しない
