# アズール

タイルを集めて壁に並べるボードゲーム「アズール」（基本ゲーム）を、ブラウザで CPU と遊べるようにしたもの。2〜4人（あなた＋CPU 1〜3人）。スマホの縦・横、PC で遊べ、ホーム画面に追加すればオフラインでも遊べる。

絵・タイルの模様・画面はすべて自作。

## 遊ぶ

```bash
python3 -m http.server 8000 --directory public
# http://localhost:8000/ を開く
```

ビルドは要らない（素の HTML / CSS / ES Modules）。

## テスト

```bash
npm install
npm test             # Vitest
npm run bench:cpu    # CPU の強さと試合の長さを測る（node tools/cpu-bench.mjs [試合数] [名前で絞り込み]）
```

## 実装したルール（基本ゲーム）

- 工房の数：2人 5枚、3人 7枚、4人 9枚。各ラウンドの始めに袋から4枚ずつ並べる
- 袋が空になったら箱のふたのタイルを袋に戻して続ける。両方とも空なら、並べられた分でラウンドを始める
- 手番：工房か場の中央から1色を全部取る。工房の残りは中央へ。そのラウンドで中央から最初に取った人は先手マーカーも取り、床ラインの左に置く
- パターンライン：1段には同じ色だけ。壁の同じ段にもうある色は置けない。入りきらない分は床ラインへ。床ラインに直接置くこともできる
- 床ライン：−1 −1 −2 −2 −2 −3 −3。7つ埋まったあとのタイルは箱のふたへ
- 工房と中央が空になったらラウンドの終わり。全員、上の段から順に、埋まった段の1枚を壁へ移して得点（縦横につながった数。つながりがなければ1点）。残りは箱のふたへ。埋まっていない段は持ち越す。床の失点を引く（0点より下にはならない）
- 先手マーカーを取った人が次のラウンドの先手
- 誰かの壁で横1列がそろったラウンドの後にゲームの終わり。横1列 +2、縦1列 +7、同じ色5枚 +10
- 同点なら横の列が多い方が上。それも同じなら同じ順位（勝ちを分け合う）

灰色の壁（自由配置）の変種は入れていない。

### 解釈したところ

- 床ラインが7つとも埋まっているときに先手マーカーを取った場合：マーカーは床に置かず（失点なし）、次のラウンドの先手にはなる
- そのラウンドで誰も中央から取らなかった場合（工房がすべて1色ずつだったなど）：先手は変わらない
- すでに埋まった段を選んで全部を床へ落とす操作は受け付けない（床を選ぶのと結果が同じなので、床に置く操作にまとめた）
- 最初のラウンドの先手は、シードから決める（ランダム）

## CPU

`public/js/cpu-player.js`。打てる手を全部挙げ、手ごとに「このラウンドで得られそうな点数」（壁に置いたときの点数、埋まりそうかどうか、床の失点、先手マーカー、終盤の列・色のボーナスの見込み）を見積もって、いちばん高い手を選ぶ。

強すぎないように、人間らしい見落としを入れている。

| 強さ | 工房や中央を見落とす確率 | 見積もりのぶれ |
|---|---|---|
| やさしい | 40% | ±3.5点 |
| ふつう | 22% | ±1.6点 |

CPU の判断には、ゲームの乱数を使わない（状態から作った別の乱数を使う）。CPU だけの試合は、記録からそのまま再現できる。

測った結果（`npm run bench:cpu`、各 400 試合。strong は見落としもぶれもない同じ CPU、simple は置ける枚数が多く床に落ちる枚数が少ない手を選ぶだけの素朴な打ち方）：

| 組み合わせ | 結果 |
|---|---|
| ふつう 同士（2人） | 平均 51.8点、5.0 ラウンド・53.6 手 |
| ふつう 対 strong | ふつうの勝率 25% |
| ふつう 対 simple | ふつうの勝率 79%（52.6点 対 30.3点） |
| やさしい 同士（2人） | 平均 37.6点 |
| やさしい 対 ふつう | やさしいの勝率 25% |
| やさしい 対 simple | やさしいの勝率 59% |

壁の1段には1ラウンドに1枚しか入らないので、5 ラウンドが最短。CPU 同士ではほぼ最短で終わる。

## ファイル

| ファイル | 内容 |
|---|---|
| `public/js/game.js` | ルールと状態（DOM に依存しない）。操作は `applyCommand(seat, command)` に通し、`Game.replay` で記録から作り直せる |
| `public/js/game-view.js` | ビュー（そのプレイヤーから見てよい情報の JSON。袋は枚数だけ） |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦のコントローラー（`getView()` / `send(command)`）。途中経過の保存 |
| `public/js/main.js` | 画面と入力 |
| `public/js/motion.js` | タイルが飛ぶ動き |
| `public/sw.js` | Service Worker（オフライン） |
| `tools/cpu-bench.mjs` | CPU の強さを測る |

### オンライン対戦を入れるとき

netplay-kit の「サーバーがゲームを進める型」にそのまま差し込める形にしてある。

- `create`：`new Game(players, { seed })`
- `persist` / `restore`：`{ players, options: { seed }, commands }` と `Game.replay`
- `view`：`createGameView(game, seat)`
- 操作：`{ type: 'take', source, color, line }` の1種類。断る操作は状態を変えない
- CPU：`runCpuStep(game)`
