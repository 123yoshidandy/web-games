# サントリーニ

職人を動かして建物を建て、3段目に上った人が勝つボードゲーム「サントリーニ（Santorini）」を、ブラウザで CPU と遊べるようにしたもの。2人（あなたと CPU）か3人（あなたと CPU 2人）。初心者向けの神の力 10柱を選べる。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

絵（盤・建物・ドーム・職人・アイコン）は、すべて SVG で自作している。

## 遊び方

- 盤は 5×5。最初の手番はランダムで、最初の手番の人から順に、職人を2人ずつ空いたマスに置く
- 手番には、職人を1人選んで**動き**、その職人のまわりに**建てる**
  - 動く：まわり8マスへ1マス。上るのは1段まで、下りは何段でもよい。職人とドームのマスへは動けない
  - 建てる：動いた職人のまわり8マスの、職人もドームもないマスに1段。3段の上にはドーム
- 自分の番に、職人が3段目へ上ったら勝ち
- 番の初めに動ける職人がいないか、動いたあとに建てられなければ負け。3人では、負けた人の職人を取り除いて続け、最後に残った人が勝ち
- ブロックは 1段22・2段18・3段14・ドーム18 個まで。尽きた段は建てられない

### 神の力（2人のとき）

タイトルで「神：あり」にすると、それぞれが神の力を1つ持つ。自分の神は選ぶか「おまかせ」、CPU の神は自分と重ならないようにくじで決める。

| 神 | 力 |
|---|---|
| アポロン | 動くとき、相手の職人のいるマスへ動ける。相手の職人は、自分が今いたマスへ移る |
| アルテミス | 動くとき、もう1回動ける（元のマスへは戻れない） |
| アテナ | 自分の職人が上った次の相手の番には、相手は上れない |
| アトラス | 建てるとき、どの段にもドームを建てられる |
| デメテル | 建てるとき、もう1回建てられる（同じマスには建てられない） |
| ヘファイストス | 建てるとき、同じマスにもう1段ブロックを建てられる（ドームは不可） |
| ヘルメス | 職人が上りも下りもしないなら、2人とも何マスでも動け（動かなくてもよい）、そのあとどちらかが建てる |
| ミノタウロス | 動くとき、相手の職人のいるマスへ動ける。相手の職人は、まっすぐ後ろの空いたマスへ押し出す（段は問わない） |
| パン | 職人が2段以上下りても勝ち |
| プロメテウス | 上らないなら、動く前にも建てられる（動く前と後に建てる） |

押し出された（入れ替わった）職人は「動いた」とはみなさず、3段目に移っても勝ちにならない（公式のルールシートの「Forced is not moved」）。

### 決めたこと

- ルールは、ボードゲームアリーナのページと、公式のルールシート（第2版）で確かめた。神の力の文は、ルールシートに載っていないので、初心者向けの神のよく知られた公式の文に合わせた
- ブロックの数の上限は、部品の数どおりにした（尽きた段は建てられない）。第2版のルールシートでは「ブロックは無制限。尽きたら完成した塔を取り除いて、地面にドームを置く」となっている
- 神は2人戦だけ（3人戦で使えない神の決まりを確かめられなかったため）。4人戦（2対2のチーム戦）は入れていない
- 神の選び方は、公式の「チャレンジャーが2柱を選び、相手が先に取る」ではなく、自分で選ぶか「おまかせ」、CPU はくじにした。最初の手番も神に関係なくくじ
- 動いたあとに建てる先がない手も、ルールどおり選べる（選ぶと負け）
- ヘルメスで同じ段を続けて動くときは、上り下りする移動を選べない。最初の移動で上り下りしたら、ふつうの1回の移動になる
- プロメテウスで先に建てたときは、建てた職人が動く（その職人は上れない）

### 画面の操作

- 盤は、真上に近い角度から見下ろした形で、段は同心の四角と正面の帯で見せる。ドームは青い半球
- 自分の職人を押して選ぶと、動ける先に点が出る（動ける職人が1人なら自動で選ぶ）。動いたあとは、建てられる先に四角が出る
- 神の力で「動く」と「建てる」のどちらもできるとき（アルテミスの2回目の移動・プロメテウスの先に建てる・ヘルメス）は、下のボタンで切り替える。アトラスは「ドーム」のボタン、デメテル・ヘファイストスは「終える」のボタンが出る
- 名前を押すと、その人の神の力が見られる。自分の欄の「残り」は、1段・2段・3段・ドームのブロックの残り
- 相手の前の番に動いた・建てたマスは、水色の線で示す
- 遊び方を開いている間は、CPU が止まる。途中でホームに戻っても、「続きから」で再開できる

## CPU

手番を「動く→建てる」（神の力の追加の操作を含む）の操作の列として数え上げ、同じ結果になる列は1つにまとめて比べる。局面の値打ちは「自分の職人の良さ − 相手（3人では一番良い相手）の職人の良さ」で、職人の良さは、段の高さ・上れる先・2段にいて隣に3段がある（次に勝てる）・中央への近さ。次に動く人が次に勝てる形なら、ほぼ勝ちとみる。

- やさしい：自分の番だけを読む。誰の番かを見ずに評価し（相手の勝ち筋を見落とすことがある）、評価の揺れが大きく、ときどき3番目までの手を選ぶ
- ふつう：相手（3人では次の人）の応手まで読む。3人では、2つ先の人に勝ち筋を残す手を避ける
- どちらも、すぐ勝てる手は見逃さない。置く番は、中央に近く相手に近いマスを選ぶ
- 1手番の考える時間は 0.8 秒で打ち切る。神がないときは 20ms ほど。ヘルメスは歩き方の組み合わせが多いので、調べる数に上限を付け、打ち切りに届くことがある

CPU 同士の結果（`scripts/cpu-match.mjs`。席を回して対戦）：

| 対戦 | 試合 | 結果 |
|---|---|---|
| ふつう 対 やさしい（神なし） | 200 | ふつう 159勝・やさしい 41勝 |
| ふつう 対 ふつう（神なし） | 100 | 59勝・41勝（最初の手番の人の勝ち 45） |
| ふつう 対 やさしい（両者おまかせの神） | 100 | ふつう 68勝・やさしい 32勝 |
| ふつう1・やさしい2（3人） | 90 | ふつう 55勝・やさしい 5勝と30勝 |
| やさしい 対 でたらめ | 20 | やさしい 20勝 |

どの対戦でも、終わらない試合・進まなくなった試合はなかった。

```bash
# 試合数・強さ（easy・normal・random）を2つ（2人）か3つ（3人）・神（2人のみ。例 apollo,pan、all は両者おまかせ、- はなし）
node scripts/cpu-match.mjs 100 normal,easy
node scripts/cpu-match.mjs 40 normal,easy all
node scripts/cpu-match.mjs 30 normal,easy,easy
```

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm install
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/rules.js` | ルールの中身（選べる操作・操作を当てる・神の力・勝ち負け）。CPU の先読みでも使う |
| `public/js/game.js` | 進行と記録。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる。神の名前と力の文 |
| `public/js/game-view.js` | 見る人ごとのビュー（手番の人には選べる操作の一覧を付ける） |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`art.js` | 画面・絵 |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |

### オンライン対戦を入れるとき

ルールとビューは、netplay-kit の「ゲームの定義」の形（`server/src/game-definition.js`）で用意してある。2人か3人で始め、CPU の強さと神の力（なし・おまかせ）を部屋の設定に持つ。netplay-kit の `sync.mjs` で部屋の処理を写し、この定義を `createHandler` と `startDevServer` に渡す。画面は、ローカル対戦と同じ `getView()` / `send()` の形のオンライン用のコントローラーを足す。
