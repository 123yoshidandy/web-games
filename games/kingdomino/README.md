# キングドミノ

ドミノをつないで 5×5 の王国を作るボードゲーム「キングドミノ」（基本ゲーム）を、ブラウザで CPU と遊べるようにしたもの。2〜4人（あなた＋CPU 1〜3人）。スマホの縦・横、PC で遊べ、ホーム画面に追加すればオフラインでも遊べる。

絵（地形・城・王冠）と画面はすべて自作。

## 遊ぶ

```bash
python3 -m http.server 8000 --directory public
# http://localhost:8000/ を開く
```

ビルドは要らない（素の HTML / CSS / ES Modules）。

## テスト

```bash
npm install
npm test             # Vitest
npm run bench:cpu    # CPU の強さを測る（node tools/cpu-bench.mjs [試合数] [名前で絞り込み] [--rules]）
```

## 実装したルール（基本ゲーム）

- ドミノは 48 枚（番号 1〜48）。2人は 24 枚、3人は 36 枚、4人は 48 枚を使う（残りは見ずに箱へ）
- 王様の駒：2人は1人2つ、3・4人は1人1つ。並びは王様の数（2・4人は4枚、3人は3枚）
- 並びは山から引いて番号の小さい順に並べ、表にする
- 最初の並びには、王様をランダムな順に置く。そのあと次の並びを出す
- 手番：今の並びの、番号の小さいドミノに乗った王様から順に、次の並びのドミノを選んで王様を移し、王様が離れたドミノを自分の王国に置く。最後の並びは置くだけ
- 置き方：どちらかのマスが、城か同じ地形のマスに縦横で接していること。城を含めて 5×5 に収めること。重ねない
- どこにも置けないドミノは捨てる。置ける場所があるときは捨てられない
- 得点：同じ地形がつながった領域ごとに「マスの数 × 王冠の数」の合計
- 同点：最大の領域（マスの数）が広い方、それも同じなら王冠の合計が多い方、それも同じなら勝ちを分け合う
- 追加ルール（タイトルで選ぶ。既定はオフ）
  - 中王国：城が 5×5 の真ん中にあれば +10点
  - 調和：1枚も捨てなければ（＝5×5 が埋まれば）+5点

ドミノの内訳は、地形ごとのマスの数（小麦畑 26・森 22・湖 18・草原 14・沼地 10・鉱山 6）と王冠の数（5・6・6・6・6・10）が公式の合計と合うことをテストで確かめている。

### 解釈したところ

- 手番の中の順番は「次のドミノを選ぶ → 今のドミノを置く」にした（王様を次の並びへ移すと、離れたドミノを置く、という流れ）
- 中王国の「真ん中」は、王国の範囲が城から上下左右に2マスずつ（-2〜2）のとき。捨てたドミノがあって 5×5 が埋まっていなくても、範囲が届いていれば真ん中とする
- 調和は「1枚も捨てていない」で判定する（全員が12枚を扱うので、捨てなければ必ず 5×5 が埋まる）

## CPU

`public/js/cpu-player.js`。

- 置く：置ける場所ごとに「得点と、王冠のある領域の伸びしろ（隣の空きマス）の増え方」「埋められなくなる空きマス」「中王国のとき、城が真ん中から外れるか」を見積もる
- 選ぶ：並んだドミノごとに「今の王国に置いたときのいちばんよい見積もり」「王冠の数」「番号の小ささ（次の回に先に選べる）」を見積もる
- 強すぎないように、置ける場所やドミノの見落としと、見積もりのぶれを入れている

| 強さ | 見落とす確率 | 見積もりのぶれ |
|---|---|---|
| やさしい | 35% | ±2.2点 |
| ふつう | 12% | ±0.8点 |

CPU の判断には、ゲームの乱数を使わない（状態から作った別の乱数を使う）。

上の帯の電球（ヒント）を押すと、見落としもぶれもない CPU が選ぶ手を、金の枠で示す（置く番なら、その場所と向きを選んでおく）。上の帯の一覧のボタンで、これまでの履歴を見られる。

測った結果（`npm run bench:cpu`、各 300 試合。strong は見落としもぶれもない同じ CPU、simple は「その場の得点がいちばん増える場所に置き、王冠の多いドミノを選ぶ」素朴な打ち方）：

| 組み合わせ | 結果 |
|---|---|
| ふつう 同士（2人） | 平均 30.4点、48手 |
| ふつう 同士（4人） | 平均 34.5点、96手 |
| ふつう 対 strong | ふつうの勝率 37% |
| ふつう 対 simple | ふつうの勝率 46% |
| やさしい 対 ふつう | やさしいの勝率 32% |
| やさしい 対 simple | やさしいの勝率 31% |
| ふつう 対 random | ふつうの勝率 98% |

### オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜4人で、足りない席は CPU で埋められる。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

追加ルール（中王国・調和）はロビーで決める。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'kingdomino' })`。web-games の1つのスタックから `?game=kingdomino` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
