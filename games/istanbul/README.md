# イスタンブール

商人と助手を動かして市場の16の場所を回り、品物とお金を集めてルビーを競うボードゲーム「イスタンブール（Istanbul、基本セット）」を、ブラウザで CPU と遊べるようにしたもの。2〜5人（あなた＋CPU 1〜4人）。スマホの縦持ち向け（PC でも遊べる）。ホーム画面に置くと、オフラインでも遊べる。

絵（品物・ルビー・駒）は、すべて SVG で自作している。

## 遊び方

- 4×4に並べた16の場所が盤になる。並びは「基本」（ルールブックが最初に勧める短い道）・「番号順」・「ランダム」（噴水は真ん中の4マス、闇市と茶屋は3マス以上離す）から選ぶ
- 手番では、商人を1〜2マス動かす（斜めは2マス）。行き先に自分の助手がいれば連れ戻し、いなければ助手を1人置いて、その場所の行動をする。連れている助手がいなければ行動できない（噴水だけは助手なしで行動できる）
- 行き先にほかの商人がいれば、1人に2リラずつ払う（噴水では払わない）。2人のときは、中立の商人が3つ（小モスク・大モスク・宝石商）にいて、払ったらサイコロで動く
- 行動のあと、ほかの人の家族（警察署へ送って3リラかカード）・総督（2リラか手札1枚でカード）・密輸人（2リラか品物1つで好きな品物）に会う。総督と密輸人は、使われたらサイコロで動く
- 16の場所：手押し車工房・布／香辛料／果物の倉庫・郵便局・隊商宿・噴水・闇市・茶屋・大市場・小市場・警察署・スルタンの宮殿・小モスク・大モスク・宝石商
- ボーナスカード26枚（10種類）。自分の番ならいつでも使える
- だれかのルビーが5個（2人なら6個）になったら、そのラウンドの最後の人まで遊んで終わり。ルビーの数で決め、同じならリラ → 品物 → カードの多い順。残ったカードのうち、5リラと品物のカードは使ってから比べる

ルールは基本セットの英語版ルールブック（AEG）に合わせた。部品の数値（郵便局のマス、需要タイル、宮殿の品物の並び、宝石商の値段、ボーナスカードの内訳）は、図からしか読めないので、ルールブックの図と、公開されている複数の実装を照らし合わせて決めた。

| 部品 | 数値 |
|---|---|
| 宝石商の最初の値段 | 2人 15・3人 14・4〜5人 12。23 まで買える |
| 宮殿 | 宝石・布・香辛料・果物・好きな品物 を2周（10マス）。最初に要るのは2〜3人で5マス、4〜5人で4マス |
| モスクのタイル | 2・3・4・5個の山（3人は5を除く、2人は3と5を除く）。ルビーは1人1個（5人は4個） |
| 手押し車 | 品物ごとに2つから、7リラの拡張で5つまで。3つ目の拡張でルビー |

### ルールブックに書かれていないので決めたこと

- 行き先に自分の助手がいないとき、助手は必ず置く（置かずに番を終える選択は省いた）
- 出会いの順は、家族 → 総督 → 密輸人に固定する
- 「3〜4マス動く」のカードは、縦横に数えた距離が3か4の場所へ動ける
- 「居残り」のカードは、今の場所に助手をもう1人置いて、もう一度行動する
- 宮殿の「好きな品物」のマスは、多く持っている品物から払う
- ボーナスカードは、行動の途中（隊商宿で引いている間・サイコロ・闇市の品物選び）には使えない
- 宝石商の最初の値段と宮殿の最後の段は、実装によって違ったので、多い方に合わせた

### 画面

- 光っている場所をタップして動かす。ほかの商人がいる場所には、払うリラ（−2 など）を出す
- 行動の選択は、下の操作の欄のボタンか、下から出るシート（茶屋の賭け・市場で売る数・密輸人など）で答える
- 場所を長押し（PC では右クリック）すると、くわしい説明と、今の値段や要る品物が出る
- 手札をタップすると説明が出て、使えるときは使える
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

自分から見える情報だけで手を決める（ほかの人の手札・山札の並び・これから出るサイコロの目は見ない。先読みの写しでは、山札とサイコロを CPU 専用の乱数で混ぜ直す）。行き先ごとに、その番の行動の候補を写しの上で試し、盤面の点数（ルビー・リラ・品物・ルビーへの近さ）が一番上がる手を選ぶ。

| 強さ | 中身 |
|---|---|
| やさしい | その番の行動だけを見る。揺れと、ときどきの見当違いの移動を混ぜる |
| つよい | その番の行動に加えて、次の番に届く場所での行動までを見る |

CPU 同士の対戦（並びは基本）：

| 対戦 | 試合数 | つよいの勝率 | 公平なら |
|---|---|---|---|
| 2人：つよい1 対 やさしい1 | 100 | 97.0% | 50% |
| 3人：つよい1 対 やさしい2 | 100 | 89.0% | 33.3% |
| 4人：つよい1 対 やさしい3 | 60 | 75.0% | 25% |
| 5人：つよい1 対 やさしい4 | 60 | 76.7% | 20% |
| 2人：やさしい1 対 でたらめ1 | 100 | やさしい 100% | 50% |

```bash
# 試合数・人数・席ごとの強さ（easy・hard・random はでたらめ）・並び（short・order・random）
node scripts/cpu-match.mjs 100 3 hard,easy,easy short
```

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/data.js` | 場所・並び・需要タイル・宮殿と宝石商の値・ボーナスカードなどの数値 |
| `public/js/game.js` | ルール。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー（ほかの人の手札は枚数だけ） |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`art.js` | 画面と絵 |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |

### オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜5人で、足りない席は CPU で埋められる。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'istanbul' })`。web-games の1つのスタックから `?game=istanbul` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
