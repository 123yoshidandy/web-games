# ティチュー

2対2のチームで手札を出し切るカードゲーム「ティチュー（Tichu）」を、ブラウザで CPU と遊べるようにしたもの。4人（あなた＋CPU 3人。向かいの CPU が味方）。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

絵（カード・色の印・特別な4枚・アイコン）は、すべて SVG で自作している。

## 遊び方

- カード：4色（翡翠・剣・宝塔・星）×2〜A の52枚と、特別な4枚（麻雀・犬・不死鳥・竜）
- 8枚ずつ配り、各自が大ティチュー（200点）を宣言するか決める。残りの6枚を配る
- 左・向かい（味方）・右の3人に1枚ずつ渡す
- 小ティチュー（100点）は、自分の最初の札を出す前ならいつでも宣言できる（大ティチューを宣言した人を除く）。宣言した人が1番目に上がれば得点、上がれなければ失点
- 麻雀を持つ人から出す。出せる組は、1枚・ペア・連続したペア（2組以上）・3枚組・フルハウス・5枚以上の階段。前の組と同じ形（同じ長さ）のより強い組を出すか、パス。ほかの人が続けて全員パスしたら、最後に出した人が場を取って次を出す（上がっていれば、その次の人）
- 爆弾（同じ数の4枚・同じ色の5枚以上の階段）は、場に組があれば、自分の番でなくても出せる。爆弾どうしは枚数、次に数で比べる
- 麻雀：1として出す（1枚でも、階段の1としても）。出すとき、2〜A の数を願える。願いの数を持ち、場に出せる組（爆弾や、不死鳥を使った組も含む）にできる人は、出さなければならない（番でないときの爆弾は別）。不死鳥を願いの数の代わりにしても、願いは満たされない
- 犬：最初に1枚だけで出し、味方に出す番を渡す（味方が上がっていれば、その次の人）
- 不死鳥：1枚出しなら直前の札の 0.5 上（最初に出せば 1.5）。竜には勝てない。組の中では 2〜A の好きな数の代わり（爆弾には使えない）
- 竜：1枚出しでいちばん強い。竜で取った場は、相手のどちらかに渡す
- 1人だけ札が残るか、味方どうしが1・2番目に上がったら、ラウンドの終わり
  - ダブル勝利（味方どうしが1・2番目）：200点。札の点は数えない
  - それ以外：最後の人の手札は相手のチームへ、取った札は1番目に上がった人へ。札の点（5は5点、10とKは10点、竜25点、不死鳥−25点）を数える
- どちらかのチームが目標の点（1000点。500点も選べる）に届き、点が違えばゲームの終わり。同じならもう1ラウンド

ルールは、出版社（Fata Morgana）の英語のルールと、ボードゲームアリーナの遊び方のページで確かめた。

### 決めたこと

- 不死鳥を使った組の読み方は自動で決める（場に勝てる読み方の中で、いちばん強いもの）。例：2-2-不死鳥-A-A は A のフルハウス
- CPU は自分の番でだけ爆弾を出す（あなたは、番でなくても出せる）
- ラウンドの最後の手で竜が場に残ったまま終わったときは、その場を、札の残っている相手（いなければ席の順で先の相手）に渡す
- 犬の札は、出した人の取った札に入れる（0点なので点には響かない）
- 目標点は 1000 点を既定にした（ボードゲームアリーナの既定は確かめられなかった。500点の「半分のゲーム」があることは確かめた）

### 画面の操作

- 手札は数の順。8枚を超えたら2段に並べる。札を押して選ぶか、下の組の候補を押すと、その札がまとめて選ばれる。出せない選び方なら、出すボタンに理由が出る
- 札を渡す場面では、押した順に「左へ・味方へ・右へ」の印が付く。もらった札には「左から」などの印が付く（最初の札を出すまで）
- 麻雀を出すと、願う数を選ぶ画面が出る。竜で場を取ると、渡す相手を選ぶ画面が出る
- 番でないときに出せる爆弾があれば、組の候補に出て、「爆弾を出す」で出せる
- 各席には、残りの枚数・宣言（成功・失敗）・取った札の点・上がった順と、この場で最後にしたこと（出した組かパス）が出る。場には、最後の組・出した人・場の点・願いの数が出る
- ラウンドの終わりに、札の点・宣言・合計の表が出る。結果・遊び方・記録を開いている間は、CPU が止まる
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

手札を組に分け（爆弾 → 階段 → 連続ペア → 3枚組・フルハウス → ペア → 1枚）、組の数と強い札（竜・不死鳥・A・爆弾）で手札の強さを測る。

- 宣言：最初の8枚が強ければ大ティチュー、14枚が強ければ最初の札を出す前にティチュー。味方が宣言していればしない
- 渡す：味方には強い札（自分が宣言したら弱い札）、相手にはばらの弱い札（犬は相手へ）
- 出す：最初に出すときは弱い組から（枚数の多い組を先に）。味方が宣言していたり上がりに近ければ、犬で味方に番を渡す。続けて出すときは、味方の場には重ねない。相手の場には、組を崩さずに出せるいちばん弱い組で勝つ。相手が宣言している・上がりそう・場の点が多い・味方が宣言しているときは、強い札や爆弾も使う
- 竜の場は、札の多い相手に渡す。麻雀では、自分の持っていない高い数を願う
- やさしい：犬と爆弾を作戦に使わず、宣言は少なく、ときどき気まぐれにパスする

```bash
# 試合数・チームごとの強さ（easy・normal・random）・目標点。試合ごとに席を入れ替える
node scripts/cpu-match.mjs 100 normal,easy 1000
```

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm install
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/cards.js` | カードと組（判定・強さ比べ・手札から出せる組を並べる） |
| `public/js/game.js` | 進行と点の数え方。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`art.js` | 画面・絵 |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |
| `server/src/handler.js` | オンライン対戦のサーバーの入口（AWS Lambda） |
| `public/js/online-config.js` | オンライン対戦の接続先 |
| `public/js/netplay/` | netplay-kit のクライアントとロビーの画面の写し（同期で置く。手で直さない） |

### オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。4人（2人ずつの組）で、足りない席は CPU で埋められる。ほかの人の手札はビューに入れない。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'tichu' })`。web-games の1つのスタックから `?game=tichu` で呼ばれる）
- ゲームの定義は `server/src/game-definition.js`（記録だけを保存して再現する。各席には、その席から見えるビューだけを送る）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
