# サイズ -大鎌戦役-

メック・指導者・労働者で領地を広げ、6つの星を目指すボードゲーム「サイズ -大鎌戦役-（Scythe）」を、ブラウザで CPU と遊べるようにしたもの。2〜5人（あなた＋CPU 1〜4体）。スマホの縦持ち向け（PC では地図を左、マットを右に並べる）。ホーム画面に置くと、オフラインでも遊べる。

地図・駒・アイコンは、すべて SVG で自作している。

## 遊び方

- 手番では、プレイヤーマットの区画を1つ選び、その区画の上段と下段を順に行う（どちらも省ける）。前の手番と同じ区画は選べない
  - 上段：移動（2体を1マス。代わりに金1）／生産（労働者のいる2か所）／交易（金1で資源2つか人気1）／支持（金1で力2かカード1）
  - 下段：アップグレード（石油）／展開（金属でメック）／建設（木材で建物）／募集（食料で新兵）。行うとマットに書かれた金をもらう
- 地図：山（金属）・森（木材）・農場（食料）・ツンドラ（石油）・村（労働者）・湖・工場。川は渡れず、湖には入れない。トンネルどうしは隣り合う
- 資源は、支配する領地（自分のユニットがいる、または自分の建物がある領地）にあれば、どこからでも使える
- 指導者が遭遇の印に止まると、遭遇カードの3つの選択肢から1つを選ぶ。工場に初めて着くと、工場カード（5つ目の区画）をもらう
- 指導者かメックが、ほかの人の指導者かメックのいる領地に入ると戦闘。力（0〜7）と戦闘カード（その領地の指導者とメックの数まで）を伏せて選び、合計の大きい方が勝つ（同点は仕掛けた方）。負けた方のユニットは本拠地へ退く。勝つと星（2つまで）
- 労働者だけの領地に入ると、労働者は本拠地へ退き、入った人は1人につき人気が1下がる
- 星：アップグレード6回／メック4体／建物4つ／新兵4人／労働者8人／目標1枚／戦闘の勝利（2つまで）／人気18／力16
- だれかが6つ目の星を置いたらその場で終わり。金＋人気の段に応じた星・領地・資源の点＋建物の得点のタイルの合計が一番多い人の勝ち

| 人気 | 星1つ | 領地1つ | 資源2つ |
|---|---|---|---|
| 0〜6 | 3 | 2 | 1 |
| 7〜12 | 4 | 3 | 2 |
| 13〜18 | 5 | 4 | 3 |

工場は領地3つ分として数える。

### 勢力（基本セットの5つ）

| 勢力 | 力・カード | 能力 | メックの能力 |
|---|---|---|---|
| ノルディック | 4・1 | 泳ぐ：労働者が川を渡れる | 渡河（森・山）・航海・砲撃・速さ |
| ルスヴィエト | 3・2 | 不屈：前と同じ区画を選べる | 渡河（農場・村）・町・人民軍・速さ |
| ポラニア | 2・3 | 放浪：遭遇で2つまで選べる | 渡河（村・山）・潜水・友愛・速さ |
| クリミア | 5・0 | 徴発：1手番に1回、戦闘カードを資源1つの代わりにできる | 渡河（農場・ツンドラ）・旅路・偵察・速さ |
| サクソニー | 1・4 | 支配：目標と戦闘の星に上限がない | 渡河（森・山）・地下道・武装解除・速さ |

プレイヤーマットは 工業・技術・愛国・機械・農業 の5つ。手番の順はマットの番号の小さい順。本家で使わない組み合わせ（ルスヴィエト＋工業、クリミア＋愛国）は、おまかせのときに避ける。

### 本家から割り切ったこと・自分で決めたこと

- **数値とカードは自作。** マットの費用・金・人気、地図の配置（地形・川・トンネル・遭遇の印の位置）、遭遇カード16枚・工場カード12枚・目標カード13枚・建物の得点のタイル5種は、本家の構成に合わせて自作した。本家の数値とは同じではない
- 遭遇カードは「もらう／金を払う／人気を払う」の3択で、もらえるのは金・人気・力・カード・資源・労働者だけ（本家にある「無料で下段を行う」などの選択肢はない）
- 工場カードは、上段が「払ってもらう」、下段が「1体を2マスまで動かす」の形にそろえた。工場では3枚から1枚を選ぶ
- 戦闘の前の能力（砲撃・偵察・武装解除）は、使えるときは自動で使う
- クリミアの徴発は、資源が1つ足りないときに自動で使う
- 支払う資源は、多く置いてある領地から自動で取る
- 移動で資源を運ぶのは「その領地から最後に離れるユニット」が自動で全部運ぶ。メックが運ぶ労働者の数は、画面で選べる
- 目標は、満たしたときに自動で公開する（1枚まで。サクソニーは2枚とも）
- 生産の費用は、盤上の労働者が4人以上で力1、6人以上で人気1、8人で金1
- 建物は湖と工場には建てない。湖は支配する領地として数えない
- 同点の勝ちは分け合う
- 万一終わらないときのため、全員の手番の合計が 400 で終わる（CPU 同士の試合では一度も起きていない）

## 画面

- 地図は2本指かホイールで拡大、ドラッグで移動。右上のボタンでも拡大・縮小・全体表示
- 移動は、動かすユニットのいる領地をタップ（もう一度タップで指導者・メック・労働者を切り替え）→ 光った行き先をタップ、を繰り返し、「移動を決める」でまとめて行う
- 生産・交易・展開・建設は、光った領地をタップして選ぶ
- 戦闘・遭遇・工場はダイアログで選ぶ
- 上の勢力の札をタップすると、その人の能力・星・アップグレード・メック・目標（自分のだけ）が見られる
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

自分から見える情報だけ（ほかの人の戦闘カードの数字・目標・山札の並びは見ない）で選ぶ。区画ごとに上段の候補と下段の候補を写しの上で試し、盤面の評価（金・星・星までの進み具合・使い道のある資源・領地・生産の見込み・指導者から遭遇の印までの近さ）が一番上がる組み合わせを選ぶ。戦闘は、相手の力と使えるカードの枚数から強さを見積もり、勝てそうなときだけ仕掛ける。ゲームの乱数は使わない。

| 強さ | 中身 |
|---|---|
| やさしい | ゆらぎが大きく、移動は1体ずつ。上段の候補を1つだけ見て下段を決める。戦闘の見積もりが甘い |
| ふつう | 上段の候補の上位3つと下段を組み合わせて比べる。移動は2〜3体を組み立てる |

CPU 同士の対戦：

| 対戦 | 試合数 | ふつうの勝率 | 公平なら |
|---|---|---|---|
| 2人：ふつう 対 やさしい | 100 | 74.5% | 50% |
| 3人：ふつう1 対 やさしい2 | 50 | 66.0% | 33.3% |
| 4人：ふつう1 対 やさしい3 | 30 | 58.3% | 25% |
| 5人：ふつう1 対 やさしい4 | 30 | 51.7% | 20% |

どの組み合わせも、全試合が6つ目の星で終わった（手番の上限に達した試合はない。ふつう同士の2人戦 100 試合・4人戦 30 試合も同じ）。1人あたりの手番は平均 31〜36。

```bash
# 試合数・人数・席ごとの強さ（easy・normal）
node scripts/cpu-match.mjs 100 2 normal,easy
```

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜5人で、勢力と個人ボードは部屋が決め、足りない席は CPU で埋められる。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'scythe' })`。web-games の1つのスタックから `?game=scythe` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest。モノレポの直下で）
npm test -w games/scythe
```

| ファイル | 役割 |
|---|---|
| `public/js/data.js` | 勢力・マット・地図・カードのデータ |
| `public/js/rules.js` | 盤面だけで決まるルール（移動できる先・支配・資源・得点・目標）。ゲームとビューの両方に使う |
| `public/js/game.js` | 進行。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー（ほかの人のカードの数字・目標・戦闘の選択は伏せる） |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/board-view.js` | 地図の描画と、拡大・移動・タップ |
| `public/js/ui.js` | 画面 |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |
| `server/src/handler.js`・`public/js/online-config.js`・`public/js/netplay/` | オンライン対戦のサーバーの入口・接続先・netplay-kit の写し |
