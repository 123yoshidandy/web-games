# ごきぶりポーカー

虫のカードを「これは○○」と押しつけ合う、はったりのカードゲーム「ごきぶりポーカー（Kakerlakenpoker／Cockroach Poker、Jacques Zeimet、Drei Magier Spiele 2004）」の基本ゲームを、ブラウザで CPU と遊べるようにしたもの。2〜6人（あなた＋CPU 1〜5人）。スマホの縦持ち向けで、スクロールなしで1画面に収まる。ホーム画面に置くと、オフラインでも遊べる。

虫の絵とアイコンは、すべて SVG で自作している（公式の画像は使っていない）。説明の文も自分で書いたもので、公式の文は写していない。

## 遊び方（基本ゲーム）

- 8種の虫（ゴキブリ・ネズミ・コウモリ・ハエ・カエル・サソリ・カメムシ・クモ）×8枚の64枚を、全部伏せて配る。割り切れなくてよい
- 親は手札から1枚を伏せてだれかに渡し、「これは○○」と虫の名前を言う。本当でも嘘でもよい
- 受けた人は、次のどちらか
  - **受ける**：「本当」か「うそ」と答えて表にする。当たれば渡した人が、外れたら受けた人が、そのカードを自分の前に表で置く
  - **見て回す**：こっそり見てから、まだ見ていない人に伏せて渡し、同じ虫か別の虫を言う。全員が見たカードは、受けるしかない
- カードを置いた人が、次の親になる
- 自分の前に同じ虫が4枚たまった人、または親になったのに手札がない人の負け。ほかの全員の勝ち
- **2人のとき**：最初に10枚を伏せたまま除く（だれも見ない）。見て回すことはできない。同じ虫が5枚で負け

### 資料と、資料で分からない点の決め方

ルールは、Drei Magier Spiele のルールブック（ドイツ語版。準備・進め方・終わり・「2人のときのルール」）を読んで合わせた。名前は日本語版の呼び方（ゴキブリ・ネズミ・コウモリ・ハエ・カエル・サソリ・カメムシ・クモ）にした。

資料の食い違い：

- 2人のとき：ドイツ語版のルールブックでは「10枚を除く・回せない・5枚で負け」。一方、続編の「ごきぶりポーカー・ロイヤル」のレビューには「前のカードが5枚以上で負け」という2人の変種が書かれている。これはロイヤルの決まりなので、基本ゲームのルールブックに合わせた
- ルールの紹介ページ（英語）には、だれが次の親になるかが書かれていないものがある。ルールブックの「カードを引き取った人が、次の回の親」に合わせた
- ドイツ語版の虫は Kröte（ヒキガエル）だが、日本語版の呼び方に合わせて「カエル」にした
- 日本語の紹介記事には「最初の親は不利なので、じゃんけんで負けた人などにする」とある。ルールブックには最初の親の決め方がない

自分で決めた点：

- **最初の親はランダム**（シードから決める）。配るのは親から順に1枚ずつで、割り切れない分は親から順に1枚多い（3人なら親が22枚、ほかが21枚）
- **親はだれにでも渡せる**。手札がない人にも渡せる（手札がない人は、受けて外すと親になって負ける）
- **回すときの「まだ見ていない人」に、最初に渡した親は入らない**（親はカードを見ている）。見てから回すと決めたら、受けることには戻れない
- **4枚目と、手札なしで親になるのが同時のとき**は、4枚そろったことを負けの理由として出す（どちらでも負けは同じ）
- 1回で出る負けは1人だけ。順位はつけない（結果の画面では、負けた人を最後に、前のカードが少ない順に並べる）

### 画面の操作

- 上に相手の欄（名前・手札の枚数・前に置いたカード）。前のカードは虫ごとの枚数で、あと2枚で負けるものは黄色、あと1枚のものは赤く光る
- 自分の番（親）は、下の手札（虫ごとの枚数）からカードを選び、上の相手の欄を押して相手を選び、最後に「何と言うか」の8つのボタンから虫を選ぶと渡す。2人のときは相手を選ぶ手間はない
- 受けたら「本当」「うそ」「見て回す」。見て回すと、真ん中にカードが表で出るので、まだ見ていない人（光る欄）と言う虫を選ぶ。見た人の欄には目の印が付く
- 真ん中に、今だれからだれへ何と言って渡したか、終わった回の結果（当たり・外れとだれが引き取ったか）を出す。右上のボタンで記録が見られる
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

## CPU

強さは「ふつう」と「やさしい」。CPU は自分の席のビュー（自分の手札、全員の前のカード、終わった回の記録、自分が見た伏せたカード）だけを見て決め、ほかの人の手札や伏せたカードの中身はのぞかない（`chooseCommand(view, level, rand)`）。CPU の迷いにはゲームの乱数を使わない（記録の再現がずれないように）（`public/js/cpu-player.js`）。

**ふつう**

- **答える**：言われた虫が本当である確率を出す
  - 見えていない枚数：8枚から、自分の手札と全員の前のカードを引く。0枚なら確実な嘘なので「うそ」
  - 言った人の正直さ：終わった回では、言った人が全員カードを見ているので、言ったことが本当だったかが分かる。その割合（少ないうちは 45% に寄せる）を、見えていない枚数の多さで補正する
  - そのうえで、外れて自分が引き取る痛さ（自分の前にその虫が何枚あるか。負けになるなら最大）と、当たって渡した人に引き取らせる得を比べて「本当」か「うそ」を選ぶ。どちらも分が悪いとき（外れると負ける、迷う）は、回せるなら見てから回す
- **渡す**：相手が負けに近い虫を、自分が引き取っても怖くない範囲で選ぶ（当てられたら自分が引き取るため）。言う虫は、相手がこれまで「本当」と答えやすい人なら嘘に、「うそ」と答えやすい人なら本当に寄せ（25〜75%）、はったりを混ぜる。嘘で言う虫は、相手の前に多い虫を選びやすい
- **回す**：見たカードを、その虫で負けに近い人へ回す。言う虫は渡すときと同じ

**やさしい**：答えはほぼ当てずっぽう（見えていない枚数が0の虫を言われたときだけ、6割で「うそ」）。回せるときは 15% で見て回す。渡すカード・相手・言う虫はでたらめ（本当と嘘は半々）。

```bash
# 試合数・人数・席ごとの強さ（easy・normal）。最初の親は試合ごとに入れ替える
node scripts/cpu-match.mjs 1000 3 easy,normal,easy
```

負けは1人なので、勝率は「100% − 負けた割合」。

| 対戦 | 試合数 | ふつうの負け | やさしいの負け | 回の数の平均 |
|---|---|---|---|---|
| 2人（やさしい・ふつう） | 2000 | 20.4% | 79.6% | 29.8 |
| 2人（ふつう・やさしい） | 2000 | 18.9% | 81.1% | 29.7 |
| 3人（やさしい・ふつう・やさしい） | 1000 | 5.5% | 47.9%・46.6% | 20.9 |
| 4人（やさしい・ふつう・やさしい・ふつう） | 1000 | 7.8%・8.0% | 40.8%・43.4% | 19.9 |
| 6人（やさしいとふつうを交互） | 1000 | 6.4%・6.0%・5.6% | 27.8%・26.9%・27.3% | 21.0 |
| 2人（ふつう・ふつう） | 2000 | 50.1%・49.9% | — | 42.1 |
| 4人（ふつうだけ） | 1000 | 24.4〜26.5% | — | 14.7 |

ふつうどうしの4人では、答えの 55% が当たる（やさしいが混ざると約 50%）。どの組み合わせでも、止まった試合はない。6人では、手札が少ない（10〜11枚）ので、手札なしで負ける試合が2割ほどある。

## 開発

```bash
npm install
# 画面（http://localhost:8000/ を開くと public/ へ移る）
python3 -m http.server 8000
# テスト（Vitest）
npm test
```

| ファイル | 中身 |
|---|---|
| `public/js/kinds.js` | 虫の名前と色、枚数、負けの枚数 |
| `public/js/game.js` | 進行（DOM に依存しない）。操作は `applyCommand` だけで受け、記録から `Game.replay` で再現できる。断る操作は状態を変えない |
| `public/js/game-view.js` | 席ごとのビュー（ほかの人の手札、2人のときに除いたカード、見ていない人には伏せたカードの中身を隠す） |
| `public/js/cpu-player.js` | CPU（ビューだけを見る） |
| `public/js/game-controller.js` | 人間1人と CPU のローカル対戦（途中経過の保存） |
| `public/js/ui.js`・`art.js` | 画面・絵 |
| `public/sw.js`・`manifest.webmanifest` | PWA（オフラインでも開ける） |
| `server/src/game-definition.js` | オンライン対戦用のゲームの定義（netplay-kit の形。まだつないでいない） |
| `scripts/cpu-match.mjs` | CPU 同士の対戦と負けた割合・嘘・当たりの数 |

テスト（`test/`）：

- `game.test.js`：準備（64枚を全部配る、割り切れない分、2人のときの10枚と5枚）、当たり・外れでだれが置くか、次の親、見て回す（見ていない人だけ、言う虫を変えられる、全員が見たら受けるしかない、2人では回せない）、負けの判定（4枚・2人の5枚・手札なしで親）、断る操作で状態が変わらないこと
- `replay.test.js`：記録からの再現、CPU の判断がゲームの乱数を使わないこと、ランダムな操作を浴びせても断った操作で状態が変わらず64枚のままで再現できること
- `cpu-player.test.js`：CPU どうしの試合が人数（2〜6）・強さ・シードを変えても止まらないこと、ふつうがやさしいより負けにくいこと、確実な嘘を見抜く、正直さと答えの傾向の使い方、負けに近い人に渡す・回す、外れると負ける場面で見て回す
- `game-definition.test.js`：オンライン対戦の定義と、ビューで手札・除いたカード・伏せたカードの中身・シードが漏れないこと（見た人にだけ見える）
- `game-controller.test.js`：CPU との対戦で、CPU が人の操作を待って止まること、断った操作を伝えること
- `pwa.test.js`：service worker が画面のファイルを全部先に読むこと、manifest とアイコン
- `offline.test.js`：service worker を差し替えた入れ物で動かし、ネットワークが切れてもページと JS をキャッシュから返すこと

### オンライン対戦を入れるとき

netplay-kit の `scripts/sync.mjs` で部屋の処理を写し、`server/src/game-definition.js` を `createHandler` と `startDevServer` に渡す。部屋には参加者・シード・操作の記録だけを保存し、操作のたびに記録から再現する。操作を待っている人は、いつも1人（`game.actors()`、ビューの `answering`）。伏せたカードの中身は、見た人（親と、見てから回した人）のビューにだけ入る。だれが見たか（`round.seen`）は全員に見せる。シードと CPU の値（`cpuSalt`）はビューに入れない。
