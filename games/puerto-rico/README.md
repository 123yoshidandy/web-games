# プエルトリコ

島に農園を開き、都市に建物を建て、品を船で本国へ送って勝利点を競うゲーム（基本ゲーム。拡張なし）。ブラウザで、CPU を相手に 3〜5 人で遊べる（人間 1 人＋CPU 2〜4 人）。スマホの縦・横の画面と PC に対応し、ホーム画面に追加するとオフラインでも遊べる（PWA）。

絵とアイコンは自作。建物の名前の日本語は自分で付けた訳。

## 遊ぶ

ビルドは要らない。リポジトリのルートで HTTP サーバーを立てて開く。

```bash
python3 -m http.server 8080
# http://localhost:8080/public/ を開く（ルートを開くと public/ へ移る）
```

## ルール

- 人数ごとの準備

  | 人数 | 役割 | 入植者（山＋船） | 勝利点チップ | お金 | 船 | 最初の農園（総督から） |
  |---|---|---|---|---|---|---|
  | 3 | 6（金鉱掘りなし） | 55＋3 | 75 | 2 | 4・5・6 | 藍・藍・とうもろこし |
  | 4 | 7（金鉱掘り 1） | 75＋4 | 100 | 3 | 5・6・7 | 藍・藍・とうもろこし・とうもろこし |
  | 5 | 8（金鉱掘り 2） | 95＋5 | 122 | 4 | 6・7・8 | 藍・藍・藍・とうもろこし・とうもろこし |

  農園はとうもろこし 10・藍 12・砂糖 11・タバコ 9・コーヒー 8（最初の分を除いて山にする）、石切り場 8、品はとうもろこし 10・藍 11・砂糖 11・タバコ 9・コーヒー 9。表の農園は人数＋1 枚
- ラウンド：総督から順に 1 人ずつ役割を選び、選んだ人から順に全員が行う（選んだ人には特権）。全員が選んだら、選ばれなかった役割に 1 ドゥブロンずつ載せ、総督が左へ移る
- 役割：開拓者（農園を 1 枚。特権で石切り場も）・市長（船の入植者を配って並べ直す。特権で 1 人多く）・建築家（建物を 1 つ。特権で 1 安い。石切り場で列の数まで安い）・監督（生産。特権で 1 つ多く）・商人（商館に 1 つ売る。特権で +1）・船長（積んで 1 つ 1 点。特権で +1 点）・金鉱掘り（1 ドゥブロン）
- 建物 23 種（小さい生産 2 種×4、大きい生産 4 種×3、紫 12 種×2、大きい建物 5 種×1）。紫の建物の効果と大きい建物の点は、入植者がいるときだけ
- ゲームの終わり：入植者が足りずに船を満たせない、勝利点チップが尽きた、だれかの都市の 12 マスが埋まった、のどれかが起きたら、そのラウンドの終わりに終わる。得点はチップ＋建物の点＋大きい建物の点。同点ならお金と品の合計

### データの照合

公開されている実装（mgrau/rico、jneem/puertorico、ghirschhorn987/puertorico、ArturKorop/PuertoRico、koshamo/puri、kyle-burke/rico）で照らし合わせた。食い違いと採った値：

- 工場と大学：mgrau・jneem は工場 8・大学 7、ghirschhorn・ArturKorop は工場 7・大学 8（kyle-burke も大学 8）。工場 7・大学 8 にした
- 大市場・大倉庫：jneem だけが 1/1・5/2。ほかの 3 つが一致する 5/2・6/2 にした
- 5 人の役割：mgrau は金鉱掘り 1 枚、ghirschhorn は 2 枚。2 枚にした
- 5 人の勝利点チップ：mgrau は 122、koshamo は 126。122 にした（3 人 75・4 人 100 は一致）

### 決めたこと（説明書だけでは決まらない点）

- 最初の総督は無作為に決める
- 市長：空いたマスがあるうちは、入植者をサンフアンに残せない。全部のマスを埋められるときは自動で埋める。船には、全員の建物の空いた枠の数（少なくとも人数）だけ載せ、補充の山が足りなければ、ゲームの終わりの条件になる
- 船長：積める貨物船があれば必ず積む（品と船は選べる。選んだ船には積めるだけ積む）。波止場は使わなくてもよい（波止場にしか積めないときはパスできる）
- 船長のあと、品は 1 つと倉庫の種類の分だけとっておける。選ぶことがなければ自動
- アシエンダは農園を取る前に使う。救護院の入植者は、取った農園か石切り場に付く（アシエンダの分には付かない）
- 監督の特権は、自分が作った品の種類から 1 つ（在庫があれば）。工場の種類の数には特権の分を数えない
- 砦は島・都市・サンフアンの入植者をすべて数える。市庁舎は大きい建物を含む紫の建物を数える
- 勝利点チップが尽きたあとも、点は数えて渡す
- 2 人用の変種は入れていない（資料で細部を確かめられなかったため）

## 操作

- 役割は、押すと説明が出て、「決定」で選ぶ
- 市長のときは、島の農園や都市の建物を押して入植者を置いたり外したりする（建物は押すたびに 1 人ずつ増え、満員の次で 0 に戻る）。「おまかせ」で生産の組を優先して並べられる
- 建物は「建物を見る」で一覧（列ごと、割引後の費用、効果）を開いて選び、「建てる」
- 役割が終わるたびに、何が起きたかの一覧が出る（押すか約 3 秒で閉じる）
- 相手の欄を押すと、その人の島と都市が見られる。自分の建物を押すと効果が見られる
- 途中で閉じても、タイトルの「続きから」で再開できる（操作の記録を保存して再現する）

## CPU

自分のビュー（全員の島・都市・品・お金）だけで判断する。役割は「自分の得 − ほかの人の得 ＋ 役割に乗ったお金」で選ぶ。入植者は、生産の組（農園と建物）・紫の建物・石切り場の順に価値の高いところへ置く。建物・農園・売り・積み込み・とっておく品も、それぞれ値打ちの表で決める。ゆらぎを入れて、強すぎないようにしている。

- ふつう（既定）・やさしい の 2 段階
- 強さの測定：`npm run sim -- <試合数> <強さの並び>`（例：`npm run sim -- 200 normal,easy,easy`）。`strong`（ゆらぎなし）と `random` は測定用

## ファイルの構成

| ファイル | 内容 |
|---|---|
| `public/js/data.js` | 建物・品・役割・人数ごとの準備のデータ |
| `public/js/game.js` | ゲーム本体。判断は 1 度に 1 人。`applyCommand` と `Game.replay` |
| `public/js/game-view.js` | ビュー（山の並びと、ほかの人の判断の中身は入れない） |
| `public/js/cpu-player.js` | CPU（ビューだけを見る） |
| `public/js/game-controller.js` | ローカル対戦のコントローラー（`getView()` / `send()`） |
| `public/js/art.js` | 品・役割のアイコン、タイトルの絵、記録の文 |
| `public/js/main.js` | 画面の進行 |
| `server/src/game-definition.js` | オンライン対戦用のゲームの定義（netplay-kit の形。まだ使っていない） |
