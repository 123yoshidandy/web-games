# 花火

みんなで協力して5色の花火を打ち上げるカードゲーム「花火（Hanabi）」（基本ルール）を、ブラウザで CPU と遊べるようにしたもの。2〜5人（あなた＋CPU 1〜4人）。スマホの縦・横、PC で遊べ、ホーム画面に追加すればオフラインでも遊べる。

札の絵と画面はすべて自作。

## 遊ぶ

```bash
python3 -m http.server 8000 --directory public
# http://localhost:8000/ を開く
```

ビルドは要らない（素の HTML / CSS / ES Modules）。

## テスト

```bash
npm install
npm test             # Vitest
npm run bench:cpu    # CPU 同士の点数を測る（node tools/cpu-bench.mjs [試合数]）
```

## 実装したルール（基本ルール）

- 札は 5色 × 1が3枚・2〜4が2枚・5が1枚（50枚）
- 手札は 2・3人で5枚、4・5人で4枚。自分の手札は見えず、ほかの人の手札は見える
- ヒント8つ、ミス3回まで
- 手番の操作（どれか1つ）
  - ヒント：ヒントを1つ使い、ほかの人1人に色か数字を1つ教える。その色（数字）の札をすべて指す
  - 出す：続きの数字なら花火に並ぶ。違えばミスになり、札は捨て札へ
  - 捨てる：ヒントが1つ戻る（8つのときは捨てられない）
- 出すか捨てたら、山札から1枚引く。5を出し切るとヒントが1つ戻る（8つのときは戻らない）
- 終わり：ミスが3回になったとき、25点になったとき、山札が尽きてから全員（最後の札を引いた人を含む）があと1回ずつ手番を終えたとき
- 得点：各色の一番大きな数字の合計。ミスが3回になったときは花火が爆発して全員の負け（0点）

虹色の変種は入れていない。

### 解釈したところ

- 1枚も指さないヒント（「赤はない」）は出せないことにした
- 最初の手番の人はランダム
- 新しく引いた札は手札の右に入る（一番左が一番古い札）

## CPU

`public/js/cpu-player.js`。協力ゲームなので、強さを抑えるのではなく、人が読みやすい決まった約束事で動く（遊び方の画面にも書いた）。

- 出せる合図：ヒントで新しく指した札のうち一番左の札は「今出せる」
- 取っておく合図：5 のヒントと、今は出せないと分かる札へのヒントは「捨てないで」
- 捨てるときは、一番左のまだヒントのない札を捨てる

手番では、出せると分かる札（合図をもらった札）を出す → 次の人の捨て札候補が残り1枚の大事な札なら取っておく合図 → 誰かの出せる札を教えるヒント → 捨てる、の順に選ぶ。

ヒントを出す前に、受け取る人が自分の知っていることだけで約束事どおりに読めるかを確かめ、読み違えが起きるヒントは出さない。CPU は自分の手札の中身を見ない（テストで、ヒントのない札の中身を入れ替えても判断が変わらないことを確かめている）。

CPU 同士の点数（`npm run bench:cpu`、各 300 試合）：

| 人数 | 平均 | 中央 | 最低〜最高 | 25点 | ミス3回 |
|---|---|---|---|---|---|
| 2人 | 18.3点 | 18 | 10〜25 | 0.3% | 0% |
| 3人 | 19.0点 | 19 | 11〜25 | 1.0% | 0% |
| 4人 | 19.0点 | 19 | 12〜25 | 0.3% | 0% |
| 5人 | 18.7点 | 19 | 11〜23 | 0% | 0% |

## ファイル

| ファイル | 内容 |
|---|---|
| `public/js/game.js` | ルールと状態（DOM に依存しない）。操作は `applyCommand(seat, command)` に通し、`Game.replay` で記録から作り直せる |
| `public/js/game-view.js` | ビュー（自分の手札は中身を隠し、ヒントで分かったことだけ。山札は枚数だけ） |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦のコントローラー（`getView()` / `send(command)`）。途中経過の保存 |
| `public/js/main.js` | 画面と入力 |
| `public/sw.js` | Service Worker（オフライン） |
| `tools/cpu-bench.mjs` | CPU 同士の点数を測る |

### オンライン対戦を入れるとき

netplay-kit の「サーバーがゲームを進める型」にそのまま差し込める形にしてある。

- `create`：`new Game(players, { seed })`
- `persist` / `restore`：`{ players, options: { seed }, commands }` と `Game.replay`
- `view`：`createGameView(game, seat)`（本人の手札の中身は入らない）
- 操作：`clue`・`play`・`discard` の3種類。札は配られた順の番号（order）で指す。断る操作は状態を変えない
- CPU：`runCpuStep(game)`
