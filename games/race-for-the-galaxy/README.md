# レース・フォー・ザ・ギャラクシー

銀河に世界を広げ、技術を開発して勝利点を競うカードゲーム（基本ゲーム。拡張なし。カード 95 種 114 枚）。ブラウザで、CPU を相手に 2〜4 人で遊べる（人間 1 人＋CPU 1〜3 人）。2 人のときは上級ルール（行動を 2 つ選ぶ）も選べる。スマホの縦・横の画面と PC に対応し、ホーム画面に追加するとオフラインでも遊べる（PWA）。

絵とアイコンは自作（カードは種類で色分けした札で、効果は日本語の短い説明を出す）。カードの名前の日本語は自分で付けた訳。

## 遊ぶ

ビルドは要らない。リポジトリのルートで HTTP サーバーを立てて開く。

```bash
python3 -m http.server 8080
# http://localhost:8080/public/ を開く（ルートを開くと public/ へ移る）
```

## ルール

- 開始の世界 5 枚から 1 枚ずつ無作為に配り、手札 6 枚から 2 枚を捨てる。使わない開始の世界は山札に混ぜる。勝利点チップは人数×12
- ラウンド：全員が同時に行動を選び、公開する。だれかが選んだ段階だけを、探索 → 開発 → 入植 → 消費 → 生産 の順に全員で行う。選んだ人はボーナスを受ける
  - 探索：2 枚引いて 1 枚残す（+5：5 枚多く引く／+1+1：1 枚多く引いて 1 枚多く残す）
  - 開発：開発を 1 枚、費用の枚数の手札を捨てて置く（ボーナス：費用 -1）。同じ開発は 2 枚置けない
  - 入植：世界を 1 枚置く。ふつうの世界は手札で払い、軍事の世界は軍事力が防御以上なら払わずに置く（ボーナス：置いたら 1 枚引く）
  - 消費：交易（先に商品を 1 つ売る。新奇品 2・希少品 3・遺伝子 4・異星の品 5 枚＋交易の力）か、勝利点 2 倍。そのあと消費の力を使う
  - 生産：生産の世界に商品が載る（ボーナス：ウィンドフォールの世界に 1 つ）
- ラウンドの終わりに手札は 10 枚まで
- だれかの場札が 12 枚以上になるか、勝利点チップが尽きたら、そのラウンドの終わりにゲームが終わる。得点は、チップ＋カードの点＋6 コストの開発の得点。同点なら商品と手札の合計が多い人
- 2 人の上級ルール：行動を 2 つ選ぶ。開発と入植は 2 枚目の行動カードがあり、両方を選ぶと段階が 2 回ある

### カードのデータ

Keldon Jones の RFTG（cards.txt）の基本ゲームを元にし、BGA 向けの実装（martyychang/RaceForTheGalaxy の cards.inc.php）と、別のカード一覧（tobymanders/race-for-the-galaxy）で、費用・勝利点・種類・軍事・ウィンドフォール・商品・力のある段階を照らし合わせた。食い違ったのは次の 4 枚。

- 生物災害の鉱山（費用 3・2 点）、帝国の兵器工場（費用 4・2 点、軍事力 +1）、無法の世界（軍事力の力なし）：Keldon と別の一覧が一致したので、その値にした（BGA 向けの実装の値は採らなかった）
- 闇市場の世界：Keldon は費用 3・2 点、BGA 向けの実装は費用 2・1 点。別の一覧には載っていない。Keldon の値にしたが、確かではない

### 決めたこと（説明書だけでは決まらない点。Keldon の実装に合わせた）

- ウィンドフォールの世界は、置いたとき（開始の世界も）に商品が 1 つ載る
- 商品を使う消費の力は、使えるなら必ず使う（順番は選べる）。使う数は「回数と使える商品の少ない方」。手札を捨てる力・賭博の世界・売る力は使わなくてよい
- 交易を選んだ人は、商品があれば必ず 1 つ売る
- 賭博の世界：1〜7 の数を言って山札の一番上をめくり、費用が同じなら手札に入れる（外れたら捨てる）
- 接触の専門家：軍事の世界（異星を除く）を、費用 -1 の手札で払って置ける。植民船と組み合わせると 0
- 新戦術・植民船は、その入植で使うときに場から捨てる
- 鉱業複合企業の「いちばん多く生産」は、ほかの全員より多いとき（同数は含まない）
- 6 コストの開発の得点は、場のカード 1 枚につき、先に当てはまった条件の点だけを足す。銀河新秩序の「軍事力」は種類を限らない軍事力だけ

## 操作

- 行動は 4 列のボタンから選ぶ（選んだ行動のボーナスが下に出る）。全員がそろうと、各人の行動と行う段階の順が出る
- カードを押すと、下の欄に効果の全文が出る。「詳しく」で大きく見られる
- 開発・入植は、置くカードを押してから、払うカードを押す。軍事の世界では、軍事力と防御、新戦術・接触の専門家・植民船の切り替えが出る
- 消費は、使う力を選んでから、場札の商品を押す
- 相手の欄を押すと、その人の場札が見られる。途中で閉じても、タイトルの「続きから」で再開できる（操作の記録を保存して再現する）

## CPU

自分のビュー（自分の手札と、全員の場札）だけで判断する。行動は、開発・入植で置けるカードの値打ち、消費で得られる点、生産できる世界の数、手札の枚数から、勝利点の見込みで選ぶ。カードの値打ちは、点・力・6 コストの開発の得点の見込みで見る。ゆらぎを入れて、強すぎないようにしている。

- ふつう（既定）・やさしい の 2 段階
- 強さの測定：`npm run sim -- <試合数> <強さの並び> [advanced]`（例：`npm run sim -- 200 normal,easy`）。`strong`（ゆらぎなし）と `random` は測定用

自分が選ぶ番に、案内文の右の「ヒント」を押すと、ゆらぎのない CPU が選ぶ手を、選んだ状態にして光らせる（捨てる札・行動・残す札・置く札と払い・売る商品・使う力）。CPU と同じく、自分のビューだけで決める。

## ファイルの構成

| ファイル | 内容 |
|---|---|
| `public/js/cards.js` | カード 95 種のデータ（費用・点・種類・商品・力・6 コストの開発の得点） |
| `public/js/card-text.js` | カードの効果の日本語の説明（力のコードから組み立てる） |
| `public/js/game.js` | ゲーム本体。同時に選ぶ判断を席ごとに持ち、そろったら次へ。`applyCommand` と `Game.replay` |
| `public/js/game-view.js` | ビュー（自分の手札、公開前の行動は本人だけ、開発・入植の費用の材料） |
| `public/js/cpu-player.js` | CPU（ビューだけを見る） |
| `public/js/game-controller.js` | ローカル対戦のコントローラー（`getView()` / `send()`） |
| `public/js/art.js` | 段階のアイコン・タイトルの絵と、記録の文 |
| `public/js/main.js` | 画面の進行 |
| `server/src/game-definition.js` | オンライン対戦用のゲームの定義（netplay-kit の形） |
| `server/src/handler.js`・`public/js/online-config.js`・`public/js/netplay/` | オンライン対戦のサーバーの入口・接続先・netplay-kit の写し |

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜4人で、足りない席は CPU で埋められる。CPU の強さと2人の上級ルールを部屋の設定に持つ。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'race-for-the-galaxy' })`。web-games の1つのスタックから `?game=race-for-the-galaxy` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
