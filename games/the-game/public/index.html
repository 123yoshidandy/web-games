THE GAME

ザ・ゲーム　98枚を出し切れ

人数
仲間

合図

記録

    遊び方

    目的

    全員で協力して、2〜99 の98枚を4つの山に出し切ります。出し切れなくても、残りが少ないほど良い結果です（10枚以下ならすばらしい）。

    山

    • 上り（▲ 1から）の2つには、一番上より大きいカードを出します
    • 下り（▼ 100から）の2つには、一番上より小さいカードを出します
    • 10戻し：ちょうど10違うカードは、逆向きにも出せます（上りの 47 に 37、下りの 52 に 62）。山が戻るので、とても助かります

    自分の番

    • 手札を選んで、出したい山を押します。山には、どれだけ進むかが出ます
    • 2枚以上出したら「番を終える」で、手札が元の枚数になるまで引きます。山札がなくなったら、1枚以上でかまいません
    • 手札の枚数：1人 8枚・2人 7枚・3〜5人 6枚
    • 番の人が決まった枚数を出せなくなったら、そこで終わりです

    合図

    数字は伝えられません。代わりに、山の下の「合図」で、この山には出さないで（手のひら）か、この山に大事なカードがある（星）を置けます。番でなくても置けます。仲間の CPU も、手札に近いカードがあると合図を置き、合図のある山に大きく飛ばして出すのを避けます。

    結果

    残ったカード（山札と全員の手札）の枚数で決まります。0枚なら出し切り、10枚以下ならすばらしい結果です。

    コツ

    • 飛ばす数はできるだけ小さく。大きく飛ばすと、仲間の出せるカードが減ります
    • 手札の中で10違う2枚があれば、大きい方を出してから10戻せます
