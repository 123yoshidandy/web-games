# SET（セット）

場に並んだカードから、3枚の「セット」を誰よりも早く見つけるカードゲーム「SET」のブラウザ版です。タイムアタック・CPU 対戦・オンライン対戦で遊べます。スマホ縦向き。

## 遊び方

- カードは 81 枚。4つの特徴（数・形・塗り・色）がそれぞれ3通りで、同じカードはありません
- 3枚の組で、4つの特徴のどれも「3枚とも同じ」か「3枚とも違う」なら**セット**
- 12 枚が並んで始まります。カードを3枚タップすると取りにいきます
  - セットなら1点。12 枚の場では、空いた所に山札から足します（15 枚以上の場では足さずに詰めます）
  - セットでなければ1点減り（0 より下にはなりません）、3秒は取れません
- 場にセットがないときは、自動で3枚足します
- 山札がなくなり、場にセットが残っていなければ終わり。点の多い人の勝ち
- モード
  - **タイムアタック**：1人で全部のセットを取り切るまでのタイム。ベスト5を端末に残します（ヒントを使った回は残しません）
  - **CPU 対戦**：CPU 1〜3人と早い者勝ち。ヒントを使うと1点減ります
  - **オンライン**：2〜4人（足りなければ CPU）で、同じ場を早い者勝ち
- ヒント：場のセットの1枚を光らせます（ローカルだけ）
- 色の印：色ごとの記号（●▲■）をカードの隅に出します。色は朱・緑・青で、色覚の違いでも見分けやすく、明るさも変えてあります
- 結果の画面から、記録を時刻どおりに見直す「リプレイ」（×1〜×8）を見られます

## CPU

- 場が変わってから、強さに応じた時間がたつとセットを1つ取ります。CPU はまちがえません
- 時間は「強さの基準 × 0.6〜1.4 ÷ √(場のセットの数)」（下限あり）。セットが少ない場ほど時間がかかります
  - やさしい：基準 26 秒、ふつう：15 秒、つよい：8.5 秒
- 時間の乱数はゲームの乱数を使わず、「シード・席・場の版」から作った別の乱数で決めます。同じ記録からは同じ時刻になり、記録の再現がずれません
- `npm run cpu-match` で、強さの組ごとに 200 試合ずつ戦わせ、勝率と止まる試合がないかを確かめます

## オンライン対戦

- netplay-kit の「ゲームの定義」（`server/src/game-definition.js`）。部屋には参加者・シード・操作の記録・始まりの時刻だけを保存し、記録から再現します
- 早い者勝ちの判定はサーバーで行います
  - 端末は選んだ3枚だけを送ります。時刻はサーバーの時計で付けます（端末の時刻は使いません）
  - サーバーは届いた順に確かめ、最初に届いた正しい組が取ります。先に取られたカードを含む組は、まちがいにせず「先に取られました」と断ります（点も減らず、待ちも付きません）
  - まちがいの3秒の待ちも、サーバーの時刻で確かめます
- CPU は、取る時刻を期限（`deadline`）にし、届いたメッセージのたびに確かめます（Lambda はタイマーを持てないため）。CPU のいる間は、端末が1秒ごとに ping を送ります。CPU の記録の時刻は、届いた時刻ではなく取る時刻そのもので、期限は操作より先に確かめるので、CPU の時刻より後に届いた人の組は CPU のあとに扱われます
- 対戦中に部屋を出た人の席は CPU が続けます（保存と再現のあとも CPU のまま）
- ビューに、シードと山札の並びは入れません（入れると、これから出るカードを計算できるため）

## 開発

```bash
npm test -w games/set          # ルール・CPU・再現・ヒント・コントローラー・オンライン・PWA のテスト
npm run cpu-match -w games/set # CPU どうしの対戦
npm run dev:online             # 手元のオンライン対戦のサーバー（web-games の直下で）
```

- `public/js/game.js`：ルールと状態（DOM に依存しない）。操作は `applyCommand(seat, { type, cards, t })` の1つの入口で、時刻 `t` も記録に入る
- `public/js/cpu-player.js`：CPU の取る時刻と選ぶセット、おすすめ（`suggest`）
- `public/js/game-controller.js`：ローカルのコントローラー（時計・CPU・途中経過の保存）と、リプレイのコントローラー
- `public/js/game-view.js`：ビュー（席から見てよい情報だけ）
- `public/js/card-art.js`：カードの絵（SVG）
- `public/js/main.js`：画面と入力
- `server/src/`：オンライン対戦の定義と、Lambda の入口
