# リコシェロボット

ロボットを壁で跳ね返らせて目標のマスに止める手順を、だれより早く、少ない手数で見つける早解きのパズル（原題 Ricochet Robots）。ブラウザで、ひとりの練習・CPU との早解き（1〜3体）・オンライン対戦（2〜4人）で遊べる。スマホの縦画面が基本で、PC では盤面の横に操作を並べる。ホーム画面に追加するとオフラインでも遊べる（PWA）。

盤面の絵と、壁と目標の配置は自作。対戦ごとにシード付きの乱数で、4つの区画に L 字の壁で囲んだ目標（4色×4記号と渦の17枚）と外周の短い壁を置いて作る。

## 遊び方

- 16×16 の盤に、赤・青・緑・黄の4体のロボット（銀のじゃま役を足せる）。ロボットは上下左右に、壁かほかのロボットに当たるまで滑る。1回動かすと1手
- 目標を1枚めくり、全員で同時に考える。見つけたら手数を宣言する。最初の宣言で60秒の砂時計が動き、その間はだれでも（自分も）もっと少ない手数を宣言できる
- 時間切れ（か全員のパス）で、少ない手数を宣言した人から実演する（同じ手数なら先に宣言した人）。宣言した手数以内で、目標の色のロボット（渦はどのロボットでも）を止めればチップを得る。ロボットはそのまま残る。失敗したら戻して次の人
- だれも宣言しないまま3分たつか、全員がパスすると、その目標は流す
- 目標を決めた枚数（5・9・17）めくったら終わり。チップの多い人の勝ち（ヒントを使った分は引く）
- ひとりで練習：自分で動かして目標に止める。最短と同じなら3点、1手多いごとに1点減る。タイムも記録し、ベストを残す
- ヒント：最短の手順の最初の1手か、最短の手数を見る（それぞれ1点引く。オンラインでは使えない）

### 決めたこと

- 実演は「宣言した手数以内」で成功とした（原作の版によって「ちょうど」の決まりもある）。実演に失敗したときの罰はない
- スマホでは頭の中だけで手を追うのが難しいので、考えている間に試しに動かせる（本当の盤面は変わらず、元の位置は影で出す）。試しで着いた手順は、自分の実演のときに使える
- ロボットがもう乗っている目標は、めくらずに飛ばす（0手になるため）
- 実演は手順をまとめて送る（1手ずつは送らない）。ほかの人の画面では、送られた手順を1手ずつ動かして見せる

## CPU

目標ごとに「いつ・何手を見つけるか」の計画を立てる。最短の手数は探索（反復深化の深さ優先探索 IDA*。下限の見積もりと、同じ配置を覚えて切る表つき）で求め、強さで、見つけるまでの時間と、最短を見つける割合を変える。最短でないときは1〜2手多い手数で宣言し、あとで最短に気づいて宣言し直すこともある。

- やさしい・ふつう・つよい の3段階。見つけるまでの時間は人の速さに合わせ、手数が多いほど長くかかる

| 強さ | 6手の目標で見つけるまで | 最短を見つける割合 | 見えずにパスする割合 |
|---|---|---|---|
| やさしい | 約45秒 | 50% | 20%（12手以上は見つけない） |
| ふつう | 約24秒 | 62% | 15%（16手以上は見つけない） |
| つよい | 約15秒 | 70% | 12% |

- 時間には目標ごとの当たり外れ（対数正規のばらつき）があり、弱い CPU が先に見つける目標もある
- 1対1（目標9枚・100試合）で、ふつうはやさしいに 89%、つよいはふつうに 88% 勝つ（チップはおよそ2対1）
- 計画はシード・目標の番号・席から作る別の乱数で決め、ゲームの乱数は使わない。記録からの再現で同じ計画になる
- 探索の打ち切りは時間ではなく試した局面の数で決めるので、端末の速さで答えが変わらない
- 人が全員パスしたら、CPU の残りの宣言は待たずに今の時刻で入れる
- 強さの測定：`npm run cpu-match -- <試合数> <強さの並び> <目標の枚数>`（例：`npm run cpu-match -- 100 normal,hard 9`。枚数を省くと17枚）

## オンライン対戦

サーバーがゲームを進める型。宣言・パス・実演にサーバーの時計で時刻を付け、手数の検証と実演の判定もサーバーが行う。砂時計・実演の持ち時間・CPU の宣言は期限として返し、届いたメッセージ（端末が数秒ごとに送る `tick` を含む）のたびに確かめる。ビューにはシードも目標をめくる順も入れない。対戦中に抜けた人の席は CPU が引き継ぐ。

## 開発

ビルドは要らない。web-games の直下で HTTP サーバーを立てて `games/ricochet-robots/public/` を開く。

```bash
npm test -w games/ricochet-robots           # ルール・探索・CPU・ヒント・記録からの再現・オンライン・PWA
npm run cpu-match -w games/ricochet-robots  # CPU 同士の対戦
npm run dev:online                          # 手元のオンライン対戦のサーバー（ws://localhost:8787）
```

| ファイル | 内容 |
|---|---|
| `public/js/board.js` | 盤面の生成（壁・目標・ロボット）と、ロボットの滑り方 |
| `public/js/solver.js` | 最短手の探索（IDA*） |
| `public/js/game.js` | ゲーム本体。時刻付きの操作を `applyCommand` に通し、`Game.replay` で再現する |
| `public/js/game-view.js` | ビュー（シードと山の順は入れない） |
| `public/js/cpu-player.js` | CPU の計画と、時間で進む出来事（時間切れ・CPU の宣言）、`suggest` |
| `public/js/game-controller.js` | ローカルのコントローラー（止められる時計・続きから）と、記録を時刻どおりに見せるリプレイ |
| `public/js/render.js` | 盤面の SVG |
| `public/js/main.js` | 画面の進行と入力（試し動かし・宣言・実演） |
| `server/src/game-definition.js` | オンライン対戦のゲームの定義（netplay-kit の形） |
