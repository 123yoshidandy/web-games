# ラブレター

手札は 1 枚。毎回 1 枚引いて 1 枚出し、推理とはったりでラウンドを生き残るカードゲーム（2019 年の改訂版）。ブラウザで、CPU を相手に 2〜6 人で遊べる（人間 1 人＋CPU 1〜5 人）。スマホの縦・横の画面と PC に対応し、ホーム画面に追加するとオフラインでも遊べる（PWA）。

カード・アイコンの絵は、すべて自作の SVG。

## 遊ぶ

ビルドは要らない。リポジトリのルートで HTTP サーバーを立てて開く。

```bash
python3 -m http.server 8080
# http://localhost:8080/public/ を開く（ルートを開くと public/ へ移る）
```

## ルール（2019 年版）

| 値 | 名前 | 枚数 | 効果 |
|---|---|---|---|
| 0 | スパイ | 2 | 効果なし。ラウンドの終わりに、残っている人のうち自分だけがスパイを出したか捨てていれば、好意の印を 1 つ |
| 1 | 兵士 | 6 | ほかの人を 1 人選び、兵士以外のカードを言い当てる。当たれば脱落 |
| 2 | 道化 | 2 | ほかの人の手札を見る |
| 3 | 騎士 | 2 | ほかの人と手札を比べ、小さい方が脱落（同じなら何もない） |
| 4 | 僧侶 | 2 | 次の自分の番まで、効果を受けない |
| 5 | 魔術師 | 2 | 自分を含めて 1 人選び、手札を捨てて 1 枚引かせる（姫を捨てたら脱落。山札が尽きていたら、伏せて除外したカードを引く） |
| 6 | 宰相 | 2 | 山札から 2 枚引き、3 枚から 1 枚を残して 2 枚を山札の下に戻す（山札が 1 枚なら 1 枚） |
| 7 | 将軍 | 1 | ほかの人と手札を交換する |
| 8 | 大臣 | 1 | 将軍か魔術師と一緒に持っていたら、大臣を出さなければならない |
| 9 | 姫 | 1 | 出したり捨てたりしたら脱落 |

- 準備：1 枚を伏せて除外する。2 人のときは、さらに 3 枚を表にして除外する。全員に 1 枚配る
- 手番：1 枚引き、2 枚から 1 枚を出して効果を使う。選べる人がいなければ効果なし（魔術師は自分を選ぶ）
- ラウンドの終わり：残りが 1 人、または山札が尽きたとき。手札の一番大きい人が勝ち、同じなら出したカードの合計、それも同じなら全員が好意の印をもらう
- 勝つのに要る好意の印：2 人 6、3 人 5、4 人 4、5・6 人 3
- 次のラウンドは、前のラウンドの勝者から始める（勝者が何人もいれば、その中からシードで選ぶ）。最初のラウンドの最初の人もシードで選ぶ
- 同時に勝つのに要る数に届いて同じ数なら、もう 1 ラウンド行う

## 操作

- 手札を押して選び、相手を選んで（兵士は言い当てるカードも）、「出す」
- 出されたカードは、真ん中に大きく出して、誰が誰に何をしたかと結果を見せる
- 道化などで知った相手の手札は、その人の欄に小さく表で出る（自分にだけ見える）。自分の手札を知られているときは「〜に見られている」と出る
- 右上の「記録」で、これまでに起きたことを見られる。自分だけが知っている中身には「（あなただけ）」が付く
- 「カード一覧」で、カードごとの、自分から見えていない残りの枚数を見られる
- 途中で閉じても、タイトルの「続きから」で再開できる（操作の記録を保存して再現する）

## CPU

CPU は自分のビュー（自分に見える情報）だけで判断し、ほかの人の手札や山札の並びはのぞかない。見えていないカードの枚数から相手の手札を確率で推定し（大臣を出した直後の人は、将軍か魔術師を持っている見込みを上げる）、脱落させる見込み・自分が脱落する見込み・残す手札の強さで手を選ぶ。人間らしいゆらぎ（評価のゆらぎ、知っている手札を忘れる）を入れて、強すぎないようにしている。

- ふつう（既定）・やさしい の 2 段階
- 強さの測定：`npm run sim -- <試合数> <強さの並び>`（例：`npm run sim -- 300 normal,strong`）。`strong`（見落としなし）と `random` は測定用

「出す」の左の電球（ヒント）を押すと、見落としのない CPU が選ぶ手（カード・相手・言い当てる札）を、そのまま選んだ状態にする（「出す」が光り、押せば打てる）。CPU と同じく、自分のビューだけで決める。

## ファイルの構成

| ファイル | 内容 |
|---|---|
| `public/js/cards.js` | カードの定義、勝つのに要る好意の印の数 |
| `public/js/game.js` | ゲーム本体。誰が何を知っているか（`knowledge`）も持つ。`applyCommand` と `Game.replay` |
| `public/js/game-view.js` | ビュー（自分の手札と知っていることだけ。関係者だけのイベントの中身） |
| `public/js/cpu-player.js` | CPU（ビューだけを見る） |
| `public/js/log.js` | 記録の文 |
| `public/js/game-controller.js` | ローカル対戦のコントローラー（`getView()` / `send()`） |
| `public/js/card-art.js` | カードの絵 |
| `public/js/main.js` | 画面の進行 |
| `server/src/game-definition.js` | オンライン対戦用のゲームの定義（netplay-kit の形。まだ使っていない） |
