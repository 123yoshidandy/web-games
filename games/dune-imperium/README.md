# デューン・インペリウム

砂の惑星アラキスで、名家の当主として4つの勢力と手を結び、デッキを育ててエージェントを送るボードゲーム（原題 Dune: Imperium、基本セット）。デッキ構築とワーカープレイスメントを合わせた遊び。あなた1人と CPU 1〜3人の2〜4人で遊べ、オンライン対戦もできる。スマホの縦持ち向け。

## 遊び方

- 10点を目指す。だれかが10点以上になったラウンドの終わりか、紛争の山（10枚）がなくなったら終わり。同点はスパイス・ソラリ・水・駐屯地の部隊の順で比べる
- ラウンドの初めに紛争を1枚めくり、全員が5枚引く。先手番から順に、エージェントを送るか公開する
  - エージェント：手札1枚の印（皇帝・ギルド・ベネ・ゲセリット・フレメン・ランドスラード・都市・スパイス交易）と同じ印の空いた場所に送り、費用を払って場所とカードの効果を受ける。勢力の場所では影響力+1。紛争の場所では、この番に得た部隊と駐屯地の2部隊までを紛争に送れる
  - 公開：残りの手札を公開し、説得で列（5枚）や予備（アラキスの連絡員・スパイスは流れねばならない）のカードを買う。剣は紛争の戦力になる
- 全員が公開したら戦い。戦力は部隊×2＋剣（部隊がいなければ0）。部隊がいる人は戦闘の陰謀カードを使える。1位・2位（4人なら3位も）が褒美を得る。同点の1位は2位の褒美、同点の2位は3位の褒美
- 影響力2で1点、4で勢力の褒美（1度だけ）。影響力4以上で一番の人が同盟（1点、追い越されると移る）
- 最高評議会（ソラリ5。以後の公開で説得+2）・メンタート（ソラリ2。このラウンドだけエージェント+1）・ソードマスター（ソラリ8。3人目のエージェント）
- だれも送らなかった砂漠には、ラウンドの終わりにスパイスが1たまる

### 決めたこと（原作との違い）

- **人数**：2〜4人。原作の1人・2人用の自動の相手（ハガル家）は入れず、そのかわり CPU が普通のプレイヤーとして座る。2人でも3人と同じ規則で遊び、紛争の褒美は2位まで
- **カード**：カードの名前は登場人物などに合わせたが、効果は言い換えて数を整えた（原作の文は写していない）。インペリウムの山は33種43枚、陰謀カードは14種25枚、紛争はレベル1・2・3から1・5・4枚
- **リーダー**：原作の基本セットの8人。能力と印章の指輪の効果は、遊びやすく単純にした（遊び方の「リーダー」に一覧）
- **戦いの順番**：戦闘の陰謀カードを持っていない人は自動でパスにする（手番を待たせないため）
- **支配**：支配した場所は、だれかが置くたびに持ち主がソラリかスパイスを得る（守りの部隊は入れていない）
- **同盟**：同盟は1点だけ（同盟の追加の褒美は入れていない）。影響力が下がる効果はない
- **紛争の部隊を引く・撤退させる効果**、**戦闘中の部隊の追加**、**陰謀カードの複合の型**は入れていない

### 画面の操作

- 手札のカードを選ぶと、送れる場所が光る（場所を先に選んでもよい）。もう一度場所を押すか「送る」で送る
- 選ぶこと（紛争に送る部隊・勢力・払うか・除外・売る量）は、ダイアログで答える。閉じると盤面を見られ、「選ぶ」で開き直す
- 公開のあとは買い物のダイアログが開く。「盤面を見る」で閉じ、「買う」で開き直す
- 紛争の帯を押すと褒美と戦力、ほかの人の段を押すとその人の手元、自分のリーダーを押すと山札と捨て札が見られる
- 電球のボタンで、おすすめの手を光らせる（ローカル対戦だけ）

## CPU

- 効果の部品ごとに「今の自分にとっての値打ち」を見積もり、一番値打ちの高い手を選ぶ（`public/js/cpu-player.js`）
- ふつう：いつも一番の手。戦いでは、順位が上がるときだけ戦闘の陰謀カードを使う
- やさしい：上位の手から迷って選ぶ。買い物や紛争に送る部隊も気まぐれで、戦闘の陰謀カードは使わない
- 迷いには、ゲームの乱数ではなく、手数と席から作った別の乱数を使う（記録の再現をずらさない）
- ヒントはふつうの CPU と同じ手を出す

```bash
# 試合数・強さの並び（easy・normal）。席の並びは試合ごとに1つずつずらす
npm run cpu-match -w games/dune-imperium
node scripts/cpu-match.mjs 200 easy,normal,normal
```

## オンライン対戦

- netplay-kit の共通のロビー（`netplay-lobby.js`）を使う。2〜4人、足りない席は CPU（ふつう）
- サーバーは参加者・シード・操作の記録だけを保存し、操作のたびに再現する。手札・陰謀カード・山札の並び・シードは各端末に送らない
- 対戦中に部屋を出た人の席は CPU が引き継ぐ。切断は戻るのを待つ
- 手元で遊ぶ：web-games の直下で `npm run dev:online`（ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- `public/js/online-config.js` の `DEPLOYED_SERVER_URL` はまだ空（公開したページでは「オンラインで遊ぶ」を出さない）

## 開発

```bash
# 画面
cd public && python3 -m http.server 8000
# テスト（Vitest。リポジトリの直下から）
npm test -w games/dune-imperium
```

- `public/js/game.js`：ルール（DOM に依存しない）。操作はすべて `applyCommand(seat, command)` を通し、記録から `Game.replay` で再現できる。断る操作は状態を変えない。効果は「効果の部品」の列（`todo`）で進め、選ぶことがあると `pending` で止まる
- `public/js/cards.js`：場所・カード・紛争・陰謀カード・リーダーのデータと、効果の文
- `public/js/game-view.js`：プレイヤーから見てよい情報だけのビュー
- `public/js/cpu-player.js`：CPU とヒント（`suggest`）
- `public/js/game-controller.js`：ローカル対戦。操作のたびに `dune-imperium.save` に記録を保存し、「続きから」で再現する
- `public/js/ui.js`・`help.js`：画面と遊び方
- `server/src/game-definition.js`・`handler.js`：オンライン対戦の定義と入口
- 音：`public/js/sound/bgm.js`（曲「砂の海と香料の風」）。エンジンと効果音は `node packages/sound/scripts/sync.mjs dune-imperium` で同期する
