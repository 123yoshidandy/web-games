# コロレット

カメレオンを集めて得点を競うカードゲーム「コロレット（Coloretto）」を、ブラウザで CPU と遊べるようにしたもの。3〜5人（あなた＋CPU 2〜4人）。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

絵（カメレオン・カード・アイコン）は、すべて SVG で自作している。

## 遊び方（標準版）

- カード：カメレオン7色×9枚、ジョーカー3枚、+2 カード10枚、最後のラウンドのカード1枚
- 3人では1色を除く（6色）。列は人数と同じ数
- 準備：各自に違う色のカメレオンを1枚ずつ配る。山札の下から15枚目の上に、最後のラウンドのカードを入れる
- 手番には、どちらか1つを行う
  - 山札から1枚引いて表にし、まだ取られていない、3枚未満の列に置く
  - カードが1枚以上ある列を1つ取る。取ったら、そのラウンドはもう手番がない
- 全員が列を取ったらラウンドの終わり。最後に列を取った人から次のラウンドを始める
- 最後のラウンドのカードが出たら、そのラウンドの終わりでゲームが終わる
- 得点：色ごとの枚数で点が決まる。多い3色がプラス、残りの色はマイナス。ジョーカーは最後に好きな色として数える。+2 は1枚2点

| 枚数 | 1 | 2 | 3 | 4 | 5 | 6以上 |
|---|---|---|---|---|---|---|
| ふつう（茶色の面） | 1 | 3 | 6 | 10 | 15 | 21 |
| 上級（灰色の面） | 1 | 4 | 8 | 7 | 6 | 5 |

### ルールブックに書かれていないので決めたこと

- プラスにする3色とジョーカーの色は、得点がいちばん高くなるように自動で選ぶ
- 点数が同じなら、その全員を勝ちとする
- 最初の1番手はランダム

### 入れていないもの

- 2人用の変種。列のカードに置ける枚数を確かめられなかったため、入れていない

### 画面の操作

- 「山から引く」で引いたカードは下に表で出て、置ける列が光る。列を押すとそこに置く
- 自分の手番では、各列の下に「今取ったら何点増えるか」が出る。列を押して選び、「この列を取る」で取る
- 集めたカードは色ごとの枚数で出し、プラスの3色を縁取る。ジョーカーは得になる色に数えて「+1」のように見せる
- 遊び方を開いている間は、CPU が止まる
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

自分から見える情報だけ（山札の並びは見ない）で打つ。カードを足したときの得点の増え方（ジョーカーとプラスの3色は最善に選ぶ）で列の値打ちを測り、十分に得な列があれば取る。引いたカードは、自分の得から、まだ列を取っていないほかの人の得を引いた値がいちばん大きい列に置く。強すぎないように、評価の揺れと、ときどき2番目の手を選ぶ誤りを混ぜている。

```bash
# 試合数・人数・席ごとの強さ（normal は画面の CPU、strong は揺れのない比較用、random はでたらめに打つ比較用）
node scripts/cpu-match.mjs 400 4 normal,normal,normal,strong
```

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm install
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/game.js` | ルールと得点の計算。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`art.js`・`animator.js` | 画面・絵・動き |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |

### オンライン対戦を入れるとき

ルールとビューは、netplay-kit の「ゲームの定義」の形（`server/src/game-definition.js`）で用意してある。netplay-kit の `sync.mjs` で部屋の処理を写し、この定義を `createHandler` と `startDevServer` に渡す。画面は、ローカル対戦と同じ `getView()` / `send()` の形のオンライン用のコントローラーを足す。
