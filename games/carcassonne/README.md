# カルカソンヌ

タイルをつないで土地を広げ、道・都市・修道院・草原にコマを置いて得点を競うボードゲーム。ブラウザで、CPU を相手に 2〜5 人で遊べる（人間 1 人＋CPU 1〜4 人）。スマホの縦・横の画面と PC に対応し、ホーム画面に追加するとオフラインでも遊べる（PWA）。

タイル・コマ・アイコンの絵は、すべて自作の SVG。

## 遊ぶ

ビルドは要らない。リポジトリのルートで HTTP サーバーを立てて開く。

```bash
python3 -m http.server 8080
# http://localhost:8080/public/ を開く（ルートを開くと public/ へ移る）
```

## ルール

基本セット（72 枚。拡張なし）を、第2版の得点で実装している。

- タイル：24 種類 72 枚（開始タイル 1 枚を含む。紋章 10 個、修道院 6 つ）。最初の手番は、シードから決める
- 置き方：辺の絵（道・都市・草原）がすべて合い、少なくとも 1 枚に接する場所。どこにも置けないタイルは取り除いて引き直す
- コマ：1 人 7 つ。置いたタイルの道・都市・修道院・草原のどれか 1 か所に置ける。つながった先に誰かのコマがいる所には置けない
- 完成したとき（すぐに数えてコマを戻す）
  - 道：1 枚 1 点
  - 都市：1 枚 2 点＋紋章 1 つ 2 点（**第2版：2 枚だけの都市も 1 枚 2 点**。初版は 2 枚の都市が 2 点）
  - 修道院：周りの 8 マスが埋まると 9 点
- ゲームの終了時（最後のタイルを置いたあと）
  - 未完成の道：1 枚 1 点、未完成の都市：1 枚 1 点＋紋章 1 つ 1 点、未完成の修道院：1 点＋周りのタイル 1 枚 1 点
  - 草原：接している完成した都市 1 つにつき 3 点（草原ごとに数える。同じ都市を別の草原も数えてよい）
- 多数決：コマの一番多い人が得点する。同じ数なら全員が満点。勝ちも同点なら分け合う
- 人数によるルールの違いはない（2〜5 人とも同じ）

## 操作

- 光っているマスを押すと仮に置く。同じマスをもう一度押すか「回す」で向きを変え（置ける向きだけを回る）、「置く」で決める
- コマを置ける場所が丸で出るので、押して「決定」。置かないときは「コマなし」
- 盤面は 1 本指でずらし、2 本指（PC はホイール）で拡大・縮小する。ページそのものの拡大は止めている
- 残りの枚数を押すと、袋に残っているタイルの種類と枚数が見られる
- 途中で閉じても、タイトルの「続きから」で再開できる（操作の記録を保存して再現する）

## CPU

置ける場所・向き・コマの置き方をすべて試し、盤面の見込みの点（完成の見込み、相手の点の増え方、コマを使う手間）で選ぶ。強すぎないように、人間らしい見落としを入れている（置ける場所の一部を見ない、評価のゆらぎ、草原をあまり考えない、相手の邪魔をあまり考えない）。

- ふつう（既定）・やさしい の 2 段階
- 強さの測定：`npm run sim -- <試合数> <強さの並び>`（例：`npm run sim -- 200 normal,strong`）。`strong`（見落としなし）と `random`（でたらめ）は測定用

## ファイルの構成

| ファイル | 内容 |
|---|---|
| `public/js/tiles.js` | タイルの定義（辺・草原の半辺・紋章・コマの位置）と回転 |
| `public/js/board.js` | 盤面、置ける判定、つながった領域の探索、得点 |
| `public/js/game.js` | ゲーム本体。操作は `applyCommand(seat, command)` だけ、`Game.replay` で再現 |
| `public/js/game-view.js` | ビュー（袋の並びは入れない） |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦のコントローラー（`getView()` / `send()`） |
| `public/js/board-view.js` | 盤面の描画と、移動・拡大縮小・タップ |
| `public/js/tile-art.js` | タイルとコマの絵（SVG） |
| `public/js/main.js` | 画面の進行 |
| `server/src/game-definition.js` | オンライン対戦用のゲームの定義（netplay-kit の形。まだ使っていない） |
| `server/src/handler.js` | オンライン対戦のサーバーの入口（AWS Lambda） |
| `public/js/online-config.js` | オンライン対戦の接続先 |
| `public/js/netplay/` | netplay-kit のクライアントとロビーの画面の写し（同期で置く。手で直さない） |

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜5人で、足りない席は CPU で埋められる。CPU の強さは、ロビーで部屋を作った人が決める。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'carcassonne' })`。web-games の1つのスタックから `?game=carcassonne` で呼ばれる）
- ゲームの定義は `server/src/game-definition.js`（記録だけを保存して再現する。各席には、その席から見えるビューだけを送る）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
