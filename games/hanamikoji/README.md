# 花見小路

7人の芸者の好意を競う2人用のカードゲーム「花見小路（Hanamikoji）」を、ブラウザで CPU と遊べるようにしたもの。スマホの縦持ち向け（横にしても遊べる）。ホーム画面に置くと、オフラインでも遊べる。

絵（芸者の家紋のような印・カード・好意の印・行動の印・アイコン）は、すべて SVG で自作している。芸者の名前（椿・山吹・柳・朝顔・桔梗・藤・桜）も、この版で付けたもの。

## 遊び方

- 芸者7人（点数 2・2・2・3・3・4・5）と、品物のカード21枚（芸者ごとに点数と同じ枚数）
- ラウンドの準備：カードを切って1枚を伏せたまま除き、各自に6枚配る。残りの8枚が山札
- 手番の初めに1枚引き、まだ使っていない行動を1つ行う。4つの行動を各ラウンドに1回ずつ使う
  - 秘密（1枚）：伏せて取っておき、ラウンドの終わりに自分の側に置く
  - 放棄（2枚）：伏せて捨てる。このラウンドでは数えない
  - 贈り物（3枚）：見せた3枚から相手が1枚取り、残りの2枚は自分の側に置く
  - 競争（2枚×2組）：相手が1組取り、残りの1組は自分の側に置く
- 両者が4つの行動を使い終えたら、秘密を開け、芸者ごとに置いたカードの多い方が好意を得る。同数なら好意の印は動かない
- 好意を得た芸者の点数が11点以上か、芸者4人以上の好意を得た方の勝ち（11点を先に見る）。決まらなければ、好意の印を残して次のラウンド。手番の順はラウンドごとに入れ替える

### 公式のルールに書かれていないので決めたこと

- 最初のラウンドの1番手はランダム
- 除いた1枚と放棄したカードは、ラウンドの終わりにも見せない

### 画面の操作

- 手札を選んだ枚数で行動が決まる（1枚 秘密・2枚 放棄・3枚 贈り物・4枚 競争）。競争は、選んだ順に前の2枚と後の2枚が組になる（番号の札が付く）
- 相手が贈り物・競争を出したら、手札の欄が差し出されたカードの欄に替わる。選ぶと、置いたあとの数が芸者の列に点線で出る
- 自分の秘密は、自分の側に斜線の札で見せる（相手には見えない）
- 好意の印は、芸者の札の下の縁（自分）か上の縁（相手）に付く
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

自分から見える情報だけ（相手の手札・秘密・放棄・山札・除いた1枚は見ない）で打つ。

- 相手の手札の推測：見えていないカードを芸者ごとに数え、相手がこれから自分の側に置く枚数を、その割合で見込む
- 評価：芸者ごとに、置いた枚数と見込みの差から好意を得る確率を出し、点数・人数と、11点・4人に届く見込みを点数にする
- 贈り物・競争は、相手が自分にいちばん不利なものを選ぶとみなして選ぶ
- 強さは「やさしい」「ふつう」の2段階（タイトル画面で選ぶ）。評価に揺れを入れ、ときどき2番目以下の手を選ぶ。やさしいの方が揺れと誤りが大きい

CPU 同士の勝率（2000試合、席は交互。strong は揺れのない比較用、random はでたらめに打つ比較用）：

| 対戦 | 勝率 |
|---|---|
| ふつう 対 やさしい | 63.2% |
| ふつう 対 random | 88.5% |
| やさしい 対 random | 79.4% |
| strong 対 ふつう | 55.4% |

```bash
# 試合数・強さA・強さB（easy・normal・strong・random）
node scripts/cpu-match.mjs 400 normal easy
```

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm install
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/game.js` | ルール。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`art.js`・`animator.js` | 画面・絵・動き |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |

### オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2人で（片方を CPU にもできる）、足りない席は CPU で埋められる。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'hanamikoji' })`。web-games の1つのスタックから `?game=hanamikoji` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
