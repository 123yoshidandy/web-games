# スカル

花とドクロの札で読み合う、はったりのゲーム「スカル（Skull）」を、ブラウザで CPU と遊べるようにしたもの。3〜6人（あなた＋CPU 2〜5人）。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

絵（札・コースター・アイコン）は、すべて SVG で自作している。

## 遊び方

- 各自、花3枚・ドクロ1枚の札と、コースターを持つ。最初に始める人はランダム
- ラウンドの始めに、札の残っている全員が1枚伏せる
- 手番には、手札から1枚を伏せて自分の山に重ねるか、挑戦（めくる枚数を宣言）する。宣言は 1〜伏せた札の合計。手札がなければ挑戦する
- 挑戦が始まったら、順に、より大きな数に上げるか、パス（そのラウンドは降りる）。1人だけ残るか、伏せた札の合計まで上がったら終わり
- いちばん大きな数を宣言した人が、まず自分の山を上から全部めくり、それからほかの人の山の上から好きにめくる
  - 宣言の数だけ花が出たら成功。コースターを裏返し、2回目の成功で勝ち
  - ドクロが出たら失敗。ほかの人のドクロなら、失敗した人の札から1枚を見ずに取り除く。自分のドクロなら、自分で選んで1枚取り除く。取り除いた札は、本人にしか分からない
- 札が0枚になった人は脱落。最後の1人も勝ち
- 次のラウンドは挑戦した人から。挑戦した人が脱落したら、ほかの人のドクロならその持ち主から、自分のドクロなら次の人から

ルールは、ボードゲームアリーナの遊び方のページで確かめた。

### 決めたこと

- 自分のドクロで脱落したとき、本来は本人が次に始める人を選ぶが、ボードゲームアリーナと同じく自動で決める（次の人）
- ほかの人のドクロで失敗したときに取り除く札は、シードの乱数で決める（持ち主が見ずに1枚取るのと同じ）

### 画面の操作

- 手札の札を押すと伏せる。自分の伏せた札は、中身を薄く見せる（自分にだけ見える）
- 「挑戦する」を押すと −／＋ で数を選べる。上げるときも同じ
- めくる場面では、まず「自分の山をめくる」。そのあと、めくれる人の山が光るので、押してめくる。めくった札は回って表になり、ドクロなら山が赤く揺れる
- 挑戦が決着したら、結果の帯を出し、少しのあいだ CPU を止める。次のラウンドの始めに、直前の挑戦でめくった札を見せる
- 遊び方と記録を開いている間は、CPU が止まる。途中でホームに戻っても、「続きから」で再開できる

## CPU

自分の札と、公開された情報（だれが何枚伏せたか・めくられた札・成功の数・取り除かれた札の数・このラウンドでだれが宣言したか）だけを使う。

- 推し量り：ほかの人の山にドクロがある見込みを、まだドクロを持っている見込み（取り除かれた枚数から）と、手札のうち伏せた割合から出す。このラウンドで挑戦・宣言した人は、自分の山から先にめくるので、ドクロを伏せていなさそうと見る
- 成功の見込み：宣言の数ごとに、ほかの人の山を見込みどおりに作って何度も試し、ドクロの見込みの低い山からめくったときに成功する割合を出す。自分の山のめくる分にドクロがあれば 0
- 手番：伏せた札が十分あり、成功の見込みの高い数があれば挑戦する。なければ伏せる（ときどきドクロ。だれかが1回成功していると多め）
- 上げ下げ：次の数の成功の見込みが十分なら上げる。自分の山にドクロがあるときは、ときどきはったりで上げてほかの人を誘う
- 自分のドクロで失敗したら、花が2枚以上なら花を、なければドクロを手放す
- やさしい：宣言から推し量らず、見込みの線が甘く、はったりをしない

```bash
# 試合数・席ごとの強さ（easy・normal・random）。席の並びは試合ごとにずらす
node scripts/cpu-match.mjs 400 normal,easy,easy,easy
```

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm install
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/game.js` | ルールと進行。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`art.js` | 画面・絵 |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |

### オンライン対戦を入れるとき

ルールとビューは、netplay-kit の「ゲームの定義」の形（`server/src/game-definition.js`）で用意してある。netplay-kit の `sync.mjs` で部屋の処理を写し、この定義を `createHandler` と `startDevServer` に渡す。画面は、ローカル対戦と同じ `getView()` / `send()` の形のオンライン用のコントローラーを足す。
