# エバーデール

森の動物たちの街を、ワーカーとカードで作るボードゲーム「エバーデール（Everdell）」を、ブラウザで CPU（1〜3体）と遊べるようにしたもの。スマホの縦持ちで遊べる（PC でも遊べる）。

## 遊び方

```bash
cd public && python3 -m http.server 8000
```

`http://localhost:8000/` を開く。ホーム画面に置くと、オフラインでも遊べる（PWA）。

- 画面の上に相手、真ん中のタブに「草原・場所・行事・街」、下に自分の資源・手札・操作のボタンを置いた
- カードや場所をタップすると説明が出て、そこから出す・ワーカーを置く
- 効果の途中で選ぶことがあると、選択のシートが出る（「盤面を見る」で閉じて、あとで戻れる）
- 途中経過は操作のたびに保存され、タイトルの「続きから」で再開できる

## ルール

基本セットのルールに沿っている。

- 街は15枠（放浪者は枠を使わず、夫と妻の組は1枠）、手札は8枚まで、草原は8枚
- 資源は小枝・樹脂・小石・ベリー。建造物は小枝・樹脂・小石、住民はベリーで出す
- 建造物があれば、対応する住民を1回だけ無料で出せる（永遠の木はどの住民でも）
- ワーカーの置き場：基本の場所8つ、森の場所（2人は3つ、3〜4人は4つ。4人のときは、ちがう2人まで）、港、旅（秋だけ）、行事、目的地のカード（宿屋と郵便局は相手のものも使え、持ち主に1点）
- 季節の準備：ワーカーは冬2人 → 春3人（緑の生産が動く）→ 夏4人（草原から2枚まで取る）→ 秋6人（緑の生産が動く）。修道院と墓地のワーカーは戻らない
- 行事：基本の行事4つ（各色のカードの枚数。3点）と、特別な行事13種から4つ
- 得点：カードの点、紫の繁栄の加点（妻の組の3点も含む）、点数トークン（時計塔・礼拝堂の上も含む）、行事、旅。同点なら行事の多い人、次に残った資源の多い人
- カードは基本セットの48種、129枚（各カードの枚数は基本セットに合わせた）

### 割り切った点・解釈した点

- 割引（宿屋・クレーン・宿の主人・地下牢・森の場所の「1つ安く」）で安くする資源と、裁判官で置きかえる資源は、払えるように自動で選ぶ
- 地下牢に入れる住民は、点数がいちばん低いものを自動で選ぶ
- 遺跡と大学で捨てられるのは、ワーカーが置かれていないカードだけ
- 森番で動かせるのは、修道院・墓地以外に置いたワーカー
- 鉱夫モグラは、相手の倉庫・煙突掃除・鉱夫モグラはまねない。煙突掃除は、自分の煙突掃除・鉱夫モグラはまねない
- 森の場所11種と特別な行事13種は、基本セットのものをもとに、効果を分かりやすく整えたもの（名前と細かな数は原作と同じとは限らない）
- 最初の手番はランダム。秋には、ワーカーが残っていても「終える」を選べる

## CPU

- 手番の行動は、ゲームを写して実際に行い、そのあとの盤面を点数にして比べる（写しでは山札を CPU 用の乱数で混ぜ直すので、次に引くカードはのぞかない）
- ふつう：今の点・資源・手札・ワーカーだけを見る。評価に揺らぎがある
- 強い：さらに、生産の残りの回数・あと1枚で達成できる行事・無料で出せる住民・目的地の使い道を見て、よさそうな6手は自分の次の1手まで試す

```bash
node scripts/cpu-match.mjs 60 2 strong,normal   # 強い 93%・ふつう 7%（2人、60試合）
```

## ファイル

| ファイル | 中身 |
|---|---|
| `public/js/cards.js` | カード・場所・行事のデータ |
| `public/js/game.js` | ルール（DOM に依存しない。操作は `applyCommand` だけ。記録から `Game.replay` で再現できる） |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と保存 |
| `public/js/ui.js`・`art.js` | 画面と図柄 |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）に差し込む定義。まだオンライン対戦は入れていない |
| `scripts/cpu-match.mjs` | CPU 同士の対戦 |
