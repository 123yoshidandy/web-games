# レイルロードインク

全員が同じダイスの目を自分のボードに描き、道と線路で外周の出口をつないでいくゲーム「レイルロードインク（Railroad Ink）」の基本ゲーム（拡張のダイスなし）を、ブラウザで遊べるようにしたもの。1人でも、CPU と合わせて6人までで遊べる。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

絵（タイル・ボード・アイコン）は、すべて SVG で自作している。説明の文も自分で書いたもので、公式の文は写していない。

## 遊び方（基本ゲーム）

- 7×7 のボード。外周に出口が12ある。上下の辺は 道・線路・道、左右の辺は 線路・道・線路（それぞれ2・4・6 列目と行目）
- 7ラウンド。毎ラウンドのはじめにダイス4つを振り、全員が同じ目を自分のボードに描く
  - 道・線路のダイス3つ：道の直線・カーブ・T字、線路の直線・カーブ・T字
  - 高架・駅のダイス1つ：高架・直線の駅・カーブの駅が2面ずつ
- 目は回しても裏返してもよいが、別の形にはできない。4つの目は全部描く（どこにも描けない目だけ飛ばせる）
- 描くマスは、出口か、描いてある道・線路に、少なくとも1辺でつながっていること
- 道と線路は直接つなげない。駅でつなぐ。高架は道と線路が交わるだけで、つながらない
- 特別なタイル6つ（駅の十字・線路3と道1の駅・道の十字・線路の十字・道3と線路1の駅・道2と線路2が隣り合う駅）は、ダイスの目に加えて描ける。1ラウンドに1つまで、ゲーム全体で3つまで、それぞれ1回だけ
- 全員が描き終えたら次のラウンド。7ラウンドのあとに得点を数える

### 得点

| 項目 | 点 |
|---|---|
| 出口 | 同じつながり（ネットワーク）に入った出口の数ごとに 2→4・3→8・4→12・5→16・6→20・7→24・8→28・9→32・10→36・11→40・12→45 |
| 一番長い道 | 枝分かれを含まない一本の道の、マスの数 |
| 一番長い線路 | 同じく線路 |
| 中央の9マス | 描いたマス1つにつき1点 |
| 減点 | どこにもつながっていない端1つにつき −1 |

### 資料で分からない点の決め方

- 違う種類の辺（道と線路）を向かい合わせて描くことは、できないことにした。出口とも、種類が違えば向かい合わせて描けない。「道と線路は直接つなげない」の読み方が分かれるため、置けないほうに倒した（置けるとしても、減点が増えるだけで得にはならない）
- 外周に向いた端は、出口でなくても減点しない
- 一番長い道・線路は、駅で途切れない。線路が通り抜ける特別な駅（駅の十字・線路3と道1の駅）は、線路を続けて数える。高架は、道と線路の流れに1回ずつ数える。同じ区間を2度は通らない
- 同点なら、減点の少ない人の勝ち（それでも同じなら引き分けで、全員を勝ちとする）
- そのラウンドに描いたものは、ラウンドを終えるまで取り消せる（前のラウンドのものは消せない）
- 描ける目が残っている間は、ラウンドを終えられない。描けない目は描かずに終えてよい
- 特別なタイルは、ダイスの目の前でもあとでも描ける

### 画面の操作

- 上のダイスか特別なタイルを押し、ボードのマスを押すと、置いたときの姿が出る。描けるマスは緑に光る
- 回す・裏返すで向きを変え、「描く」か、同じマスをもう一度押して描く。描けないときは、下に理由が出る
- 描き終えたら「次へ」（最後のラウンドは「終える」）。ほかの人は同時に描き、右上の人のボタンで全員のボードと得点の見込みを見られる
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

## CPU

強さは「ふつう」と「やさしい」。全員が同じ目を同時に描くゲームなので、CPU は自分のボードだけを見て、盤の良さの点数（`evaluate`）が一番上がる目・場所・向きを1つずつ選ぶ（`public/js/cpu-player.js`）。

- 出口のつながりの点、一番長い道・線路、中央の9マスを足す
- つながっていない端は、ラウンドが進むほど重く減点する。まだつないでいない出口の近くまで伸びた端には、少し加点する
- 特別なタイルは、ダイスの目を描き終えたあと、点が十分に上がるときだけ使う。残りのラウンドで使い切れなくなるなら、必ず使う
- やさしいは、一番長い道・線路を考えず、ダイスを決まった順に描き、上位4つの候補からランダムに選ぶ
- CPU の判断にはゲームの乱数を使わない（記録の再現がずれるため）

```bash
# 試合数・人数・強さ（normal・easy・mixed）。mixed は席ごとに強さを交互に変えて比べる
node scripts/cpu-match.mjs 200 2 mixed
```

| 対戦 | ふつう | やさしい |
|---|---|---|
| 1人で100試合の平均点 | 29.4点 | 15.6点 |
| 2人（ふつう対やさしい）200試合の平均点 | 30.9点 | 15.5点 |
| 同じ200試合の勝ち数 | 192勝 | 9勝 |

ふつうの内訳の平均は、出口 21.6・道 6.8・線路 7.0・中央 4.8・減点 −9.2。慣れた人なら上回れるくらいの強さ。

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜6人で、足りない席は CPU で埋められる（1人で遊ぶのはローカルだけ）。全員が同じダイスの目で同時に描く。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'railroad-ink' })`。web-games の1つのスタックから `?game=railroad-ink` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）

## 開発

```bash
npm install
# 画面（http://localhost:8000/ を開くと public/ へ移る）
python3 -m http.server 8000
# テスト（Vitest）
npm test
```
