# 世界の七不思議

3 つの時代を通して自分の都市を発展させ、勝利点を競うカードゲーム（基本ゲーム・第1版のカード構成）。ブラウザで、CPU を相手に 3〜7 人で遊べる（人間 1 人＋CPU 2〜6 人）。スマホの縦・横の画面と PC に対応し、ホーム画面に追加するとオフラインでも遊べる（PWA）。

絵とアイコンは自作。カードの名前は日本語の一般的な訳。

## 遊ぶ

ビルドは要らない。リポジトリのルートで HTTP サーバーを立てて開く。

```bash
python3 -m http.server 8080
# http://localhost:8080/public/ を開く（ルートを開くと public/ へ移る）
```

## ルール

- 3〜7 人。不思議を 1 つずつ無作為に配る。面は A・B・ランダムから選ぶ。はじめのコインは 3
- 各時代、手札 7 枚。全員が同時に 1 枚を選び、そろったら公開して、建てる・不思議の段階に使う・捨てて 3 コインのどれかをする。残りの手札を隣へ渡す（第1・第3時代は左、第2時代は右）。6 回選んだら、最後の 1 枚は捨てる
- 費用：資源は自分の生産で払い、足りなければ両隣の茶色・灰色のカードとはじめの資源を 1 つ 2 コインで買う（交易所・市場・オリンピア B で 1 コイン）。隣に払ったコインは手番の終わりに隣が受け取る。商業のカードと不思議の段階の生産は、隣に売れない
- 連鎖：前の時代の決まった建物があれば無料。同じ名前の建物は 2 つ建てられない
- 時代の終わりに、両隣と盾の数を比べる（勝ち：第1時代 1・第2時代 3・第3時代 5 点、負け：-1）
- 第3時代には、ギルド 10 枚から人数＋2 枚を無作為に入れる
- 得点：軍事、コイン 3 枚で 1 点、不思議、市民、科学（同じ記号の 2 乗と 3 種そろうごとに 7 点）、商業、ギルド。同じ点ならコインの多い人
- 不思議の特別な力：アレクサンドリア（資源を選んで生産）、バビロン（好きな科学の記号、B：7 枚目も使える）、オリンピア（A：各時代に 1 回無料で建てる、B：原材料を両隣から 1 コイン・隣のギルドを写す）、ハリカルナッソス（捨て札から無料で建てる）、エフェソス・ロードス・ギザ（点・コイン・盾）

## 操作

- 手札を押すと、建てる・段階・捨てるのボタンが出る。払い方は一番安いものを選んでおき、ほかの候補（左右どちらに払うか）があれば選び直せる
- 全員がそろうと、各人が何をしたかの一覧が出る（押すか 5 秒で閉じる）。時代の終わりには軍事の結果も出る
- 左右の隣の欄や右上のボタンで、隣や全員の都市を詳しく見られる
- 途中で閉じても、タイトルの「続きから」で再開できる（操作の記録を保存して再現する）

## CPU

自分のビュー（自分の手札と、公開されている都市）だけで判断する。手札ごとに、建てる・段階・捨てるを、点の増え方（最後の得点の計算で足したときの差）、軍事の勝ち負けの変化、資源・交易の値打ち（早い時代ほど高い）、払うコインで評価する。ゆらぎを入れて、強すぎないようにしている。

- ふつう（既定）・やさしい の 2 段階
- 強さの測定：`npm run sim -- <試合数> <強さの並び> <面>`（例：`npm run sim -- 60 normal,strong,normal A`）。`strong`（ゆらぎなし）と `random` は測定用

## ファイルの構成

| ファイル | 内容 |
|---|---|
| `public/js/cards.js` | カードと不思議のデータ（人数ごとに入るカード、費用、連鎖、効果） |
| `public/js/city.js` | 都市の計算：生産、隣から買える資源、交易の値段、払い方の候補、科学、軍事、得点 |
| `public/js/game.js` | ゲーム本体。同時に選んで公開する手番、特別な力。`applyCommand` と `Game.replay` |
| `public/js/game-view.js` | ビュー（自分の手札と、自分が選んだ中身だけ） |
| `public/js/cpu-player.js` | CPU（ビューだけを見る） |
| `public/js/game-controller.js` | ローカル対戦のコントローラー（`getView()` / `send()`） |
| `public/js/card-text.js` | カードの効果・費用の短い表示 |
| `public/js/main.js` | 画面の進行 |
| `server/src/game-definition.js` | オンライン対戦用のゲームの定義（netplay-kit の形） |
| `server/src/handler.js` | オンライン対戦の Lambda の入口 |
| `public/js/online-config.js` | オンライン対戦の接続先 |

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。3〜7人で、足りない席は CPU で埋められる。全員が同時に選び、各人のビューには自分の手札と自分が選んだ中身だけを入れる（配るカードもシード付きの乱数で、記録から再現できる）。対戦中に部屋を出た人の席は CPU が引き継ぐ。不思議の面と CPU の強さは、ロビーでホストが決める。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'seven-wonders' })`。web-games の1つのスタックから `?game=seven-wonders` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
