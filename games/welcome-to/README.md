# ウェルカム・トゥ

3本の通りに家番号を書き込み、家並み・公園・プール・都市計画で得点を競うゲーム「ウェルカム・トゥ（Welcome To...、Blue Cocker Games 2018）」の基本ゲームを、ブラウザで遊べるようにしたもの。1人（公式の1人用の変種）でも、CPU と合わせて6人までで遊べる。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

絵（効果のアイコン・得点表の通り・アイコン）は、すべて SVG で自作している。説明の文も自分で書いたもので、公式の文は写していない。

## 遊び方（基本ゲーム）

- 得点表には3本の通り（上 10軒・中 11軒・下 12軒）がある。プールを作れる家は、上が3・7・8軒目、中が1・4・8軒目、下が2・7・11軒目
- 家番号のカード81枚を27枚ずつ3つの山にする。毎手、各山の上のカードをめくって横に置く。めくったカードの裏（効果）と、山の新しい一番上（番号）が1つの組み合わせになり、全員が同時に3つから1つを選ぶ
- 番号は、どこかの通りの空き家に書く。通りの中では左から右へ大きくなるように（同じ番号は書けない。間は空けてよい）
- どこにも書けなければ、断り（建築許可の却下）が1つ増え、効果も使えない
- 効果（使うかは選べる）
  - 測量士：家と家の間にフェンスを1本立てる。フェンスではさまれた1〜6軒が全部建つと、家並みが完成する
  - 不動産屋：家並みの大きさを1つ選び、1つあたりの値を上げる
  - 造園家：建てた通りに公園を作る
  - プール業者：プールの印のある家に建てると、プールができる
  - 派遣：番号を ±1・±2 変えられる（0〜17）。雇った人数を数える
  - ビス：隣の家と同じ番号の家をもう1軒建てる（フェンスはまたげない）
- 都市計画（n°1〜3 から1枚ずつ）：条件の大きさの家並みがそろったら達成できる。最初に達成した手の人は高い点、それより後の人は低い点。使った家並みは、ほかの計画に使えず、フェンスで分けられない
- 誰かが、断りを3つ・都市計画を3つ・家を全部、のどれかに達した手で終わる

### 1人で遊ぶとき（公式の1人用の変種）

- 81枚を1つの山にし、後半に1人用のカードを混ぜる。毎手3枚をめくり、1枚の番号と、別の1枚の効果を使う
- 1人用のカードが出たら、都市計画はどれも低い点になる
- 山札がなくなっても終わる（81枚で27手）。派遣は、6人以上を雇えば7点（それより少なければ0点）

### 資料と、資料で分からない点の決め方

ルールは、公式のルールブック（英語版。Blue Cocker Games・Deep Water Games）に合わせた。得点表の数値・プールの位置・都市計画の内訳・カードごとの効果は、ルールブックに載っていないため、Board Game Arena の版（説明のページと、公開されている実装の数値）で確かめた。

- 山札がなくなったとき：ルールブックは「切り直して配り直す」とだけ書いている。Board Game Arena に合わせ、表に出ているカードと、捨て札の一番上（その手に捨てた効果のカード）を残して、ほかを切り直す
- 派遣の点：1人以上を雇った人のうち、人数の多い順に 7・4・1点。同じ人数なら同じ点で、次の人は次の順位になる（例：5・5・3人なら 7・7・4点）。Board Game Arena に合わせた
- 派遣は、番号を変えなくても、その組み合わせで建てたら1人と数える。人数に上限は設けない
- 公園・プール・派遣は、選んだ組み合わせで建てたときに自動で消す（使わない理由がないため）
- 都市計画は、その手に家を建てた（か断った）あとに達成できる。使う家並みは自動で選ぶ（まだ使っていないものから、上の通りの左から）。同じ手に達成した人は、全員が高い点
- 最初の都市計画の達成で切り直すか：その手に達成した人のうち、1人でも選べば切り直す（Board Game Arena に合わせた）。1人用の変種では切り直さない。CPU は切り直さない
- ビスは9回まで（減点の表が9つまでのため）。両隣の番号のどちらでも写せる家では、画面からは左隣の番号を写す
- 1人用のカードは、山札の後半（41〜82枚目）のどこかに入る
- 同点なら、完成した家並みの多い人、それも同じなら1軒の家並みの多い人、2軒の…の順。それでも同じなら全員の勝ち（ルールブックは「もう1回遊ぶ」）
- その手に書いたものは、手を終えるまで取り消せる
- 基本ゲームだけ。ラウンドアバウト・上級の都市計画・エキスパートルールは入れていない

### 画面の操作

- 上のカード（効果と番号）を押すと、その番号を書ける家が光る。家を押すと建つ
  - 1人のときは、番号に使うカードを押してから、効果に使うカードを押す
  - 派遣のときは、下の −・＋ で書く番号を変える
- 測量士・不動産屋・ビスは、建てたあとに、光ったフェンスの場所・家並みの値・家を押して使う。使わないなら「次へ」
- そろった都市計画は光るので、押して達成する
- どこにも書けないときは「断る」
- 右上の人のボタンで、全員の街と得点の見込みを見られる
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

## CPU

強さは「ふつう」と「やさしい」。CPU は自分のビュー（全員の紙とめくったカード。山札の並びは見ない）だけを見て、紙の良さの点数（`evaluate`）が一番上がる組み合わせ・番号・家・効果を選ぶ（`public/js/cpu-player.js`）。

- 今の得点（公園・プール・完成した家並み・ビスと断りの減点）と派遣の人数を数える
- フェンスで区切った6軒以下の区画は、建った家の割合に応じて、家並みの値の一部を足す
- 両隣の番号の間に、書ける番号が足りない空き家を減点する（出やすい番号ほど埋まりやすいと見る）
- そろった都市計画は、すぐ達成する
- やさしいは、そろいかけの計画と派遣を軽く見て、候補の点数に大きなゆらぎを足す

```bash
# 試合数・人数・強さ（normal・easy・mixed）。mixed は席ごとに強さを交互に変えて比べる
node scripts/cpu-match.mjs 200 2 mixed
```

| 対戦 | ふつう | やさしい |
|---|---|---|
| 1人で100試合の平均点（1人用の変種） | 83.4点 | 71.8点 |
| 2人（ふつう対やさしい）200試合の平均点 | 95.5点 | 78.1点 |
| 同じ200試合の勝ち数 | 164勝 | 36勝 |
| 4人（ふつう2・やさしい2）100試合の勝ち数 | 84勝 | 16勝 |

1人で遊ぶときの目安：ふつうの CPU の平均は約83点（内訳の平均は、計画 8.9・公園 29.1・プール 16.6・家並み 29.2）。複数人の対戦では、誰かの断りが3つになって終わることが多い（2人で約86%）。

### オンライン対戦を入れるとき

netplay-kit の `scripts/sync.mjs` で部屋の処理を写し、`server/src/game-definition.js` を `createHandler` と `startDevServer` に渡す。部屋には参加者・シード・操作の記録だけを保存し、操作のたびに記録から再現する。全員が同じ手を同時に進めるので、操作を待っている人は複数いる（`game.actors()`）。ビューは全員の紙を含む（隠すのは山札の並びだけ）。1人で部屋を作ると、1人用の変種になる。
