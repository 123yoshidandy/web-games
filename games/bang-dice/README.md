# バン！ダイスゲーム

保安官・副保安官・無法者・裏切り者に分かれ、ダイスで撃ち合う正体隠しのゲーム「バン！ダイスゲーム（BANG! The Dice Game）」の基本ゲーム（拡張なし）を、ブラウザで CPU と遊べるようにしたもの。3〜8人（あなた＋CPU 2〜7人）。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

絵（ダイスの目・アイコン）は、すべて SVG で自作している。説明の文も自分で書いたもので、公式の文は写していない。

## 遊び方（基本ゲーム）

- 役割：人数ごとに配り、保安官だけ公開する。保安官から始める

| 人数 | 保安官 | 副保安官 | 無法者 | 裏切り者 |
|---|---|---|---|---|
| 4 | 1 | 0 | 2 | 1 |
| 5 | 1 | 1 | 2 | 1 |
| 6 | 1 | 1 | 3 | 1 |
| 7 | 1 | 2 | 3 | 1 |
| 8 | 1 | 2 | 3 | 2 |

- 3人：副保安官・無法者・裏切り者を全員に公開し、副保安官から始める。副保安官は裏切り者を、裏切り者は無法者を、無法者は副保安官を、自分の手で倒せば勝ち
- キャラクター16人から1人ずつ配る。体力の上限はキャラクターの体力（保安官は +2）
- 手番：ダイス5つを振り、好きなダイスを2回まで振り直す
  - 矢：出たらすぐ矢を1本取る。矢の山（9本）が尽きたらインディアンの襲撃。全員が持っている矢の数だけ体力を失い、矢は山に戻る
  - ダイナマイト：振り直せない。3つそろうと体力を1失い、もう振り直せない（残りの目は使う。ダイナマイトで脱落したら使わない）
- 振り終えたら、1・2 → ビール → ガトリングの順に、出た目をすべて使う
  - 1：距離1の人の体力を1減らす。2：距離2の人。距離は左右の近いほうを数え、前の手番までに脱落した人は飛ばす（この手番の中で倒れた人は数える）。残りが3人以下なら、2も距離1の人に使う
  - 1と2は、相手を全部決めてから同時に撃つ（残りの体力より多く割り当ててもよい）
  - ビール：だれか（自分でもよい）の体力を1回復（上限まで）
  - ガトリング3つ以上：ほかの全員の体力を1減らし、自分の矢をすべて山に戻す
- 体力が0になったら脱落し、役割を公開する。持っていた矢は山に戻す
- 保安官が倒れたら無法者の勝ち。裏切り者が1人だけ残ったときだけ裏切り者の勝ちで、副保安官や2人目の裏切り者が残っていれば無法者の勝ち。全員が同時に倒れても無法者の勝ち
- 無法者と裏切り者が全員倒れたら、保安官と副保安官の勝ち（脱落していてもチームが勝てば勝ち）。8人の裏切り者2人は、それぞれ1人で戦う
- 3人で、的をほかの人に倒されたら、残った2人は最後の1人になることを目指す

ルールは、公式のルールブックの新しい版（dV Giochi の「BANG! Dice Game_Rules_ENG.pdf」）に合わせた。体力と能力は、古い版（fgbradleys.com の PDF）と rulespal.com の写しでも一致を確かめた（どれも公式のルールブックがもとで、独立した資料ではない）。新しい版と古い版で違う点（ダイナマイト3つのあと、ペドロ・ラミレスの捨てる本数、ヴァルチャー・サムの同時の脱落、1・2を同時に撃つ、距離の数え方）は、新しい版に合わせた。

### 資料で分からない点の決め方

- バート・キャシディは、2点のダメージ（スラブの2倍）なら、矢を何本取るか（0〜2本）を選べる
- ガトリングは、4つ以上出ても1回（ウィリー・ザ・キッドの書き方から）
- シド・ケッチャムの回復は、体力の上限を超えない（ビールと同じ）
- ガトリングや襲撃で何人かが同時に倒れたときは、全員に与えてから勝ち負けを判定する
- 手番の人が襲撃で倒れたときも、ダイナマイトと同じく、残りの目は使わずに次の人へ
- 3人で、残った2人の一方が襲撃・ダイナマイトで倒れたときは、残った1人の勝ちとする。3人で全員が同時に倒れたときは、ふつうの対戦と同じく無法者の勝ちとする
- キャラクターは選ばせず、1人ずつ配る（Board Game Arena にダイス版が見つからず、既定は確かめられなかった）
- CPU のペドロ・ラミレスは、捨てられるだけ矢を捨てる

### 画面の操作

- 席は、自分を下に、手番の順（時計回り）に並ぶ。席の右上の数字は、手番の人からの距離
- 席を押すと、そのキャラクターの能力と体力・矢が見られる
- 振ったあと、ダイスを押すと振り直すダイスに選べる（ダイナマイトは赤い印で、振り直せない）。「振り直す」か「決定」
- 撃つ・回復させる相手は、光った席を押して選ぶ。1・2 が2つ以上あるときは、ダイスを押して使う目を選べる。撃つのは、1・2 の相手を全部決めてから（決めた相手の席に「狙い」の数が出る）
- 上の矢の数は、矢の山の残り。記録のボタンで、振った目を含むすべての出来事を見られる
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

## CPU

強さは「ふつう」と「やさしい」。どちらも自分のビュー（自分の役割と、公開された情報）だけを見て判断し、ほかの人の隠れた役割はのぞかない（`public/js/cpu-player.js`）。

- 公開された行動（だれがだれを撃った・回復した・ガトリングを撃った）から、各人が保安官の味方らしいか敵らしいかを点数にする
- 自分の役割から、各人をどれだけ倒したいかを決め、ダイスを残す・撃つ相手・回復させる相手を選ぶ
- ふつうは、まだ分からない役割の残りの数（副保安官が残っていなければ全員敵、など）も使う
- やさしいは、保安官への行動だけで推測し、ときどきダイスを残す判断や撃つ相手を誤る

```bash
# 試合数・人数・強さ（normal・easy・mixed）。mixed は席ごとに強さを交互にして、同じ役割で勝率を比べる
node scripts/cpu-match.mjs 1000 5 normal
```

ふつうの CPU 同士の、役割ごとの勝率（各 600 試合）：

| 人数 | 保安官側 | 無法者 | 裏切り者 |
|---|---|---|---|
| 3 | 副保安官 33% | 39% | 28% |
| 4 | 17% | 61% | 22% |
| 5 | 54% | 30% | 16% |
| 6 | 23% | 68% | 9% |
| 7 | 49% | 42% | 9% |
| 8 | 50% | 37% | 13%（2人のどちらか） |

```bash
npm install

python3 -m http.server 8000

```

### オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。3〜8人で、足りない席は CPU で埋められる。ほかの人の役割は、保安官と脱落した人のほかはビューに入れない。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'bang-dice' })`。web-games の1つのスタックから `?game=bang-dice` で呼ばれる）
- ゲームの定義は `server/src/game-definition.js`（記録だけを保存して再現する。各席には、その席から見えるビューだけを送る）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
