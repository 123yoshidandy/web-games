# センチュリー：スパイスロード

香辛料を集めて交換し、得点カードを買うカードゲーム「センチュリー：スパイスロード（Century: Spice Road）」の基本ゲームを、ブラウザで CPU と遊べるようにしたもの。2〜5人（あなた＋CPU 1〜4人）。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

絵（香辛料・カード・硬貨・アイコン）は、すべて CSS と SVG で自作している。

## 遊び方（基本ゲーム）

- 香辛料は4種類。黄（ターメリック）＜赤（サフラン）＜緑（カルダモン）＜茶（シナモン）の順に価値が上がる
- カード：商人カード43枚（ほかに、最初の手札の2種類を人数分）、得点カード36枚
- 準備：商人カードを6枚、得点カードを5枚並べる。左端の得点カードの上に金貨を人数×2枚、2番目の上に銀貨を人数×2枚置く
  - 各自の最初の手札は「黄2個を得る」「格上げ2回」の2枚
  - 手番の順に、黄3／黄4／黄4／黄3と赤1／黄3と赤1 をもらう
- 手番には、次のどれか1つを行う
  - 出す：手札の商人カードを1枚使い、使用済みにする
    - 香辛料のカード：描かれた香辛料を得る
    - 交換のカード：描かれた交換を、香辛料がある限り何回でも続けて行う
    - 格上げのカード：香辛料を1段ずつ、描かれた回数まで上げる（同じ香辛料を続けて上げてもよい。回数より少なくてもよい。茶は上げられない）
  - 取る：商人カードを1枚手札に加える。それより左のカードに、香辛料を1個ずつ置いていく。取ったカードの上に置かれていた香辛料ももらう
  - 休む：使用済みのカードを全部手札に戻す
  - 得点カードを買う：描かれた香辛料を払って取る。左端なら金貨、2番目なら銀貨ももらう。金貨が尽きたら、銀貨が左端に移る
- キャラバン（持てる香辛料）は10個まで。手番の終わりに超えていたら、選んで戻す
- だれかが得点カードを、2〜3人なら6枚、4〜5人なら5枚取ったら、その巡の終わり（最初の手番の人に戻る前）で終わる
- 得点：得点カードの点＋金貨3点・銀貨1点＋黄以外の香辛料1個につき1点。同点なら、手番の順が後の人の勝ち

カードのデータ（商人カードと得点カード）は、公開されている3つの別々の実装のデータを突き合わせ、すべて一致したものを使っている。

### 決めたこと

- 最初の手番の人はランダム
- 商人カードの山・得点カードの山が尽きたら、並びは補充されずに減っていく
- 金貨・銀貨が両方尽きたら、おまけはない

### 画面の操作

- カードを押して選ぶと、下の欄に、そのカードでできることが出る。もう一度押すか × で選ぶのをやめる
  - 交換：−／＋で回数を選ぶ（回数の数字を押すと、できるだけ多く）
  - 格上げ：自分の香辛料（下の色の数）を押すたびに、その色を1段上げる。「決定」で使う
  - 商人カードを取る：左のカードに置く香辛料は、黄から順に自動で選ぶ。自分の香辛料を押すと、その色を左から置く。置く見込みは、カードの下に点線で出る
  - 得点カード：払えるカードは緑に光る。払えないカードを選ぶと、足りない香辛料が出る
- 自分の香辛料の数は、選んでいる操作のあとの数で出す（増える色は緑、減る色は赤で縁取る）
- 10個を超えたら、自分の香辛料を押して戻す数を選ぶ
- 右上のボタンで、これまでの記録が見られる。遊び方と記録を開いている間は、CPU が止まる
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

自分から見える情報だけ（山の並び・ほかの人の手札は見ない）で打つ。通る手をすべて並べ、自分の次の手番までの2手を読んで、局面の値打ちで比べる。値打ちは、取った点＋狙える得点カードへの近さ＋商人カードの力（終わりが近いほど軽い）＋香辛料。得点カードへの近さは、足りない香辛料の格を、手持ちのカードで1手番あたりに増やせる格（休む手番も入れる）で割って、何手番かかるかで見積もる。強すぎないように、画面の CPU は評価の揺れと、ときどき2番目の手を選ぶ誤りを混ぜている。

```bash
# 試合数・人数・席ごとの強さ（normal は画面の CPU、strong は揺れのない比較用、random はでたらめに打つ比較用）
node scripts/cpu-match.mjs 200 3 normal,normal,strong
```

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm install
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/cards.js` | 商人カードと得点カードのデータ |
| `public/js/game.js` | ルールと得点の計算。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`art.js`・`animator.js` | 画面・絵・動き |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |
| `server/src/handler.js` | オンライン対戦のサーバーの入口（AWS Lambda） |
| `public/js/online-config.js` | オンライン対戦の接続先 |
| `public/js/netplay/` | netplay-kit のクライアントとロビーの画面の写し（同期で置く。手で直さない） |

### オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜5人で、足りない席は CPU で埋められる。ほかの人の手札はビューに入れない。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'century' })`。web-games の1つのスタックから `?game=century` で呼ばれる）
- ゲームの定義は `server/src/game-definition.js`（記録だけを保存して再現する。各席には、その席から見えるビューだけを送る）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
