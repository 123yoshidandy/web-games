# モダンアート

画家5人の絵を競りにかけ、買い、売ってお金を集めるカードゲーム「モダンアート（Modern Art、Reiner Knizia、Hans im Glück 1992）」を、ブラウザで CPU と遊べるようにしたもの。3〜5人（あなた＋CPU 2〜4人）。スマホの縦持ちでも横持ちでも、スクロールなしで1画面に収まる。ホーム画面に置くと、オフラインでも遊べる。

絵とアイコンは、すべて SVG で自作している（公式の画像は使っていない）。5人の画家の作風は、次のように描き分けた。説明の文も自分で書いたもので、公式の文は写していない。

| 画家 | 色 | 作風 | 枚数 |
|---|---|---|---|
| ライト・メタル（Lite Metal） | 黄 | 金属の円と斜めの帯 | 12 |
| ヨーコ（Yoko） | 緑 | やわらかい葉と曲線 | 13 |
| クリスティン・P（Christin P.） | 桃 | 花と水玉のポップな絵 | 14 |
| カール・ギッター（Karl Gitter） | 青 | 格子の色面（Gitter は格子） | 15 |
| クリプト（Krypto） | 茶 | 羊皮紙の上の謎の記号 | 16 |

## 遊び方

- 準備：70枚を混ぜて配る。所持金は1人100。自分の所持金は、ほかの人には見えない
- 手番：出す人が手札の絵を1枚出し、カードのしるしの方法で競る。**ほかの人が買ったら出した人に払い、出した人が自分で買ったら銀行に払う。** だれも値を付けなければ、出した人が無料でもらう（指値を除く）。値は1以上・自分の所持金まで。次は、出した人の左隣（手札のある人）が出す

| 競り | 進め方 |
|---|---|
| 公開 | だれでも値を上げられる。ほかの全員が降りたら、いちばん高い人が買う |
| 一声 | 出した人の左から1人1回だけ、前より高い値を言うか降りる。出した人が最後 |
| 入札 | 全員（出した人も）が同時に値を握り、いちばん高い人が買う。同額なら、出した人から時計回りで近い人（出した人が同額なら出した人） |
| 指値 | 出した人が値を決め（所持金まで）、左から順に買うか断る。全員断ったら、出した人がその値で買う |
| ダブル | 同じ画家のダブルでない1枚を足し、2枚まとめて、足したカードの方法で競る。出した人が足さなければ、左から順に足せる。足した人が新しく出す人になってお金を受け取り、次はその人の左から（間の人は飛ばされる）。だれも足さなければ、最初に出した人が無料でもらう |

- 回の終わり：ある画家の**5枚目**が出たら、その回は終わり。5枚目は競らない（ダブルの2枚目が5枚目なら、2枚とも競らない。ダブルが5枚目なら、2枚目は出さない）。全員の手札がなくなったときも終わり（最後に出た絵は競らない）
- 順位：その回に出た枚数（競らなかった絵も数える）の多い3人の画家に 30・20・10 を足す。同数なら盤の左の画家（ライト・メタルに近いほう）が上。1枚も出ていない画家は順位に入らない
- 売る：買った絵を全部銀行に売る。1枚の値は、**その回に3位までに入った画家だけ、これまでの回の値の合計**。入らなかった画家の絵は、前の回の値があっても0。売った絵は片付け、手札は次の回に持ち越す
- 次の回：配って、最後の絵を出した人の左隣から。4回で終わり、お金の多い人の勝ち。残った手札には価値がない

| 人数 | 1回目 | 2回目 | 3回目 | 4回目 |
|---|---|---|---|---|
| 3人 | 10枚 | 6枚 | 6枚 | 0枚 |
| 4人 | 9枚 | 4枚 | 4枚 | 0枚 |
| 5人 | 8枚 | 3枚 | 3枚 | 0枚 |

### 資料と、資料どうしの食い違い

ルールは、次の英語のルールブックを読んで合わせた。

- 2017年の CMON 版（画家は Manuel Carvalho 12・Sigrid Thaler 13・Daniel Melim 14・Ramon Martins 15・Rafael Silveira 16）
- 2017年の韓国 Boardpia 版（実在の画家 マネ 12・セザンヌ 13・ゴッホ 14・ムンク 15・クリムト 16。ルネサンスの絵の組もある）

どちらも、手番・競り5種類・回の終わり・順位と値・配る枚数（3人 10・6・6・0、4人 9・4・4・0、5人 8・3・3・0）・所持金100で一致した。画家の名前と絵柄が版ごとに違うだけで、枚数は 12・13・14・15・16 の5人。ここでは、Hans im Glück 版（1992）の5人の名前を使った。

画家ごとの競りの種類の枚数は、ルールブックに表がない。有志の実装を比べ、多数の値を採った。

| 資料 | ヨーコの 一声・指値 | ほかの4人 |
|---|---|---|
| brdgme（Go と Rust。同じ作者） | 2・3 | 上の表と同じ |
| welol5（Java） | 2・3 | 上の表と同じ |
| 日本の有志の実装（Python） | 3・2 | 上の表と同じ |

食い違いはヨーコの一声と指値だけ。2対1で、一声2・指値3を採った。印刷されたカードとは照らし合わせていない。

版ごとの違いとして読めたのは次の点。

- 全員の手札がなくなったとき：CMON 版は「最後に出た絵は競らず、だれのものにもならない」と明記している。Boardpia 版は「最後の絵が競りにかかったら、ゲームが終わる」と書き、競るかどうかがはっきりしない。明記のある CMON 版に合わせた
- 3人の変種（見えない4人目の札を表にして順位にだけ数える）、2人の変種、CMON の要約カードにあるダブルの代金を折半する変種：ここでは入れていない
- CMON 版の古い規則書には「12・15・15・15・13 枚」とあるが、直した版（v18）で 12〜16 枚になっており、誤植と見た

### 資料で分からない点の決め方

ルールブックで読み方が分かれる点や、画面のために形を決めた点は、次のようにした（`public/js/game.js` の先頭にも書いた）。

- **公開の競りは、出した人の左から順に（出した人も含めて）「値を上げる」か「降りる」を回す。** 降りた人は、その競りには戻れない。いちばん高い人のほかが全員降りたら終わり。原作の「だれでも好きなときに声を出す」形を、画面で遊べる順番の形にした
- **お金が同点なら、勝ちを分け合う。** どの規則書にも同点の決め方がない
- 指値で、出した人の所持金が0のときは、値は0（実質ただ）にした
- ダブルの2枚目を足す番では、足せる絵を持っていない人も「足さない」を選ぶ（持っていないことを、ほかの人に知らせないため）

### 画面の操作

- 出す番では、手札の絵を選んで「出す」。光っている絵が出せる絵
- 競りでは、値を −10・−1・+1・+10 で決めて「入札」か「降りる」。入札（握り）は「握る」（0なら「入れない」）。指値は「この値」で決め、ほかの人の指値には「買う」か「断る」
- 上の段は画家ごとの、その回に出た枚数（5つの点）、回ごとの値、これまでの合計。その下の人の欄は、所持金（自分だけ。ほかの人は ?）、手札の枚数、その回に買った絵（画家の色と枚数）
- 回が終わると、画家の順位と1枚の値、各人が売った額を出す。閉じるまで CPU は待つ
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

## CPU

強さは「ふつう」と「やさしい」。CPU は、その席のビュー（`createGameView`）だけを受け取って決める（`chooseCommand(view, level)`）。ほかの人の手札・所持金・握った額と、山の並びは見えない。ゲームの乱数も使わない（`public/js/cpu-player.js`）。

- ふつう：画家ごとに、この回の終わりの絵1枚の値打ちを見積もる（`estimateValues`）
  - 見込みの枚数 ＝ その回に出た枚数 ＋ 自分の手札の約半分 ＋ 見えていないカードのうち、ほかの人の手札にありそうな分の約3分の1
  - 見込みの順位が3位までなら「これまでの値＋順位の値」を、4位以下との差に応じて割り引く。4位以下なら、3位に届く見込みに応じて小さく見る
  - 競り：買う側は値打ちの8割まで、出した人が自分で買うときは5割5分まで。入札はその少し下を握る。指値は値打ちの7割5分に決め、ほかの人の指値は値打ちの8割5分までなら買う
  - 出す絵：高く売れそうな絵（値打ちの6割5分。ダブルで足せる絵があれば2枚分）と、自分の買った絵の値が上がるかを足して選ぶ。自分の絵で回が終わるときは、終わらせたときの自分の売り上げとほかの人の平均を比べる
- やさしい：値打ちを「これまでの値＋15」と大まかに見て、揺らぎを付けて競る。出す絵はでたらめ

```bash
# 試合数・強さの並び（easy・normal）。席の並びは試合ごとに1つずつずらす
node scripts/cpu-match.mjs 400 easy,normal,easy
```

| 対戦 | 試合数 | ふつうの勝率 | やさしいの勝率 | 平均の所持金（ふつう／やさしい） |
|---|---|---|---|---|
| 3人（やさしい・ふつう・やさしい） | 400 | 83.8% | 7.5%・8.8% | 548／394 |
| 4人（やさしい3・ふつう） | 400 | 70.4% | 13.5%・8.1%・8.0% | 481／350 |
| 5人（やさしい4・ふつう） | 400 | 63.5% | 10.5%・9.5%・8.0%・8.5% | 436／317 |
| 4人（ふつう4人） | 400 | 29.8%・24.9%・23.5%・21.9% | — | 349 |
| 4人（やさしい4人） | 400 | — | 25.1%・23.8%・25.3%・25.9% | 418 |

同点で複数が勝った試合は、勝ちを等分して数えた。どの組み合わせでも、止まった試合はない。

```bash
# 画面（http://localhost:8000/ を開くと public/ へ移る）
python3 -m http.server 8000

```

### オンライン対戦を入れるとき

netplay-kit の `scripts/sync.mjs` で部屋の処理を写し、`server/src/game-definition.js` を `createHandler` と `startDevServer` に渡す。部屋には参加者・シード・操作の記録だけを保存し、操作のたびに記録から再現する。入札では、まだ握っていない全員が同時に操作を待つ（`game.actors()`）。端末から届いた操作は `sanitize` で種類ごとの項目だけを取り出してから `applyCommand` に渡す。
