# 麻雀

日本のリーチ麻雀（4人打ち）を、ブラウザで CPU 3人と打てるようにしたもの。東風戦と半荘戦を選べる。横画面向け（縦持ちのスマホでは、画面ごと横向きに回して描く）。PC でも遊べる。ホーム画面に置くと、オフラインでも遊べる。

牌の絵とアイコンは、すべて SVG で自作している。

## 遊び方

- 25,000点で始め、終局のときに一番点数が多い人の勝ち
- 牌を1回タップで選び（少し持ち上がる）、もう1回タップで捨てる
- ツモ・リーチ・カン・九種九牌は、右下のボタンで行う。リーチは、ボタンを押してから宣言牌を選ぶ（テンパイを保てる牌だけ選べる）
- ほかの人の捨て牌で鳴けるときは、卓のその牌が光り、右下に「上家の打牌」とロン・ポン・チー・カン・スキップのボタンが出る。チーの組み合わせが複数あれば、押したあとに選ぶ
- 左上の吹き出しのボタンで、鳴きの確認を切れる（切ると、ポン・チー・カンは聞かずに見送る。ロンは聞く）
- テンパイすると、左下に待ちの牌を出す。フリテンなら「フリテン」と出す
- リーチのあとは、和了やカンができないツモは自動でツモ切りする
- 途中でホームに戻っても、「続きから」で再開できる

## 採用したルール

ネット麻雀で標準的なものに合わせた。

| 項目 | ルール |
|---|---|
| 持ち点 | 25,000点。30,000点を基準に延長を決める（ウマ・オカはなく、順位と点数だけを出す） |
| 赤ドラ | 5萬・5筒・5索に1枚ずつ |
| 喰いタン・後付け | あり |
| 喰い替え | なし（鳴いた牌と同じ種類、チーの筋の牌は、その打牌で捨てられない） |
| ドラ | 表ドラ・裏ドラ（立直で和了したとき）・カンドラ・カン裏 |
| 立直 | 門前でテンパイ、1,000点以上、山の残りが4枚以上。立直のあとの暗槓は、待ちが変わらないときだけ。宣言牌でロンされたら立直は成立せず、供託も出さない |
| フリテン | 自分の捨て牌に待ちがある・ロンできる牌を見送った（次の自分の打牌まで）・立直のあとに見送った（その局の終わりまで）。ツモはできる |
| ダブロン | あり。本場は両方に、供託は放銃者から見て近いほう（上家取り） |
| 本場 | ロンで300点、ツモで1人100点 |
| 流局 | 荒牌流局はテンパイ料（合わせて3,000点）。形式テンパイ（役がなくてもよい）を認める。手の中で4枚使っている牌だけを待つ形はノーテン |
| 途中流局 | 九種九牌・四風連打・四家立直・四槓散了・三家和 |
| 連荘 | 親の和了と、流局で親がテンパイのとき。途中流局も連荘。本場は親の和了・流局で1つ増え、子の和了で0に戻る |
| 終局 | 東風戦は東4局、半荘戦は南4局まで。そこで30,000点以上の人がいなければ次の風に延長し、だれかが30,000点に届いたら終わる（延長は1つの風まで）。0点未満の人が出たら終わり（飛び）。オーラスの親が和了・テンパイで、30,000点以上の単独トップなら終わり（和了止め・テンパイ止め） |
| 順位 | 点数の順。同点は起家に近い順。残った供託はトップがもらう |
| 符 | 副底20符、門前ロン10符、ツモ2符（平和ツモは20符）、刻子・槓子、役牌の雀頭（連風牌は4符）、嵌張・辺張・単騎2符。鳴いた平和形のロンは30符。七対子は25符 |
| 点数 | 切り上げ満貫なし。13翻以上は数え役満 |

### 割り切った点

- **カンドラは、どのカンでもすぐにめくる**（大明槓・加槓のあとの打牌を待たない）
- 槍槓は加槓だけ（国士無双の暗槓への槍槓はない）
- 流し満貫・人和・責任払い（包）はない
- ダブル役満（国士13面・四暗刻単騎・純正九蓮・大四喜）は数えない。役満が複数そろったら重ねる（字一色＋大四喜＋四暗刻なら3倍役満）
- 配牌は4枚ずつではなく1枚ずつ配る（並びはシードから決まるので、遊ぶうえでは同じ）
- 起家はランダムに決める

## CPU

自分から見える情報（ビュー）だけで決める。ほかの人の手牌や山の並びは見ない。

- 和了できれば必ず和了する
- 打牌は、向聴数が小さく、受け入れ（向聴数が進む牌の、まだ見えていない枚数）が多いものを選ぶ。ドラ・赤・役牌の対子は少し残し、孤立した字牌は早めに切る
- 門前でテンパイしたら立直する（待ちが残っていないときはしない）。宣言牌は待ちが一番多くなるもの
- 立直した人（や3つ鳴いた人）がいて、手が2向聴以上（1向聴でも危ない牌しかない）なら降りる。現物・筋・見えている字牌の順に安全とみる
- 鳴くのは、役牌のポンと、喰いタン・混一色の見込みがあるとき、役牌をすでに鳴いているときで、向聴数が進むときだけ
- 九種九牌は、国士無双が遠いときに宣言する

CPU 同士の対局（`node scripts/cpu-match.mjs 100 south`）で、100対局すべてが最後まで終わることを確かめている。1対局あたり約11局、和了は約8割（ツモ 36%・ロン 64%）、荒牌流局は約2割。

```bash
# 対局数と長さ（east・south）
node scripts/cpu-match.mjs 100 south
```

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest。リポジトリの直下で）
npm test -w games/mahjong
```

| ファイル | 役割 |
|---|---|
| `public/js/tiles.js` | 牌の番号と種類、表記 |
| `public/js/shanten.js` | 向聴数と待ち |
| `public/js/scoring.js` | 役・符・翻と点数 |
| `public/js/game.js` | 局と対局の進行。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`art.js` | 画面と牌の絵 |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |

テストは、点数表との突き合わせ（子・親のロンとツモ、本場）、代表的な手の役と符（平和・七対子・役牌・喰いタン・裏ドラ・清一色・数え役満・三色・一通・対々和・三暗刻・チャンタ・純チャン・混一色・小三元・二盃口・嶺上開花など）、役満、局の進行（ロン・ダブロン・三家和・ツモ・ポン・チー・食い替え・暗槓・フリテン・立直・流局・連荘・延長・飛び・和了止め）、記録からの再現、断った操作で状態が変わらないこと、CPU だけの対局が最後まで終わること、を確かめている。

### オンライン対戦を入れるとき

ルールとビューは、netplay-kit の「ゲームの定義」の形（`server/src/game-definition.js`）で用意してある。netplay-kit の `sync.mjs` で部屋の処理を写し、この定義を `createHandler` と `startDevServer` に渡す。ロビーの設定は東風戦・半荘戦（`length`）。画面は、ローカル対戦と同じ `getView()` / `send()` の形のオンライン用のコントローラーを足す。鳴きの確認では複数の人が同時に答えるので、画面は自分の答えを送ったら、ほかの人を待つ表示にする。
