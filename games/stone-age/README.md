# ストーンエイジ

人を置いて資源を集め、建物と文明カードで点を競うボードゲーム「ストーンエイジ（Stone Age、Michael Tummelhofer（Bernd Brunnhofer）、Hans im Glück 2008）」の基本ゲーム（拡張なし）を、ブラウザで CPU と遊べるようにしたもの。2〜4人（あなた＋CPU 1〜3人）。スマホの縦持ち向けで、スクロールなしで1画面に収まる。ホーム画面に置くと、オフラインでも遊べる。

絵とアイコンは、すべて SVG で自作している（公式の画像は使っていない）。説明の文も自分で書いたもので、公式の文は写していない。

## 遊び方（基本ゲーム）

- 各自、人5人・食料12で始める。最初の番の人は、ラウンドごとに次の人へ移る
- ラウンドは3つの段階
  1. **人を置く**：最初の番の人から順に、1か所に1人以上を置く。全員が置き終えるか、置ける場所がなくなるまで続ける。同じ場所に2回は置けない
  2. **行動する**：最初の番の人から順に、置いた場所を好きな順で使う
  3. **食べさせる**：畑の段の分だけ食料を得て、人1人に食料1つ。足りなければ食料を全部出し、残りを資源で払うか −10点
- 場所

| 場所 | 置ける人数 | すること |
|---|---|---|
| 狩り場 | 何人でも | サイコロの合計÷2の食料 |
| 森・粘土採り場・石切り場・川 | 合わせて7人まで | 合計÷3の木・÷4の粘土・÷5の石・÷6の金 |
| 畑 | 1人 | 畑が1段上がる（10段まで） |
| 道具作り | 1人 | 道具が1つ増える（3つまで。そのあとは低いものから1つずつ上がり、4・4・4まで） |
| 小屋（「愛の小屋」とも呼ばれる） | ちょうど2人 | 人が1人増える（10人まで） |
| 文明カード（4枚） | 各1人 | 右から1〜4つの資源（木・粘土・石・金のどれでも。食料は不可）を払って取る |
| 建物の山（人数分） | 各1人 | 表の建物の資源を払って建て、すぐに点が入る |

- 2人・3人のとき：畑・道具作り・小屋のうち、1ラウンドに使えるのは2か所。森・粘土採り場・石切り場・川には、2人なら1人、3人なら2人までしか置けない
- 道具：サイコロを振ったあと、まだ使っていない道具の値を合計に足せる。道具は1ラウンドに1回ずつ（分けては使えない）
- 文明カード：上半分はすぐ受け取り、下半分は終わりの得点。ラウンドの終わりに、残ったカードを右（安い側）へ寄せ、山から補充する
- 終わり：建物の山が1つでも空になったら、そのラウンドの食べさせる段階のあとで終了。ラウンドの初めに文明カードを4枚に補充できなければ、そこで終了
- 終わりの得点
  - 緑の文化（8種×2枚）：違う種類の組ごとに、種類の数の2乗（8種で64点）。同じ種類の2枚目は、次の組に入る
  - 砂色の職業：人の数 × もとになる数（農民＝畑の段、道具職人＝道具の値の合計、小屋の建築家＝建物の数、シャーマン＝人の数）
  - 残った資源：1つ1点（食料は数えない）
- 点が同じなら、畑の段＋道具の値の合計＋人の数が多い人の勝ち

### 文明カード（36枚）

| 上半分（すぐ受け取る） | 枚数 | 下半分 |
|---|---|---|
| ダイス：人数分のサイコロを振り、取った人から1つずつ選ぶ（1 木・2 粘土・3 石・4 金・5 道具・6 畑） | 10 | 土器・文字・日時計・運搬・小屋の建築家1・小屋の建築家2・農民1・農民2・道具職人2・道具職人2 |
| 食料 7・5・4・3・3・2・1 | 7 | 土器・医術・小屋の建築家1・機織り・農民2・小屋の建築家2・機織り |
| 石1・石2・石1・金1・粘土1 | 5 | 農民1・運搬・シャーマン1・シャーマン1・シャーマン2 |
| サイコロ2個で金・木・石（道具を足せる） | 3 | 芸術・シャーマン2・シャーマン1 |
| 3点 | 3 | 小屋の建築家3・音楽・音楽 |
| 道具 | 1 | 芸術 |
| 畑 | 2 | 農民1・日時計 |
| 山の上のカードを伏せて取る（下半分だけ数える） | 1 | 文字 |
| 1回だけの道具 4・3・2 | 3 | 道具職人1・道具職人1・道具職人2 |
| 好きな資源2つ（いつでも） | 1 | 医術 |

職業の人数の合計は、農民7人・道具職人8人・小屋の建築家9人・シャーマン7人（それぞれ5枚）。

### 建物（28枚）

- 決まった資源（17枚）：木2粘土1（10点）・木2石1（11）・木1粘土2（11）・木2金1（12）・木1石2（13）・粘土2石1（13）・粘土2金1（14）・粘土1石2（14）・石2金1（16）、木粘土石（12）・木粘土金（13）・木石金（14）・粘土石金（15）が2枚ずつ。点は資源の値（木3・粘土4・石5・金6）の合計と同じ
- 4個を1〜4種類で（4枚）・5個を1〜4種類で（4枚）：払った資源の値の合計が点
- 1〜7個を好きに（3枚）：払った資源の値の合計が点

### 資料と、資料で分からない点の決め方

ルールは、公式のルールブック（Rio Grande Games の英語版 PDF。yucata.de に置かれているもの）を読んで合わせた。カードと建物の一覧は、次の資料を照らし合わせた。

- ルールブックの「文明カード」の頁：上半分の種類ごとの枚数（ダイス10・食料7・資源5・サイコロで資源3・3点3・道具1・畑2・追加のカード1・1回だけの道具3・好きな資源2つ1）と、緑16枚・砂色20枚
- yucata.de のルールの頁：今の版（種類ごとの枚数と、食料・資源・1回だけの道具の数）と、以前の版（カード1枚ごとの上半分と下半分、建物28枚の一覧）
- BrettspielWelt のカードの頁：職業ごとの人数と枚数（農民7人／5枚・道具職人8人／5枚・小屋の建築家9人／5枚・シャーマン7人／5枚）
- Board Game Arena の遊び方の頁：人数ごとの制限と、終わりの条件

食い違いと、決めたこと：

- **ダイスのカードの10枚目**：yucata の以前の版の一覧には、ダイスのカードが9枚しか載っていない（ほかの35枚はルールブックの種類ごとの枚数と合う）。BrettspielWelt の職業ごとの人数と照らすと、足りないのは「道具職人2人」の1枚だけ（一覧では6人／4枚）なので、10枚目を「ダイス／道具職人2人」とした
- **砂色のカードの枚数**：BrettspielWelt は「茶色のカード21枚」と書くが、内訳は5枚×4種で20枚。ルールブックの20枚に合わせた
- **ダイスの6の目**：BrettspielWelt は「食料」と書くが、ルールブックは「畑（食料の段）を1つ上げる」。ルールブックに合わせた
- **取った文明カードを見せるか**：ルールブックでは、取ったカードは伏せて重ねる。ただし取るときは全員に見えるので、画面では全員に見せる。山の上を伏せて取ったカード（追加のカード）だけは、本人にしか見せない（ビューで隠す）

ルールブックに書かれていない、または読み方が分かれる点：

- 最初の番の人は、ゲームの初めにランダムで決める
- 小屋（人が10人）・畑（10段）・道具作り（4・4・4）が上限でも置ける（効果はない。ほかの人に使わせないために置ける）
- 払えない文明カード・建物は、行動するときに自動で取らない（好きな資源2つのカードを持っていれば、その分も見込んで聞く）
- 道具を足しても得る数が変わらないときは、道具を使うかを聞かない
- 食料が足りないとき、資源で払うのは足りない分ちょうど（一部だけ払って −10点、はできない）。食料は全部出す
- ダイスのカードで、最後の人は残った1つを自動で受け取る。道具・畑が上限なら、その目を選んでも何も得ない
- 好きな資源2つのカードは、自分が操作する番（行動する段階と、食べさせる段階で払うとき）ならいつでも使える
- 道具のタイル（18枚）・資源・食料の数の上限はない（ルールブックの「資源が足りなくなったら、代わりのもので」から）
- 同点で、畑・道具・人の合計も同じなら、その全員の勝ち
- 画面の文明カードは、盤面と同じく左から費用4・3・2・1の順に並べ、残ったカードは右へ寄せる

### 画面の操作

- 光っている場所を押して選び、下の「置く」で置く。森などは −／＋ で人数を変える
- 行動する段階では、光っている自分の場所を押して「振る」「取る」「建てる」「使う」。残りが1か所なら自動で使う
- 道具・文明カードと建物の支払い・ダイス・食料が足りないときは、ダイアログで決める。ダイアログを閉じると盤面を見られ、下の「選ぶ」で開き直す
- 上の欄はほかの人（★点・人・食料・畑・道具の合計・木・粘土・石・金・取ったカードの数）。押すと、その人のカードと、いま終わったときに足される点の見込みが見られる。下の金色の欄が自分
- 光っていない場所を押すと、その場所の説明が下に出る
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

## CPU

強さは「ふつう」と「やさしい」。CPU は、その席のビュー（`createGameView`）だけを受け取って決める（`chooseCommand(view, level)`）。ビューにあるのは、公開されている情報（場・各人の資源と道具・山の枚数・建物の山の表）と自分のカードだけなので、文明カードの山の並び、建物の山の2枚目以降、ほかの人が伏せて取ったカードは見えない。CPU の判断にはゲームの乱数を使わない（記録の再現がずれないように）。やさしいの迷いは、ビューの操作の数とラウンドから作る（`public/js/cpu-player.js`）。

- ふつう：場所ごとに「得られるものの見込みの価値（点に換算）」を見積もって選ぶ
  - 食べさせる分の食料が足りなくなりそうなら、狩り場に足りる人数を先に残す
  - 1人で使う場所（文明カード・建物・畑・道具作り・小屋）は、残りのラウンドの見込みと職業の倍率から価値を出し、見合えば先に置く
  - 残りは、1人あたりの価値が高い資源の場所へ。見えている建物に足りない資源は高く見る。たくさん持っている資源は安く見る（ためこんで終わらない形を防ぐ）
  - 行動は、道具作り → 畑 → 小屋 → 道具のカード → サイコロの場所 → 建物 → 文明カードの順。道具は、得る数が増える分だけ使う
  - 食料が足りないときは、払う資源の価値が10点より低ければ払う
- やさしい：見積もりに大きな迷いを足し、資源の場所と人数をばらばらに選ぶ。道具はあるだけ使い、食料の備えも甘い
- 安全弁：30ラウンドを超えたら、払える文明カードと建物は必ず取る（下の試合では一度も使われていない。最長20ラウンド）

```bash
# 試合数・強さの並び（easy・normal）。席の並びは試合ごとに1つずつずらす
node scripts/cpu-match.mjs 1000 easy,normal
```

| 対戦 | 試合数 | ふつうの勝率 | やさしいの勝率 | 平均点（ふつう／やさしい） |
|---|---|---|---|---|
| 2人（やさしい・ふつう） | 1000 | 96.4% | 3.6% | 265.7／185.2 |
| 3人（やさしい・ふつう・やさしい） | 1000 | 94.1% | 2.9%・3.0% | 193.4／123.3 |
| 4人（やさしい・ふつう・やさしい・ふつう） | 1000 | 51.3%・48.1% | 0.3%・0.3% | 168.1／89.7 |
| 2人（ふつう・ふつう） | 1000 | 51.1%・48.9% | — | 239.8 |
| 3人（ふつう3人） | 1000 | 32.7%・33.3%・34.0% | — | 172.4 |
| 4人（ふつう4人） | 1000 | 24.3%・25.3%・25.0%・25.4% | — | 148.5 |
| 2人（やさしい・やさしい） | 1000 | — | 49.7%・50.3% | 198.2 |

同点で複数が勝った試合は、勝ちを等分して数えた。どの組み合わせでも、止まった試合はない（2〜4人の7通り×2000シードでも0）。やさしいは、ルールを覚える相手として弱めにしてある。

npm install

### オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜4人で、足りない席は CPU で埋められる。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'stone-age' })`。web-games の1つのスタックから `?game=stone-age` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
