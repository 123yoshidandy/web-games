# ウボンゴ

ピース（ポリオミノ）で盤面の形をすき間なく埋める早解きパズル「ウボンゴ（Ubongo）」を、スマホの縦画面で遊べるようにしたもの。1人ならタイムアタック、2〜4人なら CPU かオンラインの相手と宝石を集めて競う。

## 遊び方

- 毎ラウンド、全員が自分の盤面の形（カード）を受け取る。ダイスの目で、使う3つ（むずかしいは4つ）のピースが決まる
- ピースはドラッグで盤面に置く（マスに吸いつく）。タップで右に回し、2回タップか「反転」で裏返す。盤面の外に落とすとトレイに戻る
- 全部のピースで埋まったら解けたことになる。砂時計（上のバー。60・90・120秒から選ぶ）が尽きる前に解いた人は、早い順に宝石を取る
  - 宝石のボードは6列×12個。1位はコマを3列まで、2位は2列、3位は1列まで動かせ、4位は動けない。止まった列の手前から2個取る
- 9ラウンドで、1色をいちばん多く集めた人の勝ち。同じなら2番目に多い色、その次…で比べる（原作の初版のルール）
- ヒントは、正しいピースを1つ置く（1回ごとにタイムに10秒足す）。宝石を取る番には、おすすめの列を光らせる
- 1人のタイムアタックは、9問を解く時間の合計を競う。「飛ばす」と60秒足して次へ。最高記録はピースの数ごとに残る
- 結果の画面の「記録を見る」で、ラウンドごとに、自分のピースの動きと各人が解いた時刻を、時刻どおりに再生できる

## CPU

- CPU が解き終える時刻は、シード・ラウンド・席から作った乱数で決まる（`game.js` の `cpuFinishTime`。ゲームの乱数は使わない）。強さごとに、制限時間に対する平均の割合が違う（やさしい 0.8・ふつう 0.6・つよい 0.4）。制限時間を過ぎる回は解けない
- 宝石の列は `cpu-player.js` の `chooseRow` で選ぶ。やさしいは取れる数だけを見て、ふつう・つよいは多い色をさらに伸ばす列を選ぶ
- 人が全員解き終えたか、あきらめたら、残りの CPU は予定の時刻で結果を決めて、ラウンドを締める（待たない）
- `npm run cpu-match -w games/ubongo` で、CPU だけの対戦が最後まで進むことと、強さの違う CPU の勝ち数を確かめる

## 開発

```bash
npm test -w games/ubongo                 # ルール・問題・ヒント・オンライン・PWA のテスト
npm run cpu-match -w games/ubongo        # CPU どうしの対戦
npm run puzzles -w games/ubongo          # 問題のカード（public/js/puzzles.js）を作り直す
```

- `public/js/game.js`：ルール（DOM に依存しない）。状態はただのオブジェクトで、操作は `applyCommand(state, seat, command)` だけで変える。時刻はラウンドの始まりからのミリ秒 `t` を操作に入れる。`replay(options, commands)` で記録から同じ状態に戻る
- `public/js/puzzles.js`：問題のカード（3ピースと4ピースを各36枚）。`scripts/gen-puzzles.mjs` が、ピースをつなげて形を作り、同じ面積になるピースの組をソルバー（`solver.js`）で全部解いて、解ける組が6つ以上ある形だけを選ぶ。手で直さない
- `public/js/game-controller.js`：ローカル対戦の時計。CPU が解く時刻と時間切れを `tick`・`timeUp` の操作として記録し、途中経過（操作の記録・ピースの動き・経過時間）を保存して「続きから」で戻す
- `public/js/replay-player.js`：記録を時刻どおりに再生する
- 画面はスマホの縦向き（`manifest` の `orientation: portrait`）

## オンライン対戦

- 早解きの型：全員が同時に自分の問題を解き、解いた順はサーバーの時計で決める。端末から受け付けるのは `submit`（ピースの置き方）・`giveUp`・`pick` だけで、時刻はサーバーが入れ直す。サーバーは置き方が盤面をちょうど埋めているかを確かめる
- 問題はサーバーがシードから作ってビューで配る。ビューにシード・乱数・山札・CPU の予定の時刻は入れない
- CPU が解く時刻・時間切れ・宝石を選ぶ期限（20秒）は、定義の `deadline` で扱う。端末はビューの `nextEventIn`・`pickAt` から期限を知って ping を送り、サーバーに締切を確かめてもらう
- 対戦中に抜けた人の席は CPU が引き継ぐ。ヒントはオンラインでは出さない
- 手元では web-games の直下で `npm run dev:online` を動かし、`http://localhost:<port>/games/ubongo/public/` などで開く。通し試験は `node scripts/online-e2e.mjs ubongo`
- `public/js/online-config.js` の `DEPLOYED_SERVER_URL` は、サーバーをデプロイするまで空にしておく（公開したページでは「オンラインで遊ぶ」を出さない）

## 決めたこと

- 原作のカードはダイスの目ごとにピースの組が描かれている。ここでは、カードごとに目1〜6の6組を、どれも解けることをソルバーで確かめて作った（絵柄と問題は自作）
- ヒントとタイムアタックの「飛ばす」は原作にない。ヒントは1回10秒、飛ばすは60秒をタイムに足す
