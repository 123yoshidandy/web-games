# アバロン

一列に並べた玉で相手の玉を押し、6個盤の外へ押し出せば勝ちのボードゲーム「アバロン（Abalone）」を、ブラウザで CPU と遊べるようにしたもの。あなたと CPU の2人。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

絵（盤・玉・矢印・アイコン）は、すべて SVG で自作している。

## 遊び方

- 盤は1辺5マスの六角形（61マス）。玉は14個ずつ。先手は黒で、どちらが黒かはくじで決める
- 最初の並べ方は、標準（既定）・ベルギーデイジー・ジャーマンデイジーから選ぶ
- 手番には、自分の玉を1〜3個（2個以上なら一列に並んだ玉）選び、1マス動かす
  - 列の向きに動かす：先頭の玉の前が空いていれば進む
  - 列の横に動かす（平行移動）：動く先がすべて空いているときだけ
- 押し出し：列の向きに動かすとき、前に相手の玉が並んでいて、自分のほうが多ければ押せる（3対2・3対1・2対1）。同じ数か相手のほうが多いとき、相手の玉の後ろに自分の玉があるとき、横に動かすときは押せない。自分の玉は盤の外へ出せない
- 相手の玉を6個盤の外へ押し出したら勝ち

ルールは、ボードゲームアリーナの遊び方のページで確かめた。

### 決めたこと

- 並べ方の既定は標準にした。ボードゲームアリーナのアリーナ（ランク戦）の設定はベルギーデイジーなので、選べるようにした
- 手数の制限・同じ局面の繰り返しによる引き分けは入れていない（ボードゲームアリーナで見つからなかった）。CPU は前に出た局面へ戻る手を避ける
- どちらの手番かは、盤の色（黒が先手）で示す。人が白のときは、盤を180度回して自分の玉を下にする

### 画面の操作

- 自分の玉を押すと選べる。一列に並んでいれば3個まで足せ、両端を押すと真ん中も選ぶ。選んだ玉を押すと外す（真ん中なら、その玉だけを選び直す）。「選び直す」ですべて外す
- 選ぶと、動かせる向きにだけ矢印が出る。列の向きの矢印は先頭の玉の先、横の矢印は列の横に出る。赤い矢印は相手を押す手
- 各人の欄の6つの丸は、押し出した数（押し出した相手の色で埋まる）
- 玉は動いた先へ滑り、盤の外へ押し出された玉は外へ動いてから消える。相手の最後の手で動いた玉は、点線の輪で示す
- 遊び方を開いている間は、CPU が止まる。途中でホームに戻っても、「続きから」で再開できる

## CPU

局面の値打ちは、押し出した数の差（重く。勝ちに近いほど1個を重く）＋中央への近さ（いちばん外の輪は押し出されやすいので、急に下げる）＋玉のまとまり（隣り合う同じ色の組の数）。

- やさしい：自分の1手だけを読む。評価の揺れが大きく、ときどき3番目までの手を選ぶ
- ふつう：アルファベータ法で、相手の応手まで2手を読む（押し出す手から調べる）。3手読みは2手読みに 19勝0敗と強すぎたので、2手にした
- どちらも、すぐ勝てる手は見逃さない。前に出た局面へ戻る手は下げる
- 1手の考える時間は、実際は 15ms 以内（調べる局面の数の上限と、0.8 秒の打ち切りを安全弁にしている）

CPU 同士の結果（`scripts/cpu-match.mjs`。先手・後手を入れ替えて対戦。400手を超えたら「長引いた」として数える）：

| 対戦 | 試合 | 結果 |
|---|---|---|
| ふつう 対 やさしい（標準） | 100 | ふつう 100勝・長引いた 0 |
| ふつう 対 やさしい（ベルギーデイジー） | 40 | ふつう 40勝 |
| ふつう 対 やさしい（ジャーマンデイジー） | 40 | ふつう 38勝・やさしい 2勝 |
| やさしい 対 やさしい（標準） | 40 | 16勝・24勝 |
| やさしい 対 でたらめ | 20 | やさしい 20勝 |
| ふつう 対 ふつう（標準） | 40 | 7勝・4勝・長引いた 29 |

ふつう同士は、互いに外の輪を避けて守り合うので、多くが長引く（アバロンは、守り合うと決着しにくいことで知られる）。進まなくなった試合はなかった。

```bash
# 試合数・強さ（easy・normal・random）を2つ・並べ方（standard・belgian・german）
node scripts/cpu-match.mjs 100 normal,easy
node scripts/cpu-match.mjs 40 normal,easy belgian
```

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm install
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/rules.js` | ルールの中身（盤・並べ方・手の判定・押し出し・勝ち負け）。CPU の先読みでも使う |
| `public/js/game.js` | 進行と記録。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | 見る人ごとのビュー（手番の人には通る手の一覧を付ける） |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`art.js` | 画面・絵 |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |

### オンライン対戦を入れるとき

ルールとビューは、netplay-kit の「ゲームの定義」の形（`server/src/game-definition.js`）で用意してある。CPU の強さと並べ方を部屋の設定に持つ。netplay-kit の `sync.mjs` で部屋の処理を写し、この定義を `createHandler` と `startDevServer` に渡す。画面は、ローカル対戦と同じ `getView()` / `send()` の形のオンライン用のコントローラーを足す。盤は、ビューの `seat` の色に合わせて回して描くので、そのまま使える。
