# パンデミック

世界に広がる4色の病気の治療薬を、仲間と力を合わせて発見する協力ゲーム「パンデミック（Pandemic、Matt Leacock、Z-Man Games 2008／2013年の新版）」の基本ゲームを、ブラウザで遊べるようにしたもの。2〜4人分の役割を、1人で全部動かすか、自分の役割だけを動かして仲間を CPU に任せて遊ぶ。スマホの横画面向け（縦持ちのときは、画面ごと横に回して描く）。ホーム画面に置くと、オフラインでも遊べる。

地図・アイコンは、すべて SVG で自作している（大陸の形は、都市の位置に合わせて描いた粗い多角形）。説明の文も自分で書いたもので、公式の文や画像は使っていない。

## 遊び方（基本ゲーム・2013年版）

- 48都市（青・黄・黒・赤の4色×12都市）が線でつながった世界地図で遊ぶ。研究所と全員の駒はアトランタから始まる
- 準備：感染カードを9枚めくり、3都市に3個・3都市に2個・3都市に1個の病原体を置く。プレイヤーカード（都市カード48枚＋イベント5枚）を、2人なら4枚・3人なら3枚・4人なら2枚ずつ配る。残りを伝染カードの枚数（入門4・標準5・英雄6）の山に分け、1枚ずつ混ぜて重ねる。人口がいちばん多い都市カードを持つ人から始める
- 手番は、アクションを4回 → プレイヤーカードを2枚引く → 感染、の順
- アクション
  - 移動：車・船（つながった都市へ）、直行便（行き先の都市カードを捨てる）、チャーター便（今いる都市のカードを捨てて、どこへでも）、シャトル便（研究所から研究所へ）
  - 研究所の建設（今いる都市のカードを捨てる。6つまで。7つ目は既存のものを移す）
  - 治療（今いる都市の病原体を1個。治療薬のある色は全部）
  - 知識の共有（同じ都市にいる人と、その都市のカードを渡し合う）
  - 治療薬の発見（研究所で、同じ色の都市カード5枚を捨てる）
- 伝染：感染率が上がり（2・2・2・3・3・4・4）、感染カードの山の一番下の都市に病原体を3個置き、感染カードの捨て札を切って山の上に戻す
- 感染：感染率の枚数だけ感染カードをめくり、その都市に1個ずつ置く
- アウトブレイク：3個ある都市にさらに置くと、つながった都市すべてに1個ずつ広がる（連鎖する。1回の連鎖で同じ都市は1回だけ）
- 手札は7枚まで。8枚以上になったら、すぐに捨てる（イベントを使ってもよい）
- 根絶：治療薬のある色が盤上から消えたら、その色はもう置かれない
- 勝ち：4色の治療薬を発見した時点。負け：アウトブレイクが8回・置く病原体（各色24個）が足りない・プレイヤーカードを2枚引けない

### 役割（7種）

| 役割 | 能力 |
|---|---|
| 衛生兵 | 治療で、その色の病原体を全部取り除く。治療薬のある色は、いる都市から自動で取り除き（駒を動かされたときや、治療薬を発見したときも）、置かれるのも防ぐ |
| 科学者 | 治療薬の発見に、同じ色のカードが4枚でよい |
| 研究員 | 知識の共有で、今いる都市でなくても、どの都市カードでも渡せる（同じ都市にいる人は、研究員から好きな都市カードをもらえる） |
| 作戦エキスパート | カードを捨てずに研究所を建てる。手番に1回、研究所から都市カード1枚を捨てて、好きな都市へ移動する |
| 検疫官 | いる都市と、つながった都市に、病原体を置かせない（アウトブレイクで広がる分も） |
| 危機管理官 | アクションで、捨て札のイベントを1枚拾って取っておける（手札に数えない。1枚まで）。使うとゲームから取り除く |
| 通信指令員 | ほかの駒を自分の駒のように動かせる（カードは通信指令員が捨てる。チャーター便は、動かす駒のいる都市のカード）。駒を、ほかの駒のいる都市へ動かせる |

### イベント（5枚）

誰の手番でも使える（アクションではない）。カードを引いて解決している途中は使えないが、「強い住民」だけは伝染の感染と強化の間に使える。

| イベント | 効果 |
|---|---|
| 空輸 | 好きな駒1つを、好きな都市へ |
| 予測 | 感染カードの山の上6枚を見て、好きな順に並べ替える |
| 政府の助成金 | 好きな都市に研究所を1つ（カードは要らない） |
| 静かな夜 | 次の感染を1回とばす |
| 強い住民 | 感染カードの捨て札から1枚を、ゲームから取り除く |

### 画面の操作

- 地図で、線でつながった都市を押すと、そこへ移動する（行ける都市は点線の輪で光る）。遠い都市を押すと、行き方（車・船とシャトル便の道、直行便、チャーター便など）を選べる
- 下の欄のボタンで、治療・研究所・共有・治療薬・特殊（作戦エキスパートの移動、危機管理官の拾う、通信指令員の動かす駒）・終える
- 左下の仲間の欄を押すと、その人の手札を下に見せる。手札のイベントを押すと使える
- 右上のカードの数を押すと、捨て札や「山の上にある都市」（伝染で戻った都市。次に出る見込み）、次に引く2枚に伝染が出る見込みを見られる
- 「引く」「感染」は、使えるイベントを持っている人がいなければ、自動で進む
- ロボットのボタンで、今の操作を CPU に1手任せられる
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

### 資料と、資料で分からない点の決め方

ルールは、2013年の新版の公式ルールブック（英語版。[Pandemic Rules](https://lot.ahml.info/Pandemic%20Rules.pdf)）で確かめ、ルールの解説ページ（[boardgame-rules の Pandemic](https://lehi-innovation.github.io/boardgame-rules/rules/pandemic/)、[officialgamerules.org](https://officialgamerules.org/game-rules/pandemic/)）と照らし合わせた。イベントカードの文はルールブックに載っていないため、解説ページ（非公式の要約）の1つだけで確かめた。衛生兵が、治療薬を発見した時点でいる都市の病原体を取り除くことは、役割の文（「その都市に入るか、いるだけで取り除く」）からの解釈で、公式の FAQ では確かめていない。

都市とつながりは、覚えていた一覧を、盤の網をグラフとして分析した資料（[Overanalyzing Board Games: Network Analysis and Pandemic](https://optimistic-lichterman-dd9228.netlify.app/post/overanalyzing-board-games-network-analysis-and-pandemic)。48都市それぞれのつながりの数）と突き合わせた。48都市すべてで、つながりの数が一致し、合計は93本（テストで確かめている）。つながりそのものと色の割り当ても、GitHub にある独立した3つの実装（TypeScript・JavaScript・Perl）と一致した。太平洋をまたぐ3本（サンフランシスコ–東京、サンフランシスコ–マニラ、ロサンゼルス–シドニー）は、地図の左右の端へ抜ける線で描く。

資料で分からない点・食い違う点は、次のように決めた。

- **準備の順番：** 公式のルールブック（2013年版）は、最初の9都市の感染が先で、役割を配るのが後。解説ページの1つは逆の順に書いているが、ルールブックに合わせた（準備の感染は検疫官・衛生兵が防がないので、どちらでも結果は同じ）
- **最初の手番の人口：** 都市カードの人口は、カードの値を覚えていたものを万人で丸めて入れた（`cities.js`）。使うのは「誰から始めるか」だけ
- **「引く」「感染」：** 手番の人が押して進める（イベントを使う間を作るため）。画面は、動かせる人が使えるイベントを持っていなければ自動で押す
- **伝染の途中のイベント：** 「強い住民」を誰かが持っているときだけ、感染と強化の間で止まる。2枚とも伝染だったときは、イベントを持っている人がいるときだけ、1枚目を解決したあとで止まる（どのイベントも使える）
- **感染カードの山が切れたとき：** 原作では起きない想定。捨て札を切り直して続ける
- **「山の上にある都市」：** 強化で山の上に戻した都市のまとまり（順は分からない）と、予測で並べた順を、見てよい情報として画面に出す（実物でも、覚えていれば分かる情報）。CPU もこれを使う
- **通信指令員が動かす駒：** 持ち主の同意は聞かない（全員を1人で動かすか、CPU の仲間なので）
- 地図の座標は、実際の緯度・経度ではなく、原作の盤の並びに近い形に自分で置いた（ヨーロッパなどの混んだ所を広げている）。都市の日本語名は、一般的な表記にした（サンクトペテルブルクは、地図に収めるため「ペテルブルク」）
- 役割はランダムに配る（選ぶ画面は作っていない）

## CPU

「CPU に任せる」で、自分以外の役割を CPU が受け持つ。全員を操作するときも、ロボットのボタンで今の操作を1手任せられる（`public/js/cpu-player.js`）。

- アクション：自分の残りのアクションを、ビーム探索（幅8）で並べて試し、盤面の評価が一番高い並びの先頭を打つ
- 病原体の危険度：これから4回の感染でめくられる見込み（近い回ほど重い）で重みを付ける。強化で山の上に戻った都市のまとまりは確実に出る分として数え、捨て札の都市は、その間に伝染が来て山の上に戻る見込みで数える。3個の都市（隣も3個ならさらに）と、駒から遠い都市を重く見る
- 治療薬に向けたカード：色ごとに「集める人」（その色を一番多く持つ人。科学者は1枚多いと見る）を決め、その人の進み具合の2乗で点を付ける。ほかの人の同じ色のカードは、足りない枚数までは、集める人に渡しに会う距離（研究員なら研究員のいる都市）が近いほど高い。それより多い分と、治療薬のある色のカードは安い（直行便・チャーター便に使ってよい）
- 5枚そろった人は研究所に近いほど高い。研究所は、ほかの研究所から離れた都市にだけ建てる
- 終盤（プレイヤーカードの山が40枚より少ない）ほど病原体を軽く見て、治療薬を急ぐ。アウトブレイクが6回以上のときと、駒が6個以下の色は重く見る
- 手札の上限：評価が一番下がらないカードを捨てる。捨てると損が大きければ、代わりにイベントを使う。イベントは1枚目だけ高く見る（ため込むと都市カードを捨てることになる）
- イベント：危ない都市が次に出そうなら「静かな夜」「予測」（危ない都市を下へ）、伝染で病原体の多い都市が捨て札にあれば「強い住民」、治療薬を作れる手札で研究所が遠ければ「空輸」「政府の助成金」
- 見てよい情報だけを使う：感染カードの捨て札、強化で山の上に戻った都市のまとまり、山の枚数、伝染の山の分け方。山の並びはのぞかない
- ゲームの乱数は使わない。同じ状態なら同じ手を打つ（記録の再現がずれない）

勝率（CPU だけで、各200試合。シードは1〜200。`node scripts/cpu-match.mjs 200 <人数> all`）

| 人数 | 入門（伝染4枚） | 標準（伝染5枚） | 英雄（伝染6枚） |
|---|---|---|---|
| 2人 | 50.5% | 30.0% | 25.0% |
| 3人 | 33.0% | 13.0% | 9.5% |
| 4人 | 12.0% | 6.5% | 3.5% |

重みの調整に使った別のシード（1000〜1199）では、2人の入門が45.5%・標準が34.0%だった。200試合での誤差は ±3〜4% ほどある。

- 人数が多いほど弱い。手札が少なく、知識の共有のために会う手間が増えるため。入門の負けの多くは山札切れ（治療薬が間に合わない）
- 感染を止めた試しで、2人・入門でも勝ちは4分の3ほどだった。手札の上限（7枚）のため、各自が2色ほどを受け持ち、ほかの色を引くとその場で捨てるしかないことが、治療薬の速さの天井になっている
- 効いたもの：カードの価値を「集める人」と「会う距離」で決める、イベントを使って手札を空ける、危険度の見積もりを4回先の感染まで延ばす、終盤に治療薬を急ぐ
- 試したが効かなかったもの：探索の幅を広げる（20でも変わらない）、次の人の手番まで読む（間の感染を読めず、治療を先送りして弱くなった）、隠れた山を並べ直して数手番先まで実際に進めて比べる（モンテカルロのロールアウト。1手ごとに重くなるだけで、勝率は変わらなかった）、治療薬までのアクション数の見積もり（治療薬を追って病原体を放置した）、チーム全体の色の枚数、仲間と離れない項

電球（ヒント）を押すと、CPU の仲間と同じ判断で選んだ手を、短い文で知らせ、行き先の都市・押すボタン・カードを光らせる（打つのは自分）。隣の「CPU に1手任せる」とは別で、手は進めない。

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。協力ゲームで、2〜4人。足りない席は CPU で埋められ、難易度を部屋の設定に持つ。オンラインでは自分の役割の駒だけを動かす。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'pandemic' })`。web-games の1つのスタックから `?game=pandemic` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）

## 開発

```bash
npm install
# 画面（http://localhost:8000/ を開くと public/ へ移る）
python3 -m http.server 8000
# テスト（Vitest）
npm test
# CPU だけで遊ばせて、難易度ごとの勝率を測る（試合数・人数・難易度 intro・standard・heroic・all）
node scripts/cpu-match.mjs 200 4 all
```
