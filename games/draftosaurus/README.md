# ドラフトザウルス

恐竜を 1 匹ずつ選んで自分の公園に置き、点を競うドラフトゲーム（基本ゲーム・夏の面）。ブラウザで、CPU を相手に 2〜5 人で遊べる（人間 1 人＋CPU 1〜4 人）。スマホの縦・横の画面と PC に対応し、ホーム画面に追加するとオフラインでも遊べる（PWA）。

恐竜とダイスの絵、アイコンは自作。

## 遊ぶ

ビルドは要らない。リポジトリのルートで HTTP サーバーを立てて開く。

```bash
python3 -m http.server 8080
# http://localhost:8080/public/ を開く（ルートを開くと public/ へ移る）
```

## ルール

- 2〜5 人。恐竜は 6 種×10 匹のうち、人数に応じた数を袋に入れる（5 人は 60 匹すべて、4 人は各種 2 匹・3 人は各種 4 匹・2 人は各種 2 匹を箱に残して、48・36・48 匹）
- 3〜5 人は 2 ラウンド×6 手番。ラウンドの初めに、全員が袋から 6 匹を取る（手は他の人に見せない）
- 手番：ダイスを振る人が配置ダイスを振る。全員が同時に 1 匹を選んで自分の公園に置き、そろったら公開する。残りを左の人へ渡す（どのラウンドも左）。ダイスは手番ごとに左の人へ移る
- 2 人：4 ラウンド×3 手番。置いて公開したあと、それぞれが手からもう 1 匹を選んで箱に戻し（相手には見せない）、残りの手を交換する。ダイスは交互に振る。最後の手番で手に 1 匹だけ残るときは、自動で箱に戻す
- 配置ダイス：森の側／草原の側／トイレの側（川の右）／カフェの側（川の左）／空いた囲い／ティラノのいない囲い。振った人はダイスの決まりを受けない。川には、ダイスに関係なくいつでも置ける
- 囲いと点（夏の面。川の左＝カフェの側に、上から同じ種類の森・3 匹の木・恋人の草原。右＝トイレの側に、王の座・違う種類の草原・ひとりぼっちの島。森の側は森・3 匹の木・王の座、ほかは草原の側）
  - 同じ種類の森：同じ種類だけを左から。1〜6 匹で 2・4・8・12・18・24 点
  - 違う種類の草原：違う種類だけを左から。1〜6 匹で 1・3・6・10・15・21 点
  - 恋人の草原：どの種類でも、何匹でも。同じ種類の 2 匹の組ごとに 5 点
  - 3 匹の木：ちょうど 3 匹で 7 点
  - 王の座：1 匹。その種類を自分より多く持っている人がいなければ 7 点（相手 1 人ずつと比べ、同じ数なら得点する）
  - ひとりぼっちの島：1 匹。その種類が自分の公園（川も含む）に 1 匹だけなら 7 点
  - 川：1 匹 1 点
  - ティラノサウルス：ティラノがいる囲い 1 つごとに +1 点（2 匹いても +1。川は数えない）
- 同点なら、ティラノサウルスの少ない人が上。それも同じなら同じ順位

## 操作

- 手の恐竜を押すと、置ける場所が金色に光り、今置いたら増える点（+の数。減るときは赤）が出る。場所を押すと薄く置いて見せ、「置く」で決める（同じ場所をもう一度押しても置ける）
- 恐竜を選ぶ前は、ダイスの決まりで置ける囲いを点線で示す
- 上の欄は全員の今の点と、最後に置いたもの。✓ は選び終えた人。「渡す」の札が、手を渡す相手。押すと、その人の公園を見られる
- 2 人のときは、置いたあとに手の恐竜を押して「戻す」で箱に戻す
- 全員がそろうと、自分の恐竜が公園に落ち、上の欄に各人が置いたものが光り、隣から渡ってきた手が滑り込む
- 途中で閉じても、タイトルの「続きから」で再開できる（操作の記録を保存して再現する）

## CPU

自分のビュー（自分の手と、公開されている全員の公園）だけで判断する。手の恐竜と置ける場所の組み合わせごとに、「今置いたら増える点」と「囲いの先の伸びの見込み」（森・草原の次の 1 匹、恋人の相手、3 匹の木の残り、空いた王の座・島。残りの手番が多いほど、その種類がまだ出ていないほど大きい）の和で評価する。ゆらぎを入れて、強すぎないようにしている。

- ふつう（既定）・やさしい の 2 段階
- 強さの測定：`npm run sim -- <試合数> <強さの並び>`（例：`npm run sim -- 400 normal,easy`）。`strong`（ゆらぎなし）と `random` は測定用

## ファイルの構成

| ファイル | 内容 |
|---|---|
| `public/js/dinos.js` | ルールのデータ（恐竜の種類、人数ごとの決まり、公園の囲いの区分・容量・点、ダイスの面） |
| `public/js/park.js` | 公園の計算：置ける場所の判定と得点 |
| `public/js/game.js` | ゲーム本体。袋とダイス、同時に選んで公開する手番、手を渡す向き、2 人のときの箱に戻す段階。`applyCommand` と `Game.replay` |
| `public/js/game-view.js` | ビュー（自分の手と、自分が選んだ中身だけ。置ける場所ごとの点の増え方） |
| `public/js/cpu-player.js` | CPU（ビューだけを見る。2 人のときは、相手に渡すと一番得をされる恐竜を箱に戻す） |
| `public/js/game-controller.js` | ローカル対戦のコントローラー（`getView()` / `send()`） |
| `public/js/board.js` | 公園の盤面の描画 |
| `public/js/art.js` | 恐竜とダイスの面の絵（SVG） |
| `public/js/main.js` | 画面の進行 |
| `server/src/game-definition.js` | オンライン対戦用のゲームの定義（netplay-kit の形。まだ使っていない） |

## オンライン対戦（未実装）

ロジックは DOM から切り離し、操作の入口を 1 つにして、記録から再現できるようにしてある（袋とダイスもシード付きの乱数）。各人のビューには、自分の手と自分が選んだ中身だけを入れている。netplay-kit を同期すれば、`server/src/game-definition.js` をそのまま部屋の処理に渡せる。抜けた人の番を CPU が代わりに打つ処理（代行）は、そのときに足す。
