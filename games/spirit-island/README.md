# スピリット・アイランド

島の精霊になり、島を開拓しに来た侵略者を恐れさせて追い払う協力ゲーム（原作：Spirit Island）。1〜4体の精霊で遊ぶ。自分の精霊だけを動かして仲間を CPU に任せるか、全員を1人で動かす。オンラインでは、全員が同じ側で協力する（勝ち負けは全員に共通）。

## 遊び方

- **目的**：恐怖カードを集めて恐怖の段階を上げ、段階ごとの条件（段階1：侵略者が1つもいない／段階2：町と都市がない／段階3：都市がない）を満たすか、恐怖カードをすべて得れば勝ち。荒廃カードの荒廃が尽きる・どれかの精霊の存在が島からなくなる・侵略者の山が尽きて探検できない、のどれかで負け
- **ターンの流れ**
  1. 精霊フェイズ（全員が同時に）：成長を1つ選ぶ → 存在の列で見えているエネルギーを得る → 力のカードを選んで使う（費用はエネルギー、枚数は上限まで）
  2. 速い力：速い力を、対象を選んで使う
  3. 侵略者フェイズ（自動）：恐怖カード → 荒らし → 建設 → 探検。侵略者カードが1つずつ進む
  4. 遅い力：遅い力を使う
  5. 時が過ぎる：使ったカードを捨て札に、ダメージと防御を消す
- **侵略者**：探検は海沿いの土地か、町・都市のある土地とそのとなりへ。建設は侵略者のいる土地に、町（町が都市より多ければ都市）。荒らしは探検者1・町2・都市3のダメージで、土地へのダメージが2以上なら荒廃。生き残ったダハンが1体2ダメージで反撃する
- **荒廃**：置かれた土地の各精霊の存在を1つ壊す。荒廃のある土地に足されると、となりへ連鎖する
- **精霊**（はじめの4体）
  - 陽光に輝く奔流：押し出しと水の力。湿地の存在は1つでも聖地
  - 大地の活力：防御と守り。聖地のある土地はいつも防御3
  - 稲妻の迅撃：町と都市を壊す。風の元素の数だけ、遅い力を速い力として使える
  - 炎のように揺らめく影：恐怖を生む。エネルギー1でダハンのいる土地を範囲の外から狙える
- **操作**：下の欄で成長・存在の列・カードを選び、光った土地を押す。精霊の名前を押すと存在の列と生まれ持つ力、カードの長押しで全文、上の欄を押すと侵略者と恐怖の詳しい状態が出る。電球のボタンでおすすめの手が光る

### 難易度

| 難易度 | 恐怖（1人あたり） | 恐怖カード | 荒廃（1人あたり＋1） | 裏返ったとき（1人あたり） |
|---|--:|--:|--:|--:|
| やさしい | 2 | 6枚 | 3 | 5 |
| ふつう | 3 | 6枚 | 3 | 5 |
| むずかしい（原作の基本の設定） | 4 | 9枚 | 2 | 4 |

## CPU

- 協力ゲームなので、CPU は相手ではなく仲間の精霊。人の足りない席と、オンラインで抜けた人の精霊を受け持つ。ヒント（`#hint`）は同じ判断（`cpu-player.js` の `suggest`）から出す
- 成長は目安の点数で選ぶ（手札が尽きそうなら取り戻し、序盤は存在を増やす。範囲0の存在は低く見る）。存在の置き場は、侵略者の近さと聖地で選ぶ
- 使うカードの組み合わせと、力の対象・押し出す先は、盤面の写しで試して選ぶ。良さ（`evaluate`）は、次の荒らしと建設を写しの上で本物のルールで起こしてから測る（荒廃・連鎖・ダハンの反撃・恐怖・勝ちの条件までの距離）。遅い力は、このターンの侵略者フェイズが済んだ盤面で測る。隠れた山（侵略者・恐怖・力のカード）はのぞかない
- 判断の重み（`cpu-player.js` の `TUNING`）は、CPU どうしの勝率を見比べて決めた
- ゲームの乱数を使わないので、同じ局面からはいつも同じ手を選ぶ（記録の再現がずれない）
- CPU の精霊だけの勝率（`npm run cpu-match -w games/spirit-island -- <試合数> <人数> all`。2体は各100試合、ほかは各40試合。進まなくなった試合はなし）。3〜4体で むずかしい を遊ぶと、CPU の仲間にはとても難しい（ほとんど勝てない）。CPU と組むなら、3〜4体では やさしい か ふつう を勧める

| 精霊の数 | やさしい | ふつう | むずかしい（原作の基本の設定） |
|--:|--:|--:|--:|
| 1 | 75% | 65% | 35% |
| 2 | 75% | 49% | 24% |
| 3 | 75% | 38% | 0% |
| 4 | 93% | 65% | 5% |

## 開発

```bash
npm test -w games/spirit-island                       # ルール・記録からの再現・ヒント・CPU・オンライン・PWA のテスト
npm run cpu-match -w games/spirit-island -- 20 2 all  # CPU の精霊だけの試合（試合数・人数・難易度）。止まった試合も数える
node scripts/standards.mjs --check spirit-island      # web-games の標準
node scripts/online-e2e.mjs spirit-island             # 2人の画面での通し試験（手元のサーバーを立てる）
```

- `public/js/data.js`：ボード・精霊・力のカード・恐怖カード・侵略者カード・難易度
- `public/js/rules.js`：ルール（状態 `s` を変える関数。乱数は ctx から受け取る）
- `public/js/game.js`：対局（`applyCommand` で操作を通して記録し、`Game.replay` で再現する）
- `public/js/game-view.js`：画面とオンラインに送るビュー（山の並びは入れない）
- `public/js/cpu-player.js`：CPU とヒント
- `public/js/ui.js`・`map.js`・`help.js`：画面
- `server/src/game-definition.js`：オンライン対戦の定義（netplay-kit）

## オンライン対戦

- netplay-kit の共通のロビーで、1〜4人。足りない席は CPU の精霊。精霊は席の順に 奔流・大地・稲妻・影
- 精霊フェイズと力のフェイズは全員が同時に進める。操作を待っている精霊（`actors()`）なら、いつでも操作を受け付ける
- 対戦中に部屋を出た人の精霊は、CPU が引き継ぐ。ビューにシードと山の並びは入れない

## 決めたこと

原作をもとに、スマホで遊べる形にするため、次のように変えた。

- はじめの4体の精霊だけで、敵対国・シナリオ・拡張（枝と爪など）のカードは入れていない
- 島のボードは同じ形（8つの土地と海）にし、土地の種類と最初の駒をボードごとに変えた独自の配置にした。2枚は縦に、3〜4枚は2列に並べ、端の土地どうしがつながる
- 力のカード（小さな力16枚・大いなる力8枚）と恐怖カード（9枚）は、原作の文を写さず、効果を言い換えたり作り直したりしたもの。精霊の固有のカードと生まれ持つ力は、原作の働きに近づけた
- 存在の列の元素の印は入れていない。奔流のカードの列の「取り戻し」は、毎ターン費用の一番高い捨て札を自動で手札に戻す
- ダメージの割り振り（都市・町・探検者の順に倒せるものから）、集める元、荒廃の連鎖先（荒廃のない土地へ近い方）、恐怖カードと恐怖の外套の対象の土地は、自動で選ぶ
- 押し出す力は、1回の力で選んだ1つのとなりの土地へまとめて動かす。「〜まで」は、できるだけ多く動かす
- 荒廃カードは1種類（裏返ったときに荒廃が足されるだけで、特別な効果はない）
- 恐怖の段階は、得た恐怖カードが山の3分の1・3分の2に届いたときに上がる
- 待ったは置かない（同時に進め、引いたカードを見てからやり直せてしまうため。`standards.skip.undo`）
