# ジャイプル

市場で商品を集めて売り、トークンの点数を競う2人用のカードゲーム「ジャイプル（Jaipur）」を、ブラウザで CPU と遊べるようにしたもの。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

絵（商品・ラクダ・トークン・印・アイコン）は、すべて SVG で自作している。

## 遊び方

- カード55枚：ダイヤ6・金6・銀6・布8・香辛料8・革10・ラクダ11
- ラウンドの準備：市場にラクダ3枚を置き、各自に5枚配る（手札のラクダは自分の群れに出す）。市場を5枚にする
- 手番には、次のどれか1つを行う
  - 市場の商品を1枚取る
  - 市場のラクダを全部取る
  - 市場の商品を2枚以上取り、同じ枚数の手札かラクダを返す（取った種類と同じ商品は返せない）
  - 手札の1種類を好きな枚数売り、その商品のトークンを上から枚数分もらう（ダイヤ・金・銀は2枚以上）。3・4・5枚以上売ると、ボーナスのトークンも1枚もらう
- 手札は7枚まで（ラクダは数えない）
- 商品のトークンの山が3種類なくなるか、市場を補充できなくなったらラウンドの終わり。ラクダの多い方に5点
- 点数の多い方がラウンドの勝ちで、印を1つもらう。同点ならボーナスのトークンの多い方、それも同じなら商品のトークンの多い方。印を2つ集めた方の勝ち
- 次のラウンドは、前のラウンドで負けた方から始める

| 商品 | トークン（上から） |
|---|---|
| ダイヤ | 7・7・5・5・5 |
| 金 | 6・6・5・5・5 |
| 銀 | 5・5・5・5・5 |
| 布 | 5・3・3・2・2・1・1 |
| 香辛料 | 5・3・3・2・2・1・1 |
| 革 | 4・3・2・1・1・1・1・1・1 |

ボーナスのトークンは、3枚売り（1・1・2・2・2・3・3）、4枚売り（4・4・5・5・6・6）、5枚以上売り（8・8・9・10・10）の山から、伏せたまま1枚もらう。

### ルールブックに書かれていないので決めたこと

- ラウンドの勝ち負けが、点数・ボーナスの数・商品トークンの数のどれでも決まらなければ引き分けにし、印はだれにも渡さない。次のラウンドは、そのラウンドの2番手から始める
- 最初のラウンドの1番手はランダム

### 画面の操作

- 市場の商品・手札・ラクダをタップして選ぶと、下に今できる操作が1つだけ出る
  - 市場の商品1枚 → 取る
  - 市場のラクダ（または、何も選んでいないときのボタン） → ラクダを全部取る
  - 市場の商品2枚以上と、返す手札・ラクダ → 交換。返すラクダは、自分のラクダを押した回数だけ。通らないときは理由を短く出す
  - 手札だけ → 売る。手札を1枚押すと、その種類をまとめて選ぶ
- 相手のボーナスのトークンは、ラウンドの終わりまで伏せたまま（枚数だけ見える）
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

自分から見える情報だけ（相手の手札・山札の並び・ボーナスの値は見ない）で打つ。手札とラクダの見込みの価値を点数で見積もり、売る・1枚取る・ラクダを取る・交換のうち、もらう点数と見込みの増えた分がいちばん大きい操作を選ぶ。市場に返した商品が相手に渡る分も見込む。強すぎないように、評価の揺れと、ときどき2番目の手を選ぶ誤りを混ぜている。

```bash
# 試合数・席0の強さ・席1の強さ（normal は画面の CPU、strong は揺れのない比較用、random はでたらめに打つ比較用）
node scripts/cpu-match.mjs 400 normal strong
```

自分の欄の電球（ヒント）を押すと、揺れのほとんどない CPU が選ぶ手を、そのまま選んだ状態にする（操作の欄のボタンが光り、押せば打てる）。CPU と同じく、自分のビューだけで決める。

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm install
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/game.js` | ルール。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`art.js`・`animator.js` | 画面・絵・動き |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |

### オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2人で（片方を CPU にもできる）、足りない席は CPU で埋められる。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'jaipur' })`。web-games の1つのスタックから `?game=jaipur` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
