# ロストシティ

5つの探検にカードを並べて得点を競う2人用のカードゲーム「ロストシティ（Lost Cities）」を、ブラウザで CPU と遊べるようにしたもの。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

絵（カード・地形・握手・アイコン）は、すべて SVG で自作している。

## 遊び方

- カード60枚：5色（黄・青・白・緑・赤）×（2〜10 の数字と、握手（賭け）3枚）
- 各自に8枚配る。手番には、1枚を出し、1枚を引く
  - 出す：自分の探検に置くか、その色の捨て場に捨てる
  - 引く：山札か、どれかの捨て場の一番上から。今捨てたカードは、その手番には引けない
- 探検には、同じ色のカードを小さい順にしか置けない（間を飛ばしてもよい）。握手は、その色の数字より前にだけ置ける
- 山札の最後の1枚を引いたら、ラウンドの終わり
- 得点：始めた探検ごとに（数字の合計 − 20）×（握手の枚数 + 1）。8枚以上なら、さらに +20（倍にしない）。始めていない色は0点
- ラウンドの数（1か3。既定は3）の合計で、多い方の勝ち

### ルールブックに書かれていないので決めたこと

- 最初のラウンドの1番手はランダム。そのあとは交代する
- 合計が同じなら引き分け

### 入れていないもの

- 6色目（紫）の変種。公式の細かい決まりに自信がないため、入れていない

### 画面の操作

- 手札を押すと、出せる自分の探検と、その色の捨て場が光る。光った場所を押すか、下のボタン（出す／捨てる）で決める。「出す」には、出したあとのその色の得点が出る
- 引くときは、引ける捨て場が光る。捨て場を押すか、下の「山札から引く」
- 各色の今の得点を、探検の列ごとに出す
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

自分から見える情報だけ（相手の手札・山札の並びは見ない）で打つ。始めた色には、間を飛ばさない小さいカードを優先して置き、新しい色は、手札とこれから引く見込みで20点を十分超えるときだけ始める。捨てるのは、自分に要らず、相手の探検に役立たないカード。捨て場の一番上は、自分の探検にすぐ役立つときだけ引く。強すぎないように、評価の揺れと、ときどき2番目の手を選ぶ誤りを混ぜている。

```bash
# 試合数・席0の強さ・席1の強さ（normal は画面の CPU、strong は揺れのない比較用、random はでたらめに打つ比較用）
node scripts/cpu-match.mjs 400 normal strong
```

自分の行の電球（ヒント）を押すと、揺れのほとんどない CPU が選ぶ手を示す（出す手はそのカードを選んでおき、出し先のボタンを光らせる。引く手は山札か捨て場を光らせる）。CPU と同じく、自分のビューだけで決める。

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm install
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/game.js` | ルール。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`art.js`・`animator.js` | 画面・絵・動き |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |

### オンライン対戦を入れるとき

ルールとビューは、netplay-kit の「ゲームの定義」の形（`server/src/game-definition.js`）で用意してある。netplay-kit の `sync.mjs` で部屋の処理を写し、この定義を `createHandler` と `startDevServer` に渡す。画面は、ローカル対戦と同じ `getView()` / `send()` の形のオンライン用のコントローラーを足す。
