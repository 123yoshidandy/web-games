# クアックサルバー

袋から材料を1つずつ引いて鍋に入れ、白（かんしゃく玉）で爆発する前に止める、引き際が勝負のボードゲーム「クアックサルバー（Die Quacksalber von Quedlinburg / The Quacks of Quedlinburg）」を、ブラウザで CPU と遊べるようにしたもの。2〜4人（あなた＋CPU 1〜3人）。スマホの縦持ち向け（PC でも遊べる）。ホーム画面に置くと、オフラインでも遊べる。

絵（材料の札・渦巻きの鍋・アイコン）は、すべて SVG で自作している。

## 遊び方

- 9回の調合で、いちばん点を集めた人の勝ち
- 回の始めに占いカードを1枚めくる（24枚。その回だけのルールか、すぐ起きること）
- いちばん点の多い人との間にあるネズミのしっぽの数だけ、しずくの先から置き始める
- 調合：全員が同時に、袋から1つずつ引き、値の数だけ先のマスに置く。好きなときに止められる。白の合計が7を超えると爆発
- フラスコが満ちていれば、引いた白を袋に戻せる（爆発させた白は戻せない）
- 評価：最後の材料の次のマスを見る
  1. 爆発せずにいちばん先まで進んだ人がボーナスのサイコロ（1点・1点・2点・ルビー・しずく・カボチャ）
  2. 材料の効果（ドクロガ・クモ・ゴースト）
  3. マスにルビーの印があればルビー1つ
  4. マスの点
  5. マスのお金で材料を買う（違う色を2つまで）
  6. ルビー2つで、しずくを1マス進めるか、フラスコを満たす
- 爆発したら、点か買い物のどちらか一方だけ
- マンドラゴラは2回目から、ゴーストは3回目から買える。6回目に全員の袋に白1が1つ入る
- 9回目は買い物をせず、お金5につき1点、ルビー2つにつき1点。同点なら、最後の回に先まで進んだ人の勝ち

材料は基本セットの「本1」：

| 材料 | 色 | 値段（値：お金） | 効果 |
|---|---|---|---|
| かんしゃく玉 | 白 | 売っていない | 合計が7を超えると爆発 |
| カボチャ | 橙 | 1：3 | なし |
| クモ | 緑 | 1：4、2：8、4：14 | 最後か最後から2番目のクモ1つにつきルビー1つ |
| カラス | 青 | 1：5、2：10、4：19 | 値の数だけ引き、1つを鍋に置ける |
| ベニテングダケ | 赤 | 1：6、2：10、4：16 | 鍋のカボチャが1〜2つで1マス、3つ以上で2マス余分に進む |
| マンドラゴラ | 黄 | 1：8、2：12、4：18 | すぐ前の白を袋に戻せる |
| ゴースト | 紫 | 1：9 | 1つは1点、2つは1点とルビー、3つ以上は2点としずく |
| ドクロガ | 黒 | 1：10 | 両どなりより多ければしずく、両方より多ければルビーも（2人なら、相手より多ければしずくとルビー、同じならしずく） |

### 決めたこと・割り切ったこと

- 調合は全員が同時に行うルールだが、画面では「あなた → CPU」の順に見せる（あなたが止めたあと、CPU が一斉に1つずつ引く）。CPU の判断は、あなたの鍋を見ていない
- 材料の数の上限（箱に入っている数）は数えない
- マンドラゴラで白を戻しても、マンドラゴラは置いたマスのまま
- カラスで置いた材料の効果は起きる（カラスならさらに引ける）。「念のため」で置いたカラスは、もう引かない
- 「サイコロ2回」は、2回振って好きなほうを選ぶ
- 「やり直し」は、5つ目を置いたあと、6つ目を引く前まで
- 「とばっちり」の左どなりは、席の次の人
- 鍋のいちばん外まで進んだら、そこで止まる

## 画面

- 鍋は渦巻きで、マスにお金の数とルビーの印を出す。最後の材料の次のマス（点数を数えるマス）を金色の輪で示す
- 鍋の下に、白の合計と「次に引いたら爆発する確率」、次のマスのお金・点・ルビーを出す
- 引くと、材料が袋のボタンから飛び出して鍋のマスに落ちる。爆発すると鍋が揺れ、閃光と煙が出て、鍋が暗くなる。動きを減らす設定では動かさない
- ほかの人の欄には小さな鍋を出す。タップすると、その人の鍋を大きく見られる
- 袋のボタンで、袋と鍋の中身を見られる
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

袋の並びはのぞかず、袋の中身の数（実物でも分かる）だけを見る。ゲームの乱数は使わない。

| 強さ | 止める判断 | 買い物 |
|---|---|---|
| やさしい | 爆発の確率がしきい値（毎回揺れる）を超えたら止める | 買えるものから気まぐれに選ぶ。ルビーはフラスコにしか使わない |
| ふつう | もう1つ引いたときの見込み（爆発の確率と、進んだマスの点・お金・ルビー）と、今止めた値を比べる | 材料ごとの値打ち（進む量・効果・残りの回数）で、いちばんよい組み合わせを選ぶ。ルビーでしずくを進める |

`npm run cpu-match -- 300 4 normal,easy,normal,easy` で CPU 同士を対戦させ、勝率を測れる（300試合で、ふつう 約44%・やさしい 約6%。2人なら ふつう 約80%）。

## 構成

| ファイル | 中身 |
|---|---|
| `public/js/data.js` | 鍋のマス・材料・占いカードなどの数値 |
| `public/js/game.js` | ルールと進行（DOM に依存しない。操作の記録から再現できる） |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と保存 |
| `public/js/ui.js`・`art.js`・`animator.js` | 画面・絵・動き |
| `server/src/game-definition.js` | オンライン対戦用のゲームの定義（netplay-kit の形） |
| `server/src/handler.js`・`public/js/online-config.js`・`public/js/netplay/` | オンライン対戦のサーバーの入口・接続先・netplay-kit の写し |
| `scripts/cpu-match.mjs` | CPU 同士の対戦 |

自分が選ぶ場面の電球（ヒント）を押すと、ゆらぎのない CPU が選ぶ手を光らせる（引く・止める、占いやサイコロの選択肢、カラスで置く材料）。買い物では、買う材料・しずく・フラスコを選んでおき「買う」を光らせる。CPU と同じく、袋の並びはのぞかない。

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜4人で、足りない席は CPU で埋められる。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'quacks' })`。web-games の1つのスタックから `?game=quacks` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）

## 開発

```bash
npm test                 # テスト
npm run cpu-match        # CPU 同士の対戦
python3 -m http.server 8000 --directory public   # 画面
```

保存の名前は `quacks.save`（途中経過）と `quacks.settings`（人数と CPU の強さ）。
