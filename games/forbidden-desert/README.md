# 禁断の砂漠

Forbidden Desert（2〜5人の協力ゲーム）をスマホの縦画面で遊べるようにしたもの。砂に埋もれた古代の都市から飛行機の部品を4つ掘り出し、全員で発射台から飛び立てば勝ち。仲間を CPU に任せるか、1人で全員を動かすか、オンラインで仲間と遊べます。

## 遊び方

- 手番に行動を4つまで行い、そのあと嵐のカードを嵐の目盛りの枚数だけ引く
- 行動：移動（上下左右）・砂を取り除く（自分かとなりのタイル）・掘り出す（砂のない自分のタイル）・部品を拾う・役割の力。掘り出したトンネルどうしは1行動で移れる
- 水と装備は、同じタイルの仲間にいつでも渡せる。装備もいつでも使える（行動を使わない）
- 嵐のカード
  - 風：真ん中の嵐の目が矢印の向きに動き、すべり込んだタイルに砂が1つ積もる。駒と部品はタイルと一緒に動く
  - 嵐が強まる：目盛りが上がり、引く枚数が増える
  - 日差しが照りつける：トンネルと日よけの下にいない全員が水を1つ失う
- 部品の手がかりは、部品ごとに「行」と「列」の2枚。2枚とも表になると、交わるタイルに部品が出る
- 井戸（水の印のタイル3枚のうち2枚。1枚は蜃気楼）を掘り出すと、そのタイルの全員が水を2つ得る
- 負け：水が0の人がさらに日差しを受ける・置く砂（48個）がなくなる・嵐の目盛りが最後を越える
- 役割（6種から人数分）：考古学者・登山家・探検家・気象学者・航海士・水運び。装備（12枚）：砂の吹き飛ばし・ジェットパック・日よけ・地中鏡・秘密の水・時間の加速
- 画面：タイルを押すと、そこで行う行動を選べる。下のボタンで、掘る・拾う・役割の力・水と装備・待った・手番を終える（条件がそろうと「離陸」）。電球のボタンで、おすすめの手を光らせる

## CPU

- `public/js/cpu-player.js`。手番の人の「やること」（掘り出す・部品を拾う・水をくむ／渡す・砂を取り除く・発射台へ集まる・嵐を静める）を、得られるものと必要な行動の数で比べ、いちばん効率のよいものへ1手進める。1手ごとに選び直す
- 水に余裕がないときは、その手番のうちにトンネル（日陰）へ戻れることだけをする
- 手番でない CPU の仲間も、渇いた仲間に水を分け、嵐の前に日よけを広げる
- 見るのは公開の情報だけ（裏のタイルの中身・山の並びは見ない。地中鏡でのぞいたタイルは使う）。ゲームの乱数は使わない
- ヒント（`suggest`）は CPU と同じ手を出す
- 強さ（`npm run cpu-match -w games/forbidden-desert -- 200 all all`、2〜5人 × 200 試合）：見習い 79%・標準 52%・熟練 22%・伝説 2%（進まなくなった試合なし）

## 決めたこと

- 嵐の目盛りの段の値は原作の写しではなく、人数ごとに決めた（人数が多いほど低い段を長くする）。CPU 同士の勝率が、見習い 7 割・標準 4 割以上になるように合わせた。難易度は目盛りの始まりの段（見習い 0・標準 1・熟練 2・伝説 3）
- 水が0の人がさらに日差しを受けたら負け（0 はまだ生きている）
- 気象学者の力は「引く嵐のカードを1枚減らす」だけ。山の上を見て1枚を下に回す力は入れていない
- 時間の加速は、持っている人の手番の行動の段階でだけ使える
- 嵐のカードは手番の人が1枚ずつ引く（ローカルでは自動で引く。オンラインでは「嵐を引く」を押す）
- 待ったは、手番中の行動のうち、隠れた情報を見せないもの（掘り出す・地中鏡・嵐のカード以外）だけを戻せる。オンラインでは出さない
- カードの文は原作を言い換えたもの。絵は使っていない

## 開発

```bash
npm test -w games/forbidden-desert                         # ルール・CPU・ヒント・オンライン・PWA のテスト
npm run cpu-match -w games/forbidden-desert -- 200 all all  # CPU 同士の勝率（試合数・人数・難易度）
node packages/netplay-kit/scripts/sync.mjs games/forbidden-desert --client-only   # 画面側の netplay-kit を写す
node packages/sound/scripts/sync.mjs forbidden-desert      # 音のエンジンを写す
```

- `public/js/game.js`：ルールと進行（DOM に依存しない。操作は `applyCommand` に通して記録し、`Game.replay` で再現する）
- `public/js/data.js`：タイル・役割・装備・嵐のカード・嵐の目盛り
- `public/js/game-view.js`：プレイヤーに送るビュー（裏のタイルの中身・山の並び・シードは入れない）
- `public/js/cpu-player.js`：CPU とヒント
- `public/js/game-controller.js`：ローカルで遊ぶときのコントローラー（途中経過の保存と「続きから」）
- `public/js/ui.js`：画面
- `server/src/game-definition.js`：オンライン対戦の定義（netplay-kit）。対戦中に部屋を出た人の席は CPU が引き継ぐ

## オンライン対戦

web-games の1つのサーバーに `?game=forbidden-desert` でつなぐ。手元では web-games の直下で `npm run dev:online` を立て、画面を開く。入口とロビーは共通の `netplay-lobby.js`（公開の部屋だけ）。`public/js/online-config.js` の `DEPLOYED_SERVER_URL` は、デプロイしてから書く（空のあいだは公開したページで「オンラインで遊ぶ」を出さない）。オンラインでは、ヒントと待ったを出さない。
