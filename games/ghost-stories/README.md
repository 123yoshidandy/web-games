# ゴーストストーリーズ

4人の僧が力を合わせ、3×3 の村を幽霊から守る協力ゲーム（原作：Ghost Stories）。スマホの縦画面で遊ぶ。自分の僧だけを動かして仲間を CPU に任せるか、1人で4人の僧を動かす。オンライン対戦（公開の部屋、1〜4人。足りない僧は CPU）にも対応する。

名前・文章・絵は、このゲームのために作ったもの（原作の札や絵は写していない）。

## 遊び方

- **勝ち**：山の底の近くにいる魔王の化身を祓う
- **負け**：呪われたタイルが3枚になる／僧が全員倒れる／魔王が残ったまま幽霊の山が尽きる
- 手番は2つの段階
  - **陰**（自動）：手番の僧のボードの幽霊が動く（憑き手が進む・呪いのダイス・仲間を呼ぶ・気を奪う）→ ボードの3か所が埋まっていれば気を1つ失う → 幽霊が1体来る。色の幽霊はその色のボード、黒い幽霊は手番の僧のボードへ。置き場は手番の人が選ぶ（埋まっていれば、どこかの空き）
  - **陽**：となりのタイル（斜めも）へ動いてよい → 「頼む」（村人の力）・「除霊」・「終える」のどれか1つ
- **除霊**：道のダイスを3つ振り、いるタイルに向いた幽霊（角のタイルは2体）を祓う。幽霊の色の目（白はどの色にもなる）と道の札を、抵抗の数だけそろえる
- **村のタイル**（毎回並びが変わる）：茶屋・薬草屋・呪術師の庵・祈りの輪・仏堂・風の楼閣・墓所・道士の祭壇・夜回りの番所
- **僧の力**：赤 峰渡り（どこへでも動ける）・黄 底なしの袋（札をもう1枚）・緑 天の息吹（ダイスを1つ多く振る）・青 真言（幽霊の抵抗を1下げる札）
- 仏像（仏堂で受け取る）と真言は、手番を使わずに置ける
- 難易度

| 難易度 | 幽霊 | 魔王の下の枚数 | はじめの気 | はじめの道の札 | 魔王の化身 |
|---|---|---|---|---|---|
| 入門 | 30枚 | 7枚 | 4 | 自分の色と黒を1枚ずつ | 影（抵抗3） |
| 標準 | 36枚 | 9枚 | 4 | 自分の色を1枚 | 影か千の顔（抵抗4） |
| 悪夢 | 40枚 | 10枚 | 3 | なし | 夜喰らい（抵抗4・ダイスを奪う・呪いと気を奪う） |

操作：盤のタイルを押すと動く。置き場を押すと幽霊を置く・除霊で祓う幽霊を選ぶ。札・タイル・僧を押すと説明が出る。ヒント（電球）はローカルで遊ぶときだけ出す。

### 原作から変えたところ

- 僧はいつも4人。人が受け持たない僧は CPU が動かす（原作の1〜3人用の「中立のボード」の決まりは使わない）
- 村人の力・幽霊の効果・難易度の数値は、原作の形（憑き手・呪いのダイス・ダイスを奪う・力を封じる・仏像・祈りの輪など）に沿って言い換え、CPU の勝率で釣り合いを決めた
- 祓ったごほうびの「呪いを解く」は、決まった順（番所・茶屋・薬草屋…）で自動で選ぶ
- 薬草屋のダイスの白は、自分の色の札になる

## CPU

`public/js/cpu-player.js`。陽の段階では、動ける各タイルについて「除霊の見込み」（出目の組み合わせをすべて数え、出目と札で祓える幽霊の組の値打ちの平均）と「村人の力の値打ち」を比べ、一番よいタイルへ動いてから打つ。ヒントも同じ関数（`suggest`）から出す。

- 幽霊の値打ち：憑き手の位置（タイルの上なら次に呪う）・呪い・呼び寄せ・気を奪う・ダイスを奪う・力を封じる・ボードのあふれ・ごほうび。呪われたタイルが2枚になると、憑き手と呪いを重く見る。陰の段階が早く来るボードほど重く見る
- 札の色は、盤の幽霊の抵抗の合計と、魔王に備える黒から選ぶ。黒の札は使うのを一番控える
- 幽霊を置く場所は、仏像の置き場を最初に選び、次に僧の近くで除霊しやすく、大事なタイルを狙われにくい場所
- ゲームの乱数は使わない（同じ局面なら同じ手）

CPU だけの勝率（`npm run cpu-match -w games/ghost-stories`、または `node scripts/cpu-match.mjs 1000 all 1000`）：

| 難易度 | 勝率（1000試合） | 主な負け方 |
|---|---|---|
| 入門 | 85.6% | 山切れ・全滅 |
| 標準 | 47.1% | 全滅・呪い |
| 悪夢 | 10.5% | 全滅・呪い |

## 開発

- ルール：`public/js/game.js`（DOM に依存しない。操作はすべて `applyCommand(seat, command)` を通して記録し、`Game.replay` で再現する。乱数はシード付き）。データは `public/js/data.js`
- ビュー：`public/js/game-view.js`（幽霊の山の並びとシードは入れない）
- 画面：`public/js/ui.js`・`art.js`（絵はすべて SVG）・`help.js`・`game-controller.js`（ローカル対戦と「続きから」）
- オンライン対戦：`server/src/game-definition.js`（抜けた人の僧は CPU が引き継ぐ。`isCPU` は記録と一緒に保存する）・`server/src/handler.js`（`keyPrefix: 'ghost-stories'`）・`public/js/online-config.js`（`DEPLOYED_SERVER_URL` はデプロイ前なので空）
- 音：`public/js/sound/bgm.js`（曲「灯籠の夜」）。エンジンと共通の効果音は `node packages/sound/scripts/sync.mjs ghost-stories` で同期する

```bash
npm test -w games/ghost-stories                        # ルール・再現・ヒント・CPU・オンライン・PWA
npm run cpu-match -w games/ghost-stories               # CPU だけの勝率（300試合ずつ）
node scripts/online-e2e.mjs ghost-stories --moves 8    # 2つの画面でのオンラインの通し試験（web-games の直下で）
```
