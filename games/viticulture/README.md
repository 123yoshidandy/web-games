# ヴィティカルチャー

ブドウを植えてワインを造り、注文に届けて点を競うボードゲーム「ヴィティカルチャー（Viticulture Essential Edition、Jamey Stegmaier・Alan Stone、Stonemaier Games）」の基本ゲーム（拡張なし）を、ブラウザで CPU と遊べるようにしたもの。2〜6人（あなた＋CPU 1〜5人）。スマホの縦持ち向けで、スクロールなしで1画面に収まる（PC でも遊べる）。ホーム画面に置くと、オフラインでも遊べる。

絵とアイコンは、すべて SVG で自作している（公式の画像は使っていない）。カードの名前と説明の文も自分で書いたもので、公式の文は写していない。

## 遊び方

- だれかが **20点以上** になった年の終わりに、点の一番多い人の勝ち。同点ならリラ → ワインの価値の合計 → ブドウの価値の合計
- はじめ：人2人と大きいワーカー1人、畑3つ（上限5・6・7）、小さい地下室（ワインは価値3まで）。ママのカード（はじめの手札とリラ）とパパのカード（リラと、建物・人・1点のどれかかリラ）を1枚ずつ
- 1年の流れ
  1. **春**：最初の番の人から順に、起床時間の表（7段）の段を選ぶ。上の段ほど夏と冬に先に動け、下の段ほどおまけがよい（なし・ブドウのカード・注文カード・1リラ・訪問者カード・1点・臨時の人）
  2. **夏**：起床の早い順に、夏の行動の場所に人を1人置くかパス。全員がパスするまで続く
  3. **秋**：夏か冬の訪問者カードを1枚引く（離れがあればもう1枚）
  4. **冬**：冬の行動の場所に人を置く。夏に置いた人は年の終わりまで戻らない
  5. **年の終わり**：ブドウとワインの価値が1上がる（ワインは地下室の大きさまで）。手札は7枚まで。残りの収入のリラを受け取る。最初の番は右隣へ
- 行動の場所（枠は2人で1つ・3〜4人で2つ・5〜6人で3つ。最初の枠にはおまけ）

| 季節 | 場所 | すること（おまけ） |
|---|---|---|
| 夏 | ブドウのカード | 1枚引く（もう1枚） |
| 夏 | 見学 | 2リラ（+1リラ） |
| 夏 | 建てる | 建物を1つ（1リラ引き） |
| 夏 | 夏の訪問者 | 夏の訪問者カードを1枚出す（もう1枚） |
| 夏 | 売り買い | ブドウを売る（価値1〜3は1リラ・4〜6は2・7〜9は3）か、ブドウのない畑を売る・買い戻す（+1点） |
| 夏 | 植える | ブドウを1本（もう1本） |
| 冬 | 注文カード | 1枚引く（もう1枚） |
| 冬 | 収穫 | 畑を1つ（もう1つ）。同じ畑は1年に1回 |
| 冬 | 人を雇う | 4リラで1人（1リラ引き）。次の季節から使える。大きいワーカーを含めて6人まで |
| 冬 | 冬の訪問者 | 冬の訪問者カードを1枚出す（もう1枚） |
| 冬 | 醸造 | ワインを2つまで（もう1つ） |
| 冬 | 注文 | 注文を1つ果たす（+1点） |
| 冬 | 1リラ | 何人でも置ける |

- **大きいワーカー**：枠が埋まった場所にも置ける（そのときおまけはない）
- **ワイン**：赤ブドウ→赤ワイン、白ブドウ→白ワイン（同じ価値）。赤＋白→ブラッシュ（合計の価値、中の地下室が要る、4以上）。赤2つ＋白→スパークリング（合計、大きな地下室が要る、7以上）
- **注文**：書かれたワイン（その価値以上）を出して、点と残りの収入（毎年のリラ。5まで）を得る
- **建物**：ブドウ棚（2リラ）・水路（3）・くびき（2。自分だけの場所で、ブドウを抜くか畑を収穫）・風車（5。植えたとき1点、1年に1回）・離れ（4。秋に訪問者をもう1枚）・試飲室（6。見学でワインがあれば1点、1年に1回）・中の地下室（4）・大きな地下室（6）

### 固有名詞の日本語

Trellis＝ブドウ棚、Irrigation＝水路、Yoke＝くびき、Cottage＝離れ、Tasting Room＝試飲室、Medium/Large Cellar＝中の地下室・大きな地下室、Crush Pad＝ブドウ（の置き場）、Residual Payment＝残りの収入、Wake-up Chart＝起床時間の表、Grande Worker＝大きいワーカー、lira＝リラ。ブドウの品種（サンジョヴェーゼ・メルロー・シャルドネなど）は、日本でも通じるカタカナのまま。

### カードの揃え方（原作と違うところ）

- **ブドウ**（46枚）：サンジョヴェーゼ（赤1）6・マルヴァジア（白1）6・ピノ（赤1白1、棚）6・シラー（赤2、棚）5・トレッビアーノ（白2、棚）5・メルロー（赤3、水路）5・ソーヴィニヨン・ブラン（白3、水路）5・カベルネ（赤4、棚と水路）4・シャルドネ（白4、棚と水路）4。枚数と、どの品種がどの建物を要るかは記憶にもとづくもので、原作と細部が違うおそれがある
- **注文**（36枚）：要るワインの組み合わせは自作。点は「要る価値の合計÷2（ブラッシュ1つにつき+0.6、スパークリング1つにつき+1.2）を四捨五入」、残りの収入は合計5以下で2・9以下で1・それより上で0、という式で決めた
- **訪問者**：夏30枚・冬30枚（原作は各38枚）。原作の訪問者の効果を手本に、1枚ずつ作った（名前と文は自作）。**ほかの人に選ばせる効果**（「ほかの全員は〜してもよい。した人ごとに〜」など）と、**ほかの季節に人を置く・戻す効果**は、手番の進め方が大きく変わるので入れていない。そのぶん、成り立つ数（各30枚）にとどめた
- **ママとパパ**：ママ12枚・パパ10枚。持ち物の組み合わせは自作（ママはカード3枚前後、パパはリラ3〜6と「建物・人・1点」かリラ）

### ルールで割り切った点・自分で決めた点

- 人は、空いている最初の枠に入る（おまけの付かない枠をわざと選ぶことはできない）
- 同じ季節に、同じ場所へ自分の人を2人は置けない（大きいワーカーも同じ）
- できない行動には置けない（植えられるブドウがないのに「植える」など）。訪問者カードも、効果のどれか1つを行えるものだけを出せる
- ワインの価値が地下室に入らないときや、同じ価値のところが埋まっているときは、空いている一番近い下の価値に置く（ブドウも同じ）。下に空きがなければ造れない
- 注文に使うワインは、条件を満たすうちで価値の低いものを自動で選ぶ
- 「1リラ」の場所は冬だけに置いた
- 最初の番は、年ごとに右隣（反時計回り）へ移る
- 終わりの年の数に上限はない（だれかが20点に届くまで続く）

### 画面の操作

- 春は段を、夏と冬は行動の場所をタップする。枠が埋まっていれば大きいワーカーで置く。下の「大きいワーカー」を押してからタップすると、空いていても大きいワーカーで置く
- 選ぶものがあると、下から一覧が出る。「盤面を見る」で閉じ、「選ぶ」で開き直す
- 上のプレイヤーの名前をタップすると、その人のブドウ園（畑・ブドウ・ワイン・建物・手札の枚数）を見られる。自分のブドウ園をタップすると大きく見られる
- 操作のたびに途中経過を保存し、タイトルの「続きから」で再開できる（決着したら消す）

## CPU

- 選択肢と置き場所を、ゲームの写しで1つずつ試し、そのあとの自分の状態（点・リラ・残りの収入・畑とブドウ・ワイン・果たせる注文・建物・人・夏に残した人）を点数にして、一番よいものを選ぶ
- 写しでは山札を CPU 自身の乱数で混ぜ直すので、まだ見えていないカードをのぞかない。ゲームの乱数も使わない（記録の再現がずれないように）
- 「やさしい」は、決める場面の一部（約半分）でランダムに選ぶ
- `node scripts/cpu-match.mjs 100 easy,normal` で CPU 同士を対戦させ、勝率と平均点・平均の年数を出せる。手元では、ふつうがやさしいに 2人で約87%、3人（やさしい2人と）で 100% 勝ち、ふつう同士の2人で平均約9年、3〜6人で約7〜9年で終わった

## 開発

```bash
cd ~/MyProjects/web-games
npm test -w games/viticulture        # ロジック・CPU・オンライン用の定義・PWA のテスト
node games/viticulture/scripts/cpu-match.mjs 100 easy,normal
cd games/viticulture/public && python3 -m http.server 8000
```

- `public/js/cards.js`：カード・建物・起床時間の表・行動の場所のデータ。訪問者カードの効果は「手順」（`{ op, ... }`）の並びで書く
- `public/js/game.js`：ルール（DOM に依存しない）。操作は `wake`・`place`・`pass`・`choose` の4つだけで、`applyCommand` に通し、記録から `Game.replay` で再現できる。断る操作は状態を変えない
- `public/js/game-view.js`：そのプレイヤーから見てよい情報だけのビュー（ほかの人の手札は山ごとの枚数だけ）
- `public/js/cpu-player.js`：CPU。`public/js/game-controller.js`：ローカル対戦と保存。`public/js/ui.js`：画面
- `server/src/game-definition.js`：netplay-kit の「ゲームの定義」の形。`server/src/handler.js`（サーバーの入口）・`public/js/online-config.js`（接続先）・`public/js/netplay/`（netplay-kit の写し。手で直さない）は、下の「オンライン対戦」

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜6人で、足りない席は CPU で埋められる。ほかの人の手札と山札の並びはビューに入れない。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'viticulture' })`。web-games の1つのスタックから `?game=viticulture` で呼ばれる）
- ゲームの定義は `server/src/game-definition.js`（記録だけを保存して再現する。各席には、その席から見えるビューだけを送る）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
