# スモールワールド

小さすぎる世界を、種族と特殊能力の組で奪い合う陣取りゲーム「スモールワールド（Small World）」を、ブラウザで CPU と遊べるようにしたもの。2〜5人（あなた＋CPU 1〜4人）。スマホの縦持ち向け（横持ちと PC では、地図の右に欄を並べる）。地図は2本指でつまむ・ホイール・＋−のボタンで拡大でき、ドラッグで動かせる。ホーム画面に置くと、オフラインでも遊べる。

絵（地図・印・アイコン）は、すべて SVG で自作している。

## 遊び方

- 種族14と特殊能力20を、それぞれ混ぜて上から組にし、6組を並べる。1人5金
- 種族がなければ、並びから組を選ぶ。上から i 番目なら、上の i 組に1金ずつ置き、選んだ組に乗っていたコインをもらう。部隊の数は種族と特殊能力の数の合計
- 征服：2＋部隊＋山・トロルの巣・砦・野営地の数だけ部隊を置く。最初は地図の縁（縁の海に面した領域を含む）から入り、そのあとは自分の領域の隣。海と湖は取れない（航海する種族を除く）
- 部隊が足りなくなったら、最後に1回だけ援軍のサイコロ（0・0・0・1・2・3）に賭けられる
- 攻められた側は1体を失い（エルフは失わない）、残りは手に戻る
- 番の初めには、各領域に1体ずつ残して部隊を手に戻す。最初の征服の前なら、領域を放棄できる
- 征服を終えたら再配置。番の終わりに、自分の種族（衰退した種族も）がいる領域1つにつき1金と、種族・特殊能力のボーナス
- 衰退：番の初めに、征服の代わりに選ぶ。各領域に1体だけ残り（グールは全部残る）、前の衰退した種族は消えて山の下に戻る（霊の種族は残る）。その番は得点だけして、次の番に新しい組を選ぶ
- ラウンド数は 2・3人 10、4人 9、5人 8。終わったときにコインが一番多い人の勝ち。同点なら地図の部隊が多い人

種族14（アマゾネス・ドワーフ・エルフ・グール・巨人・ハーフリング・人間・オーク・ネズミ人・ガイコツ・魔術師・海の民（トリトン）・トロル・魔法使い）と特殊能力20（錬金術・狂戦士・野営・奇襲・外交・竜使い・空飛ぶ・森・砦・英雄・丘・商人・騎馬・略奪・航海・霊・頑丈・沼・地底・裕福）は、基本セットのとおりすべて入れた。

### 地図

原作の地図の絵は使えないので、小さな六角マスを集めて領域を作る地図を、人数ごとに1つずつ用意した（決まったシードから作るので、毎回同じ形）。

| 人数 | 領域 | 中身 |
|---|---|---|
| 2人 | 23 | 海2・湖1・山4、魔法の源・鉱山・洞窟 各3、失われた部族 6 |
| 3人 | 30 | 海2・湖1・山5、各4、失われた部族 8 |
| 4人 | 39 | 海3・湖1・山6、各5、失われた部族 11 |
| 5人 | 48 | 海3・湖1・山8、各6、失われた部族 13 |

領域の数は原作の地図と同じにした。地形・特別な領域・失われた部族の数と並びは、原作に近い割合で自分で決めた。

### 原作どおりにしなかった点・解釈した点

- **攻められた人の手に戻った部隊は、攻めた人の番の終わりに、自動で自分の領域に置き直す**（守りの薄い領域から）。原作では攻められた人が自分で置く
- 再配置の初めに、手の部隊・英雄・野営地・砦を自動で置く。そこから、自分の領域を選んで＋−・英雄・野営・砦で動かせる
- コインは伏せず、全員に見せる
- アマゾネスの4体は、選んだときの数（6＋特殊能力）とは別に、征服のときだけ足す（再配置の前に戻す）
- 竜は、次に竜を使うか衰退するまで、その領域に残る
- 衰退したグールが征服するときは、特殊能力の力を持たない
- ハーフリングが地図のどこからでも入れるのは、地図に領域がないとき（最初と、すべて失ったあと）
- 魔術師は海と湖には使えない。魔術で奪われた部隊は手に戻らない
- 外交の和平は、和平を結んだ人の次の番の初めまで続く
- 最後の征服でサイコロが外れたら、そのまま再配置に移る

### 画面

- 征服できる領域は金色の縁で光り、置く部隊の数が出る（橙の点線はサイコロに賭ける領域、赤は竜・魔術）。選んでから「征服」、または同じ領域をもう一度タップで征服する
- ほかの人が前の番に取った領域は、白い点線で囲む
- 人の欄か旗のボタンで、並んでいる組と、場の種族の説明を見られる
- 征服でできることがなくなったら、少し間を置いて再配置に移る
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

見える情報（盤面・種族・コイン・並び）だけで決める。山の並びとサイコロの先は見ない。

- 組を選ぶ：部隊の数＋種族と特殊能力の強さの目安＋乗ったコイン−払うコイン
- 征服：領域の値打ち（毎番のコイン・ボーナス・相手を削る分・守りやすさ）から、要る部隊の数を引いた点が一番高い領域。部隊が足りなくなったら、届く見込みの高い領域にサイコロで賭ける
- 衰退：この番に取れそうな領域が少なく、持っている領域が多いとき。最後のラウンドでは衰退しない

| 強さ | 中身 |
|---|---|
| やさしい | 判断の揺れが大きく、ときどき早めに征服をやめる |
| ふつう | 揺れが小さい |

CPU 同士の対戦（各 300 試合）：

| 対戦 | ふつうの勝率 | 公平なら |
|---|---|---|
| 2人：ふつう 対 やさしい | 80.7% | 50% |
| 3人：ふつう1 対 やさしい2 | 51.3% | 33.3% |

```bash
# 試合数・人数・席ごとの強さ（easy・normal）
node scripts/cpu-match.mjs 300 3 normal,easy,easy
```

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/data.js` | 種族・特殊能力・地形などの決まった値 |
| `public/js/map.js` | 人数ごとの地図（六角マスを集めた領域） |
| `public/js/rules.js` | 征服に要る数・攻められる領域・得点の計算（状態を変えない） |
| `public/js/game.js` | ルール。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー（山の並びは入れない） |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js`・`board-view.js` | 画面と地図（拡大・移動・タップ） |
| `public/js/art.js`・`help.js` | 絵と遊び方 |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |

### オンライン対戦を入れるとき

ルールとビューは、netplay-kit の「ゲームの定義」の形（`server/src/game-definition.js`）で用意してある。netplay-kit の `sync.mjs` で部屋の処理を写し、この定義を `createHandler` と `startDevServer` に渡す。画面は、ローカル対戦と同じ `getView()` / `send()` の形のオンライン用のコントローラーを足す。
