# テラミスティカ

14の勢力から1つを選び、地形を自分の住める地形に変えて建物を広げるボードゲーム「テラミスティカ（Terra Mystica）」の基本セットを、ブラウザで CPU と遊べるようにしたもの。2〜5人（あなた＋CPU 1〜4体）。スマホの縦持ち向け（PC では地図を左、操作の欄を右に並べる）。ホーム画面に置くと、オフラインでも遊べる。

地図・建物・アイコンは、すべて SVG で自作している。

## 遊び方

- 6ラウンドで、勝利点が一番多い人の勝ち。全員 20 点から始まる
- 準備：手番の順に住居を1つずつ、逆の順にもう1つずつ置く（遊牧民は3つ目、混沌の魔術師は全員のあとに1つだけ）。そのあと、手番の逆順にボーナスカードを取る
- ラウンドの始めに収入（建物・恩恵タイル・ボーナスカード）。手番の順に1つずつ行動し、パスするまで続ける。最初にパスした人が次のラウンドの先手
- 行動（どれか1つ）
  - 変換と建設：自分の建物の隣（航海で川の向こう、橋の先も）の土地を、鋤で自分の地形に変えて住居を建てる。地形は 砂漠→平原→沼地→湖→森→山→荒地→砂漠 の輪で、1つ離れるごとに鋤1つ（職人3。鋤の改良で2・1）
  - 改良：住居→交易所→寺院か要塞、寺院→聖域。交易所は、隣にほかの人の建物があるとコインが半分。寺院・聖域で恩恵タイル
  - 航海・鋤の改良、司祭を宗教の段に送る（置き場に置くと3つか2つ。置き場が埋まっていれば1つ進んで司祭は戻る）
  - 魔力アクション（橋・司祭1・職人2・コイン7・鋤1・鋤2。ラウンドに1回ずつ早い者勝ち）、特別な行動（ボーナスカード・恩恵タイル・要塞）、パス（ボーナスカードを取り替える）
- 魔力は3つの器を回る。ほかの人が隣に建てると、隣の自分の建物の分（住居1・交易所と寺院2・要塞と聖域3）だけ魔力をもらえ、もらった魔力−1点を払う
- つながった自分の建物が4つ以上（聖域は2つ分）で、建物の魔力の合計が7以上になると町。町タイル（点など）と鍵をもらう。宗教の段の10には鍵が要り、1つの段に1人だけ
- ラウンドごとの得点タイルに合う行動で点。ラウンドの終わり（6ラウンド目を除く）に、宗教の段に応じたボーナス
- 最後に、一番大きな建物のつながり（18・12・6点）、宗教の段ごとの順位（8・4・2点）、残りの資源（3コインで1点）を足す。同じ順位は、その順位の点を合わせて頭数で割る

### 勢力

| 勢力 | 地形 | 能力 | 要塞 |
|---|---|---|---|
| 魔女 | 森 | 町を作るたびに5点 | ラウンドに1回、どこの森にでも住居を無料で建てる |
| 森の賢者 | 森 | — | すぐに恩恵タイル。ラウンドに1回、宗教の段を2つ |
| 錬金術師 | 沼地 | いつでも 1点→コイン1、コイン2→1点 | すぐに魔力12。以後、鋤1つで魔力2 |
| 闇の民 | 沼地 | 鋤は司祭1で払い、払った鋤1つで2点。鋤の改良はない | すぐに職人を3人まで司祭に替える |
| 小人族 | 平原 | 鋤1つごとに1点。鋤の改良が安い | すぐに鋤3つ（1か所に住居を建ててよい） |
| 教団 | 平原 | 建てたとき、だれかが魔力を受け取れば宗教の段を1つ。全員が断れば魔力1 | すぐに7点 |
| 人魚 | 湖 | 航海1から始まり5まで。町は川1マスをはさんでもつながる | すぐに航海＋1 |
| 群れの民 | 湖 | 町で職人3。建物は高いが収入が多い | ラウンドに1回、住居を無料で交易所に |
| 苦行僧 | 砂漠 | 航海の代わりにじゅうたん（司祭1で1マス先まで飛ぶ。4点） | じゅうたんの距離＋1 |
| 遊牧民 | 砂漠 | 最初の住居が3つ | ラウンドに1回、隣の土地を砂漠に変え、住居を建ててよい（砂嵐） |
| 巨人 | 荒地 | どの地形も鋤2つで荒地に | ラウンドに1回、無料の鋤2つ |
| 混沌の魔術師 | 荒地 | 最初の住居は1つ。寺院・聖域で恩恵タイル2枚 | ラウンドに1回、続けて2回行動 |
| ドワーフ | 山 | 航海の代わりにトンネル（職人2を足して1マス先へ。4点） | トンネルの職人が1 |
| 技師 | 山 | 建物が安い。職人2で橋を架けられる | パスのとき、自分の建物どうしをつなぐ橋1本ごとに3点 |

費用・収入・最初の資源と宗教の段・ボーナスカード9枚・恩恵タイル12種・町タイル5種（各2枚）・得点タイル8種は、基本セットの値に合わせた（`public/js/data.js`）。ボーナスカードは人数＋3枚、得点タイルは8枚から6枚を使い、鋤の得点タイルは5・6ラウンドに来ない。

### 本家から割り切ったこと・自分で決めたこと

- 地形の変換は、自分の地形へ近づける向きだけ（ほかの人の地形に変えて邪魔する手は使えない）
- 人魚の町は、川1マスをはさんだ自分の建物どうしを、自動でつながっているとみなす（本家では町を作るときに1か所だけ選ぶ）
- 魔力のもらいは、建てた手番の直後に、手番の順で1人ずつ決める
- 技師の橋は、ほかの行動と同じく1手番を使い、ラウンドに何回でも（3本まで）架けられる
- 遊牧民の砂嵐は、橋でなく、じかに隣り合う土地だけ
- 小人族の要塞の鋤3つも、魔力アクションの鋤と同じく、足りない分を職人で足して自分の地形まで変えられる

## 画面

- 地図は2本指かホイール、右下のボタンで拡大・縮小、ドラッグで移動。光っている土地が選べる土地
- 土地をタップすると、そこでできること（変えて建てる・変えるだけ・改良）と費用が出る。資源が足りなければ、魔力などの交換を付けて払える
- 下のボタンで、魔力アクションと特別な行動・宗教の段（司祭を送る）・航海と鋤の改良・交換・情報（得点タイル・残りのタイル）・パス
- 鋤を使う場面（魔力アクション・ボーナスカード・要塞・宗教のボーナス）では、変える土地をタップし、変えた土地にもう一度タップして住居を建てる。使わない分は「使わない」で終える
- 橋は、岸の土地と向こう岸をタップする
- 魔力のもらい・恩恵タイル・町タイル・教団の宗教の段・闇の民の司祭は、自分の番になるとシートが開く
- 上の札をタップすると、その勢力の能力・資源・残りの駒・収入が見られる
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

手番の行動は、候補（建てる・変える・改良・航海・鋤の改良・司祭・魔力アクション・橋・特別な行動・パス）ごとに状態を写して打ってみて、評価（勝利点＋資源・収入・建物・宗教の段の順位・つながり・町の見込み・要塞の力）が一番上がるものを選ぶ。上位の候補は、続けて自分がもう1手打った先まで読む。恩恵タイル・町タイル・魔力のもらい・鋤の使い道などは簡単な決まりで選ぶ。ゲームの乱数は使わない（判断の揺れには別の乱数を使い、記録から同じ試合を再現できる）。

| 強さ | 中身 |
|---|---|
| やさしい | 評価の揺れが大きく、ときどき候補から適当に選ぶ。先を読まない |
| ふつう | 揺れが小さく、上位5つの候補をもう1手先まで読む |

CPU 同士の対戦（ふつう同士は各 40 試合。全試合が最後まで終わった）：

| 対戦 | ふつうの勝率 | 公平なら |
|---|---|---|
| 2人：ふつう 対 やさしい（40 試合） | 85.0% | 50% |
| 4人：ふつう1 対 やさしい3（30 試合） | 56.7% | 25% |

| 人数 | 得点の平均 | 1人の操作の数 | 強い勢力（勝率） | 弱い勢力（勝率） |
|---|---|---|---|---|
| 2人 | 105 | 37 | 群れの民 83%・ドワーフ 75%・錬金術師 71% | 森の賢者 0%・技師 17%・人魚 20% |
| 3人 | 97 | 39 | 闇の民 83%・小人族 60% | 技師・群れの民・森の賢者 0%・巨人 8% |
| 4人 | 87 | 42 | ドワーフ 63%・群れの民 43% | 巨人 0%・技師 8% |
| 5人 | 81 | 42 | 闇の民 50%・苦行僧 42% | 森の賢者 0%・巨人と技師 6% |

勢力ごとの試合数は 2〜18 なので、勝率の差は大まかな目安。闇の民とドワーフが強く、巨人と技師が弱い（巨人は最後の得点の前まではほかと同じくらいだが、宗教の段とつながりで差がつく）。

```bash
# 試合数・人数・席ごとの強さ（easy・normal）
node scripts/cpu-match.mjs 40 4
node scripts/cpu-match.mjs 40 2 normal,easy
```

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest。モノレポの直下で）
npm test -w games/terra-mystica
```

| ファイル | 役割 |
|---|---|
| `public/js/data.js` | 地形・地図・勢力・タイルのデータ |
| `public/js/map.js` | 六角の地図（隣・川をはさんだ距離・橋を架けられる組） |
| `public/js/game.js` | 進行。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | 画面に渡すビュー（隠す情報はないので、状態をそのまま写す） |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/board-view.js` | 地図の描画と、拡大・移動・タップ |
| `public/js/ui.js` | 画面 |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |

### オンライン対戦を入れるとき

ルールとビューは、netplay-kit の「ゲームの定義」の形（`server/src/game-definition.js`）で用意してある。魔力のもらいは1人ずつ順に決めるので、`game.actors()` はいつも1人を返す。netplay-kit の `sync.mjs` で部屋の処理を写し、この定義を `createHandler` と `startDevServer` に渡す。画面は、ローカル対戦と同じ `getView()` / `send()` の形のオンライン用のコントローラーを足す。
