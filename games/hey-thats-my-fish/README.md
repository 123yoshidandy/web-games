# それはオレの魚だ！

ペンギンを滑らせて氷を取り、魚を集めるボードゲーム「それはオレの魚だ！（Hey, That's My Fish!／Packeis am Pinguinpol、Günter Cornett・Alvydas Jakeliunas、2003）」を、ブラウザで CPU と遊べるようにしたもの。2〜4人（あなた＋CPU 1〜3人）。スマホの縦持ち向けで、スクロールなしで1画面に収まる。ホーム画面に置くと、オフラインでも遊べる。

ペンギン・魚・氷の絵とアイコンは、すべて SVG で自作している（公式の画像は使っていない）。説明の文も自分で書いたもので、公式の文は写していない。

## 遊び方

- 六角の氷60枚（魚1匹30枚・2匹20枚・3匹10枚）を混ぜて、7枚と8枚の列が交互の8列に並べる（上から 7・8・7・8・7・8・7・8）
- ペンギンは 2人なら4羽、3人なら3羽、4人なら2羽ずつ
- 最初の人から順に1羽ずつ、魚1匹の空いている氷に置く。全員が置き終えたら、同じ人から動かし始める
- 手番：自分のペンギン1羽を、6方向のどれかにまっすぐ何マスでも動かす。向きは変えられず、穴とほかのペンギン（自分のものも）は越えられない。動かしたら、出発した氷を取る
- 手番の始めにどのペンギンも動けない人は、そこで抜ける。ペンギンを全部取り除き、その足もとの氷を取る
- 全員が抜けたら終わり。取った魚の合計が多い人の勝ち。同じなら取った氷の枚数が多い人。それも同じなら、勝ちを分け合う

### 資料と、資料で分からない点の決め方

ルールは、2つの版の英語のルールブックを読んで合わせた。

- 古い版（Phalanx Games／Mayfair Games、2005年）
- 新しい版（Plan B Games／Next Move、2023年）

資料の食い違いと、どちらに合わせたか：

- **動けないペンギン**：依頼の文では「動けないペンギンは取り除いてそのタイルも取る」とペンギンごとに読めたが、どちらのルールブックも「手番の始めに、自分のペンギンが1羽も動けなければ、その人は抜け、ペンギンを全部取り除いて足もとの氷を取る」とプレイヤーごとの決まり。ルールブックに合わせた。違いは、1羽だけ閉じ込められたペンギンが、その人が抜けるまで盤に残り、ほかのペンギンの通り道をふさぎ続けること。足もとの氷は、どちらでも最後には取れる
- **並べ方**：古い版は「真ん中に8枚の列を置き、上に 7・8・7、下に 7・8・7・8」と書き、新しい版は盤の板に置く。どちらも 7枚と8枚が交互の8列（上の列が7枚）なので、その形にした
- **氷の偏り**：古い版には「2匹と3匹の氷が偏らないように入れ替えてよい」、新しい版には「全員が同意すれば入れ替えてよい」とある。この版はシードで混ぜるだけで、入れ替えない
- **だれも行けない氷**：古い版には「どのペンギンも行けない氷は場から除く」とある。得点には関係しないので、そのまま残している（画面には残るが、だれも取れない）
- **同点**：古い版は「氷の枚数でも同じなら引き分け」、新しい版は「勝ちを分け合う」。同じ意味なので、結果の画面では「引き分け」と出す
- **最初の人**：ルールブックでは「いちばん若い人」。この版はシードから決める（ランダム）

自分で決めた点：

- 抜ける処理は、手番が回ってきたときにゲームが自動で行う（押す操作は要らない）。1人だけが動けるあいだは、その人が続けて動かす
- 一度選んだペンギンでも、行き先を押す前なら、ほかのペンギンを押して選び直せる。動けるペンギンが1羽だけなら、はじめから選んでおく

### 画面の操作

- 置くとき：金色に光る氷（魚1匹で空いている）を押すと置く
- 動かすとき：光っている自分のペンギンを押すと、行き先が金色の縁で出る。行き先を押すと滑って動く。出発した氷は沈んで消える
- 上の帯に、各人の色のペンギンと取った魚の数。今の番の人は金色の枠、抜けた人は薄くなる
- 右上のボタンで記録と遊び方が見られる。操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

## CPU

強さは「ふつう」と「やさしい」。CPU はビュー（氷・ペンギン・取った魚。このゲームに伏せた情報はない）だけを見て決める（`chooseCommand(view, level, rand)`）。CPU の迷いにはゲームの乱数を使わない（記録の再現がずれないように）（`public/js/cpu-player.js`）。

**形勢の見積もり**：その人の値 ＝ 取った魚 ＋ 足もとの氷 ＋ 届く氷 ＋ 動けるペンギン

- 届く氷：各人のペンギンから、氷のとなりをたどる歩数を数え（ほかのペンギンは通れない）、いちばん近い人のものとみる。ほかの人が1人も届かない氷（自分で囲った領域）は満額、競う氷は6割から、遠いほど割り引く。同じ近さなら分ける
- 動けるペンギン：となりに氷があるペンギンは +1、閉じ込められたペンギンは −1
- 比べるのは「自分の値 − ほかの人の中でいちばん高い値」

**ふつう**：先を読む。自分の手をすべて見積もり、よい5手について、ほかの人が順にそれぞれの見積もりで一番よい手を返し、自分がもう1手打ったあとの形勢で決める。領域を囲う手と、相手を閉じ込める手が、見積もりの差として選ばれる。置くときは、置いたあとの形勢と、まっすぐ行ける先の魚の多さで選ぶ。

**やさしい**：置くのはでたらめ。動かすのは、半分は行き先の魚がいちばん多い手、半分はでたらめ。

```bash
# 試合数・人数・席ごとの強さ（easy・normal。greedy は1手だけ読む比べ用）。最初の人は試合ごとに入れ替える
node scripts/cpu-match.mjs 400 2 easy,normal
```

| 対戦 | 試合数 | ふつうの勝率 | 相手の勝率 | 魚の平均（ふつう／相手） |
|---|---|---|---|---|
| 2人（やさしい・ふつう） | 400 | 100% | 0% | 61.7／31.7 |
| 2人（ふつう・やさしい） | 400 | 100% | 0% | 61.8／31.8 |
| 3人（やさしい・ふつう・やさしい） | 300 | 95.7% | 1.3%・3.0% | 42.3／25.7・26.1 |
| 4人（やさしい・ふつう・やさしい・ふつう） | 300 | 43.0%・46.7% | 4.7%・5.7% | 26.4・26.9／19.9・20.1 |
| 2人（1手だけ読む・ふつう） | 400 | 87.0% | 13.0% | 50.7／41.9 |
| 2人（ふつう・1手だけ読む） | 400 | 89.9% | 10.1% | 51.2／41.6 |
| 2人（ふつうどうし） | 200 | 52.5%・47.5% | — | 47.0・46.1 |
| 3人（ふつうどうし） | 300 | 35.7%・31.8%・32.5% | — | 31.3・31.4・31.3 |

先読みは、1手だけ読む CPU に9割近く勝つ。どの組み合わせでも、止まった試合はない。ふつうは1手を考えるのに数十ミリ秒かかる（2人の CPU どうしの1試合で約0.1秒）。

## 開発

```bash
npm install
# 画面（http://localhost:8000/ を開くと public/ へ移る）
python3 -m http.server 8000
# テスト（Vitest）
npm test
```

| ファイル | 中身 |
|---|---|
| `public/js/board.js` | 盤の形（マスの位置、6方向のとなり、まっすぐ動ける先） |
| `public/js/game.js` | 進行（DOM に依存しない）。操作は `applyCommand` だけで受け、記録から `Game.replay` で再現できる。断る操作は状態を変えない |
| `public/js/game-view.js` | ビュー（伏せた情報はないので全員に同じ。シードと CPU の値は入れない） |
| `public/js/cpu-player.js` | CPU（ビューだけを見る） |
| `public/js/game-controller.js` | 人間1人と CPU のローカル対戦（途中経過の保存） |
| `public/js/ui.js`・`art.js` | 画面・絵（盤は1つの SVG。ペンギンは同じ要素を動かして滑らせる） |
| `public/sw.js`・`manifest.webmanifest` | PWA（オフラインでも開ける） |
| `server/src/game-definition.js` | オンライン対戦用のゲームの定義（netplay-kit の形。まだつないでいない） |
| `scripts/cpu-match.mjs` | CPU 同士の対戦と勝率・魚の平均 |

テスト（`test/`）：

- `game.test.js`：盤の形（7と8の8列・60マス・となり）、準備（魚の枚数・ペンギンの数）、置く（魚1匹の空いている氷だけ・順番）、動かす（まっすぐ・穴とペンギンは越えられない・出発した氷を取る）、動けない人が抜けて足もとの氷を取ること、得点（魚・氷の枚数・分け合う）、断る操作で状態が変わらないこと
- `replay.test.js`：記録からの再現、CPU の判断がゲームの乱数を使わないこと、ランダムな操作を浴びせても断った操作で状態が変わらず氷が60枚のままで再現できること
- `cpu-player.test.js`：CPU どうしの試合が人数（2〜4）・強さ・シードを変えても止まらないこと、ふつうがやさしいと1手だけ読む CPU に勝ち越すこと、囲った領域の見積もり、相手を閉じ込める手、置く場所
- `game-definition.test.js`：オンライン対戦の定義と、ビューにシードと CPU の値が入らないこと
- `game-controller.test.js`：CPU との対戦で、CPU が人の番で止まること、断った操作を伝えること
- `pwa.test.js`：service worker が画面のファイルを全部先に読むこと、manifest とアイコン
- `offline.test.js`：service worker を差し替えた入れ物で動かし、ネットワークが切れてもページと JS をキャッシュから返すこと

### オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜4人で、足りない席は CPU で埋められる。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'hey-thats-my-fish' })`。web-games の1つのスタックから `?game=hey-thats-my-fish` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
