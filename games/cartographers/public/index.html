王の勅令

遊び方

目的

王の命を受けた地図職人として、4つの季節のあいだ地図を描き、王の勅令（得点カード）でできるだけ多くの点を集めます。全員が同じカードを、それぞれの地図に描きます。

探索カード

カードに描かれた形と地形の組を1つ選び、回転・裏返しして、地図の空いたマスに描きます。山のマスや、描いたマスには重ねられません。のついた形を描くと、コインを1枚得ます。どの形も描けないときは、1×1 を好きな地形で描きます。

廃墟

廃墟のカードが出たら、次の形は廃墟のマスにかけて描きます。かけられないときは、1×1 を好きな地形で描きます。

季節

カードの時間（）の合計が季節の長さに達したら、季節の得点を数えます。春は勅令 A と B、夏は B と C、秋は C と D、冬は D と A。これにコインの数を足し、異形に接する空きマス1つにつき1点を引きます。

襲撃

襲撃のカードが出たら、隣の人の地図に異形の形を描きます（矢印の向きで、だれの地図に描くかが決まります）。ソロでは、カードに示された角から自動で描かれます。

山

山の上下左右の4マスがすべて埋まると、コインを1枚得ます。コインは、そのあとの季節のたびに1点になります。

操作

形を選び、地図のマスを押すと、そのマスを中心に置いたときの姿が出ます。回転・裏返しのボタンで向きを変え、「描く」で描きます。上の勅令を押すと、得点の数え方と今の点が見られます。電球のボタンを押すと、おすすめの形・向き・場所を選んだ状態にします。
