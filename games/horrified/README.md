# ホラーファイド

村に現れた怪物たちを、英雄が力を合わせて退治する協力ゲーム「ホラーファイド（Horrified、Prospero Hall、Ravensburger 2019年）」を、ブラウザで遊べるようにしたもの。1〜5人の英雄で、2〜4体の怪物に立ち向かう。自分の英雄だけを動かして仲間を CPU に任せるか、1人で全員を動かして遊ぶ。スマホの縦画面向け。ホーム画面に置くと、オフラインでも遊べる。

原作の怪物は、映画会社の登録された怪物たちだが、ここでは名前も絵もすべて自作の一般的な怪物（吸血鬼・人造人間・狼男・ミイラ・半魚人・透明人間）にしている。村の地図・地点の名前・アイテム・村人・特典・怪物カード・説明の文も、すべて自分で作ったもので、原作の文や画像は使っていない。

## 遊び方

- 20か所の地点が道でつながった村で遊ぶ。英雄と怪物は、それぞれ決まった地点から始まる。アイテムを12個、袋から出して置き、英雄は特典を1枚ずつ持つ
- 手番は、英雄の番（アクション）→ 怪物の番、の順で、英雄が1人ずつ回る
- アクション（町長は5回、ほかは4回）
  - 移動：隣の地点へ。同じ地点の村人を連れて行ける
  - 案内：同じ地点の村人を隣へ、または隣の村人を自分の地点へ
  - 拾う：その地点のアイテムを全部持つ
  - 共有：同じ地点の英雄とアイテムを渡し合う
  - 前進：怪物の目的を1つ進める（決まった地点で、決まった色のアイテムを使う）
  - 退治：目的を果たした怪物のいる地点で、決まった色のアイテムを使って退治する
  - 特殊：運び屋だけ。ほかの英雄のいる地点へ移る
- 特典は、自分の手番にアクションを使わずに使える（夜更かし：アクション+2、夜明け：次の怪物の番をとばす、急ぎ足：2つ先まで移る、差し入れ：袋からアイテムを2つ、探し物：村のアイテムを1つ）
- アイテムは赤・青・黄が20個ずつ（強さ1〜6）。使ったアイテムは脇に置き、袋が空になったら袋に戻す
- 怪物の番：怪物カードを1枚めくる → 書かれた数だけアイテムが袋から出て、それぞれの地点に置かれる → できごと → 書かれた怪物が順に、いちばん近い人（英雄・村人）へ書かれた歩数だけ近づき、同じ地点なら襲う
  - 狂乱の印は、いま狂乱している怪物が動く（狂乱は、できごとや、狂乱の怪物を退治したときに次の怪物へ移る）
  - 襲うとき、同じ地点に2人以上いれば、手番の人が標的を選ぶ。ダイス（命中2面・力1面・空き3面）を書かれた数だけ振る
  - 英雄は命中の数だけアイテムを捨てて防げる。防がなければ病院へ運ばれ、恐怖が1つ上がる。村人は命中で倒れ、恐怖が1つ上がる
  - 力の目では、怪物ごとの力が起きる
- 村人を家まで送り届けると、送った英雄が特典を1枚もらう
- 勝ち：すべての怪物を退治した時点。負け：恐怖が7に達する・怪物カード（30枚）を引けない
- 難易度は怪物の数（2体・3体・4体）。怪物はランダムに選ぶ

### 怪物

| 怪物 | 目的 | 退治 | 力 |
|---|---|---|---|
| 吸血鬼 | 洞窟・地下牢・地下墓所・墓地の棺を、それぞれ赤の合計6以上で壊す | 黄6以上 | 手番の英雄を引き寄せる |
| 人造人間 | 学院で、黄の合計4以上を使って心を教える（3回） | 赤6以上 | 命中が1つ増える |
| 狼男 | 研究所で、青の合計6以上を使って治療薬を作る | 赤9以上 | 恐怖が1つ上がる |
| ミイラ | 博物館で、石板の3つの封印を解く（赤・青・黄それぞれ1色で合計4以上） | 赤9以上 | ミイラのいる地点の英雄が、いちばん弱いアイテムを捨てる |
| 半魚人 | 波止場で、青の合計5以上を使って隠れ家を探す（2回） | 赤9以上 | いる地点のアイテムが流される |
| 透明人間 | 警察署に、出どころの違うアイテムを5つ、証拠として届ける | 青6以上 | 手番の英雄の、いちばん強いアイテムが消える |

### 英雄

| 英雄 | アクション | 能力 |
|---|---|---|
| 町長 | 5 | なし |
| 考古学者 | 4 | 隣の地点のアイテムも拾える |
| 運び屋 | 4 | 1アクションで、ほかの英雄のいる地点へ移れる |
| 科学者 | 4 | 手番に1回、使うアイテムの合計に+1できる |
| 警部 | 4 | 手番に1回、案内をアクションなしでできる |

### 画面の操作

- 地図の光る地点（隣の地点）を押すと移動する。ほかの地点を押すと、その地点の様子（アイテム・村人の家・目的の地点）を見られる
- 上の怪物の欄を押すと、その怪物の目的・退治・力を見られる
- 下の欄のボタンで、拾う・案内・共有・前進・退治・特殊・特典・終える。前進と退治は、使うアイテムを選べる（足りる組をあらかじめ選んでおく）
- 英雄の欄を押すと、その英雄の持ち物を見られる
- 怪物の番に起きたことは、地図の上にまとめて出る（押すと閉じる）。記録のボタンで、すべての記録を見られる
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

## 決めたこと

原作のルールを元に、画面で遊びやすいように次のように決めた。

- **怪物・英雄・カードの中身は自作。** 怪物の目的と退治の条件、英雄の能力、怪物カード30枚のできごとと動き、特典の種類は、原作の仕組み（目的 → 退治、色と強さのアイテム、狂乱、ダイスの命中と力）に合わせて作った。原作の文や細かな数値は写していない
- **アクションを使い切ったら、自動で怪物の番に進む。** 夜更かしを持っているとき、警部の案内が残っているときだけ、「終える」を押すまで待つ
- **怪物の動き：** いちばん近い人へ、最短の道で近づく。同じ距離なら英雄を先に、地点の番号の小さい方へ。どの道を通るかも番号で決める（原作では手番の人が選ぶ場面がある）
- **標的：** 同じ地点に英雄・村人が2人以上いるときだけ、手番の人が選ぶ。防御のアイテムは、襲われた英雄を動かす人が選ぶ
- **力の目：** 標的に命中を当てたあとに起きる（人造人間だけは、力の目がそのまま命中になる）
- **できごとの怪物がいないとき：** できごとは何も起きず、アイテムと怪物の動きだけを行う
- **村人：** 家に着いたら村から外れ、あとのできごとでまた現れることがある。倒れた村人も同じ
- **英雄の人数と怪物の番：** 英雄の人数にかかわらず、英雄の手番のたびに怪物の番が来る

## CPU

「CPU に任せる」で、自分以外の英雄を CPU が受け持つ。全員を操作するときも、ロボットのボタンで今の操作を1手任せられる（`public/js/cpu-player.js`）。電球（ヒント）は、CPU と同じ判断で選んだ手を短い文で知らせ、押すボタンか地点を光らせる（打つのは自分）。

- アクション：残りのアクションの並びをビーム探索（幅6）で試し、盤面の評価が一番高い並びの先頭を打つ。良くならなければ手番を終える
- 評価：退治した怪物と目的の進み、恐怖、要る色のアイテムの強さの合計（チーム全体で、残りの目的に要る分まで）、今進められる目的にアイテムのそろった英雄が近いほど高い、要るアイテムの置かれた地点に英雄が近いほど高い、村人が家から遠い・怪物に近いほど低い、持っている特典、怪物のそばにいるアイテムの少ない英雄は低い
- 前進と退治に使うアイテムは、合計が足りる組のうち、強さの合計がいちばん小さいもの
- 特典：夜更かし・差し入れ・探し物はすぐ使う。夜明けは、手番を終えるときに怪物のそばに人が2人以上いれば使う
- 怪物の番：標的は、命中を防げるアイテムを持った英雄 → 村人 → 英雄の順。防御は、要らない順にアイテムを捨てて必ず防ぐ
- 見てよい情報だけを使い（袋・山札の並びは見ない）、ゲームの乱数は使わない。同じ状態なら同じ手を打つ（記録の再現がずれない）

勝率（CPU だけで、各200試合。シードは1〜200。`node scripts/cpu-match.mjs 200 <英雄の数> all`）

| 英雄 | 怪物2体 | 怪物3体 | 怪物4体 |
|---|---|---|---|
| 1人 | 99.5% | 94.0% | 72.5% |
| 2人 | 98.5% | 90.0% | 55.5% |
| 3人 | 95.5% | 71.5% | 26.5% |
| 4人 | 89.5% | 59.0% | 14.0% |
| 5人 | 80.5% | 40.5% | 6.0% |

- 英雄が多いほど難しい。怪物の番の回数は人数によらず同じだが、アイテムが英雄の間で分かれ、渡し合うために会う手間が増えるため。1人のときは、すべてのアイテムを1人が持つので易しい
- 負けの多くは恐怖（村人が倒れる・英雄が倒される）。怪物4体では、山札切れも増える

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。協力ゲームで、2〜5人。1人が1人の英雄を受け持つ。足りない席は CPU で埋められ、怪物の数を部屋の設定に持つ。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'horrified' })`。web-games の1つのスタックから `?game=horrified` で呼ばれる）
- ビューには、袋・山札の並びとシードを入れない（`test/online.test.js` で確かめる）

## 開発

```bash
npm install
# 画面（public/ を配る）
cd public && python3 -m http.server 8000
# テスト（Vitest）
npm test
# CPU だけで遊ばせて、怪物の数ごとの勝率を測る（試合数・英雄の数・怪物の数 2・3・4・all）
node scripts/cpu-match.mjs 200 3 all
```

| ファイル | 中身 |
|---|---|
| `public/js/data.js` | 村の地図・アイテム・英雄・怪物・村人・特典・怪物カードのデータ |

| `public/js/game-view.js` | 画面とオンライン対戦で送るビュー（袋・山札の並びは隠す） |

| `public/js/game-controller.js` | ローカルで遊ぶときのコントローラー（全員を操作／仲間を CPU に任せる、途中経過の保存） |
| `public/js/ui.js`・`map.js`・`help.js` | 画面・村の地図・遊び方 |
| `public/js/sound/bgm.js` | BGM「月夜のワルツ」（再生エンジンと効果音は packages/sound の写し） |

| `server/src/game-definition.js`・`handler.js` | オンライン対戦のゲームの定義とサーバーの入口 |
| `scripts/cpu-match.mjs` | CPU だけの試合と、怪物の数ごとの勝率 |
