# ブルゴーニュの城

ダイスで中央の盤からタイルを取り、自分の公国に置いて点を集めるボードゲーム「ブルゴーニュの城（The Castles of Burgundy、Stefan Feld、alea 2011）」の基本ゲーム（拡張なし）を、ブラウザで CPU と遊べるようにしたもの。2〜4人（あなた＋CPU 1〜3人）、公国の盤は全員1番。スマホの縦持ち向けで、中央の盤と自分の公国を切り替えて、スクロールなしで1画面に収まる。ホーム画面に置くと、オフラインでも遊べる。

タイルの絵とアイコンは、すべて SVG で自作している（公式の画像は使っていない）。説明の文も自分で書いたもので、公式の文は写していない。

## 遊び方

### 準備

- 各自：公国の盤（1番）、中央のマスに城1枚、銀貨1枚、商品3枚（42枚から5フェーズ分の25枚を除いた残りから）
- 最初の人はランダム。労働者は手番の順に1・2・3・4つ
- 六角形のタイルは、裏の色ごとの山から引く（白い裏は種類ごと、黒い裏は1つの山）

### フェーズとラウンド

- 5フェーズ（A〜E）×5ラウンド
- フェーズの初めに、残ったタイルを取り除き、区域（1〜6）のマスと黒の区域にタイルを並べる。区域の商品は残す
  - 区域のマスは、2人12・3人18・4人24。3人のときだけ、6番の区域の城のマスにフェーズ B・D は鉱山を置く
  - 黒の区域は、2人4枚・3人6枚・4人8枚
  - そのフェーズの商品5枚を表で並べる
- ラウンドの初めに全員がダイス2つを振り、最初の人は白のダイスも振る。白の目の区域に、そのラウンドの商品を置く

### 手番

ダイス1つで行動1つを2回（順は自由、同じ行動を2回でもよい）。

| 行動 | 内容 |
|---|---|
| 取る | 目と同じ番号の区域から1枚を保管場所（3マス）へ。いっぱいなら1枚捨ててから |
| 置く | 保管場所の1枚を、色が同じで、目と同じ数の空いたマスへ。置いたタイルのとなりだけ。同じ都市に同じ建物は置けない |
| 売る | 目と同じ色の商品をすべて売る。1枚につき2人2点・3人3点・4人4点と、銀貨1枚（何枚売っても1枚） |
| 労働者 | 目に関係なく労働者を2つ |

- 労働者1つで、ダイスの目を±1（6と1はつながる）。何個でも使える
- 手番に1回、いつでも、銀貨2枚で黒の区域から1枚買える

### タイル

| タイル | 効果 |
|---|---|
| 城 | すぐに、好きな目でもう1つ行動 |
| 鉱山 | フェーズの終わりごとに銀貨1枚 |
| 船 | 区域を1つ選んで商品をすべて取る（3種類まで。入らない分は残る）。手番の順が1つ前へ（同じ位置なら上に積む） |
| 家畜（牛・豚・羊・鶏） | 頭数の点。同じ牧草地の同じ家畜のタイルも、もう一度すべて数える |
| 知識（26種） | 下の表 |
| 建物（8種） | 置いたときに1回（ダイスは要らない） |

建物：倉庫（商品を1種類売る）、大工作業場（どれかの区域から建物を1枚取る）、教会（鉱山・知識・城を1枚取る）、市場（船か家畜を1枚取る）、下宿（労働者4つ）、銀行（銀貨2枚）、市庁舎（保管場所のタイルをもう1枚、目に関係なく置く）、見張り塔（4点）。

### 点と終わり

- 地域を埋めると、大きさの点（1・3・6・10・15・21・28・36）と、フェーズの点（A10・B8・C6・D4・E2）
- ある色のマスをすべて埋めると、1番目の人に大きいボーナス（2人5・3人6・4人7点）、2番目の人に小さいボーナス（2・3・4点）
- フェーズ E のあとで終わり。残った商品・銀貨1つにつき1点、労働者2つにつき1点、知識の点を足す。保管場所のタイルは数えない
- 同点なら、空いたマスの多い人、それも同じなら手番の順の後ろの人が上

### 資料と、資料で分からない点の決め方

読み比べた資料：

- [EN] 英語版ルールブック（alea / Ravensburger 2011）：https://www.world-of-board-games.com.sg/docs/Castles-of-Burgundy.pdf
- [DE] ドイツ語版の原本：https://www.brettspiele-report.de/images/d/die_burgen_von_burgund/Spielanleitung_Die_Burgen_von_Burgund.pdf
- 有志の実装のデータ：ultimate271/Castles（https://github.com/ultimate271/Castles 、区域のマス）、ness001/castles-of-burgundy（https://github.com/ness001/castles-of-burgundy 、盤・タイルの構成）、mangorine/Burgundy（https://github.com/mangorine/Burgundy 、盤1番の配置）、ProperNovice/BurgundyBoard（https://github.com/ProperNovice/BurgundyBoard 、タイルの画像）
- Board Game Arena の日本語版の用語：https://ja.boardgamearena.com/gamepanel?game=castlesofburgundy

確かめたこと：

- **盤1番の37マス**（色と目）は、ultimate271・ness001・mangorine の3つで全マスが一致した。色ごとのマス数（城4・鉱山3・知識6・建物12・牧草地6・船6）と、都市の大きさ（1・3・3・5）は [EN] の記述とも合う
- **区域のマスの色**（人数ごと）は ultimate271 と ness001 で一致し、白い裏のタイルの枚数（建物40・家畜20・知識20・城14・鉱山10・船20）は、4人で5フェーズ分を並べるとちょうど使い切る数で、整合する
- 家畜は1種類あたり白い裏が2・2・3・3・4頭、黒い裏が3・4頭。黒い裏の知識は 7・12・14・15・24・25（ProperNovice と ness001 で一致）
- 知識の 16〜23 の建物の割り当ては、17（見張り塔）と 22（銀行）が [EN]・[DE] の例で確定し、ほかはタイルの画像と ness001 で確かめた（ultimate271 の割り当ては違うが、推測とみられる）

資料で食い違う点と、どう決めたか：

| 点 | 食い違い | この版 |
|---|---|---|
| 黒の区域の枚数 | [EN] は「2〜8枚」、[DE] は「4〜8枚」 | 2人4・3人6・4人8枚（[DE] と有志の実装。[EN] は訳の誤りとみられる） |
| 同点 | [EN] は空いたマスが「少ない」人、[DE] と BGA は「多い」人 | **多い人**（[DE] の原本） |
| 知識6の買い物 | [EN] は手番に1回、[DE] はラウンドに1回 | 手番に1回（どちらでも、手番が1回なら同じ） |
| 知識5のとなり合う区域 | 6と1をとなりとするかは書かれていない | となりとする（ness001 と同じ） |
| フェーズ E の終わりの鉱山 | 「各フェーズの終わり」とあるだけ | E の終わりにも銀貨を受け取る |
| 黄のタイルの名前 | 2011年版は「知識」、20周年版は「修道院」 | 知識（BGA の日本語版と同じ）。絵柄は修道院の建物にした |

自分で決めた点：

- 手番の順は、ラウンドの初めに決める（ラウンドの途中で船を置いても、そのラウンドの順は変わらない。次のラウンドから効く）
- 船で取る商品が3種類を超えるとき、持っている種類と枚数の多い種類を先に取る（[EN] は「入らない分は残す」だけ）
- 効果（城の追加の行動・建物の効果・船の商品）は、次の操作の前に片づける。使えない効果は自動で飛ばし、「使わない」で飛ばすこともできる
- 手番は、ダイスを2つとも使ってから終える（労働者の行動はいつでもできるので、使い切れないことはない）
- 銀貨と労働者は尽きない（ルールブックどおり）

日本語の用語は BGA の日本語版を参考にした（城・鉱山・知識・船・家畜・建物、倉庫・大工作業場・教会・市場・下宿・銀行・市庁舎・見張り塔）。日本語版の出版物での呼び方は確かめられなかった。銀は、分かりやすさのため「銀貨」とした。

### 画面の操作

- 上の「中央の盤」「公国」で、見る盤を切り替える
- 区域のタイルを押すと取る。使えるダイスのうち、労働者が一番少なくて済むものを使う（要る労働者の数は、タイルの左上の赤い丸）。先に下のダイスを押せば、そのダイスに決める
- 保管場所のタイルを押すと公国の画面になり、置けるマスが光る。マスを押すと置く
- 下の商品を押すと売る。「労働者」はダイスを選んでから押す（使っていないダイスが1つならそれを使う）
- 「買う」を押すと、黒の区域のタイルが光る。保管場所がいっぱいなら、捨てるタイルを選ぶ画面が出る
- 城・建物・船の効果は、上の帯に案内が出る。船は、光った区域を押す
- ダイスを使い切って買い物もできなければ、少し待って自動で手番を終える
- 上のプレイヤーの欄を押すと、その人の公国・保管場所・知識が見られる
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

## CPU

強さは「ふつう」と「やさしい」。CPU は自分の席のビュー（公開の情報だけ）を見て、今できる操作を列挙し、見積もりの一番高いものを選ぶ。タイルの山の並びや、先のフェーズの商品はのぞかない。CPU の判断にはゲームの乱数を使わない（記録の再現がずれないように）（`public/js/cpu-player.js`）。

**ふつう**

- 置く：すぐ入る点（地域を埋めた点・色のボーナス・家畜・見張り塔）と、タイルの値打ちと、地域の埋まり具合から、労働者の費用を引く
- 取る・買う：今置けるマスがあるタイルを高く見る（置ける場所がまだないタイルは半分、その色が埋まっていれば0）。保管場所がいっぱいなら、値打ちの一番低いタイルを捨てる
- タイルの値打ち：城（追加の行動）、鉱山（残りのフェーズの銀貨）、知識（番号ごと。終わりの点のものは高く）、建物（効果ごと）、家畜（頭数）、船（取れる商品）
- 売る：商品の点と銀貨。1枚だけの商品は、最後のフェーズまで売り急がない
- 労働者：ほかに見積もりの高い手がないとき。労働者が少ないときは高く見る
- 買う：見積もりがプラスのときだけ

**やさしい**：同じ見積もりに大きな迷いを足し、労働者を2つ以上使う手は選ばない。買い物はほとんどしない。

```bash
# 試合数・人数・席ごとの強さ（easy・normal）。最初の人は試合ごとに入れ替える
node scripts/cpu-match.mjs 500 2 easy,normal
```

| 対戦 | 試合数 | ふつうの勝率 | やさしいの勝率 | 平均の得点 |
|---|---|---|---|---|
| 2人（やさしい・ふつう） | 500 | 80.0% | 20.0% | ふつう 146・やさしい 123 |
| 2人（ふつう・やさしい） | 500 | 85.2% | 14.8% | ふつう 148・やさしい 122 |
| 2人（ふつう・ふつう） | 500 | 47.6%・52.4% | — | 140 |
| 3人（やさしい・ふつう・やさしい） | 300 | 66.0% | 21.0%・13.0% | ふつう 160・やさしい 136 |
| 4人（やさしいとふつうを交互） | 300 | 41.3%・45.0% | 7.7%・6.0% | ふつう 166・やさしい 143 |

どの組み合わせでも、止まった試合はない。公国は平均 26〜27 マス埋まる。

npm install

テスト（`test/`）：

- `game.test.js`：盤とタイルの数、区域のマス（人数・3人の例外）、準備、取る（労働者・6と1・いっぱいのとき）、置く（色・目・となり・地域の点・同じ建物）、色のボーナス、売る（人数ごとの点・知識3と4）、労働者（知識13と14）、知識8〜12の目の変更、買う（知識6）、手番とラウンド、城・家畜（知識7）・船（知識5）・手番の順・建物、使えない効果を飛ばす、フェーズの終わり（鉱山・知識2）、終わりの点（知識15〜26）、同点、断る操作で状態が変わらないこと
- `replay.test.js`：記録からの再現（2〜4人）、記録する項目、CPU の判断がゲームの乱数を使わないこと、ランダムな操作を浴びせても断った操作で状態が変わらず再現できること
- `cpu-player.test.js`：CPU どうしの試合が人数・強さ・シードを変えても止まらないこと、ふつうがやさしいに勝ち越すこと、山の並びを変えても同じ手を選ぶこと（のぞかない）、点になる置き方を選ぶこと

- `game-controller.test.js`：CPU との対戦の進行、断られた操作の知らせ、保存からの再開
- `pwa.test.js`：service worker が画面のファイルを全部先に読むこと、manifest とアイコン

### オンライン対戦を入れるとき

netplay-kit の `scripts/sync.mjs` で部屋の処理を写し、`server/src/game-definition.js` を `createHandler` と `startDevServer` に渡す。部屋には参加者・シード・操作の記録だけを保存し、操作のたびに記録から再現する。ダイスはシードから決まる乱数で振る。隠すのはビュー（`createGameView`）の役目で、このゲームでは手元の情報（保管場所・商品・銀貨・労働者・ダイス）は公開なので、隠すのはタイルの山の並びと先のフェーズの商品だけ。
