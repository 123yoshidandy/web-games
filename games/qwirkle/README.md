# クワークル

同じ色か同じ形のタイルを並べて列を作り、得点を競うタイルゲーム「クワークル（Qwirkle、Susan McKinley Ross、MindWare 2006）」の基本ゲームを、ブラウザで遊べるようにしたもの。CPU と2〜4人で遊ぶ。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

タイルの絵（6つの形）とアイコンは、すべて SVG で自作している。説明の文も自分で書いたもので、公式の文や画像は使っていない。

## 遊び方（基本ゲーム）

- タイルは108枚（6色×6形×3枚）。各自6枚ずつ引く
- 同じ色か同じ形で重複のない組を、一番多く持つ人から始める。その組を全部置いて始める
- 手番では、タイルを置くか、交換する
  - 置く：同じ色か同じ形で、重複のないタイルを1枚以上。全部を1本の線の上に置き（互いに触れていなくてよいが、すでにあるタイルをはさんで1本の列につながる）、すでにあるタイルに接するように
  - 列は「同じ色で形が全部違う」か「同じ形で色が全部違う」タイルだけ。6枚まで
  - 置いたら6枚まで引く
  - 交換：好きな枚数を脇に置き、同じ枚数を引いてから、脇のタイルを袋に戻す。袋の枚数までしか交換できない。その手番は置けない
- 得点：できた列・伸ばした列ごとに、その列の枚数（縦と横の両方の列に入るタイルは、両方で数える）。6枚の列（クワークル）は +6点
- 袋が空になったあと、最初に手札を出し切った人が +6点で、そこで終わる。一番得点の多い人の勝ち

### 画面の操作

- 手札を押してから、光ったマスを押すと置ける。手札から盤へ指で引っぱってもよい（タイルは指の少し上に出る）
- 置いたタイルを押すと手札に戻る。「戻す」で全部戻す。「決定」に、その置き方の得点が出る
- 「交換」を押してから、交換するタイルを選び、「〜枚を交換」
- 盤は広がっていくので、タイルと置けるマスが全部入るよう、自動で縮尺を合わせる
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

### 資料と、資料で分からない点の決め方

ルールは、MindWare の公式ルール（2023年の色覚に配慮した版。[Qwirkle Color Blind Friendly Rules](https://lot.ahml.info/QwirkleCB.pdf)）で確かめた。依頼で示されたルールとの食い違いはなかった。

- **最初の手番：** 公式は「一番大きな組を持つ人が、その組を置いて始める。同じ数なら年上の人」。年齢は分からないので、同じ数なら席の順（あなたが先）にした。最初の手番は、その組の枚数をちょうど置く（交換はできない）
- **置いたタイルどうしの間：** 公式は「1本の線の上に置く。互いに触れていなくてよい（列の両端に置くなど）」。間を、すでにあるタイルがつないで1本の列になる置き方だけを認める（間が空いたままの置き方は認めない）
- **何もない盤に1枚だけ置いたとき：** 公式は列（2枚以上）ごとに数えるので書いていない。1点にした
- **置けず、交換もできない（袋が空）とき：** 公式は書いていない。パスにした。全員が続けてパスしたら終わる（そのときは、手札を出し切った人の +6 はない）
- **同点：** 公式は「勝った人どうしで祝い、また遊ぶ約束をする」。全員を勝ちとして表示する

## CPU

強さは「やさしい」と「ふつう」（`public/js/cpu-player.js`）。CPU は盤・自分の手札・袋の枚数だけを見る（ほかの人の手札と袋の中身はのぞかない）。

- 置ける手を全部挙げる（`board.js` の `generateMoves`：1枚目を置ける場所から、同じ線の上で列の端へ1枚ずつ伸ばす）
- ふつう：「得点 − 相手にクワークルを作らせる危うさ ＋ 残る手札の良さ」が一番高い手を打つ
  - 危うさ：置いたあとに5枚の列（あと1枚でクワークル）が残るなら、相手がその1枚を持っている見込み（足りない種類のまだ見えていない枚数 × 相手の手札の枚数 ÷ 見えていないタイルの数）× 12点を引く。4枚の列は軽く引く。自分がその1枚を持っていれば少し足す
  - 残る手札：同じ種類の重複は減点、色か形の合う組は加点
  - よい手がなく、要らないタイル（重複・ほかと組めないもの）が3枚以上なら交換する
- やさしい：得点に大きなゆらぎ（0〜12点）を足して選ぶ。守りは考えない。置けないときだけ交換する
- ゲームの乱数は使わない。ゆらぎは状態から作った別の乱数で、同じ状態なら同じ手を打つ（記録の再現がずれない）

```bash
# 試合数・人数・強さ（normal・easy・mixed）。mixed は席ごとに強さを交互に変えて比べる
node scripts/cpu-match.mjs 200 2 mixed
```

| 対戦（各200試合） | ふつう | やさしい |
|---|---|---|
| 2人（ふつう対やさしい）の勝ち | 175勝 | 27勝 |
| 2人の平均点 | 200.2点 | 175.1点 |
| 3人（ふつう・やさしいを交互）の勝ち（席あたり） | 141/300 | 62/300 |
| 4人（ふつう2・やさしい2）の勝ち（席あたり） | 144/400 | 63/400 |

ふつうは、得点だけで選ぶ CPU にも勝ち越す（2人400試合で 219勝 176敗）。守りの減点を「5枚の列を残したら必ず −9点」のように強くすると、高得点の手を捨てて、かえって負け越した（87勝 109敗）。
下の操作の列の電球（ヒント）を押すと、ふつうの CPU が選ぶ手を、そのまま選んだ状態にする（置く手は仮置き、交換は交換するタイルを選ぶ）。「決定」を押せば打てる。電球の左のボタンで、履歴を見られる。

## 開発

```bash
npm install
# 画面（http://localhost:8000/ を開くと public/ へ移る）
python3 -m http.server 8000
# テスト（Vitest）
npm test
```

| ファイル | 中身 |
|---|---|
| `public/js/board.js` | タイルと盤の決まり（列の判定・置き方の判定と得点・置ける手の列挙） |
| `public/js/game.js` | 進行（DOM に依存しない）。操作は `applyCommand` だけで受け、記録から `Game.replay` で再現できる |
| `public/js/game-view.js` | 画面と CPU に渡すビュー（自分の手札だけ。ほかの人の手札と袋は枚数だけ） |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | 人間1人と CPU のローカル対戦（途中経過の保存） |
| `public/js/ui.js`・`art.js`・`help.js` | 画面・タイルの絵・遊び方 |
| `public/sw.js`・`manifest.webmanifest` | PWA（オフラインでも開ける） |
| `server/src/game-definition.js` | オンライン対戦用のゲームの定義（netplay-kit の形。まだつないでいない） |
| `scripts/cpu-match.mjs` | CPU 同士の対戦と平均点・勝ち数 |

### オンライン対戦を入れるとき

netplay-kit の `scripts/sync.mjs` で部屋の処理を写し、`server/src/game-definition.js` を `createHandler` と `startDevServer` に渡す。部屋には参加者・シード・操作の記録だけを保存し、操作のたびに記録から再現する。各人のビューには自分の手札だけを入れ、ほかの人の手札と袋は枚数だけ（観戦者には誰の手札も見せない）。抜けた人の席は CPU（ふつう）が続ける。
