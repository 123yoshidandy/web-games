# ノー・サンキュー

失点になるカードを、チップを払って押し付け合うカードゲーム「ノー・サンキュー（No Thanks!）」を、ブラウザで CPU と遊べるようにしたもの。3〜7人（あなた＋CPU 2〜6人）。スマホの縦持ち向け（横にすると2列に組み替える）。ホーム画面に置くと、オフラインでも遊べる。

絵（カード・チップ・アイコン）は、すべて SVG で自作している。

## 遊び方

- カードは3〜35の33枚。切って9枚を伏せて除き、残りの24枚を使う
- チップは、3〜5人なら11枚、6人なら9枚、7人なら7枚ずつ。持っているチップの数は、ほかの人には伏せる
- めくられたカードを見て、手番の人はどちらかを選ぶ
  - ノーサンキュー：チップを1枚カードに置き、次の人の番へ
  - 取る：カードと、上のチップを全部もらう。次のカードがめくられ、同じ人がまた選ぶ
- チップがなければ、取るしかない
- 最後のカードが取られたら終わり。カードの数の合計からチップの数を引いたものが得点（失点）。連続した数は、その中で一番小さい数だけを数える
- 得点が一番少ない人の勝ち。同点なら、その全員で勝ちを分け合う

ルールは Amigo の公式ルールブック（英語版）に合わせた。

### ルールブックに書かれていないので決めたこと

- 最初の手番（ルールでは「最後に No thanks! と言った人」）は、ランダムに決める
- 終わったら、除かれていた9枚と全員のチップの数を見せる

### 画面

- 相手の欄には、取ったカード（連続した数は「13–16」のように1つの札にまとめる）と、カードの失点を出す。チップの数は伏せる
- 自分の欄には、チップの数と、今の得点（カードの失点 − チップ）を出す
- 場のカードの下に「取ると +17」のように、取ったら自分の得点がいくつ動くかを出す。自分の札につながるときは「つながる」と出し、だれかの札につながるときは、その札を光らせる
- チップがないときは、少し間を置いて自動で取る
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

自分から見える情報だけ（ほかの人のチップの数、山札の並び、除いた9枚は見ない）で選ぶ。取ったときの実質の失点（増える失点 − 上のチップ）が、がまんできる値以下なら取る。がまんできる値は、手元のチップが少ないほど上がる。

| 強さ | 中身 |
|---|---|
| やさしい | チップの残りをあまり気にせず早めに取る。揺れと誤りが大きい |
| ふつう | 自分にだけつながるカードは回してチップを集め、ほかの人につながるカードは早めに取る。揺れと、ときどきの誤りを混ぜる |

CPU 同士の対戦（各 1000 試合）：

| 対戦 | 勝率 | 公平なら |
|---|---|---|
| 3人：ふつう1 対 やさしい2 | ふつう 49.1% | 33.3% |
| 4人：ふつう1 対 やさしい3 | ふつう 40.6% | 25% |
| 7人：ふつう1 対 やさしい6 | ふつう 23.8% | 14.3% |
| 4人：比較用の揺れのない CPU 1 対 ふつう3 | 比較用 27.1% | 25% |

揺れのない比較用の CPU とふつうの差が小さいので、ふつうは「読みは素直で、強すぎない」位置にある。

```bash
# 試合数・人数・席ごとの強さ（easy・normal・strong は揺れのない比較用・random はでたらめ）
node scripts/cpu-match.mjs 1000 4 normal,easy,easy,easy
```

上の帯の電球（ヒント）を押すと、いちばん強い CPU が選ぶ手（ノーサンキューか取るか）のボタンを光らせる。CPU と同じく、自分のビューだけで決める。

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。3〜7人で、足りない席は CPU で埋められる。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'no-thanks' })`。web-games の1つのスタックから `?game=no-thanks` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm install
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/game.js` | ルール。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー（ほかの人のチップは伏せる） |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js` | 画面。届いたイベント（いらない・取る・めくる）を動きで見せる |
| `public/js/art.js`・`animator.js` | 絵と動き |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |
| `server/src/handler.js`・`public/js/online-config.js`・`public/js/netplay/` | オンライン対戦のサーバーの入口・接続先・netplay-kit の写し |
