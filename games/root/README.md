# ルート

4つの陣営が森の覇権を争う非対称のボードゲーム「ルート（Root）」の基本セットを、ブラウザで CPU と遊べるようにしたもの。2〜4人（あなた＋CPU 1〜3人）。スマホの縦持ち向け（PC でも遊べる）。地図は2本指・ホイール・＋−のボタンで拡大し、ドラッグで動かせる。ホーム画面に置くと、オフラインでも遊べる。

絵（地図・カード・紋・アイコン）は、すべて SVG と CSS で自作している。

## 遊び方

- 陣営は、侯爵家（ネコ）・鷲の王朝・森林連合・放浪者から選ぶ。相手は、この順で自分の陣営を除いた陣営になる（CPU 1人なら侯爵家か鷲の王朝が相手）
- 先に 30 点を取った陣営の勝ち。10 点以上なら支配のカードを出して、支配での勝ちを目指すこともできる
- 手番は 鳥の歌 → 昼 → 夕方。夕方にカードを引き、手札は5枚まで
- 操作は、下の行動のボタンか、光っている空き地・カードを押して選ぶ。上の得点を押すと、その陣営の盤（布告・支持者・アイテムなど）を見られる
- 途中でホームに戻っても、「続きから」で再開できる

ルールは基本セットの Law of Root に合わせた。秋の地図（空き地12・道18・建物の枠22・遺跡4・森7）、支配と移動、戦闘（4面のサイコロ2つ。攻撃側が大きい目、守り手が小さい目、守り手に兵がいなければ追加の1打撃、待ち伏せ）、建物とトークンを除いたときの得点、工作（工作の駒の印）とアイテム、持続効果のカード、支配のカード、各陣営の固有のルールを入れている。

| 陣営 | 入れたルール |
|---|---|
| 侯爵家 | 本拠・初めの兵と建物、製材所の木材、工房での工作、3回の行動（戦闘・行軍・徴兵・建設・残業）と鳥のカードでの追加、つながった支配地からの木材の支払い、建物の費用と得点、徴兵所での引く枚数、野戦病院 |
| 鷲の王朝 | 4人の指導者と宰相、布告（1〜2枚・鳥は1枚まで）、緊急の命令、新しい止まり木、布告の実行（印の合う空き地で全部）、混乱（失点・布告を捨てる・指導者の交代）、森の領主（同数でも支配）、工作のアイテムは1点（建築家を除く）、止まり木での得点と引く枚数 |
| 森林連合 | 支持者（拠点がなければ5枚まで）、同調を広める費用（兵3体以上で＋1）と得点、暴動、拠点を失ったときの支持者と官吏、動員・訓練、官吏の数の作戦（移動・戦闘・徴兵・組織）、憤激、ゲリラ戦 |
| 放浪者 | 3人のキャラクター（盗賊・修理屋・狩人）と特技、アイテムの使用済み・傷み、回復（3＋お茶）、抜け出す、移動（敵対の兵がいればブーツ2つ）、戦闘（剣の数まで）、探索、援助と関係（無関心→好意→友好→同盟）、クエスト、狙撃、修理、工作、敵対と悪名、森での修理、持てる数、連合（支配のカード） |

### 割り切った点・自分で解釈した点

- **山札の54枚とクエストの15枚は、記憶から組んだ。** カード名・枚数・費用・効果は、公式の一覧と突き合わせられていない（カードの一覧のページが画像だけだった）。地図は、公開されている地図の画像から空き地のつながりを読み取り、数（枠22・遺跡4・森7・川沿い5）が一致することを確かめた
- 鷲の王朝の止まり木で引く枚数が増える位置（3つ目・6つ目）と、放浪者の関係を上げるのに要る援助の数（1・2・2）は、確かめられていない
- 自動で選ぶもの：打撃で除く建物・トークンの順（トークンから）、放浪者が傷めるアイテム、憤激で渡すカード、建設で払う木材、放浪者が回復させるアイテムと援助で使うアイテム・受け取るアイテム、持ちきれないアイテム
- 武具師・工兵・非情な戦術は、効くときに自動で使う
- 放浪者の「同盟の兵を連れて動く・一緒に戦う」は入れていない
- 打撃で放浪者は「守りのない」扱いにしない（駒は兵の代わりとして戦う）
- 2人のとき、放浪者は支配のカードを出せない（連合の相手がいないため）
- 安全弁として、40 巡で終わらなければ得点の一番多い陣営の勝ちにする（CPU の試合でもほぼ起きない）
- 準備の順は 侯爵家 → 鷲の王朝 → 森林連合 → 放浪者。最初の手番はシードで決める

## CPU

取れる操作の一覧（`legalActions`）の中から、陣営ごとの方針で点数を付けて選ぶ。ルールを守るのは一覧が保証する。ほかの人の手札・山札・遺跡の中身は見ない。

| 陣営 | 方針 |
|---|---|
| 侯爵家 | 工作は行動の前に済ませ、徴兵と建設を優先し、支配する空き地を広げる。点にならない戦闘（兵だけが相手）はしない |
| 鷲の王朝 | 布告は、今の盤面で果たせそうな列にだけ足す（2枚目は余裕があるときだけ）。止まり木を増やす。指導者は暴君を好む |
| 森林連合 | 同調者を広げ、支持者がそろえば暴動。官吏を育てて、夕方に組織する。手札は工作と待ち伏せのために残し、多すぎる分だけ支持者に回す |
| 放浪者 | 遺跡の探索・クエスト・援助を目当てに動き、守りのない建物を攻める |

強さは「やさしい」と「ふつう」。やさしいは、手の点数に大きめの揺れ（0〜3）を足して、ときどき甘い手を選ぶ（ふつうは 0〜0.05）。強さはゲームの options.level に入り、記録の再現でも同じになる。ふつう1人とやさしい3人の 40 試合で、ふつうの勝ちは 37.5%（全員ふつうでは 25%）。

プレイ中の電球のボタン（ヒント）は、ふつうの CPU と同じ判断で、人のおすすめの手を出す（操作のボタン・地図の空き地・手札に印を付ける。記録には入れない）。

ほかの陣営に共通して：

- 得点の首位の陣営の建物・トークンを、崩す値打ちを高くみる
- 同調者のある空き地には、憤激でカードを渡すことになるので、目的なく入らない
- 森林連合が勝ちに近い（得点がほかの最高に迫る、または同調者が4つ以上）ときは、勝てる数で同調者と拠点の空き地に入り、戦って崩す

CPU 同士の対戦（各 100 試合、席の順と最初の手番はシードで変わる）：

| 対戦 | 侯爵家 | 鷲の王朝 | 森林連合 | 放浪者 | 平均の巡 |
|---|---|---|---|---|---|
| 4人 | 19% | 22% | 35% | 24% | 7.7 |
| 侯爵家・鷲・連合 | 30% | 28% | 42% | — | 8.2 |
| 侯爵家・鷲・放浪者 | 47% | 29% | — | 24% | 8.0 |
| 侯爵家・連合・放浪者 | 93% | — | 2% | 5% | 6.0 |
| 鷲・連合・放浪者 | — | 37% | 57% | 6% | 8.1 |
| 侯爵家・鷲 | 35% | 65% | — | — | 9.4 |
| 侯爵家・連合 | 98% | — | 2% | — | 6.5 |
| 侯爵家・放浪者 | 89% | — | — | 11% | 6.4 |
| 鷲・連合 | — | 58% | 42% | — | 8.4 |
| 鷲・放浪者 | — | 83% | — | 17% | 8.9 |
| 連合・放浪者 | — | — | 67% | 33% | 10.9 |

4人では、どの陣営も 19〜35% に収まる。侯爵家がいて鷲の王朝がいない組み合わせでは、侯爵家が地図の多くを支配して、支配のカードか30点で勝つことが多い（89〜98%）。どの組み合わせでも、すべての試合が最後まで終わる。

```bash
# 試合数・陣営（2〜4つ）
node scripts/cpu-match.mjs 100 marquise,eyrie,alliance,vagabond
```

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜4人で、席の順に勢力が決まり、足りない席は CPU で埋められる。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'root' })`。web-games の1つのスタックから `?game=root` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest。web-games の直下で）
npm test -w games/root
```

| ファイル | 役割 |
|---|---|
| `public/js/data.js` | 秋の地図・共有の山札・陣営・クエストのデータ |
| `public/js/game.js` | ルール。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる。取れる操作は `legalActions` |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー（ほかの人の手札・連合の支持者・遺跡の中身は伏せる） |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js` | 画面。取れる操作の一覧を、操作ごとの順（移動なら移動元→移動先→数）で絞り込んで選ばせる |
| `public/js/board-view.js` | 地図の描画と、拡大・移動・タップ |
| `public/js/art.js` | 色・カード・紋 |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義。陣営は参加の順に割り当てる |
| `server/src/handler.js`・`public/js/online-config.js`・`public/js/netplay/` | オンライン対戦のサーバーの入口・接続先・netplay-kit の写し |
