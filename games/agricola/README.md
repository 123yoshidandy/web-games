# アグリコラ（ファミリー版）

家族を増やし、畑と牧場と家を育てる農場づくりのボードゲーム「アグリコラ（Agricola、Uwe Rosenberg、Lookout Games 2007）」を、ルールブックの「ファミリー版」（職業カードと小さい進歩カードを使わない形）で、ブラウザで CPU と遊べるようにしたもの。1〜4人（あなた＋CPU 0〜3人）。スマホの縦持ち向けで、スクロールなしで1画面に収まる。ホーム画面に置くと、オフラインでも遊べる。

絵とアイコンは、すべて SVG で自作している（公式の画像は使っていない）。説明の文も自分で書いたもので、公式の文は写していない。

## 遊び方（ファミリー版）

- 各自、家族2人・木の家2部屋で始める。食料はスタートプレイヤー2、ほかは3（1人なら0）
- 14ラウンド。ラウンドごとにラウンドカードが1枚めくられ、その行動が加わる（段階の中の順はシャッフル）
- スタートプレイヤーから順に、家族を1人ずつ空いている行動スペースに置き、すぐにその行動をする。1つの行動スペースは1ラウンドに1人だけ。全員が置き終えたら家族は家に戻る
- スタートプレイヤーは「スタート」の行動で替わる（次のラウンドから）
- 4・7・9・11・13・14ラウンドのあとに収穫
  1. 畑：種をまいた畑から1つずつ取る
  2. 食事：家族1人に食料2（そのラウンドに生まれた家族は1、1人用は大人1人に3）。足りなければ足りない食料1つにつき物乞いカード1枚
  3. 繁殖：2頭以上いる種類に1頭（入る場所があれば）
- 14ラウンドの収穫のあとで終わり

### 行動スペース

| | 行動 |
|---|---|
| ボード（ファミリー版の面） | 増築（部屋と厩）・スタート・穀物1・畑を耕す・貯蔵庫（食料がたまる）・日雇い（食料1と建築資材1）・森（木3）・レンガ（1）・葦（1）・漁（食料1） |
| 3人の行動カード | 林（木2）・土取り場（レンガ1）・石1 |
| 4人の行動カード | 雑木林（木1）・林（木2）・土取り場（レンガ2）・市場（葦1・石1・食料1）・旅芸人（食料1） |
| ラウンド1〜4 | 羊・種まきとパン・大きな進歩・柵 |
| ラウンド5〜7 | 家族を増やす・石・改築と大きな進歩 |
| ラウンド8〜9 | 野菜・猪 |
| ラウンド10〜11 | 牛・石 |
| ラウンド12〜13 | 耕すと種まき・急な家族（部屋がなくてもよい） |
| ラウンド14 | 改築と柵 |

数のある行動（森・羊など）は、だれも取らなければ毎ラウンドたまる。

### 農場

- 3段×5列の15マス。最初の部屋は左の列の下2マス
- 部屋：木の家は木5・葦2（レンガの家はレンガ5・葦2、石の家は石5・葦2）。今の部屋のとなりに
- 改築：木の家 → レンガの家（部屋の数のレンガと葦1）→ 石の家（部屋の数の石と葦1）。1回に1段だけ
- 家族を増やす：部屋が家族より多いときだけ（急な家族は部屋がなくてよい）。5人まで。生まれた家族は次のラウンドから動く
- 畑：空いたマスに。2つ目からは今の畑のとなり。種まきで、穀物1が穀物3に、野菜1が野菜2になる
- 柵：1本に木1、15本まで。部屋と畑は囲えない。今の牧場を、柵を足して分けられる
- 厩：木2で4つまで。柵のない厩に動物1頭、牧場の中の厩は、その牧場に入る数を倍にする
- 動物：牧場1マスに同じ種類2頭、家に1頭（ペット）。入りきらない動物は、調理の進歩があれば食料に、なければ逃がす

| 調理場（2枚） | レンガ4／5、またはかまどを返す | 1 | 調理：野菜3・羊2・猪3・牛4、パン1つ食料3 |
| レンガ暖炉 | レンガ3・石1 | 2 | パン：1回に穀物1つまで、食料5。建てたときにすぐ焼ける |
| 石の暖炉 | レンガ1・石3 | 3 | パン：1回に穀物2つまで、1つ食料4。建てたときにすぐ焼ける |
| 家具製作所 | 木2・石2 | 2 | 収穫に木1→食料2（1回）。終わりに木3/5/7で1/2/3点 |
| 製陶所 | レンガ2・石2 | 2 | 収穫にレンガ1→食料2（1回）。終わりにレンガ3/5/7で1/2/3点 |
| かご製作所 | 葦2・石2 | 2 | 収穫に葦1→食料3（1回）。終わりに葦2/4/5で1/2/3点 |

### 資料と、資料で分からない点の決め方

ルールは、元の版のルールブック（英語版とドイツ語版）と、Order of Gamers の要約（得点表・1人用）を読んで合わせた。

ファミリー版について資料で確かめたこと：

- 職業カードと小さい進歩カードを使わない。最初のボードを「ファミリー版」の面にし、3〜5人ではファミリー版の行動カードを使う。「大きな進歩か小さい進歩」の行動は、大きな進歩だけになる
- 日雇い労働者は、通常は食料2、ファミリー版は食料1と建築資材1（英語版の付録・ドイツ語版の本文）
- ファミリー版では「貯蔵庫（Lagerhaus）」に毎ラウンド食料1がたまる（ドイツ語版の本文）
- 2つ目からの牧場は、今の牧場のとなりに作る（ドイツ語版の本文）
- 1人用：食料0で始め、大人1人に食料3、森は毎ラウンド木2

資料で確かめられなかったことと、決めたこと：

- **ファミリー版の面の行動スペースの並び**：本文から分かるのは、日雇い労働者と貯蔵庫の違いだけ。通常の面の「職業」のスペースが貯蔵庫に替わり、「スタートプレイヤーと小さい進歩」は「スタート」だけになる、と決めた
- **3〜4人のファミリー版の行動カードの中身**：通常の面のカードの一覧（Lookout のカードの一覧）から、職業のカードを除いたものにした（3人：林・土取り場・石1、4人：雑木林・林・土取り場・市場・旅芸人）。そのため3人では、行動カードに食料の場所がない
- **5人**：入れていない（1〜4人）
- 換算（穀物・野菜・動物・作業場を食料に）は、収穫の食事と、動物が入りきらないときだけ行う（食料は、ほかに使い道がないため）
- 入りきらない動物は、残す数を選ぶ。残さない動物は、調理の進歩があれば自動で食料にする（なければ逃がす）
- 繁殖で全部の赤ちゃんが入らないときは、牛・猪・羊の順に入れる
- 食事で、食料が足りていて作業場も使えないときは自動で払う。足りなくて換算できるものもないときは、自動で物乞いカード
- 柵は、囲うマス（牧場）を選んで建てる。柵の本数は、牧場の境界から数える。牧場の中のマスだけを選ぶと、その牧場を分ける。部屋や畑を囲んだり、囲いの中の空きマスを残したりする形は作れない
- 行動スペースは、何かできるときだけ置ける（例：柵は、1マスの牧場を1つでも建てられるとき）
- 最初のスタートプレイヤーはランダム
- 道具の数（柵15本・厩4つ・家族5人）のほかは、資源・食料・動物の数に上限はない
- 大きな進歩と行動の名前は、日本語版で使われている呼び方に近づけたが、確かめてはいない（短い名前は画面のために自分で付けた）

### 画面の操作

- 光っている行動スペースを押して選ぶ。数をとる行動は、もう一度押すか「置く」で置く
- 日雇いは、下に出る資源（木・レンガ・葦・石）から選ぶ
- 耕す・増築・種まき・柵は、自分の農場のマスを押して選び、「決める」で決める
  - 増築：上の「部屋／厩」で建てるものを切り替える。費用は下に出る
  - 種まき：空いた畑を押すたびに、穀物 → 野菜 → なしと替わる。パンを焼けるなら、穀物の数を −／＋ で決める
  - 柵：囲うマスを選ぶと、建てる柵が点線で出る。「牧場に」で、もう1つ牧場を足せる
- 大きな進歩は、ダイアログの一覧から買う。調理場は「かまどと交換」でも買える。暖炉を建てたときは、続けてパンにする穀物の数を決める
- 入りきらない動物と収穫の食事は、ダイアログで決める（初めの数は、CPU と同じ考え方で入れてある）。ダイアログを閉じると盤面を見られ、下の「選ぶ」で開き直す
- 上の人の欄と自分の欄を押すと、その人の農場と、いま終わったときの点が見られる
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

## CPU

強さは「ふつう」と「やさしい」。CPU は、その席のビュー（`createGameView`）だけを受け取って決める（`chooseCommand(view, level)`）。ゲームの中はのぞかず、ゲームの乱数も使わない。農場の計算は、ゲームと同じ `farm.js`・`cooking.js` の関数を使う（`public/js/cpu-player.js`）。

- ふつう：置ける行動スペースごとに「得られるものの見込みの価値（点に換算）」を見積もり、一番高いものを選ぶ
  - 次の収穫の食事に足りないほど、食料・穀物と、かまど・調理場を高く見る。家族を増やすのは、増えた分の食事を見込めるとき
  - 空いた畑があれば、穀物・野菜を取って種をまく。畑は5つ、牧場は4つまでを目安にする
  - 終わりが近いほど、改築と、得点表の −1 を消すもの（穀物・野菜・動物）を高く見る
  - 入りきらない動物は、各種類を残しつつ入るだけ残す。食事は、作業場 → 余った野菜・動物（繁殖のため2頭は残す）→ 穀物の順に換算する
- やさしい：見積もりに大きな迷いを足し、どのマスにするかは最初に見つかったものにする

```bash
# 試合数・強さの並び（easy・normal）。席の並びは試合ごとに1つずつずらす
node scripts/cpu-match.mjs 1000 easy,normal
```

| 対戦 | 試合数 | ふつうの勝率 | やさしいの勝率 | 平均点（ふつう／やさしい） |
|---|---|---|---|---|
| 2人（やさしい・ふつう） | 1000 | 76.6% | 23.4% | 29.7／22.4 |
| 3人（やさしい・ふつう・やさしい） | 1000 | 61.7% | 19.9%・18.4% | 21.8／14.2 |
| 4人（やさしい・ふつう・やさしい・ふつう） | 1000 | 39.8%・43.1% | 8.3%・8.8% | 19.3／11.2 |
| 2人（ふつう・ふつう） | 1000 | 51.1%・48.9% | — | 27.8 |
| 3人（ふつう3人） | 1000 | 34.5%・35.5%・29.9% | — | 17.2 |
| 4人（ふつう4人） | 1000 | 25.9%・24.6%・25.6%・23.9% | — | 16.7 |
| 1人 | 1000 | — | — | 31.6／29.6 |

同点で複数が勝った試合は、勝ちを等分して数えた。どの組み合わせでも、止まった試合はない。3人は行動カードに食料の場所がないため、物乞いカードが多めになる（ふつうで1人あたり約1枚）。

### オンライン対戦を入れるとき

netplay-kit の `scripts/sync.mjs` で部屋の処理を写し、`server/src/game-definition.js` を `createHandler` と `startDevServer` に渡す。部屋には参加者・シード・操作の記録だけを保存し、操作のたびに記録から再現する。収穫の食事では、操作を待っている人（`game.actors()`）が何人もいる。端末から届いた操作は `sanitize` で種類ごとの項目だけを取り出してから `applyCommand` に渡す。
