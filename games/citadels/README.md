# あやつり人形

役割を選んで手番を行い、地区を建てて都市を育てるカードゲーム「あやつり人形（Citadels、Bruno Faidutti、2000）」を、ブラウザで CPU と遊べるようにしたもの。基本の8役（暗殺者・盗賊・奇術師・王様・司教・商人・建築家・将軍）と、基本の地区カード66枚の構成。2〜7人（あなた＋CPU 1〜6人）。スマホの縦持ち向けで、スクロールなしで1画面に収まる。ホーム画面に置くと、オフラインでも遊べる。

役割と地区の絵、アイコンは、すべて SVG で自作している（公式の画像は使っていない）。説明の文も自分で書いたもので、公式の文は写していない。

## 遊び方

### 準備

- 各自2金と地区カード4枚。最初の王冠はランダムな1人
- 地区カードは66枚：黄（貴族）12・青（宗教）11・緑（商業）20・赤（軍事）11・紫（特殊）12

| 色 | 地区（費用×枚数） |
|---|---|
| 黄 | 屋敷 3×5、城 4×4、宮殿 5×3 |
| 青 | 寺院 1×3、教会 2×3、修道院 3×3、大聖堂 5×2 |
| 緑 | 酒場 1×5、市場 2×4、商館 2×3、波止場 3×3、港 4×3、市庁舎 5×2 |
| 赤 | 見張り塔 1×3、牢獄 2×3、戦場 3×3、要塞 5×2 |
| 紫 | 幽霊街 2、天守 3×2、研究所 5、鍛冶屋 5、墓地 5、天文台 5、魔法学校 6、図書館 6、城壁 6、大学 6、竜の門 6 |

### 役割を選ぶ（巡の始め）

- 8枚の役割を切り、1枚を伏せて捨てる。さらに、4人なら2枚、5人なら1枚を表で捨てる（王様が出たら、王様は残して次の札を捨てる）
- 王冠を持つ人から時計回りに1枚ずつ選ぶ。7人のときは、最後の人が、残りの1枚と最初に伏せた1枚から選べる
- 3人：2周して、1人が2役（1枚余る）
- 2人：1人が2役。王冠の人が1枚選び、相手が1枚選んで1枚伏せ、王冠の人が1枚選んで1枚伏せ、相手が残り2枚から1枚選ぶ（最後の1枚は伏せる）

### 手番

役割を番号の順（1 暗殺者 → 8 将軍）に呼び、その役割の人が手番を行う。だれも持っていない役割と、殺された役割は飛ばす。

1. 行動：2金を取るか、地区カードを2枚引いて1枚を残す（残さなかった札は山の下）
2. 建てる：行動のあと、費用を払って地区を1つ建てられる（建築家は3つまで）。自分の都市と同じ名前の地区は建てられない
3. 収入と能力：手番の中でいつでも1回。収入は、役割の色の地区1つにつき1金

| 役割 | 能力 |
|---|---|
| 1 暗殺者 | 役割を1つ指名して殺す。殺された役割の人は、この巡の手番がない（呼ばれても名乗らず、巡の終わりに明かされる） |
| 2 盗賊 | 役割を1つ指名する（暗殺者と、殺された役割は選べない）。その役割の人が手番を始めるときに、持っている金をすべて奪う |
| 3 奇術師 | ほかの人と手札をすべて交換するか、好きな枚数の手札を山の下に戻して、同じ枚数を引く |
| 4 王様 | 呼ばれたときに王冠を受け取る（次の巡で最初に選ぶ）。殺されても、巡の終わりに王冠を受け取る。黄の収入 |
| 5 司教 | 将軍に地区を壊されない（殺されたときを除く）。青の収入 |
| 6 商人 | 行動のあとに1金。緑の収入 |
| 7 建築家 | 行動のあとに地区カードを2枚引く。地区を3つまで建てられる |
| 8 将軍 | 地区を1つ、費用より1少ない金で壊せる（1の地区はただ）。8地区の都市は壊せない。赤の収入 |

紫の地区：

| 地区 | 効果 |
|---|---|
| 幽霊街 | 得点を数えるとき、好きな色1つとして数える（最後の巡に建てたときを除く） |
| 天守 | 将軍に壊されない |
| 研究所 | 手番に1回、手札を1枚捨てて1金 |
| 鍛冶屋 | 手番に1回、2金を払って地区カードを3枚引く |
| 墓地 | 将軍がほかの地区を壊したとき、1金を払ってその地区を手札に加えられる（自分が将軍のときを除く） |
| 天文台 | 行動で地区カードを引くとき、3枚引いて1枚残す（図書館もあれば2枚残す） |
| 魔法学校 | 収入を受け取るとき、好きな色として数える |
| 図書館 | 行動で地区カードを引くとき、引いた札をすべて残す |
| 城壁 | ほかの地区を将軍が壊す費用が1増える |
| 大学・竜の門 | 得点は8点（費用は6） |

### 終わりと得点

- だれかの都市が8地区になったら、その巡の終わり（8 将軍まで）で終了
- 得点：地区の費用の合計（大学と竜の門は8点）、5色そろえて+3、最初に8地区にした人+4、ほかに8地区にした人+2
- 同点なら、地区の費用の合計（大学・竜の門は6）が多い人、それも同じなら金の多い人が上

### 資料と、資料で分からない点の決め方

版は、基本の8役と基本の地区カード66枚の、原版（2000年）の流れをくむ Fantasy Flight Games の英語版に合わせた。読んだ資料：

- [A] FFG 英語版のルールブック 2006年刷（原版の8役）：https://images-cdn.fantasyflightgames.com/ffg_content/Citadels/citadelsrules.pdf （元の場所は応答がなく、Wayback Machine の写しで読んだ）
- [A2] 同 2010年刷：https://desktopgames.com.ua/games/2606/Citadels_rules.pdf
- 2000年の原本（Multisim）と 2002年の FFG 初刷は手に入らなかったので、[A]・[A2] で代えた
- Universal Head による FFG 版の要約（Citadels v2、2006）：https://www.orderofgamers.com/downloads/Citadels_v2.pdf
- [C] Citadels Classic（2016年の再版）：https://world-of-board-games.com.sg/docs/Citadels-Classic.pdf
- [N] 2016年版のルールブック（Z-Man Games）：https://world-of-board-games.com.sg/docs/Citadels-2016.pdf
- 紫の地区のカードの文は、公式の資料に載っていない。費用・枚数・効果は、カードを書き写した非公式のデータ（GitHub の ChrisPMohr/Citadels など）と、[A] の補足で確かめた

版ごとの食い違いと、どう決めたか：

| 点 | FFG 英語版（[A]・[A2]） | 2016年版（[C]・[N]） | この版 |
|---|---|---|---|
| 完成の地区数 | 8（人数によらない。7で遊ぶ選択ルールあり） | 4人以上は7、2〜3人は8 | **8**（原版の8役・66枚に合わせた） |
| 紫の地区 | 11種12枚（天守は2枚） | [N] は30種から14種を選ぶ（墓地・大学はなく、幽霊街などは効果が変わった）。[C] は14枚 | **11種12枚** |
| 同点 | [A] は書かれていない。[A2] は地区の費用の合計、次に金 | 最後の巡で一番大きい番号の役割を明かした人 | **[A2] の決め方**（ほかを FFG 版に合わせたため） |
| 将軍が壊す時 | 手番の終わり | 手番のいつでも | **手番のいつでも1回**（行動の前に壊して、残りの金で建てる、もできる。原版より少し自由） |
| 商人の1金 | 行動のあと | どちらの行動でも | 行動のあと |
| 殺された司教 | 書かれていない | 将軍が壊せる | 壊せる |
| 天文台と図書館を両方 | 3枚引いて2枚を残す | — | [A] のとおり |
| 研究所 | 1金（非公式のデータ） | 2金（[N] の研究所は費用も違う） | 1金 |
| 鍛冶屋 | 2金を払って3枚（非公式のデータの1つは「3金で2枚」） | 2金で3枚 | 2金で3枚 |

確かめたこと：表で捨てる札は4人2枚・5人1枚・6〜7人0枚で、王様が出たら入れ替える（王様は山に戻す）。2人のときは「Aが1枚伏せて選ぶ → Bが選んで1枚伏せる → Aが選んで1枚伏せる → Bが選んで最後の1枚を伏せる」。3人のときは1枚伏せて、全員が2枚になるまで回し、最後の1枚を伏せる。7人のときは7人目が残りの1枚と伏せた札から選ぶ。2〜3人では、能力はその役割の手番でだけ使える（建築家の3つまでは、将軍の手番では使えない）。収入は手番のいつでもとれるが、一度にまとめて。盗賊は暗殺者と殺された役割を狙えない。王様のいない巡は、王冠は動かない。壊された地区は山の底へ。暗殺者と盗賊は能力を使わなくてもよい。

**日本語の名前**：役割は日本語版（日本語版 Wikipedia「あやつり人形 (カードゲーム)」）の暗殺者・盗賊・奇術師・王様・司教・商人・建築家・将軍に合わせた。地区の日本語版の名前は確かめられなかったので、英語版の名前（Manor・Castle・Palace など）を自分で訳した（屋敷・城・宮殿・寺院・教会・修道院・大聖堂・酒場・市場・商館・波止場・港・市庁舎・見張り塔・牢獄・戦場・要塞・幽霊街・天守・研究所・鍛冶屋・墓地・天文台・魔法学校・図書館・城壁・大学・竜の門）。色の呼び名（貴族・宗教・商業・軍事・特殊）も同じ。

自分で決めた点：

- **収入を取らずに手番を終えたら、自動で受け取る**（受け取って損をすることはないため。画面の「収入」ボタンで、建てる前に受け取ることもできる）
- 商人の1金と建築家の2枚は、行動のあとに自動で受け取る
- 研究所・鍛冶屋は、手番の中でいつでも1回（行動の前でもよい）
- 墓地は、だれの地区が壊されたときでも使える（非公式のカードの文が「a district」で、自分の地区に限っていない）。墓地そのものが壊されたときは使えない。拾うかは、墓地の持ち主に手番の途中で聞く
- 捨てた地区カード（奇術師・研究所・残さなかった札・壊されて墓地で拾われなかった地区）は、山の下に入れる
- 山が尽きたら、引ける分だけ引く（山が空なら「引く」は選べない）
- 奇術師の交換は、手札が0枚の人とでもできる
- 銀行の金は尽きない

### 画面の操作

- 役割を選ぶ番は、真ん中に候補のカードが並ぶ。押すと下に説明が出て、「選ぶ」で決める（2人のときの「伏せる」も同じ）
- 自分の番は、下のボタンで「2金」「2枚引く」、役割の能力（暗殺・盗む・魔術・破壊）、「収入」「終える」を押す。建てられる手札は金色に光る。手札を押すと下に説明が出て、「建てる」で建てる
- できることが「終える」だけになったら、少し待って自動で番を終える
- 相手の欄：王冠、名前、明かされた役割（まだなら「?」）、手札の枚数、金、都市（色と費用）。押すとその人の都市が見られる。自分の都市を押すと、自分の都市が見られる
- 真ん中の列は呼ぶ順の役割で、手番を終えた役割には持ち主、殺された役割には「殺」、盗賊が狙った役割には「盗」が付く
- 右上のボタンで記録と遊び方が見られる
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

## CPU

強さは「ふつう」と「やさしい」。CPU は自分の席のビュー（自分の手札と役割、全員の都市・金・手札の枚数、明かされた役割、自分が選んだときに見た候補）だけを見て決め、ほかの人の手札・伏せた役割・山はのぞかない。CPU の判断にはゲームの乱数を使わない（記録の再現がずれないように）（`public/js/cpu-player.js`）。

**ふつう**

- 役割：自分の都市・手札・金から、役割ごとの値打ちを見積もって選ぶ（王冠、色の収入、建築家で建てられる数、将軍で狙える相手、盗賊で取れそうな金、奇術師で増やせる手札）。2人のときに伏せる役割は、相手にとって値打ちの高いもの
- 推測：自分が選んだときに見た候補から、どの役割がだれの手にありそうかを出す。候補になかった役割は自分より前に選んだ人、候補に残っていた役割は自分より後に選んだ人（どちらも伏せた札の見込みも残す）。その中で、その人にとって値打ちの高い役割ほど、持っていそうと見る
- 暗殺者：先頭の人（得点の見込みと、完成までの近さ）が持っていそうな役割を殺す。盗賊：金を多く持つ人が持っていそうな役割を狙う
- 建てる順：手札から、今の金で建てられる組み合わせ（建築家は3つまで）を全部比べ、得点・新しい色・役割の収入の色・紫の効果の合計が一番高いものを選ぶ。収入の色の地区を建てるなら、建ててから収入を受け取る
- 行動：建てたい札がなければ引き、あれば金を取る（建てたい札が1枚で、もう払えるなら、次の札を探して引く）。建築家は金を取る
- 奇術師：手札が乏しく、2枚以上多く持つ人がいれば交換。そうでなければ、建てられない札と遠すぎる札を引き直す
- 将軍：完成が近い人か先頭の人の地区を、安く壊せるときに壊す
- 研究所で建てられない札を金に換え、手札が乏しければ鍛冶屋で引く

**やさしい**：役割はおおまかな値打ちに大きな迷いを足して選ぶ。暗殺と盗賊の的は当てずっぽう（表で捨てた役割と自分の役割は避ける）。行動はたいてい金で、建てるのは建てられる札のうち最初の1つ。将軍はただで壊せる地区だけを、ときどき壊す。

```bash
# 試合数・人数・席ごとの強さ（easy・normal）。最初の王冠は試合ごとに入れ替える
node scripts/cpu-match.mjs 1000 2 easy,normal
```

| 対戦 | 試合数 | ふつうの勝率 | やさしいの勝率 | 巡の数の平均 |
|---|---|---|---|---|
| 2人（やさしい・ふつう） | 1000 | 91.5% | 8.5% | 5.3 |
| 2人（ふつう・やさしい） | 1000 | 92.9% | 7.1% | 5.3 |
| 2人（ふつう・ふつう） | 1000 | 50.6%・49.4% | — | 5.8 |
| 3人（やさしい・ふつう・やさしい） | 500 | 71.2% | 14.6%・14.2% | 5.6 |
| 4人（やさしいとふつうを交互） | 500 | 37.0%・38.2% | 13.2%・11.6% | 10.4 |
| 5人（やさしいとふつうを交互） | 500 | 34.2%・36.8% | 8.8%・8.0%・12.2% | 10.1 |
| 7人（やさしいとふつうを交互） | 300 | 22.3%・25.7%・25.7% | 7.3%・5.7%・8.7%・4.7% | 10.0 |

平均の得点は、ふつうが 23〜34点、やさしいが 18〜21点。どの組み合わせでも、止まった試合はない。

### オンライン対戦を入れるとき

netplay-kit の `scripts/sync.mjs` で部屋の処理を写し、`server/src/game-definition.js` を `createHandler` と `startDevServer` に渡す。部屋には参加者・シード・操作の記録だけを保存し、操作のたびに記録から再現する。操作を待っている人は `game.actors()`（ビューの `answering`）で見る（墓地で拾うかを聞くときは、手番の人ではなく墓地の持ち主）。隠すのはビュー（`createGameView`）の役目で、観戦者にはだれの手札も伏せた役割も見せない。シードと CPU の値（`cpuSalt`）はビューに入れない。
