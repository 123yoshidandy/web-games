# 七不思議デュエル

2人用のボードゲーム「世界の七不思議デュエル（7 Wonders Duel、Antoine Bauza・Bruno Cathala、Repos Production 2015）」の基本ゲーム（拡張なし）を、ブラウザで CPU と遊べるようにしたもの。スマホの縦持ち向けで、どの時代のカードの並びも、スクロールなしで1画面に収まる。ホーム画面に置くと、オフラインでも遊べる。

カード・七不思議・進歩トークンの絵、アイコンは、すべて SVG で自作している（公式の画像は使っていない）。カードの名前は自分で訳したもの、効果の文も自分で書いたもので、公式の文は写していない。

## 遊び方（基本ゲーム）

- はじめは各自7コイン。進歩トークン10枚から5枚を盤に並べる（残りの5枚は使わない。大図書館で引く）
- 七不思議12枚から8枚を出し、4枚ずつ2回ドラフトする。1回目は 先手が1枚 → 後手が2枚 → 先手が残り1枚、2回目は 後手が1枚 → 先手が2枚 → 後手が残り1枚。残りの4枚は使わない
- 各時代のカード23枚から3枚を見ずに抜き、20枚を決まった形に並べる。表の行と裏の行が交互になる。時代IIIは、時代IIIのカード20枚から3枚を抜いた17枚に、ギルド7枚から3枚を混ぜる
  - 時代I：上から 2・3・4・5・6 枚（ピラミッド）
  - 時代II：上から 6・5・4・3・2 枚（逆さのピラミッド）
  - 時代III：上から 2・3・4・2・4・3・2 枚（真ん中の2枚の行は左右に分かれる）
- 手番：ほかのカードに一部でも覆われていないカードを1枚取り、次のどれかに使う。取ったことで覆いがなくなった裏のカードは表にする
  1. 建てる：費用（コインと資源）を払う。連鎖の印を持っていれば無料
  2. 捨てる：2コイン＋自分の黄のカードの数 のコインを得る
  3. 七不思議を建てる：カードを七不思議の下に入れ、七不思議の費用を払う。2人合わせて7つまで（7つ目が建ったら、残りの1つは使わない）
- 資源：茶と灰のカードが生む。足りない分は、1つにつき「2＋相手の茶と灰のカードが生むその資源の数」コインで銀行から買う。黄のカードと七不思議の「どれか1つ」は、相手の値段に数えない。蓄え（黄）があれば、その資源は1コイン
- 軍事：盾1つで、駒を相手の都へ1マス進める。3マス目と6マス目のトークンで、相手は2コインと5コインを失う（1回だけ。足りない分は失わない）。9マス目（相手の都）に着いたら、その場で勝ち
- 科学：同じ印を2つそろえたら、盤の進歩トークンを1枚取る。違う印を6種類そろえたら、その場で勝ち（法のトークンの天秤も数える）
- 時代の終わり：カードがなくなったら終わり。軍事で負けている方が、次の時代の先手を決める。並んでいれば、最後のカードを取った人が決める
- 時代IIIの終わりに、点の多い方の勝ち。点は、カード・七不思議・進歩トークンの点、軍事の位置の点（1〜2マス 2点、3〜5マス 5点、6〜8マス 10点）、3コインにつき1点。同点なら青のカードの点の多い方。それも同じなら引き分け

### 資料と、資料で分からない点の決め方

ルールは、2015年の英語版の公式ルールブック（図書館の公開の PDF）、Board Game Arena の遊び方の説明、公式の FAQ を照らし合わせて決めた。カードの費用はルールブックでは絵なので、2つの実装（Board Game Arena 版の Material.php と、ajayeb の資料）で一致したものを使い、ルールブックの例（隊商宿は 2コイン・ガラス・パピルス、など）と ultraboardgames のルールの頁とも照らした。時代I〜III とギルドの費用・効果・連鎖17本、七不思議12枚、進歩トークン10種は、どの資料とも一致した。

- 公式のルールブック（2015年英語版）：https://aadl.org/files/catalog_guides/7%20Wonders%20Duel.pdf
- 公式の FAQ：https://www.rprod.com/en/7-wonders-duel/faq
- Board Game Arena の遊び方（英語・日本語）：https://en.doc.boardgamearena.com/Gamehelpsevenwondersduel
- Board Game Arena 版の実装（カードの費用）：https://github.com/koenheltzel/bga-sevenwondersduel
- ajayeb の資料（カードの費用）：https://github.com/NightMachinery/ajayeb
- ルールの頁：https://ultraboardgames.com/7wonders/duel.php 、https://www.bargames101.com/?p=7951

ギルドの数え方は、ルールブックのとおり、2人の都市を数えて多い方を使う（建築家は七不思議の多い都市、金貸しはコインの多い都市、船主は茶と灰を合わせた枚数の多い都市を1つ）。建てたときのコインと終わりの点で、数える都市は別になってよい。

資料で食い違った点と、どう決めたか：

- 軍事で並んでいるとき（駒が中央）の次の時代の先手：2015年の英語版のルールブックでは「最後のカードを取った人が始める」、Board Game Arena の説明（英語・日本語）と新しい版の訳では「最後のカードを取った人が、先手を選ぶ」。軍事で負けている方が「選ぶ」のと形をそろえて、選ぶ方を採った（自分を選べば、旧版の読み方と同じになる）
- 軍事のトークンの位置：ルールブックは図だけで、マスの番号の文はない。ほかの資料の「3マス目に2コイン、6マス目に5コイン」（それぞれ 5点・10点の区域の入口）とした
- カードの名前：法廷（5点の青）は、ルールブックでは Tribunal、Board Game Arena では Courthouse。ルールブックの一覧は、時代IIIの近衛兵の宿舎（Pretorium）の欄にも COURTHOUSE と書いている。商人のギルドは、ルールブックの本文では Traders Guild。どれも効果は同じなので、ルールブックの一覧の名前（Tribunal・Pretorium・Merchants）から訳した
- 巨像の費用：ultraboardgames では「粘土5・ガラス1」だが、ほかの資料はすべて粘土3・ガラス1なので、粘土3とした
- 捨て札：ルールブックでは裏向きに置くが「いつでも見てよい」。画面では全員に見せる

自分で決めた点：

- 時代の最後のカードで「もう1手」の七不思議を建てたら、もう1手は失われる（ルールブックのとおり）。次の時代の先手は、ふだんどおりに決める
- 大競技場とゼウス像は、盾を進めてから相手のカードを選ぶ（その盾で都に届けば、その場で勝ち）。霊廟で建てたカードは連鎖ではないので、都市計画の4コインは出ない
- 大競技場とゼウス像で、相手にその色のカードがなければ何もしない。霊廟で捨て札がなければ、大図書館で使わないトークンがなければ、何もしない
- 同じ印の2つ目で取る進歩トークンが盤に残っていなければ、何もない
- 石工と建築の「資源が2つ少ない」は、払う額が一番少なくなるように当てる（買うと一番高い資源から減らす）。黄と七不思議の「どれか1つ」も、払う額が一番少なくなるように割り振る
- ギルドのコインは建てた時点、点はゲームの終わりの時点で、それぞれ多い方の都市を数え直す。船主のギルドは茶と灰を合わせて数える
- 銀行のコインは尽きない
- カードの日本語の名前は自分で訳した（日本語版の名前とは違うものがある）

### 画面の操作

- 上の帯：時代、盤の進歩トークン（押すと説明）、捨て札（押すと一覧）、記録、遊び方
- 相手の都市（上）と自分の都市（下）：コイン、点（今の時点で数えた合計）、科学の印、進歩トークン、生む資源（「+1」は「どれか1つ」の数）、色ごとのカードの枚数、七不思議（建てたものは金色）。押すと、都市のカードと七不思議の一覧と点の内訳が見られる
- 軍事：左が自分の都、右が相手の都。数字のマスは、駒が来たら相手（自分の側なら自分）がコインを失うトークン
- 取れるカードは金色に光る。右下の数字は、自分が建てるのに要るコイン（足りなければ赤、連鎖なら緑の印）。押すと説明と「建てる」「捨てる」と七不思議のボタンが出る
- 進歩トークン・大図書館・捨てさせるカード・霊廟・次の時代の先手は、選ぶ画面が開く（閉じても下の帯を押せば開き直せる）
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

## CPU

強さは「ふつう」と「やさしい」。並びは自分の席のビューから読み、裏のカードの中身はのぞかない。CPU の判断にはゲームの乱数を使わない（記録の再現がずれないように）（`public/js/cpu-player.js`）。

- ふつう：手ごとに「自分の得 − 払うコイン ＋ 相手に渡さない分 − 相手に新しく見せるカードの危険」を点に直して比べ、一番大きい手を選ぶ。自分の得は、点・コイン（序盤ほど重い）・資源（序盤ほど重く、すでに持っている資源は軽い）・軍事（点の差、相手が失うコイン、都に近いほど重い）・科学（新しい印、2つ目で取れる進歩トークン）・連鎖の印で数える。その場で勝てる手は必ず打ち、相手が次に勝てるカードは取るか、見せないようにする。七不思議のドラフトと進歩トークンも、同じ見積もりで選ぶ
- やさしい：建てられるカードから、安いものほど選びやすく気まぐれに選ぶ。4回に1回ほど七不思議を建て、建てられなければ捨てる

```bash
# 試合数・席ごとの強さ（easy・normal）。先手は試合ごとに入れ替える
node scripts/cpu-match.mjs 1000 easy,normal
```

| 対戦 | 試合数 | ふつうの勝率 | やさしいの勝率 | 勝ち方（軍事・科学・点） |
|---|---|---|---|---|
| やさしい・ふつう | 1000 | 85.4% | 14.6% | 8.8%・2.6%・88.6% |
| ふつう・やさしい | 1000 | 85.4% | 14.6% | 9.4%・1.9%・88.7% |
| ふつう・ふつう | 1000 | 50.0%・49.9%（引き分け1） | — | 6.5%・2.2%・91.2% |
| やさしい・やさしい | 1000 | — | 50.9%・49.1% | 10.6%・1.8%・87.6% |

どの組み合わせでも、止まった試合はない。ふつうが負ける試合は、ほとんどが点の勝負で、ギルドとコインで差を付けられたもの。

### オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2人で、相手がいなければ CPU で埋められる。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'seven-wonders-duel' })`。web-games の1つのスタックから `?game=seven-wonders-duel` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
