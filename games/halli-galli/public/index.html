遊び方

みんなの表のカードを見て、どれかの果物がちょうど5つになったら、誰よりも早くベルを鳴らします。

カード

56枚。いちご・バナナ・ライム・プラムが、1〜5個かいてあります。全部を裏のまま配って始めます。

いちごが 2＋3＝5つ → ベル！

バナナが 4＋2＝6つ → 鳴らさない

進み方

  • 順番に、自分の山札の一番上を表にして、自分の前に重ねます。見るのは、各人の一番上のカードだけです
  • 自分の番は、左下の山札をタップしてめくります。「自動」にすると、時間でめくります
  • 5つのときに一番早く鳴らすと、表のカードを全部もらえます（山札の下へ）。次はその人からめくります
  • 5つでないのに鳴らすと、ほかの全員に1枚ずつ払います
  • めくる番が来たときや払うときに山札がなければ脱落。その人の表のカードは真ん中に残り、次にベルを当てた人のものです
  • 最後の1人になるか、時間切れで終わります。時間切れなら、カードの多い人の勝ち

モード

  • れんしゅう：5つになると、ベルの上に「いま5つ！」がそっと出ます（電球のボタンで消せます）
  • CPU 対戦：ヒントなしで CPU と早押し
  • オンライン：全員が時間でめくります。サーバーに先に届いたベルが勝ち

操作

キーボードでは、スペースでベル、Enter でめくります。
