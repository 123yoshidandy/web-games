# ハリガリ（Halli Galli）

果物がちょうど5つになったら、誰よりも早くベルを鳴らす早押しのカードゲーム。2〜6人。CPU 対戦・れんしゅう・オンライン対戦。

## 遊び方

- カードは 56 枚。いちご・バナナ・ライム・プラムが、果物ごとに 14 枚（1個が5枚・2個が3枚・3個が3枚・4個が2枚・5個が1枚）
- 全部を裏のまま配り、順番に自分の山札の一番上を表にして、自分の前の表の山に重ねる。見るのは各人の一番上のカードだけ
- どれかの果物がちょうど5つなら、ベルを一番早く鳴らした人が表のカードを全部もらい（山札の下へ）、次はその人からめくる
- 5つでないのに鳴らしたら、ほかの全員に1枚ずつ払う
- めくる番が来たときや払うときに山札がなければ脱落。その人の表のカードは真ん中に残り、次にベルを当てた人のもの
- 最後の1人になるか、時間切れ（3・5・10分）で終わる。時間切れなら、山札と表の山の枚数の多い人の勝ち
- 操作：右下の大きなベルを押す（キーボードはスペース）。自分の番は左下の山札を押してめくる（Enter）。「自動」にすると、時間でめくる
- めくる速さ（手番が来てから自動でめくるまで）：ゆっくり 2.0 秒・ふつう 1.5 秒・はやい 1.0 秒。ベルのあとは 1.5 秒待つ
- れんしゅう：5つのとき、ベルの上に「いま5つ！」がそっと出る（ヒントのボタンで消せる）

## CPU

- 見えているカードが変わるたびに、鳴らすかどうかと鳴らすまでの時間を決める（`public/js/cpu-player.js`）
- 強さは、反応の時間の分布と、見落とす割合・まちがえて鳴らす割合で分ける。まちがえるのは、4つか6つの果物がある「惜しい」場だけ

| 強さ | 反応の時間 | 見落とす | まちがえる（惜しい場で） |
|---|---|---|---|
| やさしい | 平均 0.98 秒（0.42〜1.63 秒） | 12% | 7% |
| ふつう | 平均 0.82 秒（0.34〜1.37 秒） | 7% | 4.5% |
| つよい | 平均 0.68 秒（0.28〜1.13 秒） | 4% | 2.5% |

- 分布は重ねてあり、弱い側が先に鳴らすこともある。ただしベルを取るほどカードが増えて有利になるので、試合の勝ち負けは強さの差がはっきり出る
- 乱数はゲームの乱数を使わず、シード・席・場の版から作る。同じ記録からは同じ時刻に鳴らすので、記録の再現がずれない
- `npm run cpu-match -w games/halli-galli`（`--players 4` で4人）で、強さの組ごとの勝率を出す

## 開発

```bash
npm test -w games/halli-galli                 # ルール・CPU・記録の再現・ヒント・オンライン・PWA のテスト
npm run cpu-match -w games/halli-galli        # CPU どうしの対戦
npm run dev:online                            # 手元のオンライン対戦のサーバー（web-games の直下で）
node scripts/online-e2e.mjs halli-galli       # 2人の画面での通し試験
```

- ルールは `public/js/game.js`（DOM なし）。操作はすべて `applyCommand`（めくる・ベル・自動の切り替え・時間切れ）を通り、時刻つきで記録される
- 時刻で起きること（自動でめくる・CPU のベル・時間切れ）は `runUntil` が起こす。ローカルは時計、オンラインはサーバーの期限（deadline）と端末の ping で進む
- 画面は `public/js/main.js`、絵は `public/js/card-art.js`（果物とベルは自作の SVG）

## 決めたこと

- ベルには、端末が見ていた場の版を添える。見ていた場から変わっていて（先に鳴らされた・めくられた）今は5つでなければ、まちがいにせず「間に合いませんでした」で断る（通信の遅れで払わされないように）
- 脱落した人の表の山は、真ん中の「場の山」に移す（見えるカードからは外す）
- ローカルの対戦では、あなたが脱落したらその場で終わる（CPU だけの残りを待たない）
- まちがえたあと 0.8 秒は鳴らせない（続けて押したときの空振りを防ぐ）
- オンラインでは全員が自動でめくる。自分の番なら待たずにめくってもよい。CPU の番（抜けた人の席を含む）は、人の「めくる」でも進む
- 待った（undo）はない（早押しで、戻すと時間を巻き戻せてしまう）

## オンライン対戦

- netplay-kit の共通のロビーで、2〜6人（CPU で埋められる）。設定は CPU の強さ・めくる速さ・時間
- サーバーの時計で操作に時刻を付け、届いた順に判定する。部屋には記録だけを保存し、ビューにシードと山札の並びは入れない
- 対戦中に抜けた人の席は CPU が引き継ぐ
