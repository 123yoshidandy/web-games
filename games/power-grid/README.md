# 電力会社

発電所を競り、燃料を買い、都市をつないで電気を送るボードゲーム「電力会社（Power Grid / Funkenschlag、Friedemann Friese、2F-Spiele 2004）」の基本ゲームを、ブラウザで CPU と遊べるようにしたもの。地図はドイツとアメリカ。2〜6人（あなた＋CPU 1〜5人）。スマホの縦持ちでも横持ちでも、スクロールなしで1画面に収まる。ホーム画面に置くと、オフラインでも遊べる。

絵とアイコンは、すべて SVG と CSS で自作している（公式の画像は使っていない）。地図は、都市の位置と線だけを描いた図で、盤面の絵は写していない。説明の文も自分で書いたもの。

## 遊び方（基本ゲーム）

- 準備：所持金は50。人数に応じた数の、つながった地域を選ぶ（ランダム）。発電所の市場は 3〜10（上の段 3〜6 が今の市場、下の段 7〜10 が将来の市場）。山の上に13、底に「段階3」のカード。2・3人は8枚、4人は4枚を伏せて抜く。資源の市場は、石炭 1〜8、石油 3〜8、ゴミ 7〜8、ウラン 14・16 に置く。最初の手番の順はくじ
- 1巡の流れ
  1. **手番の順**：都市の多い順。同数なら大きい発電所を持つ順
  2. **発電所の競り**：順に、今の市場から1つ選んで番号以上の値で競りにかけるか、見送る。ほかの人は値を上げるか降りる（降りたら戻れない）。1巡に1人1つまで。見送った人も、その巡はもう競れない。最初の巡は全員が買う（買ったあとで手番の順を決め直す）。2巡目からは、だれも買わなければいちばん小さい発電所を除く。持てる数（2人は4つ、3人以上は3つ）を超えたら1つ手放す
  3. **資源を買う**（手番の逆順）：発電所に入るのは、使う数の2倍まで（両用は石炭と石油の合計）。安いマスから買う
  4. **都市を建てる**（手番の逆順）：最初の都市は10。次からは、自分の都市からのいちばん安い線の費用＋都市の空いたいちばん安いマス（10・15・20）。1つの都市に入れるのは、段階1は1人、段階2は2人、段階3は3人。同じ都市に2回は建てられない
  5. **官僚**：燃料を使って送電し、送電した都市の数で収入。人数と段階に応じて資源を補充（箱に残りがなければ足りない分は補充しない）。発電所の市場：段階1・2はいちばん大きい発電所を山の底へ戻して1枚引く、段階3はいちばん小さい発電所を除いて1枚引く
- 都市の数以下の番号の発電所は、競りにかけられる市場からすぐ除いて引き直す
- 段階2：建設のあとで、だれかの都市が決まった数に届いたら。いちばん小さい発電所を1回だけ除いて引き直す
- 段階3：山から「段階3」のカードが出たら。競りのフェーズで出たら、いちばん大きい発電所として置き、競りが終わってから段階3のカードといちばん小さい発電所を除く（資源のフェーズから段階3）。建設のフェーズで出たら、すぐ除いて官僚から段階3。官僚で出たら、すぐ除いて、補充は段階2のまま、次の巡から段階3。どれも山を混ぜ直す。段階3では市場が6つになり、全部を競りにかけられる
- 終わり：建設のあとで、だれかの都市が終わりの数に届いたら（その巡の官僚はしない）。今の発電所と燃料で送電できる都市のいちばん多い人の勝ち。同数ならお金、さらに同数なら都市の数

### 資料で分からない点と、画面のために決めた点

- **官僚では、全員が「送れるだけ送る」。** ルールでは送る都市の数を選べるが、この画面では、いちばん多く送れる組み合わせを自動で選ぶ（同じ数なら、ウラン・ゴミ・石油・石炭の順に重く見て、使う燃料の少ない組み合わせ。両用は余った石炭から使う）
- **資源は人ごとにまとめて持つ。** ルールでは発電所ごとに置くが、いつでも置き直せるので、全体で「入りきるか」だけを見る。発電所を手放して入りきらなくなったら、はみ出した分を箱に戻す（石炭と石油は、はみ出しの多い方から）
- 競りで値を上げる順は、手番の順で、競りを始めた人の次から回る
- 地域は、最初の地域をランダムに選び、隣り合う地域をランダムに足していく
- 2人のときの特別なルール（ダミーの会社など）は、使ったルールブックにないので入れていない

### 画面の操作

- 地図は2本指で拡大、1本指で動かす（PC はホイール）。右下のボタンで拡大・縮小・全体（使う地域に合わせる）
- 競り：下の段の光る発電所を選び、値を −5・−1・+1・+5 で決めて「競る」か「見送る」。ほかの人の競りには「入札」か「降りる」
- 資源：種類ごとに ＋ − で数を決めて「買う」。入りきらない分と、お金の足りない分は足せない
- 建設：光る都市（黄色の札は費用）をタップして「建てる」。終わったら「終える」。小さいままでタップしたときは、近くに都市が1つならそれを選び、2つ以上ならそこを拡大する
- 上の人の欄は、手番の順に、お金・都市の数・発電所の番号。下の段は、自分の発電所（燃料の数）と、送電できる数・都市の数・山の枚数
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

## CPU

強さは「ふつう」と「やさしい」。CPU は、その席のビュー（`createGameView`）だけを受け取って決める（`chooseCommand(view, level)`）。山の並びは見えない。ゲームの乱数も使わない（`public/js/cpu-player.js`）。

- ふつう
  - 競り：発電所を足したときに増える送電の数と、燃料の値段（市場に足りなければ品薄として高く見る）から値打ちを見積もり、「番号＋値打ちの3割」まで競る。送電できる数が「都市の数＋2」以上あれば買わない（お金を都市に回す）。燃料が市場に1回分もない発電所は買わない
  - 資源：全部の発電所を動かせる分を、安い方から買う
  - 建設：送電できる数まで、安い都市から建てる。次の巡に動かす分の燃料代は残す。最初の都市は、そこから広げる近くの4都市までの費用が小さい所を選ぶ。終わりの都市の数に届くとき、送電で相手に負けていれば見送る
- やさしい：手ごろな発電所を番号どおりの値で買い、燃料を1回分買い、安い都市を1巡に1つずつ建てる
- どちらも、巡が長引いたら（25巡以上）、送電の数に関係なく建てて終わらせる（発電所が尽きて、だれも終わりの数に届かなくなるのを防ぐ）

```bash
# 試合数・強さの並び（easy・normal）。席の並びは試合ごとに1つずつずらす
node scripts/cpu-match.mjs 200 easy,normal,easy
```

| 対戦 | 試合数 | ふつうの勝率 | 等分なら | 平均の送電（ふつう／やさしい） |
|---|---|---|---|---|
| 2人（やさしい・ふつう） | 200 | 66.5% | 50% | 18.3／16.6 |
| 3人（やさしい2・ふつう） | 200 | 60.3% | 33% | 14.8／13.1 |
| 4人（やさしい3・ふつう） | 200 | 30.5% | 25% | 13.1／13.5 |
| 5人（やさしい4・ふつう） | 200 | 28.2% | 20% | 12.9／12.5 |
| 6人（やさしい5・ふつう） | 200 | 27.5% | 17% | 12.7／11.9 |
| 4人（ふつう4人） | 200 | 26.5%・25.0%・26.5%・22.0% | 25% | 13.7 |

人数が多いほど、ふつうとやさしいの差は小さい。同点で複数が勝った試合は、勝ちを等分して数えた。どの組み合わせでも、止まった試合はない。1試合は 9〜14 巡ほど。

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜6人で、足りない席は CPU で埋められる。地図（ドイツ・アメリカ）を部屋の設定に持つ。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'power-grid' })`。web-games の1つのスタックから `?game=power-grid` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）
