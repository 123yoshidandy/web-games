# キングダムビルダー

地形カードの地形に家を建てて王国を広げ、王のカードの条件で金貨（点）を集めるボードゲーム「キングダムビルダー（Kingdom Builder、Donald X. Vaccarino、Queen Games 2012）」の基本ゲーム（拡張なし）を、ブラウザで CPU と遊べるようにしたもの。2〜4人（あなた＋CPU 1〜3人）。スマホの縦持ちでも横持ちでも、スクロールなしで1画面に収まる。ホーム画面に置くと、オフラインでも遊べる。

絵とアイコンは、すべて SVG で自作している（公式の画像は使っていない）。説明の文も自分で書いたもので、公式の文は写していない。

## 遊び方（基本ゲーム）

- 準備：8枚の盤面（10×10 の六角マス）から4枚を選んで 2×2 に並べ、20×20 の盤にする。それぞれ 180度回して置くこともある。場所のマスには、同じ種類の場所タイルを2枚ずつ置く。王のカード10種から3枚。地形カード25枚（草原・花畑・森・峡谷・砂漠 各5枚）を混ぜて1人1枚ずつ配る。家は1人40軒。最初の人はランダム
- 手番：手札の地形カードを見せ、その地形に家を**3軒**、1軒ずつ建てる（必須）
  - 建てられるのは、空いている草原・花畑・森・峡谷・砂漠だけ。水・山・城・場所には建てられない
  - 1軒ごとに、**自分の家に隣接するマスがあれば必ずそこに**建てる。なければ、その地形のどこにでも
  - 建て終えたらカードを捨て札にし、1枚引く。山がなくなったら捨て札を混ぜる
  - 手札の地形に建てられるマスがなければ（手番の初めでも途中でも）、そのカードはゲームから取り除いて引き直す
- 場所タイル：場所のマスに隣接して建てると（動かしても）、そこのタイルを1枚取る。1つの場所からは1人1枚まで。**取った手番には使えず、次の手番から**、必須の3軒の前か後に、タイル1枚につき1回使える（3軒の途中には使えない）。動かして場所の隣に自分の家がなくなったら、そのタイルを失う（ゲームから取り除く）

| 場所 | 効果 |
|---|---|
| 神託所（Oracle） | 手札の地形に1軒建てる。できれば自分の家の隣に |
| 農場（Farm） | 草原に1軒建てる。できれば隣に |
| オアシス（Oasis） | 砂漠に1軒建てる。できれば隣に |
| 塔（Tower） | 盤の端（20×20 のいちばん外側）に1軒建てる。できれば隣に |
| 酒場（Tavern） | 自分の家が3軒以上まっすぐ並んだ列の端に1軒建てる |
| 納屋（Barn） | 自分の家を1軒、手札の地形へ動かす。できれば隣に |
| 港（Harbor） | 自分の家を1軒、水へ動かす。できれば隣に（水に家を置けるのは港だけ） |
| 馬小屋（Paddock） | 自分の家を1軒、まっすぐ2マス先へ跳ばす（間は何でもよい。隣でなくてよい） |

- 終わり：だれかが40軒目を建てたら、その巡の最後（最初の人の右隣の人の手番）まで続けて終わる
- 得点：王のカード3枚と、城（隣接する城1つにつき3点。何軒隣接しても3点）の合計。いちばん多い人の勝ち。同点なら勝ちを分け合う

| 王のカード | 点 |
|---|---|
| 漁師（Fishermen） | 水に隣接する自分の家1軒につき1点（水の上の家は数えない） |
| 商人（Merchants） | 自分の家でほかの場所・城とつながった場所・城1つにつき4点 |
| 発見者（Discoverers） | 自分の家がある横の行1つにつき1点 |
| 隠者（Hermits） | 自分の集落（隣り合う自分の家のかたまり。1軒でもよい）1つにつき1点 |
| 市民（Citizens） | 自分のいちばん大きな集落の家2軒につき1点 |
| 騎士（Knights） | 自分の家がいちばん多い横の行の家1軒につき2点 |
| 領主（Lords） | 盤面ごとに、家がいちばん多い人に12点、2番目に多い人に6点 |
| 農夫（Farmers） | 自分の家がいちばん少ない盤面の家1軒につき3点 |
| 働き手（Workers） | 場所か城に隣接する自分の家1軒につき1点 |
| 坑夫（Miners） | 山に隣接する自分の家1軒につき1点 |

日本語の名前は、画面のために付けたもの（日本語版の名前は確かめていない）。Barn は「塀」と訳す版もあるが、ここでは「納屋」にした。

### 資料と、資料どうしの食い違い

ルールは、2012年の原版（ドイツ語）、Big Box 第2版（2017、英語）、2024年の新版（英語）のルールブック、BGG の Kingdom Builder FAQ、Board Game Arena の実装（Syarwin/bga-kingdombuilder）で照らし合わせた。手番・建て方・タイルの効果・終わり・得点・同点は、どの版も同じ。2024年の新版は盤が両面の4枚で場所タイルが32枚と物が違うので、ここでは原版（8枚の盤面・場所タイル28枚）の形にした。

8枚の盤面の地形は、次の4つの資料を同じ形（10行×10文字）に直して比べ、多数の値を採った。採った値は、BGA の実装とすべて一致する。

| 資料 | 盤面 |
|---|---|
| Board Game Arena の実装（Syarwin/bga-kingdombuilder、`KingdomBuilderBoard.class.php`） | 8枚 |
| torgoton/kbc（Ruby） | 8枚 |
| Counterfeiter/KingdomBuilder（Python） | 8枚 |
| SE2-Alpha/KingdomBuilderAPP（Kotlin） | 4枚（神託所・農場・塔・酒場） |

食い違ったのは4枚の7マス（行・列は盤面の左上を (0,0) として数える）：

| 盤面 | マス | 食い違い | 採った値 |
|---|---|---|---|
| 神託所 | (3,7) | SE2-Alpha だけ水、ほかは場所 | 場所 |
| 神託所 | (4,7) | SE2-Alpha だけ場所、ほかは花畑 | 花畑 |
| 農場 | (6,3) | SE2-Alpha だけ花畑、ほかは森 | 森 |
| 農場 | (6,4) | SE2-Alpha だけ水、ほかは花畑 | 花畑 |
| 酒場 | (3,8)・(3,9) | Counterfeiter だけ峡谷、ほかは山 | 山 |
| 納屋 | (6,4) | kbc だけ森、ほかは花畑 | 花畑 |

SE2-Alpha の神託所 (3,7) と農場 (6,4) は、元のデータにマスが書かれておらず、既定の「水」になっていたもの。ほかの食い違いも、1つの資料だけが違う値で、写し間違いと見ている。

盤面ごとの城と場所の数は、そろっていない。神託所と港は城2つ・場所1つ、ほかの6枚は城1つ・場所2つ（どの資料も同じ）。

座標は、BGA と同じく「奇数の行を半マス右にずらす」形で持つ（`public/js/hex.js`）。盤面を 180度回して置くのは BGA の「ランダムな配置」と同じ（行と列を逆から読む）。

### 資料による決まり（ルールブックの本文だけでは分かりにくい点）

- **納屋と港で家を動かすときは、動かす家を先に取り除いてから「できれば自分の家の隣に」を判定する。** ルールブックには順番の記述がなく、BGG の Kingdom Builder FAQ（https://boardgamegeek.com/wiki/page/Kingdom_Builder_FAQ ）による。その結果、元のマスに戻すしかないこともある。BGA は、動かす家を盤に残したまま判定する（動かす家の隣にも動かせる）ので、ここは BGA と違う
- **領主で1位が同数なら、その全員が12点。2位の6点は、1位の次に多い数の人**（同数なら全員6点）。Queen Games のルールブック（Big Box 第2版 https://rules.queen-games.com/kingdom-builder_2nd_bigbox_en.pdf ）の例「8・8・6・2軒なら12・12・6・0点」と注による
- **動かしてタイルを失った場所からは、また隣接しても、もう取れない。** BGG の FAQ による
- 手番・建て方・タイルの効果・終わり・得点・同点の文面は、2012年の原版、2017年の Big Box 第2版、2024年の新版で同じ。違うのは物で、新版は盤が両面の4枚、場所タイルが32枚（原版は28枚）。ここでは原版の形にした

### 資料で分からない点の決め方

ルールブックにも FAQ にも書かれていない、または資料と違う形にした点は、次のように決めた（`public/js/game.js` の先頭にも書いた）。

- **領主で、その盤面に家のない人は点にならない。** BGG の FAQ と BGA は0軒の人も順位に入れるので、2人戦で片方だけが建てた盤面では、0軒の人にも6点が入る。家を建てずに点が入るのは不自然なので、これは取らなかった（資料と違う）
- 商人：場所と城は、自分の家どうし、または家と場所・城の隣り合いでつなぐ。1つの場所を挟んだ2つの集落もつながる（BGA と同じ）。場所どうしが直接隣り合っていても、家がなければつながらない（BGA は、場所どうしの隣り合いでもつながる）
- 必須の3軒の途中で家がなくなったら、必須の行動はそこで終わり
- 山と捨て札が両方なくなり、建てられるカードを引けないときは、必須の行動なしで番を終える（実際の試合では起きなかった）
- 手番の人の地形カードは、場に出したものとして全員に見せる。ほかの人の手札は見えない

### 画面の操作

- 光るマスをタップして建てる。盤は2本指で拡大、1本指で動かす（PC はホイール）。右下のボタンで拡大・縮小・全体
- 盤が小さいまま（マスの幅が 30px 未満）でタップしたときは、指の届く範囲（約 22px）に光るマスが1つだけならそこに建て、2つ以上ならそこを拡大する。縦持ちのスマホでも、引いたまま建てられる場面が多い
- 場所タイルは、下のボタンから使う。光っているものが今使える。動かすタイルは、動かす家（白い枠）を選んでから行き先を選ぶ
- 自分の番の中なら、「1手戻す」で戻せる（カードを引き直した手は戻せない）
- 3軒建て終えて、使える場所タイルもなければ、少し待って番を終える
- 上の人の欄は、点（今の盤で数えた点）・残りの家・持っている場所タイル。王のカードの欄を押すと、カードの説明と、人ごとの今の点が見られる
- ほかの人が自分の前の番のあとに建てた家には、点線の輪が付く
- 操作のたびに途中経過を保存し、タイトル画面の「続きから」で再開できる

## CPU

強さは「ふつう」と「やさしい」。CPU は、その席のビュー（`createGameView`）だけを受け取って決める（`chooseCommand(view, level)`）。ほかの人の手札と山の並びは見えない。ゲームの乱数も使わない（`public/js/cpu-player.js`）。

- ふつう：1手ごとに、置いたあとの自分の点（その試合の王のカード3枚と城。`rules.js` の `scorePlayer`）に、持っている場所タイルの値打ち（残りの手番が多いほど高い。建てるタイルは動かすタイルの2倍）を足して、いちばん高くなるマスを選ぶ。同点なら、まだタイルが残る場所に近いマス
  - 必須の3軒を建ててから、場所タイルを使う。建てるタイルは損をしなければ使い、動かすタイルは得になるときだけ使う
  - 動かすタイルは、取り除いても損の少ない家から6軒までを試す
- やさしい：建てられるマスから、ほぼでたらめに選ぶ（半分の確率で場所の隣を選ぶ）。建てるタイルは7割の確率で、でたらめなマスに使う。動かすタイルは使わない

```bash
# 試合数・強さの並び（easy・normal）。席の並びは試合ごとに1つずつずらす
node scripts/cpu-match.mjs 400 easy,normal
```

| 対戦 | 試合数 | ふつうの勝率 | やさしいの勝率 | 平均点（ふつう／やさしい） |
|---|---|---|---|---|
| 2人（やさしい・ふつう） | 400 | 93.1% | 6.9% | 50.2／29.6 |
| 3人（やさしい・ふつう・やさしい） | 200 | 84.5% | 7.0%・8.5% | 48.2／29.0 |
| 4人（やさしい3・ふつう） | 200 | 82.4% | 5.3%・6.9%・5.4% | 46.4／27.5 |
| 4人（ふつう4人） | 200 | 27.3%・27.0%・22.8%・23.0% | — | 43.9 |

同点で複数が勝った試合は、勝ちを等分して数えた。どの組み合わせでも、止まった試合はない。1試合は平均9巡ほど。

自分の番に、自分の欄の電球（ヒント）を押すと、ふつうの CPU が選ぶ手を示す（建てるマスを黄色で光らせる。場所タイルを使う手は、そのタイルと動かす家を選んでおき、行き先を光らせる。番を終える手は「番を終える」を光らせる）。

### オンライン対戦を入れるとき

netplay-kit の `scripts/sync.mjs` で部屋の処理を写し、`server/src/game-definition.js` を `createHandler` と `startDevServer` に渡す。部屋には参加者・シード・操作の記録だけを保存し、操作のたびに記録から再現する。操作を待つのは手番の人だけ（`game.actors()`）。端末から届いた操作は `sanitize` で種類ごとの項目だけを取り出してから `applyCommand` に渡す。
