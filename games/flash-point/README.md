# フラッシュポイント

燃える家から要救助者を助け出す、2〜6人の協力ゲーム（原作：Flash Point: Fire Rescue）。スマホの縦画面で遊ぶ。仲間を CPU に任せるか、1人で全員の消防士を動かす。オンライン対戦（公開の部屋）にも対応する。

盤面の間取り・絵柄・文章は、このゲームのために作ったもの（原作の盤面や絵は写していない）。

## 遊び方

- 要救助者を **7人** 建物の外へ運び出せば勝ち。**4人** を失うか、壁のダメージが **24** になって建物が崩れると負け
- 毎手番 4AP。使わなかった AP は4まで持ち越せる
  - となりへ動く 1AP（火のマスへは 2AP）、扉を開け閉め 1AP、消火 1AP（火→煙、煙→なし）、壁を壊す 2AP（2つのダメージで壊れる）
  - 要救助者を運ぶと1歩 2AP。運びながら火には入れない。外へ出たら救出
  - 「?」の印のマスに入ると正体が分かる（誤報なら消える）
- 手番を終えると火が広がる：ダイスで決めたマスに煙を置く（煙なら火、火なら爆発）。爆発は4方向のとなりを火にし、壁にダメージを入れ、閉じた扉を吹き飛ばす。火の列は衝撃波が突き抜ける。そのあと、火のとなりの煙はすべて火になる（フラッシュオーバー）。火の中の消防士は倒れて救急車の駐車場へ、火の中の要救助者は失われる。印は3つまで補われる
- 遊び方は2つ
  - **家族向け**：決まった場所の火と印で始め、全員が 4AP の消防士
  - **上級**：はじめの爆発・危険物・ホットスポット、8つの専門職、救急車と消防車（放水）。難しさは 新人・ベテラン・ヒーロー

| 難しさ | はじめの爆発 | 危険物 | 足すホットスポット |
|---|---|---|---|
| 新人 | 3 | 3 | 0 |
| ベテラン | 3 | 4 | 3 |
| ヒーロー | 4 | 5 | 3 |

操作：となりのマスを押すと動く（できることが2つ以上あれば、下にボタンが出る）。自分のマスを押すと、運ぶ・消火・放水などを選べる。ヒント（電球）・待った・CPU に1手任せる、はローカルで遊ぶときだけ出す。

## CPU

`public/js/cpu-player.js`。手番の中で打てる手の並びを、ビーム探索（幅 24）で試し、評価が一番高い並びの先頭を打つ。ヒントも同じ関数（`suggest`）から出す。

- 評価：助け出した人数、運んでいる人と出口の距離、次に向かう印との距離（ほかの隊員のほうが近い印は後回し）、火と煙の数、印や危険物のそばの火、火の中で手番を終える危なさ、壁のダメージ、持ち越す AP
- 手番を終えたあと必ず起きるフラッシュオーバーを当ててから数える（火のとなりの煙で手番を終えない）
- 正体の分からない印の中身はのぞかない。ゲームの乱数は使わない
- 探査隊員は遠くの印を先に調べ、消防車に乗っていて区画に火が多ければ放水する

CPU だけの勝率（`npm run cpu-match -w games/flash-point`。シード 1000 から、40〜80試合）：

| 遊び方 | 2人 | 3人 | 4人 | 6人 |
|---|---|---|---|---|
| 家族向け | 88% | 83% | 64〜68% | 48% |
| 上級・新人 | | | 45% | |
| 上級・ベテラン | | | 20% | |
| 上級・ヒーロー | | | 3% | |

## 決めたこと

原作の決まりで細かいところが分からない点や、遊びやすさのために変えた点。

- 倒れた消防士は、家族向けではいちばん近い救急車の駐車場へ、上級では救急車のいる駐車場へ移る
- 運べるのは1人（か危険物1つ）まで。手当てした要救助者は 1AP で連れて歩ける（運ぶのと同じ枠で1人まで）
- 救急車はどこからでも呼べる（2AP で隣の駐車場へ、向かいは 4AP）。消防車は乗っている隊員が動かし、一緒に動くのは動かした隊員だけ
- 機関員の放水は、外れた目（火も煙もないマス）が出たときだけ自動で1回振り直す（振り直すかを選ぶ手間を省いた）
- 隊長の指揮は、ほかの隊員を1マス動かすだけ（扉の開け閉めなどはさせない）
- 印を補うときに、すでに印のあるマスが出たら振り直す。火か煙のマスなら消してから置く
- ホットスポットに当たったら、もう一度広がる（続けては6回まで）
- 上級の救急車は下、消防車は上の駐車場から始まる
- 待った：同じ手番の自分の手で、印の正体を見ず乱数も使っていない手だけを戻せる（ダイスを振る放水・正体を調べる・手番を終えるは戻せない）

## オンライン対戦

netplay-kit の共通のロビー（部屋はすべて公開。部屋番号の入力はない）。ロビーで遊び方と上級の難しさを選ぶ。足りない席は CPU。対戦中に部屋を出た人の席は CPU が引き継ぐ（保存して読み直しても CPU のまま）。ビューには、シードと、正体の分からない印の中身・残りの印の並びを入れない。オンラインではヒントと待ったを出さない。

接続先は `public/js/online-config.js` の `DEPLOYED_SERVER_URL`（デプロイ前は空。手元では web-games の直下の `npm run dev:online` につなぐ）。

## 開発

```bash
npm test -w games/flash-point                 # ルール・再現・ヒント・CPU・オンライン・PWA
npm run cpu-match -w games/flash-point        # CPU だけの勝率（家族向けと上級の3つの難しさ、4人×40試合）
node games/flash-point/scripts/cpu-match.mjs 80 3 family   # 試合数・人数・遊び方を指定
```

| ファイル | 中身 |
|---|---|
| `public/js/board.js` | 間取り・壁・扉・駐車場・専門職・難しさ |
| `public/js/game.js` | ルールの進行（`applyCommand`・`replay`・延焼） |
| `public/js/game-view.js` | 端末に送るビュー |
| `public/js/cpu-player.js` | CPU とヒント |
| `public/js/game-controller.js` | ローカルで遊ぶときのコントローラー（保存・待った・CPU の番） |
| `public/js/ui.js`・`render.js` | 画面と盤面の SVG |
| `server/src/game-definition.js` | オンライン対戦の定義 |
