# ニムト

全員が同時にカードを出し、牛の頭をできるだけ引き取らないようにするカードゲーム「ニムト（6 nimmt!）」を、ブラウザで CPU と遊べるようにしたもの。2〜10人（あなた＋CPU 1〜9人）。スマホの縦持ち向け。ホーム画面に置くと、オフラインでも遊べる。

絵（カード・牛の頭・アイコン）は、すべて SVG で自作している。

## 遊び方

- カードは1〜104。牛の頭は、ふつう1頭、5の倍数は2頭、10の倍数は3頭、ぞろ目（11・22…）は5頭、55は7頭
- 各自に10枚配り、4枚を4つの列の先頭に置く
- 全員が同時に1枚ずつ出し、そろったら公開して小さい順に列へ置く
  - 末尾がそのカードより小さい列のうち、差がいちばん小さい列の後ろに置く
  - 6枚目になるときは、その列の5枚を引き取り、出したカードが新しい列の先頭になる
  - どの列の末尾よりも小さいときは、好きな列を選んで引き取り、出したカードが新しい列の先頭になる
- 10回出したらラウンドの終わり。引き取った牛の頭の数を失点に足して、配り直す
- だれかの失点が66点以上になったら終わり。失点のいちばん少ない人が勝ち

### ルールブックに書かれていないので決めたこと

- 失点のいちばん少ない人が複数いたら、その全員を勝ちとする
- 引き取った牛の頭の数は、ラウンドの途中でも全員に見せる（実物では伏せて置くが、アプリではよく見せている）

### 画面の操作

- 手札のカードを選んで「出す」（選んだカードをもう一度押しても出せる）
- CPU も出し終えたら、全員のカードを小さい順に並べて公開し、1枚ずつ列へ置いていく
- どの列にも置けないカードを出したときは、光っている列をタップして引き取る
- 途中でホームに戻っても、「続きから」で再開できる

## CPU

自分から見える情報だけ（ほかの人の手札や、公開前に選んだカードは見ない）で打つ。手札の各カードについて、そのカードで列を引き取ってしまう危なさ（列の枚数・末尾との差・列の牛の数）を見積もり、いちばん安全なカードを出す。強すぎないように、見積もりを大ざっぱにし、揺れと、ときどき2番目の手を選ぶ誤りを混ぜている。

CPU 同士の対戦で、勝率と試合の長さを測れる。

```bash
# 試合数・人数・席ごとの強さ（normal は画面の CPU、strong は見えていないカードを数える比較用、random はでたらめに出す比較用）
node scripts/cpu-match.mjs 400 4 normal,normal,normal,strong
```

選ぶ番に操作の欄に出る電球（ヒント）を押すと、いちばん強い CPU が選ぶ手を示す（出すカードを選んでおくか、引き取る列を光らせる）。CPU と同じく、自分のビューだけで決める。

## オンライン対戦

netplay-kit の「サーバーがゲームを進める型」。2〜10人で、足りない席は CPU で埋められる。対戦中に部屋を出た人の席は CPU が引き継ぐ。オンラインではヒントを出さない。

- 手元で遊ぶ：web-games の直下で `npm run dev:online`（全ゲームのテスト用サーバー。ws://localhost:8787）を起動し、`public/` を localhost で開いて「オンラインで遊ぶ」
- 入口とロビーの画面は、netplay-kit の `netplay-lobby.js`（`public/js/netplay/` の写し。ここでは直さない）
- 接続先は `public/js/online-config.js`。`DEPLOYED_SERVER_URL` が空のあいだは、公開したページで「オンラインで遊ぶ」を出さない（web-games のサーバーをデプロイしたら書く）
- サーバーの入口は `server/src/handler.js`（`createHandler(定義, { keyPrefix: 'nimmt' })`。web-games の1つのスタックから `?game=nimmt` で呼ばれる）
- テストは `test/online.test.js`（test-kit の `testOnline` で、部屋の作成・開始・終局まで・再接続・退出を確かめる）

## 開発

素の HTML / CSS / JavaScript（ES Modules）で、ビルドはない。

```bash
# 画面（http://localhost:8000/）
python3 -m http.server 8000 --directory public

# テスト（Vitest）
npm install
npm test
```

| ファイル | 役割 |
|---|---|
| `public/js/game.js` | ルール。操作は `applyCommand` に通して記録し、`Game.replay` で再現できる |
| `public/js/game-view.js` | プレイヤーから見てよい情報だけのビュー |
| `public/js/cpu-player.js` | CPU |
| `public/js/game-controller.js` | ローカル対戦の進行と、途中経過の保存 |
| `public/js/ui.js` | 画面。全員が出したあとの流れは、届いたイベントを順に再生して見せる |
| `public/js/art.js`・`animator.js` | 絵と動き |
| `server/src/game-definition.js` | オンライン対戦（netplay-kit）用のゲームの定義 |
| `server/src/handler.js`・`public/js/online-config.js`・`public/js/netplay/` | オンライン対戦のサーバーの入口・接続先・netplay-kit の写し |
