# ブラス：バーミンガム

産業革命期のバーミンガムで、工場を建て、運河と鉄道でつなぎ、品物を売って得点を競うボードゲーム「ブラス：バーミンガム（Brass: Birmingham）」を、ブラウザで CPU と遊べるようにしたもの。2〜4人（あなた＋CPU 1〜3人）。スマホの縦持ち向け（PC では地図を左、パネルを右に置く）。ホーム画面に置くと、オフラインでも遊べる。

地図・タイル・アイコンは、すべて SVG で自作している。地名はカナ。

## 遊び方

- 運河の時代と鉄道の時代の2つ。山札と全員の手札がなくなると時代が終わる（2人は10ラウンド、3人は9、4人は8）
- 手番では、手札を1枚捨てるごとにアクションを1つ。1回の手番で2つ（運河の時代の最初のラウンドだけ1つ）。手番のあと8枚まで補う
- 次のラウンドの順は、使ったお金が少ない順。ラウンドの終わりに収入をもらう（マイナスなら払う）
- アクション：建てる・ネットワーク・開発・売る・借りる・偵察・パス
- 産業は6種（綿工場・製造所・陶器・炭鉱・製鉄所・醸造所）。ボードのいちばん低いレベルから建てる
- 石炭はつながった一番近い炭鉱から（なければ、商人につながっていれば市場から）。鉄はどこの製鉄所からでも（なければ市場から）。ビールは自分の醸造所（どこでも）か、つながったほかの人の醸造所、売るときは売り先の商人のビール
- 時代の終わりに、自分のリンクごとに両端の町の「裏返ったタイルのリンクの点」（商人の町は2点）と、裏返った自分のタイルの得点を数える
- 運河の時代のあとは、運河とレベル1のタイルを外し、商人のビールを戻し、山札を作り直す
- 得点がいちばん多い人の勝ち。同点なら収入、お金の順

### 画面

- 地図は2本指・ホイール・＋−のボタンで拡大、ドラッグで移動。選べる場所・リンク・タイルは黄色く光る
- アクションは「アクションを選ぶ → 地図か一覧で対象を選ぶ → 捨てるカードを確かめて決める」の順。捨てるカードは、使い道が少ないものを初めから選んでおく（手札で選び直せる）
- 決める前に、払うお金・増える得点・収入を出す
- 手番の欄を押すと、そのプレイヤーのボード（次に建てるタイルと残りの枚数）を見られる
- 途中でホームに戻っても、「続きから」で再開できる

### 本家と違う点・解釈した点

- **資源の取り先は自動で選ぶ。** 石炭は一番近い炭鉱（同じ近さなら自分のもの）、鉄は自分の製鉄所を先に、ビールは「売り先の商人 → 自分の醸造所 → つながったほかの人の醸造所」の順。本家では同じ近さの中や、鉄・ビールの取り先は選べる
- グロスターのおまけの開発は、外せるうちで得点が一番低いタイルを自動で外す
- 収入が払えないときは、自分のタイルを自動で選んで半額で手放す（裏返っていないもの、安いものから）。それでも足りなければ1ポンドにつき1点失う
- 地図のつながり（運河だけ・鉄道だけのところを含む）と、各町の建てる場所の産業は、本家の地図を元に作ったが、細部が本家と違うことがある
- 商人タイルの内訳（人数ごとに、綿・製造所・陶器・全部・なし）は、枚数（5・7・9枚）だけ本家に合わせ、中身は決めた
- 鉄道の時代に建てられないのは、すべてのレベル1。運河の時代に建てられないのは陶器のレベル5
- リンクの点は、裏返ったタイルの分だけを数える
- 使わない人数の町（2人のストークなど）には、建てることもリンクを引くこともできない
- 運河の時代の最後のラウンドのあとも収入をもらう。鉄道の時代の最後のあとはもらわない

## CPU

自分から見える情報だけ（ほかの人の手札と山札の並びは見ない）で選ぶ。候補の手をルールの関数で試し、試したあとの盤面の良さ（得点・今の時代の終わりの得点・裏返りそうなタイルの見込み・収入・お金）が一番高い手を選ぶ。ゲームの乱数は使わない。

| 強さ | 中身 |
|---|---|
| ふつう | 相手の得を気にしない。評価に揺れを混ぜる。鉄道は1本ずつ |
| つよい | 相手の得を少し引き、鉄道の2本引きも考える。値は対戦させて決めた |

`npm run cpu-match -- 30 3 strong,normal,normal` で、CPU 同士の勝率と得点を数えられる。

## ファイル

- `public/js/data.js`：産業タイルの表・町・つながり・商人・カード
- `public/js/rules.js`：ルール（状態を受け取る関数。画面と CPU も、手の可否をこれで確かめる）
- `public/js/game.js`：操作の入口（`applyCommand`）と記録・再現
- `public/js/game-view.js`：プレイヤーごとのビュー
- `public/js/cpu-player.js`：CPU
- `public/js/map-view.js`：地図の描画と拡大・移動
- `public/js/ui.js`・`main.js`・`art.js`：画面
- `server/src/game-definition.js`：オンライン対戦用のゲームの定義（netplay-kit の形。まだつないでいない）
