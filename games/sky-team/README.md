# スカイチーム

機長と副操縦士の2人で、飛行機を空港に着陸させる協力ダイスゲーム（原作：Sky Team）。ブラウザで、CPU の相棒と2人で遊ぶ。オンライン対戦では、2人の人で遊べる（抜けた席は CPU が引き継ぐ）。スマホの縦画面と PC に対応し、ホーム画面に追加するとオフラインでも遊べる（PWA）。

絵とアイコンは自作。

## 遊び方

- 7回（高度 6000 フィートから 1000 ずつ降りる）で着陸する。各回、2人とも4個のダイスを振り、交互に1個ずつ操縦席に置く（奇数の回は機長、偶数の回は副操縦士から）
- 相手のダイスの目は、置かれるまで見えない（画面でも、自分のダイスだけを見せ、相手は残りの数だけ）
- 軸とエンジンには、毎回2人とも1個ずつ必ず置く
  - 軸：2人の目の差だけ傾く。傾きが3に届くと墜落
  - エンジン：2人の目の合計が速度。青の値以下なら進まず、橙の値以下なら1マス、それより上なら2マス進む
- 無線（機長1・副操縦士2）：目の数だけ先のマスの飛行機を1機消す
- 着陸装置（機長、1-2・3-4・5-6）：青が1上がる。フラップ（副操縦士、上から順に 1-2・2-3・4-5・5-6）：橙が1上がる。ブレーキ（機長、2・4・6 の順）：ブレーキの値になる
- コーヒー（どちらも、3杯まで）：置くときに1杯につき目を1変えられる
- 振り直しのトークン：自分のまだ置いていないダイスを振り直す
- 負け：飛行機のいるマスから進む・空港を通り過ぎる・傾きが3に届く
- 7回目はエンジンで進まず、終わりに「空港にいる・飛行機が残っていない・着陸装置3つとフラップ4つ・水平・速度がブレーキより小さい」をすべて満たせば勝ち
- 空港：モントリオール（入門）・羽田（中級）・クアラルンプール（上級）

### 原作との違い

- 空港の進入路の長さ・飛行機の数・振り直しをもらう回は、原作を参考にした近似（CPU どうしの勝率を測って、入門・中級・上級の差が出るように決めた）
- 原作の追加のモジュール（強風・凍結・ターボなど）は入れていない
- ダイスを置けないときは「外す」で捨てる（原作では、置ける場所がない状況はほぼ起きない）

### 操作

- 自分のダイスを押すと、置ける場所が光る。光った場所を押して置く
- コーヒーがあれば、ダイスを選んだあと −・＋ で目を変える
- ヒント（電球）はおすすめの置き方に印を付ける。待ったは、同じ回の中で自分の最後の手まで戻す
- 途中で閉じても、タイトルの「続きから」で再開できる（操作の記録を保存して再現する）

## CPU

自分のビュー（自分のダイスと盤）だけで判断し、相手のまだ置いていないダイスの目は見ない。相手のダイスを何通りか仮に振り、仮の目ごとに、この回の2人のダイスの割り当てで最もよいもの（軸・エンジンの組み合わせは全部、残りは貪欲に）を探して、回の終わりの盤を評価する。候補の手を、仮の目すべての平均で比べる。

- やさしい（仮の目 2 通り）・ふつう（10 通り）・つよい（24 通り）
- 強さの測定：`npm run cpu-match -- [試合数] [強さ] [空港]`（2人とも同じ強さの CPU で、着陸できた割合を出す。どの試合も最後まで進むことも確かめる）
- モントリオールでの勝率の目安：やさしい 33%・ふつう 65%・つよい 74%

## 開発

ビルドは要らない。`public/` を HTTP サーバーで開く。

```bash
npm test -w games/sky-team          # ルール・記録の再現・ヒント・オンライン対戦・PWA のテスト
npm run cpu-match -w games/sky-team # CPU どうしの対戦
```

| ファイル | 内容 |
|---|---|
| `public/js/rules.js` | 盤のルール（純粋な関数）：空港、置き場、置いたときの効果、着陸の判定 |
| `public/js/game.js` | ゲーム本体。シード付きの乱数でダイスを振る。`applyCommand` と `Game.replay` |
| `public/js/game-view.js` | ビュー（自分のダイスだけ。相手は残りの数） |
| `public/js/cpu-player.js` | CPU とヒント（`suggest`） |
| `public/js/game-controller.js` | ローカル対戦のコントローラー（`getView()` / `send()`、待った） |
| `public/js/main.js` | 画面の進行 |
| `server/src/game-definition.js` | オンライン対戦用のゲームの定義（netplay-kit の形） |

## オンライン対戦

web-games の共通のサーバーとロビーを使う（接続の `?game=sky-team`）。席0が機長、席1が副操縦士。相手のまだ置いていないダイスの目と、乱数のシードはビューに入れない。対戦中に部屋を出た人の席は CPU が引き継ぐ。`public/js/online-config.js` の `DEPLOYED_SERVER_URL` は、サーバーをデプロイしたら書く（空のあいだは、公開したページで「オンラインで遊ぶ」を出さない）。
